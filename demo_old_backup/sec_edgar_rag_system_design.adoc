== Executive Summary

This document presents a comprehensive design for a Retrieval-Augmented Generation (RAG) system that ingests SEC Edgar filings (10-K, 10-Q, 8-K) for public companies like Apple Inc. (AAPL), processes them using ProximaDB's advanced chunking capabilities, stores them in optimized vector collections, and enables intelligent querying through integration with Ollama LLM models.

=== Key Capabilities
* **Automated SEC Filing Ingestion**: Real-time monitoring and download of new filings
* **Intelligent Document Chunking**: Context-aware chunking optimized for financial documents
* **Multi-Collection Architecture**: Separate collections for different filing types and sections
* **Rich Metadata Preservation**: Complete filing metadata for advanced filtering
* **LLM-Powered Analysis**: Natural language queries with Ollama integration
* **Performance Optimization**: Leveraging ProximaDB's compression and hardware acceleration

== Chunking Strategy

=== Document-Aware Chunking Configuration

[source,python]
----
from proximadb import ChunkingConfig, ChunkingStrategy

# Different chunking strategies for different sections
CHUNKING_STRATEGIES = {
    "risk_factors": ChunkingConfig(
        strategy=ChunkingStrategy.SEMANTIC,
        chunk_size=512,        # Smaller chunks for risk factors
        chunk_overlap=50,
        preserve_sentences=True,
        metadata_extractor="risk_factor_extractor"
    ),
    
    "mda": ChunkingConfig(
        strategy=ChunkingStrategy.PARAGRAPH,
        chunk_size=1024,       # Larger chunks for MD&A narrative
        chunk_overlap=100,
        preserve_paragraphs=True,
        include_headers=True
    ),
    
    "financial_statements": ChunkingConfig(
        strategy=ChunkingStrategy.FIXED_SIZE,
        chunk_size=2048,       # Large chunks for tables
        chunk_overlap=0,       # No overlap for structured data
        preserve_tables=True,
        table_format="markdown"
    ),
    
    "business_overview": ChunkingConfig(
        strategy=ChunkingStrategy.RECURSIVE,
        chunk_size=768,
        chunk_overlap=75,
        split_on=["\n\n", "\n", ". ", ", "],
        min_chunk_size=256
    ),
    
    "legal_proceedings": ChunkingConfig(
        strategy=ChunkingStrategy.SENTENCE,
        sentences_per_chunk=5,
        overlap_sentences=1,
        preserve_legal_citations=True
    )
}

from proximadb import CollectionConfig, StorageEngine, DistanceMetric
from proximadb import QuantizationType, CompressionType

# 1. Annual Reports (10-K) Collection
collection_10k = CollectionConfig(
    name="sec_10k_filings",
    dimension=1536,  # OpenAI text-embedding-3-small
    distance_metric=DistanceMetric.COSINE,
    storage_engine=StorageEngine.VIPER,  # Columnar for analytics
    
    # Compression for large documents
    compression=CompressionType.ZSTD,
    compression_level=3,
    
    # Quantization for storage efficiency
    quantization=QuantizationConfig(
        type=QuantizationType.INT8,
        enable_two_stage_search=True,
        rerank_top_k=100
    ),
    
    # Filterable columns for metadata queries
    filterable_columns=[
        FilterableColumn("company_ticker", FilterableDataType.STRING),
        FilterableColumn("fiscal_year", FilterableDataType.INTEGER),
        FilterableColumn("section_name", FilterableDataType.STRING),
        FilterableColumn("filing_date", FilterableDataType.TIMESTAMP),
        FilterableColumn("importance_score", FilterableDataType.FLOAT)
    ],
    
    # Index configuration
    index_config=IndexConfiguration(
        type=IndexingAlgorithm.HNSW,
        m=16,
        ef_construction=200,
        ef_search=100
    )
)

# 2. Quarterly Reports (10-Q) Collection
collection_10q = CollectionConfig(
    name="sec_10q_filings",

=== Advanced RAG Features

==== 1. Multi-Step Reasoning
[source,python]
----
async def multi_step_analysis(question: str, company: str):
    # Step 1: Decompose question
    sub_questions = await decompose_question(question)
    
    # Step 2: Gather evidence for each sub-question
    evidence = {}
    for sub_q in sub_questions:
        results = await search_filings(sub_q, company)
        evidence[sub_q] = results
    
    # Step 3: Synthesize answer
    final_answer = await ollama_synthesize(
        question=question,
        evidence=evidence,
        model="llama3:70b"
    )
    
    return final_answer
----

==== 2. Fact Verification
[source,python]
----
async def verify_facts(statement: str, company: str):
    # Extract claims from statement
    claims = extract_claims(statement)
    
    # Search for supporting/contradicting evidence
    verification_results = []
    for claim in claims:
        evidence = await search_filings(claim, company)
        verification = await ollama_verify(
            claim=claim,
            evidence=evidence,
            model="mistral:7b"
        )
        verification_results.append(verification)
    
    return verification_results
----
