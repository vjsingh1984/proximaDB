CRITICAL: Quantization-Aware Compaction
========================================
When quantization is enabled, compaction CANNOT use row-group merging!
Must load ALL vectors and recalculate quantization:
- INT8: Requires full scan for new min/max
- PQ: Requires retraining codebooks on merged data
- Impact: Compaction becomes O(n*d) memory and O(n*k*iter) compute

Key Insight for Vector Storage
==============================
Unlike BI/analytics use cases, vector storage queries typically:
1. Need few columns (ID, vector, select metadata) - ✅ Column projection helps
2. Search specific vectors by ID - ❌ Bloom filters critical but not used
3. Filter by metadata before similarity - ⚠️ Row group pruning exists but not integrated
4. Benefit from approximate filtering - ❌ Quantized vectors not utilized

The infrastructure is mostly built but not connected to the main search path!
