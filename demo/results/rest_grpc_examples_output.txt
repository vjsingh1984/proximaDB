📋 Summary and Best Practices
============================================================

✅ **Working Features:**
- Basic equality filters (field = value)
- Single field filtering
- Multi-vector storage for documents

⚠️  **Current Limitations:**
- Complex AND/OR operators may not work as expected
- Comparison operators (>, <, >=, <=) limited support
- IN operator syntax varies

💡 **Multi-Vector Text Search Strategy:**
1. Split large text into chunks (sentences, paragraphs, or fixed size)
2. Create embeddings for each chunk
3. Store with doc_id metadata to group chunks
4. Search and aggregate results by document
5. Use chunk_idx to maintain order

🔧 **Implementation Tips:**
- Use real embedding models (sentence-transformers, OpenAI, etc.)
- Overlap chunks for better context (e.g., 10-20% overlap)
- Store chunk metadata for result presentation
- Consider hybrid retrieval: initial vector search + reranking
