== 🚀 30-Second Start

[source,bash]
----
cd demo
docker-compose up --build    # Complete environment
# Wait 2-3 minutes, view logs: docker-compose logs -f demo
----

== 📋 Common Commands

[cols="2,3"]
|===
|**Task** |**Command**

|**Start Demo Environment**
|`docker-compose up --build`

|**View Demo Logs**  
|`docker-compose logs -f demo`

|**Health Check**
|`curl http://localhost:5678/health`

|**Run Basic Demo**
|`python working_demo.py`

|**Performance Benchmark**
|`python storage_engines_demo.py`

|**Clean Shutdown**
|`docker-compose down -v`

== 🔧 Troubleshooting

[cols="2,3"]
|===
|**Issue** |**Solution**

|Connection refused
|Check: `curl http://localhost:5678/health`

|Module not found
|`cd ../clients/python && pip install -e .`

|Docker build fails
|`docker system prune -a && docker-compose build --no-cache`

|Slow performance
|`export DEMO_NUM_VECTORS=100`
|===
