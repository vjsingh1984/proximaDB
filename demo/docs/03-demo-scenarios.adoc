=== Feature Demonstrations

==== 1. Vector Operations
- **Batch Upsert**: Efficiently insert large numbers of vectors
- **Similarity Search**: Find nearest neighbors using various distance metrics  
- **Vector Management**: Add, update, and delete vectors with ACID properties

==== 2. Advanced Indexing
- **HNSW Integration**: Hierarchical Navigable Small World indexing
- **AXIS Support**: Adaptive eXtensible Indexing System
- **Partitioned Indices**: Automatic partitioning for scalability

==== 3. Metadata Filtering  
- **Logical Operators**: AND, OR, NOT queries
- **Comparison Operators**: =, !=, <, >, <=, >=
- **Complex Queries**: Nested logical expressions

==== 4. Text Processing (RAG Applications)
- **6 Chunking Strategies**: Sentence, paragraph, sliding window, semantic, fixed-size, recursive
- **BERT Integration**: 384, 768, 1024-dimensional embeddings
- **Preprocessing Pipelines**: Text normalization and optimization

==== 5. Vector Quantization
- **Product Quantization**: Compressed vector representations
- **Configurable Compression**: Adjustable compression ratios (4x-32x)
- **Performance Optimization**: Memory usage vs. accuracy trade-offs

==== 6. Storage Engine Comparison
- **LSM Engine**: Optimized for frequent updates and mixed workloads
- **VIPER Engine**: Optimized for analytics and compression (4x storage reduction)
- **Performance Benchmarking**: Real server execution with tangible datasets
