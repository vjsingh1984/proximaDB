== 📊 Demo Execution Commands

=== Quick Reference

[source,bash]
----
# Docker Compose (Recommended)
docker-compose up --build              # Start complete environment
docker-compose logs -f demo            # View demo execution logs
docker-compose down -v                 # Clean shutdown

# Direct Script Execution
python working_demo.py                 # Basic vector operations
python chunking_demo.py                # Text processing strategies
python storage_engines_demo.py         # Performance comparison
python financial_analysis_demo.py      # Real-world application
python full_demo.py                    # Complete feature showcase

# Monitoring and Health Checks
curl http://localhost:5678/health       # Server health check
curl http://localhost:9091              # Prometheus metrics
curl http://localhost:5678/admin/stats  # Collection statistics
----

=== Environment Variables Quick Reference

[source,bash]
----
# Core Configuration
export PROXIMADB_SERVER_URL="http://localhost:5678"
export DEMO_NUM_VECTORS=1000
export DEMO_VECTOR_DIMENSION=768

# Performance Tuning
export RUST_LOG=info                    # Logging level
export DEMO_BATCH_SIZE=100              # Insert batch size
export PROXIMADB_WAL_STRATEGY="avro"    # Serialization strategy

# Feature Flags
export DEMO_ENABLE_QUANTIZATION=true    # Vector compression
export DEMO_ENABLE_HNSW=true           # Advanced indexing
export DEMO_ENABLE_MONITORING=true     # Prometheus metrics
----

== 🎯 What You'll Learn

After completing the demonstrations, you'll understand:

=== Core Capabilities
- ✅ **Vector Operations**: CRUD operations with metadata filtering
- ✅ **Similarity Search**: Multiple distance metrics and optimization
- ✅ **Storage Engines**: LSM vs VIPER performance characteristics
- ✅ **Text Processing**: 6 chunking strategies for RAG applications

=== Advanced Features  
- ✅ **Vector Quantization**: Memory optimization with minimal accuracy loss
- ✅ **AXIS Indexing**: Adaptive indexing for different workloads
- ✅ **Serialization**: Avro vs Bincode performance comparison
- ✅ **Real-world Applications**: Financial document intelligence

=== Production Readiness
- ✅ **Performance Benchmarking**: Latency, throughput, and scalability
- ✅ **Monitoring**: Prometheus integration and health checks
- ✅ **Troubleshooting**: Common issues and resolution strategies
