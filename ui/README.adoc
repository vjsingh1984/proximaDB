= ProximaDB Web Operator Console (`ui/`)
:toc: left
:toclevels: 2

A React (TypeScript) single-page operator console for ProximaDB — a multi-tab
admin/monitoring surface (System Overview, Collections, Metrics, Performance,
Diagnostics, Alerts, Security, Cache, SQL Query, Graph Visualization). It talks to
a running server over the REST API (proxied to `http://localhost:5678`).

[IMPORTANT]
====
*Status: standalone dev app, not part of the build/CI.* This app is **not** compiled
by CI, **not** bundled into the `proximadb-server` binary, and **not** consumed by
downstream services (e.g. `anvaiops`, which integrates via the SDK/REST API only). It
is the heavier *full operator console* counterpart to the lightweight, read-only
dashboard the server now serves at `GET /admin` (see
`docs/04-operations/admin-dashboard.adoc` / `crates/platform/proximadb-admin-ui`).

*Known gap:* `public/index.html` (and `public/manifest.json`) are absent, so a
`react-scripts build` will fail until they are restored. Treat this as a work-in-progress
operator UI, not a shipping artifact.
====

== Stack

* React 17 + TypeScript, Create-React-App (`react-scripts`) toolchain.
* Material-UI v4, Recharts (charts), Cytoscape (graph viz), Monaco (SQL editor), axios.

== Develop

[source,console]
----
$ cd ui
$ npm install
$ npm start      # dev server on :3000, proxies API calls to :5678
$ npm run build  # production bundle (requires public/index.html — see Status note)
----

== Layout

* `src/components/*Tab.tsx` — the operator tabs.
* `src/api/proximaDbApi.ts`, `src/types/api.ts` — the typed REST client + shapes.
* `src/contexts/ThemeContext.tsx`, `src/components/ThemeToggle.tsx` — theming.

The version field in `package.json` is kept in sync with the workspace by
`scripts/version-sync.sh`.
