== Current Security Features

=== Authentication
* **API Keys**: Simple API key authentication
* **JWT Tokens**: JSON Web Token authentication
* **Basic Auth**: HTTP Basic Authentication
* **Custom Auth**: Custom authentication plugins

=== Authorization
* **Role-Based Access Control (RBAC)**: User roles and permissions
* **Resource-Level Permissions**: Fine-grained access control
* **Tenant Isolation**: Multi-tenant security
* **API Rate Limiting**: Request rate limiting

=== Encryption
* **TLS 1.3**: Transport layer security
* **AES-256**: Data encryption at rest
* **Key Management**: Secure key storage and rotation
* **Certificate Management**: SSL/TLS certificate handling

== Security Configuration

=== Basic Security Setup

==== Enable TLS
[source,toml]
----
[network]
tls_enabled = true
tls_cert_file = "/path/to/cert.pem"
tls_key_file = "/path/to/key.pem"
tls_ca_file = "/path/to/ca.pem"
----

==== Configure Authentication
[source,toml]
----
[security]
auth_enabled = true
auth_method = "jwt"  # or "api_key", "basic"
jwt_secret = "your-secret-key"
jwt_expiry = "24h"
----

==== Set Up Authorization
[source,toml]
----
[security]
rbac_enabled = true
default_role = "readonly"
admin_role = "admin"
----

=== Advanced Security Configuration

==== API Rate Limiting
[source,toml]
----
[security]
rate_limiting_enabled = true
rate_limit_requests = 1000
rate_limit_window = "1m"
rate_limit_burst = 100
----

==== Audit Logging
[source,toml]
----
[security]
audit_logging_enabled = true
audit_log_file = "/var/log/proximadb/audit.log"
audit_log_level = "info"
----

== Authentication Methods

=== API Key Authentication

==== Generate API Key
[source,bash]
----
proximadb-cli auth generate-key --user admin --role admin
----

==== Use API Key
[source,bash]
----
curl -H "Authorization: Bearer your-api-key" \
     http://localhost:8080/v1/collections
----
