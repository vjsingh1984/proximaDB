== ProximaDB - Enterprise Vector Database

**Production-Ready**: 520+ tests passing, zero critical issues, gcc-14 optimized builds

ProximaDB is a **DirectVectorService-powered vector database** engineered for AI-first applications with breakthrough performance:

* **40-60% Insert Latency Reduction**: DirectVectorService eliminates registry overhead
* **Optimized Search Performance**: Storage-aware polymorphic search with automatic engine selection
* **85% Code Reduction**: Handler consolidation through proto-first architecture
* **Zero Double Serialization**: Direct Protocol Buffers throughout the entire pipeline

== Building Documentation

=== Prerequisites

.Required Tools
* **AsciiDoctor**: For converting AsciiDoc to HTML/PDF with inline Mermaid support
* **AsciiDoctor-Diagram**: For rendering Mermaid diagrams inline

.Installation Commands
[source,bash]
----
# Ubuntu/Debian
gem install asciidoctor asciidoctor-pdf asciidoctor-diagram

# macOS
gem install asciidoctor asciidoctor-pdf asciidoctor-diagram
----

=== Generating Diagrams

Use the provided script to generate all diagrams:

[source,bash]
----
cd docs
./generate_diagrams.sh
----

See link:DIAGRAMS_README.md[Diagram Generation Guide] for:
- Manual generation commands
- Troubleshooting tips

- Adding new diagrams

== Writing Guidelines

=== AsciiDoc Best Practices

. Use semantic headers (=, ==, ===)
. Include table of contents with `:toc:`
. Use source code blocks with syntax highlighting
. Reference images with proper paths
. Use tables for structured data
. Include cross-references for navigation

=== Diagram Guidelines

. Keep diagrams focused on one concept
. Use consistent color schemes
. Include labels and annotations
. Maintain reasonable size (max 1200px width)
. Use Material theme for PlantUML
. Export as PNG for compatibility

== Contributing

When adding new documentation:

. Write content in AsciiDoc format
. Create diagrams in `diagrams/plantuml/` or `diagrams/`
. Run `./generate_diagrams.sh` to update images
. Test HTML generation with `asciidoctor`
. Submit PR with both source and generated files
