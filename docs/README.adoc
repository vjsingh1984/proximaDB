== 📝 Content Guidelines

=== Accuracy First
* All content reflects actual codebase implementation
* Performance numbers are measured, not estimated
* Features described are implemented and tested

=== Audience Appropriate
* **Technical depth** varies by audience
* **Language level** matches user expertise  
* **Content focus** aligns with user goals

=== Visual Enhancement
* Use Mermaid diagrams to explain concepts
* Include performance charts and comparisons
* Provide architectural visualizations
