== 🚀 QuickStart (60 seconds)

=== Docker Setup
[source,bash]
----
# Start ProximaDB server
docker run -d \
  -p 5678:5678 \
  -p 5679:5679 \
  -v proximadb_data:/data \
  proximadb/proximadb:latest

# Verify it's running
curl http://localhost:5678/health
----

=== Python Client
[source,python]
----
from proximadb import ProximaDBClient

# Connect and create collection
client = ProximaDBClient("http://localhost:5678")
client.create_collection("vectors", dimension=384)

# Insert and search
client.insert_vectors("vectors", data)
results = client.search("vectors", query_vector, top_k=10)
----

== 🌟 Key Features Highlight

=== Core Capabilities
* **6 Index Types**: HNSW, IVF, PQ, FLAT, ANNOY, LSH
* **13 Distance Metrics**: Cosine, Euclidean, Dot Product, Manhattan, Hamming, Jaccard, and more
* **14 Compression Algorithms**: ZSTD, LZ4, Snappy, Gzip, Brotli, and intelligent "Mixed" strategy
* **Multiple Query Interfaces**: SQL, REST API, gRPC, Python SDK
* **Cloud Storage Support**: S3, Azure Blob, Google Cloud Storage, MinIO

=== Advanced Features
* **Zero-Copy Operations**: Proto-first architecture eliminates serialization overhead
* **Hardware Acceleration**: Automatic SIMD/GPU detection (AVX-512, AVX2, CUDA, ROCm)
* **Progressive Search**: 7-phase optimization (Bloom → Binary → INT8 → PQ → Hybrid → Full → Cache)
* **Unified Quantization**: Smart defaults with hardware-aware optimization
