== Key Technical Concepts

=== Storage Engines
[cols="1,2,1,1", width="100%"]
|===
|Engine |Use Case |Compression |Speed

|SST |High writes |4-8x |Fast
|VIPER |Analytics |16-32x |Medium
|NOVA |Mixed |8-16x |Balanced
|SWIFT |Low latency |2-4x |Fastest
|RAPTOR |Adaptive |4-16x |Dynamic
|PRISM |Memory-limited |8-12x |Efficient
|HELIX |Time-series |6-10x |Optimized
|===

=== Performance Characteristics
* **Throughput**: 332.3K vectors/sec @ 1536D
* **Latency**: < 10ms @ 99th percentile
* **Compression**: 4-32x with adaptive quantization
* **Memory**: 0.5-3KB per vector

=== API Endpoints
* **REST API**: Port 5678
* **gRPC API**: Port 5679
* **Metrics**: Port 9090 (Prometheus)

== Common Tasks

=== Running Benchmarks
[source,bash]
----
# All benchmarks
cargo bench

# Specific benchmark suite
cargo bench --bench bench_04_storage_comparison

# With custom parameters
cargo bench -- --warm-up-time 1 --measurement-time 5
----
