== How to Contribute to Docs

- Keep pages concise and task-oriented; avoid marketing claims without measured data.
- Cross-link files using relative paths; update section indexes (`README.adoc`) when adding new pages.
- Reflect real code behavior; include file paths or commands where helpful.
