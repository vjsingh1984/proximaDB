== Documentation Structure

[NOTE]
====
**Streamlined Two-Tier Documentation**:

* **Top-Level (`docs/`)**: High-level overviews, guides, and cross-cutting concerns
* **Module-Level (`src/*/README.adoc`)**: Detailed implementation docs within code modules

This eliminates duplication - top-level docs **reference** module docs for implementation details.
====

=== Top-Level Documentation

----
docs/
├── quickstart/           # Getting started guides
├── architecture/         # System architecture overviews
├── storage/              # Storage engine selection guides → references src/storage/
├── automl/               # AutoML user guide → references src/automl/
├── technical/            # Technical overviews → references src/ modules
├── operations/           # Production operations
├── enterprise/           # Enterprise features
├── performance/          # Performance benchmarks and tuning
├── benchmarks/           # Benchmark suite documentation
├── development/          # Contributing and development setup
├── guides/               # How-to guides
├── reference/            # API reference
├── security/             # Security overview → references src/security/
├── business/             # Business documentation
└── 09-roadmap/           # Development roadmap
----

=== Module-Level Documentation

Implementation details are documented in `README.adoc` files within source modules:

----
src/
├── storage/
│   ├── engines/
│   │   ├── impls/
│   │   │   ├── sst/README.adoc        # SST engine implementation details
│   │   │   ├── viper/README.adoc      # VIPER engine implementation
│   │   │   ├── nova/README.adoc       # NOVA engine implementation
│   │   │   └── ...
│   │   └── core/
│   │       └── ops/
│   │           └── proximacodec/README.adoc  # ProximaCodec internals
├── index/
│   └── axis/
│       └── eventlog/README.adoc       # AXIS EventLog coordination
├── services/
│   └── events/README.adoc             # Event services architecture
├── compute/
│   └── quantization/README.adoc       # Quantization implementation
└── ...
----

**Navigation Pattern**:

1. Start with `docs/` for **what** and **why**
2. Follow references to `src/*/README.adoc` for **how** (implementation details)
3. Use module docs to understand code structure before modifying
