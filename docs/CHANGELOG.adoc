== Version 0.1.1 (2025-08-11)

=== Performance & Architecture Improvements

==== Unified Cache Architecture
* Consolidated duplicate caching across storage engines.

==== I/O Optimization
* Implemented Zero Filesystem Queries and Smart Bloom Filters.

==== Clean Architecture Enhancements
* Introduced stateless storage engines and explicit error handling.

=== Performance Impact
* Significant improvements in search latency, memory efficiency, and throughput.

== Version 1.0.0 (2025-08-04)

=== Major Features

==== Core Architecture
* Introduced DirectVectorService, Dual Storage Engines, AXIS Indexing, SQL Query Engine, Centralized MVCC, and Multi-Tier Deduplication.

==== Performance Optimizations
* Implemented Zero-Copy Serialization, ZSTD Compression, Index-Based Filtering, and Hardware Acceleration.

==== Enterprise Features
* Added MVCC Support, Multi-Cloud Storage, Prometheus Metrics, and Hot Configuration Reload.

=== Performance Benchmarks
* Achieved high insert rates, low search latency, and high memory efficiency.

=== API Improvements
* Unified REST/gRPC, Python SDK, SQL Interface, and Batch Operations.
