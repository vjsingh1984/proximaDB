== Technical Implementation

=== SIMD Optimization Strategy

[source,rust]
----
// Hardware detection at startup
detect_hardware() → cache in OnceLock
    ↓
// Runtime dispatch (zero overhead)
get_cached_preferred_backend()
    ↓
// Compute with optimal SIMD
dispatch to AVX2/SSE/NEON implementation
----

=== Distance Metric Normalization

All metrics normalized so **lower values = more similar**:

* **Cosine**: `1 - similarity` (range: [0, 2])
* **DotProduct**: `-dot_product` (inverted for consistency)
* **Euclidean**: L2 distance (natural)
* **Manhattan**: L1 distance (natural)

This ensures consistent behavior across all storage engines without special casing.
