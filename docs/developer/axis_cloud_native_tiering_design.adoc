= AXIS Cloud-Native Tiering Design for Ephemeral Infrastructure
:toc: left
:toclevels: 3
:imagesdir: ../diagrams/images

== Executive Summary

This document redesigns AXIS tiering for cloud-native environments where instances and local storage are ephemeral (spot instances, auto-scaling groups, Kubernetes pods). The design prioritizes persistent cloud storage over local disk.

== Cloud Architecture Constraints

=== Ephemeral Infrastructure Reality

[WARNING]
====
**Cloud-Native Constraints:**
- **Spot Instances**: Can be terminated with 2-minute warning
- **Instance Store**: Lost on stop/terminate (not just restart)
- **Auto-scaling**: Nodes added/removed dynamically
- **Kubernetes**: Pods can be rescheduled anytime
- **Container Restarts**: Local state lost
====

=== Storage Hierarchy for Cloud

```
┌─────────────┐     Evict       ┌─────────────┐     Archive    ┌─────────────┐
│   MEMORY    │ ───────────────► │  S3 EXPRESS │ ───────────────► │ S3 STANDARD │
│  (Volatile) │ ◄─────────────── │  (Primary)  │ ◄─────────────── │   (Cold)    │
└─────────────┘     Restore      └─────────────┘     Retrieve    └─────────────┘
   Ephemeral                        Persistent                      Long-term
   <1ms                            5-20ms                          50-200ms
   
   ┌─────────────┐ Optional
   │ Local Cache │ ←── Used only as read-through cache
   │   (NVMe)    │     Never as authoritative storage
   └─────────────┘
```

pub struct CloudNativeTierManager {
    /// S3 client for persistent storage
    s3_client: Arc<S3Client>,
    
    /// Redis/ElastiCache for index metadata
    metadata_store: Arc<RedisClient>,
    
    /// Local cache (optional, best-effort)
    local_cache: Option<Arc<LocalDiskCache>>,
    
    /// Instance lifecycle manager
    lifecycle: Arc<InstanceLifecycle>,
    
    /// Distributed lock manager (DynamoDB/etcd)
    lock_manager: Arc<DistributedLockManager>,
}

impl CloudNativeTierManager {
    /// Save index to S3 Express immediately after any change
    pub async fn persist_to_s3_express(
        &self,
        collection_id: &str,
        index: &dyn AxisVectorIndex,
        generation: u64,
    ) -> Result<S3Location> {
        let key = format!("indexes/{}/v{}/index.dat", collection_id, generation);
        
        // Serialize index
        let serialized = self.serialize_index(index).await?;
        
        // Upload to S3 Express with immediate durability
        let put_result = self.s3_client
            .put_object()
            .bucket(&self.config.s3_express_bucket)
            .key(&key)
            .body(ByteStream::from(serialized))
            .storage_class(StorageClass::ExpressOnezone)
            .metadata("generation", generation.to_string())
            .metadata("instance_id", self.lifecycle.instance_id())
            .send()
            .await?;
        
        // Update metadata store
        self.metadata_store.hset(
            &format!("index:{}", collection_id),
            "location",
            &key,
        ).await?;
        
        self.metadata_store.hset(
            &format!("index:{}", collection_id),
            "generation",
            &generation.to_string(),
        ).await?;
        
        Ok(S3Location {
            bucket: self.config.s3_express_bucket.clone(),
            key,
            etag: put_result.e_tag.unwrap_or_default(),
            generation,
        })
    }
    
    /// Load index from S3 (with local cache)
    pub async fn load_from_s3(
        &self,
        collection_id: &str,
    ) -> Result<Arc<dyn AxisVectorIndex>> {
        // 1. Check local cache first (if available)
        if let Some(local_cache) = &self.local_cache {
            if let Some(cached) = local_cache.get(collection_id).await {
                info!("✅ Loaded from local cache: {}", collection_id);
                return Ok(cached);
            }
        }
        
        // 2. Get location from metadata store
        let location: String = self.metadata_store
            .hget(&format!("index:{}", collection_id), "location")
            .await?;
        
        // 3. Download from S3 Express
        let get_result = self.s3_client
            .get_object()
            .bucket(&self.config.s3_express_bucket)
            .key(&location)
            .send()
            .await?;
        
        let data = get_result.body.collect().await?.into_bytes();
        
        // 4. Deserialize index
        let index = self.deserialize_index(&data).await?;
        
        // 5. Cache locally if possible (best-effort)
        if let Some(local_cache) = &self.local_cache {
            let _ = local_cache.put(collection_id, index.clone()).await;
        }
        
        Ok(index)
    }
}

pub struct SpotInstanceHandler {
    tier_manager: Arc<CloudNativeTierManager>,
    termination_monitor: Arc<TerminationMonitor>,
}

impl SpotInstanceHandler {
    /// Monitor for spot instance termination
    pub async fn run_termination_handler(&self) {
        let mut interval = tokio::time::interval(Duration::from_secs(5));
        
        loop {
            interval.tick().await;
            
            if let Some(termination_time) = self.termination_monitor.check_termination().await {
                warn!("⚠️ Spot instance termination in {:?}", termination_time);
                self.handle_termination().await;
                break;
            }
        }
    }
    
    /// Handle imminent termination
    async fn handle_termination(&self) -> Result<()> {
        info!("🚨 Starting emergency index persistence before termination");
        
        // 1. Stop accepting new index updates
        self.tier_manager.set_readonly_mode(true).await;
        
        // 2. Get all in-memory indexes
        let memory_indexes = self.tier_manager.list_memory_indexes().await?;
        
        // 3. Persist all dirty indexes in parallel
        let mut tasks = Vec::new();
        for (collection_id, index_state) in memory_indexes {
            if index_state.is_dirty {
                let manager = self.tier_manager.clone();
                let task = tokio::spawn(async move {
                    manager.emergency_persist(&collection_id).await
                });
                tasks.push(task);
            }
        }
        
        // 4. Wait for all persistence (with timeout)
        let results = tokio::time::timeout(
            Duration::from_secs(90),  // Leave 30s buffer
            futures::future::join_all(tasks)
        ).await;
        
        match results {
            Ok(results) => {
                let failed = results.iter().filter(|r| r.is_err()).count();
                if failed > 0 {
                    error!("❌ Failed to persist {} indexes", failed);
                } else {
                    info!("✅ All indexes persisted successfully");
                }
            }
            Err(_) => {
                error!("❌ Timeout persisting indexes");
            }
        }
        
        // 5. Update metadata store with instance termination
        self.metadata_store.hset(
            "cluster:status",
            &self.lifecycle.instance_id(),
            "terminated",
        ).await?;
        
        Ok(())
    }
}

/// Monitor AWS/GCP/Azure termination notices
struct TerminationMonitor {
    platform: CloudPlatform,
}

impl TerminationMonitor {
    async fn check_termination(&self) -> Option<Duration> {
        match self.platform {
            CloudPlatform::AWS => {
                // Check EC2 metadata endpoint
                let response = reqwest::get("http://169.254.169.254/latest/meta-data/spot/termination-time")
                    .await
                    .ok()?;
                
                if response.status() == 200 {
                    let termination_time = response.text().await.ok()?;
                    let termination = DateTime::parse_from_rfc3339(&termination_time).ok()?;
                    Some(termination.signed_duration_since(Utc::now()).to_std().ok()?)
                } else {
                    None
                }
            }
            CloudPlatform::GCP => {
                // Check GCP preemptible metadata
                self.check_gcp_preemption().await
            }
            CloudPlatform::Azure => {
                // Check Azure Scheduled Events
                self.check_azure_eviction().await
            }
        }
    }
}

=== Distributed Coordination

pub struct DistributedIndexCoordinator {
    /// Etcd/Consul for leader election
    coordinator: Arc<etcd::Client>,
    
    /// Current leadership state
    is_leader: Arc<AtomicBool>,
    
    /// Index ownership map
    ownership: Arc<DashMap<String, String>>,  // collection -> owner_instance
}

impl DistributedIndexCoordinator {
    /// Elect leader for index management decisions
    pub async fn elect_leader(&self) -> Result<()> {
        let lease = self.coordinator.lease_grant(60, None).await?;
        let key = "/proximadb/axis/leader";
        
        // Try to become leader
        let result = self.coordinator
            .put(key, self.instance_id(), Some(PutOptions::new().with_lease(lease.id())))
            .await;
        
        match result {
            Ok(_) => {
                self.is_leader.store(true, Ordering::Release);
                info!("✅ Became AXIS leader: {}", self.instance_id());
                self.maintain_leadership(lease).await;
            }
            Err(_) => {
                self.is_leader.store(false, Ordering::Release);
                debug!("Following existing leader");
            }
        }
        
        Ok(())
    }
    
    /// Distribute index ownership across instances
    pub async fn rebalance_indexes(&self) -> Result<()> {
        if !self.is_leader.load(Ordering::Acquire) {
            return Ok(());  // Only leader rebalances
        }
        
        let instances = self.discover_instances().await?;
        let collections = self.list_all_collections().await?;
        
        // Simple round-robin assignment
        for (idx, collection) in collections.iter().enumerate() {
            let owner = &instances[idx % instances.len()];
            
            self.coordinator.put(
                &format!("/proximadb/axis/owner/{}", collection),
                owner,
                None,
            ).await?;
            
            self.ownership.insert(collection.clone(), owner.clone());
        }
        
        info!("✅ Rebalanced {} indexes across {} instances",
              collections.len(), instances.len());
        
        Ok(())
    }
    
    /// Handle instance failure
    pub async fn handle_instance_failure(&self, failed_instance: &str) -> Result<()> {
        warn!("🔄 Handling failure of instance: {}", failed_instance);
        
        // Find indexes owned by failed instance
        let orphaned: Vec<String> = self.ownership
            .iter()
            .filter(|entry| entry.value() == failed_instance)
            .map(|entry| entry.key().clone())
            .collect();
        
        // Reassign to healthy instances
        let healthy_instances = self.discover_healthy_instances().await?;
        
        for (idx, collection) in orphaned.iter().enumerate() {
            let new_owner = &healthy_instances[idx % healthy_instances.len()];
            
            // Update ownership
            self.ownership.insert(collection.clone(), new_owner.clone());
            
            // Trigger index loading on new owner
            if new_owner == &self.instance_id() {
                self.load_orphaned_index(collection).await?;
            }
        }
        
        Ok(())
    }
}

pub struct MultiRegionIndexManager {
    regions: Vec<RegionConfig>,
    replication_strategy: ReplicationStrategy,
}

#[derive(Debug, Clone)]
pub enum ReplicationStrategy {
    /// All regions have full copy
    FullReplication,
    
    /// Primary + read replicas
    PrimaryReplica {
        primary_region: String,
        read_regions: Vec<String>,
    },
    
    /// Sharded across regions
    GeoSharded {
        sharding_key: String,  // e.g., "country"
        region_mapping: HashMap<String, String>,
    },
}

impl MultiRegionIndexManager {
    /// Replicate index across regions
    pub async fn replicate_index(
        &self,
        collection_id: &str,
        index_data: &[u8],
        priority: ReplicationPriority,
    ) -> Result<()> {
        match priority {
            ReplicationPriority::Synchronous => {
                // Wait for all regions
                let mut tasks = Vec::new();
                for region in &self.regions {
                    tasks.push(self.upload_to_region(region, collection_id, index_data));
                }
                futures::future::try_join_all(tasks).await?;
            }
            
            ReplicationPriority::Asynchronous => {
                // Upload to primary, queue others
                self.upload_to_primary(collection_id, index_data).await?;
                for region in &self.regions[1..] {
                    self.queue_replication(region, collection_id, index_data).await?;
                }
            }
            
            ReplicationPriority::Lazy => {
                // Only replicate on read miss
                self.upload_to_primary(collection_id, index_data).await?;
            }
        }
        
        Ok(())
    }
    
    /// Read with fallback across regions
    pub async fn read_with_fallback(
        &self,
        collection_id: &str,
    ) -> Result<Vec<u8>> {
        // Try local region first
        if let Ok(data) = self.read_from_local_region(collection_id).await {
            return Ok(data);
        }
        
        // Fallback to other regions (sorted by latency)
        for region in self.get_regions_by_latency().await {
            match self.read_from_region(&region, collection_id).await {
                Ok(data) => {
                    // Cache in local region for next time
                    let _ = self.cache_in_local_region(collection_id, &data).await;
                    return Ok(data);
                }
                Err(e) => {
                    warn!("Failed to read from {}: {}", region.name, e);
                }
            }
        }
        
        Err(anyhow!("Failed to read index from all regions"))
    }
}

impl CloudNativeFlushCoordinator {
    /// Flush with immediate S3 persistence
    pub async fn flush_with_cloud_persistence(
        &self,
        collection_id: &str,
        vectors: Vec<VectorRecord>,
    ) -> Result<()> {
        // 1. Check who owns this collection's index
        let owner = self.coordinator.get_index_owner(collection_id).await?;
        
        if owner == self.instance_id() {
            // We own it - update locally and persist
            self.update_local_index(collection_id, &vectors).await?;
            
            // Immediately persist to S3 Express
            let generation = self.increment_generation(collection_id).await?;
            self.tier_manager.persist_to_s3_express(
                collection_id,
                &self.get_index(collection_id)?,
                generation,
            ).await?;
            
        } else {
            // Another instance owns it - send update via S3
            self.publish_index_delta(
                collection_id,
                IndexDelta::Additions(vectors),
                &owner,
            ).await?;
        }
        
        Ok(())
    }
}

impl CloudNativeCompactionCoordinator {
    /// Compaction with S3-based coordination
    pub async fn compact_with_cloud_coordination(
        &self,
        collection_id: &str,
        deleted_ids: Vec<String>,
        merged_vectors: Vec<VectorRecord>,
    ) -> Result<()> {
        // Acquire distributed lock
        let lock = self.lock_manager.acquire(
            &format!("compaction:{}", collection_id),
            Duration::from_secs(300),
        ).await?;
        
        // Download latest index from S3
        let mut index = self.tier_manager.load_from_s3(collection_id).await?;
        
        // Apply compaction
        for id in &deleted_ids {
            index.remove(id).await?;
        }
        for vector in &merged_vectors {
            index.insert(vector.clone()).await?;
        }
        
        // Persist back to S3
        let generation = self.increment_generation(collection_id).await?;
        self.tier_manager.persist_to_s3_express(
            collection_id,
            &index,
            generation,
        ).await?;
        
        // Release lock
        lock.release().await?;
        
        Ok(())
    }
}

pub struct CostOptimizer {
    usage_analyzer: Arc<UsageAnalyzer>,
    cost_calculator: Arc<CostCalculator>,
}

impl CostOptimizer {
    /// Automatically move indexes to most cost-effective tier
    pub async fn optimize_storage_costs(&self) -> Result<()> {
        let collections = self.list_all_collections().await?;
        
        for collection in collections {
            let usage = self.usage_analyzer.get_usage_stats(&collection).await?;
            let current_cost = self.cost_calculator.calculate_current_cost(&collection).await?;
            
            // Determine optimal tier based on access patterns
            let optimal_tier = match usage.access_per_month {
                0..=10 => CloudTierState::S3Glacier { .. },      // Very cold
                11..=100 => CloudTierState::S3Standard { .. },   // Cold
                101..=1000 => CloudTierState::S3Express { .. },  // Warm
                _ => CloudTierState::Memory { .. },              // Hot
            };
            
            let projected_cost = self.cost_calculator.calculate_tier_cost(
                &collection,
                &optimal_tier,
            ).await?;
            
            if projected_cost < current_cost * 0.8 {  // 20% savings threshold
                info!("💰 Moving {} to {:?} (saves ${:.2}/month)",
                      collection, optimal_tier, current_cost - projected_cost);
                
                self.tier_manager.move_to_tier(&collection, optimal_tier).await?;
            }
        }
        
        Ok(())
    }
}

== Conclusion

This cloud-native design:

1. **Treats local storage as ephemeral**: Never relies on instance storage
2. **S3 Express as primary tier**: Low latency persistent storage
3. **Handles spot terminations**: 2-minute warning persistence
4. **Distributed coordination**: Multiple instances share index ownership
5. **Cost optimized**: Automatic tiering based on usage patterns
6. **Multi-region capable**: Cross-region replication for resilience

The key insight: In cloud environments, **S3 Express replaces local disk** as the primary persistent tier, with memory as a cache and S3 Standard/Glacier for cold data.
