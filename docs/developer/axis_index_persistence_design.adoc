== Problem Statement

The current AXIS implementation has critical gaps in index lifecycle management:

1. **No Index Persistence**: Indexes exist only in memory, lost on eviction/restart
2. **No Reload Mechanism**: Cannot restore evicted indexes from disk
3. **Lost Incremental Updates**: Flush/compaction updates lost after eviction
4. **Expensive Rebuilds**: Must re-read all vectors from storage to rebuild

== Current Implementation Analysis

== Implementation Design

=== 1. Index Persistence Engine

[source,rust]
----
pub struct IndexPersistenceEngine {
    base_path: PathBuf,
    checkpoint_interval: Duration,
    compression: CompressionType,
}

impl IndexPersistenceEngine {
    /// Persist index to disk with incremental checkpointing
    pub async fn persist_index(
        &self,
        collection_id: &str,
        index_type: &IndexType,
        index_data: &IndexData,
        is_checkpoint: bool,
    ) -> Result<PersistenceMetadata> {
        let path = if is_checkpoint {
            // Incremental checkpoint
            self.get_checkpoint_path(collection_id, index_type)
        } else {
            // Full index snapshot
            self.get_snapshot_path(collection_id, index_type)
        };
        
        // Serialize based on index type
        match index_type {
            IndexType::HNSW => self.persist_hnsw_graph(path, index_data),
            IndexType::IVF => self.persist_ivf_clusters(path, index_data),
            IndexType::PQ => self.persist_pq_codebooks(path, index_data),
        }
    }
    
    /// Persist only incremental changes (delta)
    pub async fn persist_delta(
        &self,
        collection_id: &str,
        added_vectors: &[VectorRecord],
        deleted_ids: &[String],
        checkpoint_id: u64,
    ) -> Result<()> {
        let delta = IndexDelta {
            checkpoint_id,
            timestamp: Utc::now(),
            added: added_vectors.to_vec(),
            deleted: deleted_ids.to_vec(),
        };
        
        let path = self.get_delta_path(collection_id, checkpoint_id);
        self.write_compressed(path, &delta).await
    }
}

=== 2. Index Loading Engine

[source,rust]
----
pub struct IndexLoadEngine {
    cache: Arc<IndexMemoryTracker>,
    io_scheduler: IoScheduler,
}

impl IndexLoadEngine {
    /// Load index from disk with tiered loading
    pub async fn load_index(
        &self,
        collection_id: &str,
        index_type: IndexType,
        load_strategy: LoadStrategy,
    ) -> Result<Arc<dyn AxisVectorIndex>> {
        match load_strategy {
            LoadStrategy::Full => {
                // Load entire index into memory
                self.load_full_index(collection_id, index_type).await
            }
            LoadStrategy::Lazy => {
                // Load only metadata, fetch nodes on-demand
                self.load_lazy_index(collection_id, index_type).await
            }
            LoadStrategy::Tiered => {
                // Load hot layers in memory, cold on disk
                self.load_tiered_index(collection_id, index_type).await
            }
        }
    }
    
    /// Apply deltas to loaded index
    pub async fn apply_deltas(
        &self,
        index: &mut dyn AxisVectorIndex,
        deltas: Vec<IndexDelta>,
    ) -> Result<()> {
        for delta in deltas {
            // Remove deleted vectors
            for id in &delta.deleted {
                index.remove(id).await?;
            }
            // Add new vectors
            for vector in &delta.added {
                index.insert(vector.clone()).await?;
            }
        }
        Ok(())
    }
}

=== 3. Synchronization Protocol

[source,rust]
----
/// Synchronization between flush/compaction and indexes
pub struct IndexSyncProtocol {
    persistence_engine: Arc<IndexPersistenceEngine>,
    memory_tracker: Arc<IndexMemoryTracker>,
}

impl IndexSyncProtocol {
    /// Handle flush synchronization
    pub async fn sync_after_flush(
        &self,
        collection_id: &str,
        flushed_vectors: Vec<VectorRecord>,
    ) -> Result<()> {
        // 1. Update in-memory indexes if available
        if self.memory_tracker.is_index_available(collection_id).await {
            self.update_memory_indexes(collection_id, &flushed_vectors).await?;
        }
        
        // 2. Persist delta to disk for future reload
        let checkpoint_id = self.get_next_checkpoint_id(collection_id);
        self.persistence_engine.persist_delta(
            collection_id,
            &flushed_vectors,
            &[],  // No deletions in flush
            checkpoint_id,
        ).await?;
        
        // 3. Trigger checkpoint if interval reached
        if self.should_checkpoint(collection_id) {
            self.create_checkpoint(collection_id).await?;
        }
        
        Ok(())
    }
    
    /// Handle compaction synchronization
    pub async fn sync_after_compaction(
        &self,
        collection_id: &str,
        deleted_ids: Vec<String>,
        merged_vectors: Vec<VectorRecord>,
    ) -> Result<()> {
        // Similar to flush but includes deletions
        if self.memory_tracker.is_index_available(collection_id).await {
            self.update_memory_indexes_with_deletes(
                collection_id,
                &merged_vectors,
                &deleted_ids,
            ).await?;
        }
        
        // Persist compaction delta
        self.persistence_engine.persist_delta(
            collection_id,
            &merged_vectors,
            &deleted_ids,
            self.get_next_checkpoint_id(collection_id),
        ).await?;
        
        Ok(())
    }
}

=== 4. Memory Management Integration

[source,rust]
----
impl AxisManager {
    /// Enhanced query with automatic index loading
    pub async fn query_with_fallback(
        &self,
        query: HybridQuery,
    ) -> Result<QueryResult> {
        let collection_id = &query.collection_id;
        
        // Check index availability
        let memory_status = self.memory_tracker
            .get_memory_status(collection_id)
            .await;
        
        match memory_status {
            Some(status) if status.is_available() => {
                // Use in-memory index
                self.query_from_memory(query).await
            }
            Some(status) if status.has_disk_backup() => {
                // Try to load from disk
                match self.load_index_from_disk(collection_id).await {
                    Ok(index) => {
                        self.query_with_index(query, index).await
                    }
                    Err(_) => {
                        // Fallback to storage scan
                        self.fallback_to_storage_scan(query).await
                    }
                }
            }
            _ => {
                // No index available, scan storage
                self.fallback_to_storage_scan(query).await
            }
        }
    }
    
    /// Proactive index preloading
    pub async fn preload_hot_indexes(&self) -> Result<()> {
        let hot_collections = self.identify_hot_collections().await?;
        
        for collection_id in hot_collections {
            if !self.memory_tracker.is_index_available(&collection_id).await {
                tokio::spawn({
                    let manager = self.clone();
                    let collection = collection_id.clone();
                    async move {
                        if let Err(e) = manager.load_index_from_disk(&collection).await {
                            tracing::warn!("Failed to preload index for {}: {}", collection, e);
                        }
                    }
                });
            }
        }
        
        Ok(())
    }
}

== Persistence Format Specifications

=== HNSW Graph Format
[source]
----
File: hnsw_graph.idx
Header:
  magic: "HNSW"
  version: 1
  levels: u32
  entry_point: VectorId
  
Layers:
  [Level 0..N]:
    node_count: u32
    [Nodes]:
      id: VectorId
      neighbors: Vec<VectorId>
      vector: Option<Vec<f32>>  // Only for hot nodes
----

=== IVF Clusters Format
[source]
----
File: ivf_clusters.idx
Header:
  magic: "IVF1"
  version: 1
  num_centroids: u32
  
Centroids:
  [Centroid]:
    id: u32
    vector: Vec<f32>
    
PostingLists:
  [List]:
    centroid_id: u32
    vector_ids: Vec<VectorId>
    vectors: Option<Vec<Vec<f32>>>  // Only if cached
----

=== Checkpoint Format
[source]
----
File: checkpoint_v{N}.ckpt
Header:
  magic: "CKPT"
  version: 1
  checkpoint_id: u64
  parent_checkpoint: Option<u64>
  timestamp: DateTime
  
Deltas:
  added_count: u32
  [Added Vectors]
  deleted_count: u32
  [Deleted IDs]

== Performance Considerations

=== Storage Overhead
- Full index snapshot: ~10-20% of vector data size
- Incremental checkpoints: ~1MB per 10K vector updates
- Compression ratio: 40-60% with ZSTD

=== Load Times
- HNSW (1M vectors): ~5-10 seconds from NVMe
- IVF centroids only: ~100ms
- Full IVF with posting lists: ~2-5 seconds

=== Memory Management
- Keep hot layers (HNSW top 2 levels) always in memory
- Swap cold layers based on access patterns
- Use mmap for large posting lists

== Conclusion

The current AXIS implementation lacks critical persistence and reload capabilities. This design provides:

1. **Index Persistence**: Indexes saved to disk with checkpointing
2. **Fast Recovery**: Load indexes from disk instead of rebuilding
3. **Incremental Updates**: Deltas preserve flush/compaction changes
4. **Memory Efficiency**: Tiered loading based on access patterns
5. **Crash Recovery**: Checkpoints enable consistent state restoration

This ensures indexes remain synchronized with storage even under memory pressure or after restarts.
