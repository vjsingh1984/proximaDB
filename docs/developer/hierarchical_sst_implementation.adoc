=== Compression Markers
```
Block Format: [MARKER:1][DATA:N]

Markers:
• 0x00: Uncompressed
• 0x01: ZSTD
• 0x02: LZ4
• 0x03: Snappy
• 0x04-0x0B: Other algorithms
```

=== Streaming Operations

**Write (Flush/Compaction):**
1. Sort records by ID
2. Group into blocks
3. Apply compression
4. Add self-describing markers
5. Write to SSTable

**Read (Query):**
1. Load block data
2. Check compression marker
3. Auto-decompress
4. Extract SstRecords
5. Apply filters (zero-copy)
