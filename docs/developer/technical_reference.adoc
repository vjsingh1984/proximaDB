== Hardware Capabilities

=== Initialization
[source,rust]
----
use proximadb::core::hardware_capabilities::*;

// Required at startup
initialize_hardware_capabilities_default()?;

// Access globally
let caps = get_hardware_capabilities();
----

=== Capability Checks
[source,rust]
----
caps.has_avx512()      // AVX-512 available
caps.has_gpu()         // GPU acceleration
caps.has_simd()        // Any SIMD available

// Hardware-aware decisions
if caps.should_use_gpu_distance(vector_size) {
    // Use GPU for large vectors
}
----

=== Configuration
[source,toml]
----
[hardware]
enable_gpu_acceleration = true
enable_simd = true
gpu_min_vector_size = 512
gpu_min_batch_size = 100
----

== REST API

=== Collections
```http
POST /collections
{
  "name": "vectors",
  "dimension": 384,
  "engine": "viper"

```


== SQL Interface

[source,sql]
----
-- Create collection
CREATE COLLECTION vectors (dimension=384, engine='viper');

-- Insert
INSERT INTO vectors (id, vector, metadata) 
VALUES ('vec1', [0.1, ...], '{"key": "value"}');

-- Search
SELECT id, similarity(vector, [0.1, ...]) as score
FROM vectors
ORDER BY score DESC
LIMIT 10;
----

== Configuration

=== Server
[source,toml]
----
[server]
rest_port = 5678
grpc_port = 5679

[storage]
data_directory = "/data"
write_buffer_mb = 512

[rest]
enable_compression = false  # Default

[grpc]
enable_compression = true   # Default
----

=== Compression
* **REST**: OFF by default (debugging)
* **gRPC**: ON by default (performance)
* **Storage**: SDK-driven via CompressionConfig

== Distance Metrics

[cols="1,2,1", options="header"]
|===
| Metric | Description | Range

| cosine | Semantic similarity | [0, 2]
| euclidean | L2 distance | [0, ∞)
| dot_product | Inner product | (-∞, ∞)
| manhattan | L1 distance | [0, ∞)
| hamming | Bit differences | [0, n]
| jaccard | Set similarity | [0, 1]
|===

== Index Types

[cols="1,2,1,1", options="header"]
|===
| Type | Best For | Memory | Search

| HNSW | High recall | O(M×N) | O(log N)
| IVF | Large datasets | O(N) | O(nprobe×N/K)
| LSH | Approximate | O(L×N) | O(L)
| Annoy | Memory-constrained | O(N×trees) | O(trees×log N)
| PQ | Compression | O(N/8) | O(N)
| FLAT | Perfect recall | O(N) | O(N)
|===

== Error Codes

* **COLLECTION_NOT_FOUND**: Collection doesn't exist
* **DIMENSION_MISMATCH**: Vector dimension incorrect
* **INVALID_METADATA**: JSON parsing failed
* **STORAGE_ERROR**: Disk/permission issue
* **TIMEOUT**: Operation exceeded time limit
