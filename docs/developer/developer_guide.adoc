== Quick Setup

**Prerequisites**: Rust 1.70+, Docker 20.10+, Python 3.8+

[source,bash]
----
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb

# Install toolchain
rustup component add rustfmt clippy
cargo install cargo-watch cargo-tarpaulin

# Build and test
cargo build --release
cargo test --all

# Python SDK development
cd clients/python && pip install -e ".[dev]"
----

=== Writing Tests

Use the **UnifiedTestEnvironment** for consistent testing:

[source,rust]
----
use crate::common::unified_test_utils::{UnifiedTestEnvironment, operations};

#[tokio::test]
async fn test_example() -> Result<()> {
    let env = UnifiedTestEnvironment::new().await?;
    let engine = env.create_sst_engine().await?;
    
    let vectors = env.create_test_vectors(10);
    operations::insert_and_flush_sst(&engine, &env, vectors).await?;
    
    let results = operations::search_vectors_sst(
        &engine, &env, &query_vector, 5
    ).await?;
    
    assert!(!results.is_empty());
    Ok(())
}
----

=== Code Standards
[source,bash]
----
cargo fmt              # Format code
cargo clippy           # Lint code
cargo test --all       # Run tests
----

=== Proto-First Design
* Use proto types directly (no JSON conversion)
* VectorRecord flows natively through pipeline
* Zero double serialization

=== Key Principles
1. **No mock data** - Use real services, fail fast
2. **Clean design** - No backward compatibility layers
3. **Direct integration** - No wrapper layers
4. **Concurrency** - Prefer DashMap over Arc<RwLock>
5. **Stateless engines** - Pass parameters explicitly

== Project Structure

```
src/
├── services/         # VectorOperationsService, CollectionService
├── storage/          # VIPER and SST engines
├── api_handlers/     # REST/gRPC handlers
├── proto/            # Protocol buffer definitions
├── core/            # Hardware capabilities, compression
├── index/           # HNSW, IVF, PQ, LSH algorithms

clients/python/       # Python SDK
docs/                # Documentation
demo/                # Example configurations
```

== Key APIs

=== Hardware Capabilities
[source,rust]
----
use proximadb::core::hardware_capabilities::*;

// Initialize once at startup
initialize_hardware_capabilities_default();

// Auto-detect GPU/SIMD
let caps = get_hardware_capabilities();
if caps.has_gpu() {
    // Use GPU acceleration
}
----

=== VectorOperationsService
[source,rust]
----
// Direct memtable access (40-60% faster)
service.insert_vectors("collection_id", vectors).await?;
service.search_vectors("collection_id", query).await?;
----
