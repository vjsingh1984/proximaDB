== Quick Setup

**Prerequisites**: Rust 1.70+, Docker 20.10+, Python 3.8+

[source,bash]
----
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb

# Install toolchain
rustup component add rustfmt clippy
cargo install cargo-watch cargo-tarpaulin

# Build and test
cargo build --release
cargo test --all

# Python SDK development
cd clients/python && pip install -e ".[dev]" && cd ../..
----

== Storage Engines

**VIPER (Columnar)**:
- Parquet-based with Arrow integration
- Best for analytics and complex queries
- Supports quantization (INT8, PQ8, PQ4)
- Column pruning and predicate pushdown

**SST (Row-based)**:
- Write-optimized with three-stage filtering
- Bloom filters and sorted key ranges
- Block compression (ZSTD, LZ4, Snappy)
- Optimal for high-throughput writes

**Selection Logic:**
[source,rust]
----
match workload_type {
    WorkloadType::WriteHeavy => StorageEngine::SST,
    WorkloadType::Analytics => StorageEngine::VIPER,
    WorkloadType::Mixed => StorageEngine::SST,  // Default
}
----

## Contributing

**Pull Request Process:**
1. Fork repository
2. Create feature branch
3. Add tests for new functionality
4. Ensure all tests pass
5. Run `cargo fmt && cargo clippy`
6. Submit PR with clear description

**Code Review Checklist:**
- [ ] Tests added/updated
- [ ] Documentation updated
- [ ] Performance benchmarks (if applicable)
- [ ] Proto schema changes reviewed
- [ ] Hardware capabilities initialized in tests

**Common Patterns:**
- Use DashMap over Arc<RwLock> for concurrency
- Prefer proto types directly
- Test with `println!`, not tracing macros
- Initialize hardware capabilities in all tests
- Use absolute paths in documentation

== Release Process

1. Update version in `Cargo.toml`
2. Update `CHANGELOG.md`
3. Run full test suite: `cargo test --all --release`
4. Build release: `cargo build --release`
5. Tag release: `git tag v0.x.x`
6. Publish Python SDK: `cd clients/python && python -m build && twine upload dist/*`
