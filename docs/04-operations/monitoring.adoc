= Monitoring Guide
:toc: left
:toclevels: 2
:icons: font

[.lead]
Developer-focused monitoring for ProximaDB local and single-node deployments.

== Metrics Endpoint

[source,bash]
----
curl http://localhost:5678/metrics
----

Prometheus-compatible metrics are exposed at `/metrics`.

== Key Metrics

|===
| Metric | Description

| `proximadb_requests_total` | Total requests by endpoint
| `proximadb_request_duration_seconds` | Request latency histogram
| `proximadb_errors_total` | Error count by type
| `proximadb_vectors_total` | Total vectors stored
| `proximadb_wal_size_bytes` | WAL size on disk
|===

== Health Check

[source,bash]
----
curl http://localhost:5678/health
----

== Logging

[source,bash]
----
RUST_LOG=info ./proximadb-server
RUST_LOG=proximadb::storage=debug ./proximadb-server
----

== Local Grafana (Optional)

Use `deploy/docker/prometheus.yml` as a starting point for local dashboards.
