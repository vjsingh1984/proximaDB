= Articles — Structure & Conventions

This folder holds long‑form product/marketing articles. Use one subfolder per article, named with date and a short slug.

== Folder Layout (per article)

docs/article/
  YYYY-MM-DD_short_slug/
    index.adoc
    images/
      <diagram>.svg
      <diagram-dark>.svg (optional)

== Authoring Guidelines

- Put AsciiDoc content in `index.adoc`.
- Set an images base inside the file:
  `:imagesdir: images`
- Embed diagrams with:
  `image::diagram.svg[Alt text,align="center",width=960]`
- For Mermaid blocks:
  `[source,mermaid]` + fenced `----` body.
- Keep articles concise (≤ 600–800 words). Link to API docs for deep dives.

== Assets & Exports

- Prefer SVG for diagrams; add dark variants if needed.
- If PNG exports are required, store alongside SVG with clear suffixes (e.g., `_1200x600.png`).
- Use brand assets from `docs/assets/logos/` and `docs/assets/icons/` as needed.

== Naming

- Folder: `YYYY-MM-DD_<short-topic>`, e.g., `2025-09-10_unified_vector_graph_knowledge_platform_for_enterprise_rag`.
- Diagrams: `topic_component.svg`.
