==== Kubernetes Deployment

```yaml
# proximadb-stateless.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: proximadb
spec:
  replicas: 1
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxUnavailable: 0
      maxSurge: 1
  template:
    spec:
      # Spot instance tolerance for 70% cost savings
      tolerations:
      - key: "kubernetes.io/lifecycle"
        operator: "Equal"
        value: "spot"
        effect: "NoSchedule"
      
      containers:
      - name: proximadb
        image: proximadb/server:latest
        env:
        - name: STORAGE_BACKEND
          value: "s3"  # or "azure" or "gcs"
        - name: STORAGE_URL
          value: "s3://my-bucket/proximadb"
        
        resources:
          requests:
            memory: "48Gi"
            cpu: "12"
          limits:
            memory: "64Gi"
            cpu: "16"
        
        livenessProbe:
          httpGet:
            path: /health
            port: 5678
          initialDelaySeconds: 30
          periodSeconds: 10
        
        readinessProbe:
          httpGet:
            path: /ready
            port: 5678
          initialDelaySeconds: 10
          periodSeconds: 5
```

==== StatefulSet Configuration

```yaml
# proximadb-stateful.yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: proximadb-stateful
spec:
  serviceName: proximadb
  replicas: 1
  template:
    spec:
      containers:
      - name: proximadb
        image: proximadb/server:latest
        env:
        - name: STORAGE_BACKEND
          value: "local"
        - name: DATA_PATH
          value: "/data"
        volumeMounts:
        - name: data
          mountPath: /data
  volumeClaimTemplates:
  - metadata:
      name: data
    spec:
      accessModes: ["ReadWriteOnce"]
      storageClassName: fast-nvme
      resources:
        requests:
          storage: 10Ti
```

=== Interruption Handling

```bash
#!/bin/bash
# Universal spot interruption handler

check_interruption() {
  # AWS
  if curl -s -f http://169.254.169.254/latest/meta-data/spot/termination-time; then
    return 0
  fi
  
  # Azure
  if curl -s -H Metadata:true "http://169.254.169.254/metadata/scheduledevents?api-version=2019-08-01" | grep -q "Preempt"; then
    return 0
  fi
  
  # GCP
  if curl -s -H "Metadata-Flavor: Google" "http://metadata.google.internal/computeMetadata/v1/instance/preempted" | grep -q "TRUE"; then
    return 0
  fi
  
  return 1
}

# Main loop
while true; do
  if check_interruption; then
    echo "Spot interruption detected - initiating graceful shutdown"
    curl -X POST http://localhost:5678/admin/drain
    sleep 30
    kill -TERM $(pidof proximadb-server)
    exit 0
  fi
  sleep 5
done
```

=== Tuning Checklist

==== For Maximum Throughput
- [x] Protocol: gRPC (2.9x faster)
- [x] Batch size: 500 vectors
- [x] Compression: LZ4 or None
- [x] Cache: 25% of RAM
- [x] Compaction: Every hour

==== For Minimum Latency
- [x] Storage: Local NVMe
- [x] Batch size: 50-100 vectors
- [x] Compression: None
- [x] Cache: 50% of RAM
- [x] Index: HNSW in memory

==== For Cost Optimization
- [x] Instances: 70% spot, 30% on-demand
- [x] Storage tiering: Hot → Warm → Cold
- [x] Compression: ZSTD-6+
- [x] Cache: 10% of RAM
- [x] Compaction: Daily

=== Common Issues

|===
| Issue | Cause | Solution

| High latency
| Cache misses
| Increase cache size, check hot data

| Spot interruptions
| Limited diversity
| Use more instance types and zones

| Insufficient memory
| Enable tiering or increase RAM

| Slow inserts
| Small batch size
| Increase to 500 vectors per batch

| Firewall/ports
