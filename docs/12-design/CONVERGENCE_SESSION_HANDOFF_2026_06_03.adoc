  absent. (And the proto `VectorSearchRequest` ticket is parsed by strict

  ticket parses fine.) These block Flight vector-search *responses* in general and
  predate TD-104; flag for the Arrow-encoder owner.

== 5. Lessons
* The crate DENIES unused imports (an unused `use` => "could not compile", shown
  only as a warning line — look past the summary).
* `cargo check --lib` SKIPS `#[cfg(test)]` and feature-gated code; run a
  test-compile (`cargo test --lib <path>`) before declaring a slice done.
* WAL-recovery tests (`test_canonical_document_wal_recovery_*`) fail in ISOLATION
  (global-manifest set-once 2nd-boot singleton) but pass in the full suite — a
  pre-existing flake, not a regression. arrow_ipc has 5 pre-existing failures
  (onnx-off embedding + an arrow `StructArray` test panic) — foreign.
* For deep multi-line field-extraction chains, a `perl -0777 -pi` collapse of
  `\n[ \t]*\.request_handlers(?=\n[ \t]*\.X)` is faster + safer than manual edits;
  the compiler then proves completeness (no `.request_handlers` left + types match).
* HOT branch: HEAD moves under you (other agents commit); `git commit -o` lands on
  whatever HEAD is. Your committed work survives linter reformat of the working tree.
