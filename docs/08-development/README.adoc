== Getting Started with Development

1. **Fork and Clone**: Fork the repository and clone your fork
2. **Setup Environment**: Install Rust toolchain and dependencies
3. **Read Contributing Guide**: Follow the guidelines in CONTRIBUTING.adoc
4. **Follow Style Guide**: Use the style guide checklist for consistency
5. **Test Your Changes**: Run tests before submitting PRs

== Development Workflow

1. **Create Feature Branch**: `git checkout -b feature/your-feature`
2. **Make Changes**: Follow coding standards and add tests
3. **Run Tests**: `cargo test` and `cargo clippy`
4. **Submit PR**: Create pull request with clear description
