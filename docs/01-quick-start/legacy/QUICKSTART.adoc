Get started with ProximaDB in 5 minutes. This guide walks through installation, basic operations, and common workflows.

== Prerequisites

* Python 3.10 or higher
* pip package manager
* 500 MB free disk space

== Installation

=== Install from PyPI

[source,bash]
----
pip install proximadb-python
----

[source,bash]

== Quick Start (5 Minutes)

=== Step 1: Start ProximaDB Server

[source,bash]
----
# Using Docker (recommended)
docker run -p 5678:5678 -p 5679:5679 ghcr.io/vjsingh1984/proximadb:latest

# OR build from source
cargo run --bin proximadb-server --release
----

=== Step 2: Connect and Create Collection

Create a file `quickstart.py`:

[source,python]
----
from proximadb_sdk import ProximaDBClient, connect

# Connect to ProximaDB
client = connect(url="http://localhost:5678")

# Create a collection
collection = client.create_collection(
    name="documents",
    dimension=384,  # BERT embedding dimension
    distance_metric="cosine"
)

print(f"✅ Created collection: {collection.id}")
----

=== Step 3: Insert Vectors

[source,python]
----
# Insert sample vectors
import numpy as np

vectors = [
    {
        "id": "doc1",
        "vector": np.random.rand(384).tolist(),
        "metadata": {"category": "tech", "views": 100}
    },
    {
        "id": "doc2",
        "vector": np.random.rand(384).tolist(),
        "metadata": {"category": "science", "views": 200}
    }
]

response = client.insert_vectors("documents", vectors)
print(f"✅ Inserted {len(vectors)} vectors")
----

=== Step 4: Search

[source,python]
----
# Semantic search
query_vector = np.random.rand(384).tolist()

results = client.search(
    collection_id="documents",
    vector=query_vector,
    top_k=5
)

for result in results:
    print(f"ID: {result.id}, Score: {result.score:.4f}")
----

=== Step 5: Filter with Metadata

[source,python]
----
# Search with metadata filters
results = client.search(
    collection_id="documents",
    vector=query_vector,
    top_k=5,
    metadata_filter={
        "category": "tech",
        "views": {"$gte": 50}
    }
)
----

Run the complete example:

[source,bash]

python quickstart.py

== Common Workflows

=== Workflow 1: Document Search with BERT

[source,python]
----
from proximadb_sdk import connect
from sentence_transformers import SentenceTransformer

# Initialize
client = connect(url="http://localhost:5678")
embedder = SentenceTransformer('all-MiniLM-L6-v2')

# Create collection
client.create_collection("docs", dimension=384)

# Index documents
documents = [
    "Machine learning is a subset of AI",
    "Deep learning uses neural networks",
    "Natural language processing deals with text"
]

embeddings = embedder.encode(documents)

vectors = [
    {
        "id": f"doc{i}",
        "vector": emb.tolist(),
        "metadata": {"text": doc}
    }
    for i, (doc, emb) in enumerate(zip(documents, embeddings))
]

client.insert_vectors("docs", vectors)

# Search
query = "How do neural networks learn?"
query_emb = embedder.encode([query])[0]

results = client.search(
    collection_id="docs",
    vector=query_emb.tolist(),
    top_k=3
)

for result in results:
    print(f"{result.metadata['text']}: {result.score:.4f}")
----

=== Workflow 2: Product Recommendations

[source,python]
----
from proximadb_sdk import connect
import numpy as np

client = connect(url="http://localhost:5678")

# Create product catalog
client.create_collection("products", dimension=128)

# Add products with features
products = [
    {"id": "p1", "name": "Laptop", "price": 999, "category": "electronics"},
    {"id": "p2", "name": "Mouse", "price": 29, "category": "electronics"},
    {"id": "p3", "name": "Desk", "price": 299, "category": "furniture"}
]

# Generate feature vectors (price normalized, category embedded)
vectors = []
for p in products:
    features = np.array([
        p['price'] / 1000,  # normalized price
        1.0 if p['category'] == 'electronics' else 0.0,
        1.0 if p['category'] == 'furniture' else 0.0
    ])
    # Pad to 128 dimensions
    features = np.pad(features, (0, 125))
    vectors.append({
        "id": p['id'],
        "vector": features.tolist(),
        "metadata": p
    })

client.insert_vectors("products", vectors)

# Find similar products to a laptop
query = np.array([0.999, 1.0, 0.0] + [0.0] * 125)  # expensive electronic

results = client.search(
    collection_id="products",
    vector=query.tolist(),
    top_k=3
)

print("Products similar to Laptop:")
for result in results:
    print(f"  {result.metadata['name']}: ${result.metadata['price']} ({result.score:.4f})")
----

=== Workflow 3: Image Similarity Search

[source,python]
----
from proximadb_sdk import connect
from PIL import Image
import numpy as np

client = connect(url="http://localhost:5678")

# Create collection for image embeddings
client.create_collection("images", dimension=512)

def extract_image_features(image_path):
    """Extract features from image (placeholder for actual CNN)"""
    img = Image.open(image_path)
    img = img.resize((224, 224))
    img_array = np.array(img) / 255.0
    # Use ResNet/EfficientNet here for real features
    features = img_array.flatten()[:512]
    return features.tolist()

# Index images
import os
image_dir = "path/to/images"
vectors = []

for filename in os.listdir(image_dir):
    if filename.endswith(('.jpg', '.png')):
        features = extract_image_features(os.path.join(image_dir, filename))
        vectors.append({
            "id": filename,
            "vector": features,
            "metadata": {"filename": filename}
        })

client.insert_vectors("images", vectors)

# Search for similar images
query_image = "path/to/query.jpg"
query_features = extract_image_features(query_image)

results = client.search(
    collection_id="images",
    vector=query_features,
    top_k=10
)

print("Similar images:")
for result in results:
    print(f"  {result.metadata['filename']}: {result.score:.4f}")
----

=== Workflow 4: Real-time Analytics

[source,python]
----
from proximadb_sdk import connect
import time
from datetime import datetime, timedelta

client = connect(url="http://localhost:5678")

# Create time-series collection
client.create_collection("metrics", dimension=64)

# Insert streaming metrics
def insert_metric(name, value, timestamp):
    # Create feature vector from metric value
    features = [value / 1000.0] * 64

    vector = {
        "id": f"{name}_{timestamp}",
        "vector": features,
        "metadata": {
            "name": name,
            "value": value,
            "timestamp": timestamp
        }
    }

    client.insert_vectors("metrics", [vector])

# Simulate metrics stream
for i in range(100):
    timestamp = datetime.now() - timedelta(minutes=100-i)
    insert_metric("cpu_usage", 50 + i % 50, timestamp.isoformat())
    insert_metric("memory_usage", 60 + i % 40, timestamp.isoformat())

# Find similar patterns
query = [0.075] * 64  # Looking for ~75% usage

results = client.search(
    collection_id="metrics",
    vector=query,
    top_k=5,
    metadata_filter={"name": "cpu_usage"}
)

print("Similar CPU usage patterns:")
for result in results:
    print(f"  {result.metadata['timestamp']}: {result.metadata['value']}% ({result.score:.4f})")
----

=== Workflow 5: Multi-tenant Data Isolation

[source,python]
----
from proximadb_sdk import connect, AuthConfig, AuthMethod

# Configure tenant-specific authentication
auth_config = AuthConfig(
    method=AuthMethod.JWT,
    jwt_token="your-tenant-jwt-token",
    tenant_id="acme-corp",
    tenant_isolation=True
)

# Create isolated client for tenant
client = connect(
    url="http://localhost:5678",
    auth_config=auth_config
)

# All operations automatically scoped to tenant
collections = client.list_collections()
print(f"Acme Corp collections: {len(collections)}")

# Create tenant-specific collection
collection = client.create_collection(
    name="acme_documents",
    dimension=384
)

# This collection is only visible to acme-corp tenant
print(f"Created: {collection.id}")
----

== Performance Tips

=== 1. Use Batch Operations

[source,python]
----
# Bad: Individual inserts
for vec in vectors:
    client.insert_vectors("collection", [vec])

# Good: Batch insert
client.insert_vectors("collection", vectors)
----

=== 2. Reuse Client Connections

[source,python]
----
# Bad: Create new client each time
def search(query):
    client = connect(url="http://localhost:5678")
    return client.search("collection", vector=query)

# Good: Reuse client
client = connect(url="http://localhost:5678")
def search(query):
    return client.search("collection", vector=query)
----

=== 3. Use Async for High Concurrency

[source,python]
----
import asyncio
from proximadb.unified_client_async import ProximaDBAsyncUnified

async def search_many(queries):
    client = ProximaDBAsyncUnified(url="http://localhost:5678")
    await client.astart()

    # Process multiple queries concurrently
    tasks = [
        client.search(collection="docs", vector=q, top_k=10)
        for q in queries
    ]
    results = await asyncio.gather(*tasks)

    await client.aclose()
    return results

# Run 100 queries concurrently
results = asyncio.run(search_many(query_vectors))
----

=== 4. Use gRPC for Maximum Performance

[source,python]
----
from proximadb.protocols.grpc_sync import ProximaDBSyncGrpcClient

# gRPC is 15-25% faster than REST
client = ProximaDBSyncGrpcClient(
    endpoint="localhost:5679",
    pool_size=5  # Connection pooling
)

results = client.search(
    collection_name="docs",
    vector=query,
    top_k=10
)
----

=== 5. Optimize Memory Usage

[source,python]
----
# Use numpy arrays (more efficient than lists)
import numpy as np

vectors = np.random.rand(10000, 384).astype(np.float32)
client.insert_vectors("docs", vectors)

# Stream large result sets
results = client.search(
    collection_id="docs",
    vector=query,
    top_k=10000,
    return_vectors=False  # Save bandwidth
)
----

== Configuration

=== Client Configuration

[source,python]
----
from proximadb_sdk import connect, ClientConfig

config = ClientConfig(
    url="http://localhost:5678",

    max_retries=3,

== Troubleshooting

=== Connection Issues

**Problem**: Cannot connect to server

[source,bash]
----
# Check if server is running
curl http://localhost:5678/health

# Check server logs
docker logs proximadb-container
----

**Solution**: Ensure ProximaDB server is running on port 5678

=== Import Errors

**Problem**: `ModuleNotFoundError: No module named 'proximadb'`

[source,bash]
----
# Check installation
pip list | grep proximadb

# Reinstall if needed
pip install --force-reinstall proximadb-python
----

**Solution**: Ensure package is installed in correct Python environment

=== Performance Issues

**Problem**: Slow insert/search performance

**Solution**:
1. Use batch operations (insert 100-1000 vectors at once)
2. Increase `pool_size` for concurrent operations
3. Use gRPC instead of REST for 15-25% performance gain
4. Enable quantization for large collections

=== Memory Issues

**Problem**: Out of memory errors with large datasets

**Solution**:
1. Use streaming for large result sets (`return_vectors=False`)
2. Reduce batch size
3. Enable quantization to reduce memory footprint
4. Use columnar storage engine (VIPER) for analytics workloads
