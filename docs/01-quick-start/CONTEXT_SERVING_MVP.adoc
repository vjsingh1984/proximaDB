= Context Serving MVP Quickstart
:toc: left
:icons: font

[.lead]
Prove ProximaDB's complete supported promise in one roundtrip: create an SST collection, write typed
context records, scan and search with the same metadata boundary, inspect route health, get a
record, and tombstone it. Every request uses canonical `/api/v2`.

== Start the server

[source,bash]
----
docker run --rm -d \
  --name proximadb-mvp \
  -p 5678:5678 \
  vjsingh1984/proximadb:latest
----

For a source checkout:

[source,bash]
----
cargo run --release --bin proximadb-server -- --config config/config.toml
----

== Prove the corridor

From a ProximaDB source checkout, run:

[source,bash]
----
python3 scripts/mvp_smoke.py \
  --base-url http://127.0.0.1:5678 \
  --output artifacts/mvp/first-run.json
----

The script uses only the Python standard library. It hard-fails when:

* any endpoint returns an unexpected status;
* the metadata scan under-returns or admits a record from another metadata partition;
* vector search ignores or leaks across the same filter;
* route-health omits the write/freshness/ANN/object-economy/recall signals;
* route-health advertises conditional, filter, or patch writes that the MVP does not support.

A successful JSON report includes each request's latency. It is activation evidence, not a
performance SLA.

== The product boundary

The quickstart proves the link:../00-product/MVP_TRUST_CORRIDOR.toml[MVP trust corridor], not every
implemented subsystem. In particular:

* pgwire and extended SQL remain Beta;
* graph, document, time-series, event, observability, and hybrid projections remain Beta;
* distributed execution and full PostgreSQL parity remain Experimental;
* SST is the supported engine; selecting another engine changes the support tier;
* this quickstart proves local storage; S3, Azure, and GCS remain Beta evidence targets;
* conditional writes, update/delete by filter, and patch are not supported.

Consult link:../SUPPORTED_SURFACE.adoc[the complete support matrix] before expanding a production
deployment beyond this path.
