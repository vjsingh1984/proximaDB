== Documentation Standards

**Format**: AsciiDoc (.adoc) for all documentation
**Diagrams**: Mermaid for flowcharts, architecture
**Code Examples**: Python (primary), bash for CLI
**Claims**: All performance numbers measured and validated

**Organization Principle**:
- Main docs: Current, maintained, single source of truth
- Supplementary: Deep dives, specific analyses
- Archive: Historical reference, not for updates
