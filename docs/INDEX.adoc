== Vision & Strategy

ProximaDB is a format-first, multi-model database. Development follows three phases:

|===
| Phase | Focus | Status

| **Phase 1** | Storage formats, catalog, core APIs | ✅ Complete
| **Phase 2** | Cross-model queries, graph, observability | ✅ Complete
| **Phase 3** | Ecosystem integration, streaming, SDKs | 🔄 In Progress
|===

For detailed strategy, see link:concepts/vision.adoc[Vision Document].
