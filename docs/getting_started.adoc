== Prerequisites

Docker & Docker Compose, 4GB RAM, 10GB disk space.

== Installation

**Docker (Recommended)**: Clone repository, run `docker compose up -d`, verify with `curl http://localhost:5678/health`.

**From Source**: Rust 1.70+, `cargo build --release`, `cargo run --release --bin proximadb-server`.

== Quick Start

1. **Install**: `pip install proximadb-client`

2. **Create Collection**: 
```python
from proximadb import ProximaDBClient
client = ProximaDBClient("http://localhost:5678")
client.create_collection(name="my_docs", dimension=384, engine="viper")
```

3. **Insert Vectors**:
```python
vectors = [{"id": "doc1", "vector": [0.1, 0.2, ...], "metadata": {"title": "AI Guide"}}]
client.insert_vectors("my_docs", vectors)
```

4. **Search**:
```python
results = client.search_vectors("my_docs", query_vector, top_k=5, metadata_filter={"category": "tutorial"})
```

**Basic config.toml**: Set ports (REST 5678, gRPC 5679), data directory, compaction intervals, compression settings.

**Storage Engines**: SST (write-heavy), VIPER (analytics/complex queries).

**Hardware Acceleration**: ProximaDB automatically detects and optimizes for:

* **CPU Features**: SIMD support (AVX-512, AVX2, SSE4.1, NEON)
* **GPU Backends**: CUDA, ROCm, MPS (Apple Silicon), OpenCL
* **Memory Layout**: Cache-aware data structures and processing
* **SQL Acceleration**: GPU/SIMD parsing with intelligent CPU fallbacks

All hardware detection runs once at startup with zero runtime overhead.

== Troubleshooting

**Port conflicts**: Change ports with `REST_PORT=5680 GRPC_PORT=5681 docker compose up`

**Memory issues**: Increase Docker limit with `docker run -m 8g`

**Connection refused**: Check with `docker ps | grep proximadb` and `curl http://localhost:5678/health`
