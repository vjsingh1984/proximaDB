= Getting Started with ProximaDB
:toc: left
:toclevels: 2
:source-highlighter: rouge

Get ProximaDB running in 5 minutes.

== Prerequisites

* Docker & Docker Compose
* 4GB RAM minimum
* 10GB disk space

== Installation

=== Using Docker (Recommended)

[source,bash]
----
# Clone the repository
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb

# Start ProximaDB
docker compose up -d

# Verify it's running
curl http://localhost:5678/health
----

=== Building from Source

[source,bash]
----
# Requirements: Rust 1.70+
cargo build --release
cargo run --release --bin proximadb-server
----

== First Steps

=== 1. Install Python Client

[source,bash]
----
pip install proximadb-client
----

=== 2. Create Your First Collection

[source,python]
----
from proximadb import ProximaDBClient

# Connect to ProximaDB
client = ProximaDBClient("http://localhost:5678")

# Create a collection
collection = client.create_collection(
    name="my_docs",
    dimension=384,  # Embedding dimension
    engine="viper"  # Or "sst" for write-heavy workloads
)
----

=== 3. Insert Vectors

[source,python]
----
# Insert vectors with metadata
vectors = [
    {
        "id": "doc1",
        "vector": [0.1, 0.2, ...],  # 384-dimensional
        "metadata": {
            "title": "Introduction to AI",
            "category": "tutorial"
        }
    }
]

client.insert_vectors("my_docs", vectors)
----

=== 4. Search for Similar Vectors

[source,python]
----
# Search by vector similarity
query_vector = [0.15, 0.25, ...]
results = client.search_vectors(
    collection="my_docs",
    vector=query_vector,
    top_k=5,
    metadata_filter={"category": "tutorial"}
)

# Or use SQL
results = client.search_sql("""
    SELECT id, metadata, similarity
    FROM my_docs
    WHERE similarity(vector, :query) > 0.8
    AND metadata->>'category' = 'tutorial'
    ORDER BY similarity DESC
    LIMIT 5
""", {"query": query_vector})
----

== Configuration

=== Basic Configuration

Create `config.toml`:

[source,toml]
----
[server]
rest_port = 5678
grpc_port = 5679

[storage]
data_dir = "./data"

[storage.sst]
compaction_interval_secs = 300

[storage.viper]
enable_compression = true
----

=== Storage Engine Selection

* **SST Engine**: Best for write-heavy workloads
* **VIPER Engine**: Best for analytics and complex queries

== Troubleshooting

=== Common Issues

**Port Already in Use**
[source,bash]
----
# Change ports in docker-compose.yml or config.toml
REST_PORT=5680 GRPC_PORT=5681 docker compose up
----

**Memory Issues**
[source,bash]
----
# Increase Docker memory limit
docker run -m 8g proximadb/proximadb:latest
----

**Connection Refused**
[source,bash]
----
# Check if service is running
docker ps | grep proximadb
curl http://localhost:5678/health
----
