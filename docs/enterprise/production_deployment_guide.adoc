== **Production Configuration**

=== Basic Production Setup

**1. Install ProximaDB:**
```bash
# Clone and build production release
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb
cargo build --profile release-server

# Verify installation
./target/release-server/proximadb-server --version
```

**2. Configuration File Setup:**
```toml
# config/production.toml
[server]
http_port = 5678
grpc_port = 5679
data_dir = "/var/lib/proximadb"
log_level = "info"

[storage]
# Choose your primary engine
default_engine = "SST"  # Options: SST, VIPER, NOVA, SWIFT, RAPTOR, HELIX
metadata_url = "local:///var/lib/proximadb/metadata"
enable_write_ahead_log = true

[storage.write_buffer]
flush_threshold_mb = 256
flush_interval_seconds = 30

[compute.quantization]
default_algorithm = "PQ8"  # Options: Binary, INT8, PQ4, PQ8, PQ16, PQ32
enable_simd = true
auto_hardware_detection = true
```

**3. Start Production Server:**
```bash
# Start with production configuration
./target/release-server/proximadb-server --config config/production.toml

# Or with systemd (recommended)
sudo systemctl start proximadb
sudo systemctl enable proximadb
```

=== Engine-Specific Configuration

**SST Engine (Real-time OLTP):**
```toml
[storage.engines.sst]
bloom_filter_bits_per_key = 10
max_memtable_size_mb = 64
compaction_style = "level"
write_buffer_size_mb = 32
```

**VIPER Engine (Analytics):**
```toml
[storage.engines.viper]
row_group_size = 131072  # 128K vectors per row group
compression_algorithm = "zstd"
enable_dictionary_encoding = true
parquet_cache_size_mb = 512
```

**NOVA Engine (Advanced Analytics):**
```toml
[storage.engines.nova]
enable_progressive_search = true
superblock_size = 1048576  # 1M vectors
hierarchical_stats_depth = 3
streaming_buffer_size_mb = 256
```

**SWIFT Engine (Ultra-low Latency):**
```toml
[storage.engines.swift]
enable_proxima_encoding = true
memory_pool_size_mb = 128
prefetch_buffer_size_kb = 64
```

**RAPTOR Engine (Adaptive):**
```toml
[storage.engines.raptor]
enable_pxk_optimization = true
workload_adaptation_interval_ms = 5000
row_group_auto_sizing = true
```

**HELIX Engine (Spatial Locality):**
```toml
[storage.engines.helix]
hilbert_curve_order = 8
spatial_grouping_threshold = 0.85
enable_liquid_clustering = true
```

=== Performance Optimization

**Hardware Acceleration:**
```toml
[compute]
# Enable SIMD optimization (20M+ ops/sec)
enable_simd = true
auto_hardware_detection = true
simd_instruction_set = "auto"  # auto, avx2, neon, sse

# GPU acceleration (if available)
enable_gpu = false
gpu_memory_limit_gb = 8
```

**Memory Management:**
```toml
[memory]
# Total memory budget
max_memory_usage_gb = 32
cache_size_gb = 8
buffer_pool_size_gb = 4

# Memory pressure handling
enable_memory_monitoring = true
memory_pressure_threshold = 0.85
```

**Concurrency Settings:**
```toml
[concurrency]
max_concurrent_queries = 100
query_timeout_seconds = 30
background_thread_count = 4
io_thread_pool_size = 8
```

== **Production Deployment Steps**

=== Step 1: Environment Preparation

**System Requirements:**
```bash
# Minimum production requirements
CPU: 8 cores, x86_64 or ARM64
RAM: 16GB (32GB recommended)
Storage: 100GB SSD (NVMe recommended)
Network: 1Gbps (10Gbps recommended)

# Install dependencies
sudo apt update
sudo apt install -y build-essential pkg-config libssl-dev
```

**Directory Structure:**
```bash
# Create production directories
sudo mkdir -p /var/lib/proximadb/{data,metadata,wal,logs}
sudo mkdir -p /etc/proximadb
sudo chown -R proximadb:proximadb /var/lib/proximadb
sudo chmod 755 /var/lib/proximadb
```

=== Step 2: Security Configuration

**Authentication Setup:**
```toml
[auth]
enable_authentication = true
jwt_secret = "your-secure-jwt-secret-key"
token_expiry_hours = 24

[security]
enable_tls = true
cert_file = "/etc/proximadb/server.crt"
key_file = "/etc/proximadb/server.key"
```

**Create Service User:**
```bash
# Create dedicated user
sudo useradd -r -s /bin/false -d /var/lib/proximadb proximadb
sudo usermod -a -G proximadb proximadb
```

=== Step 3: Production Deployment

**Systemd Service File:**
```ini
# /etc/systemd/system/proximadb.service
[Unit]
Description=ProximaDB Vector Database
After=network.target

[Service]
Type=simple
User=proximadb
Group=proximadb
ExecStart=/usr/local/bin/proximadb-server --config /etc/proximadb/production.toml
Restart=always
RestartSec=5
Environment=RUST_LOG=info

[Install]
WantedBy=multi-user.target
```

**Deploy and Start:**
```bash
# Copy binary to system location
sudo cp target/release-server/proximadb-server /usr/local/bin/
sudo chmod +x /usr/local/bin/proximadb-server

# Copy configuration
sudo cp config/production.toml /etc/proximadb/

# Start service
sudo systemctl daemon-reload
sudo systemctl start proximadb
sudo systemctl enable proximadb

# Verify status
sudo systemctl status proximadb
```

=== Step 4: Health Verification

**Basic Health Check:**
```bash
# Test REST API
curl http://localhost:5678/health

# Test gRPC (requires grpc-health-probe)
grpc-health-probe -addr=localhost:5679

# Check server logs
sudo journalctl -u proximadb -f
```

**Create Test Collection:**
```bash
# Create test collection with SST engine
curl -X POST http://localhost:5678/v1/collections \
  -H "Content-Type: application/json" \
  -d '{
    "name": "production_test",
    "dimension": 768,
    "engine": "SST"
  }'

# Insert test vectors
curl -X POST http://localhost:5678/v1/collections/production_test/vectors \
  -H "Content-Type: application/json" \
  -d '{
    "vectors": [{
      "id": "test_1",
      "values": [0.1, 0.2, 0.3, ...],
      "metadata": {"env": "production"}
    }]
  }'

# Test search
curl -X POST http://localhost:5678/v1/collections/production_test/search \
  -H "Content-Type: application/json" \
  -d '{
    "query_vector": [0.1, 0.2, 0.3, ...],
    "top_k": 5
  }'
```

== **Backup and Recovery**

=== Backup Strategy

**Write-Ahead Log (WAL) Backup:**
```bash
# WAL provides ACID compliance and point-in-time recovery
cp -r /var/lib/proximadb/wal /backup/proximadb/wal-$(date +%Y%m%d)
```

**Full Data Backup:**
```bash
# Stop service for consistent backup
sudo systemctl stop proximadb

# Backup data directory
tar -czf /backup/proximadb-full-$(date +%Y%m%d).tar.gz \
  /var/lib/proximadb/data \
  /var/lib/proximadb/metadata \
  /var/lib/proximadb/wal

# Restart service
sudo systemctl start proximadb
```

**Incremental Backup (Recommended):**
```bash
# Use rsync for efficient incremental backups
rsync -av --delete /var/lib/proximadb/ /backup/proximadb-incremental/
```

=== Recovery Procedures

**Point-in-Time Recovery:**
```bash
# Stop service
sudo systemctl stop proximadb

# Restore data from backup
rm -rf /var/lib/proximadb/data
tar -xzf /backup/proximadb-full-YYYYMMDD.tar.gz -C /

# WAL replay (automatic on startup)
sudo systemctl start proximadb

# Verify recovery
curl http://localhost:5678/health
```

== **Troubleshooting Guide**

=== Common Issues

**Port Conflicts:**
```bash
# Check port usage
lsof -i :5678
lsof -i :5679

# Kill conflicting processes
kill -9 $(lsof -t -i :5678)
```

**Memory Issues:**
```bash
# Check memory usage
free -h
cat /proc/$(pgrep proximadb-server)/status | grep Vm

# Adjust memory limits in configuration
[memory]
max_memory_usage_gb = 16  # Reduce if needed
```

**Storage Issues:**
```bash
# Check disk space
df -h /var/lib/proximadb

# Clean up old WAL files (if enabled)
find /var/lib/proximadb/wal -name "*.log" -mtime +7 -delete
```

**Performance Issues:**
```bash
# Check SIMD availability
cat /proc/cpuinfo | grep -i avx2

# Verify engine selection
curl http://localhost:5678/v1/collections/collection_name | jq '.engine'

# Run performance diagnostics
cargo run --release --bin proximadb-bench -- --diagnostic
```
