== Overview

ProximaDB exposes comprehensive **Unified Intelligence APIs** via gRPC (port 5679) and REST (port 5678) for vector search, graph operations, and semantic knowledge store (SKS) capabilities. The platform features **automated API orchestration** that intelligently routes requests to appropriate engines.

**Three API Categories:**
- **Vector APIs**: Multimodal semantic search (text, image, video, audio)
- **Graph APIs**: Relationship modeling, traversal, and analysis  
- **SKS APIs**: Hybrid vector+graph intelligence with context assembly

**API Benefits:**
- **Serverless-Ready**: Zero infrastructure management required
- **Auto-Orchestration**: Intelligent routing eliminates manual integration
- **Performance Optimized**: gRPC for throughput, REST for compatibility
- **Type-Safe**: Protocol buffer definitions ensure consistency

== Collections

=== Create Collection

.gRPC Example
[source,python]
----
request = CollectionRequest(
    operation=CollectionOperation.COLLECTION_CREATE,
    collection_config=CollectionConfig(
        name="embeddings",
        dimension=1536,
        distance_metric=DistanceMetric.COSINE,
        storage_engine=StorageEngine.VIPER,
        index_configs=[
            IndexConfig(
                algorithm=IndexingAlgorithm.HNSW
            )
        ]
    )
)
response = stub.CollectionOperation(request)

== Vector Operations

=== Insert Vectors

.gRPC Example (typed metadata oneof)
[source,python]
----
vectors = [
    VectorRecord(
        id="vec_001",
        vector=[0.1, 0.2, ...],  # 1536 dimensions
        metadata=[
            MetadataItem(
                key="category",
                value=MetadataItem.Value(string_value="product")
            ),
            MetadataItem(
                key="price",
                value=MetadataItem.Value(number_value=29.99)
            ),
            MetadataItem(
                key="in_stock",
                value=MetadataItem.Value(bool_value=True)
            ),
        ]
    )
]
request = VectorBatchRequest(
    collection_id="embeddings",
    vectors=vectors
)
response = stub.VectorBatch(request)
----

.REST Example
[source,json]
----
POST /api/v1/collections/embeddings/vectors
{
    "vectors": [
        {
            "id": "vec_001",
            "vector": [0.1, 0.2, ...],
            "metadata": {
                "category": "product",
                "price": 29.99
            }
        }
    ]
}
----

== Advanced Features

=== Filtered Search

[source,python]
----
# Search with metadata filters
request = VectorSearchRequest(
    collection_id="embeddings",
    queries=[
        SearchQuery(
            vector=[...],
            metadata_filter=MetadataFilter(
                conditions=[
                    FilterCondition(
                        field_name="category",
                        operation=FilterOperation.EQUALS,
                        value=MetadataValue(string_value="product")
                    ),
                    FilterCondition(
                        field_name="price",
                        operation=FilterOperation.GREATER_THAN_OR_EQUAL,
                        value=MetadataValue(number_value=20.0)
                    ),
                    FilterCondition(
                        field_name="price",
                        operation=FilterOperation.LESS_THAN_OR_EQUAL,
                        value=MetadataValue(number_value=100.0)
                    )
                ],
                operator=FilterOperator.AND
            )
        )
    ],
    top_k=10
)
----

=== Batch Operations

[source,python]
----
# Batch search
requests = [
    SearchQuery(vector=[...]),
    SearchQuery(vector=[...])
]
request = VectorSearchRequest(
    collection_id="embeddings",
    queries=requests,
    top_k=5
)
response = stub.VectorSearch(request)

# Batch delete
request = VectorBatchRequest(
    collection_id="embeddings",
    vectors=[
        VectorRecord(id="vec_001", expires_at=int(time.time())),
        VectorRecord(id="vec_002", expires_at=int(time.time())),
        VectorRecord(id="vec_003", expires_at=int(time.time()))
    ]
)
response = stub.VectorBatch(request)
----

== Distance Metrics

[cols="1,2,1,2", options="header"]
|===
| Metric | Description | Range | Use Case

| `COSINE`
| Cosine similarity
| [0, 2]
| Text embeddings

| `EUCLIDEAN`
| L2 distance
| [0, ∞)
| General purpose

| `DOT_PRODUCT`
| Inner product
| (-∞, ∞)
| Normalized vectors

| `MANHATTAN`
| L1 distance
| [0, ∞)
| Sparse vectors

| `HAMMING`
| Bit differences
| [0, n]
| Binary vectors
|===

== Storage Engines

[cols="1,2,2", options="header"]
|===
| Engine | Description | Best For

| `VIPER`
| Columnar storage
| Analytics, batch operations

| `SST`
| LSM-tree based
| High write throughput

| `RAPTOR`
| HNSW integrated
| Graph-based search

| `NOVA`
| Zone maps
| Range queries

| `SWIFT`
| Adaptive blocks
| Mixed workloads

| `PRISM`
| Progressive search
| Large-scale search
|===

== Error Codes

[cols="1,2,2", options="header"]
|===
| Code | Description | Resolution

| `INVALID_ARGUMENT`
| Invalid parameters
| Check request format

| `NOT_FOUND`
| Collection/vector not found
| Verify resource exists

| `ALREADY_EXISTS`
| Duplicate resource
| Use update instead

| `RESOURCE_EXHAUSTED`
| Out of memory/disk
| Scale resources

| `INTERNAL`
| Server error
| Check server logs

=== Progressive Search (REST)

.GET query variant (for small vectors)
[source,http]
----
GET /api/v1/progressive/search/{collection_id}?k=10&include_metadata=true&include_vectors=false
----

.POST JSON variant (preferred)
[source,json]
----
POST /api/v1/progressive/search/{collection_id}
{
  "vector": [0.12, 0.03, ...],
  "k": 10,
  "scenario": "high_recall",
  "include_vectors": false,
  "include_metadata": true
}
----

.Explain stages
[source,http]
----
GET /api/v1/progressive/explain/{collection_id}?k=10&scenario=balanced
----

Response returns SearchVectorRecord fields (proto) for results and stage plan for explain. Use the POST variant for larger inputs.
