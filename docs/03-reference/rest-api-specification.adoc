== Overview

ProximaDB provides a RESTful HTTP API that mirrors the gRPC API functionality using a **proto-first JSON encoding** approach. All requests and responses use Protocol Buffer message definitions serialized as JSON.

**Key Characteristics:**
* **Protocol Buffer First**: All data types defined in `proto/proximadb.proto`
* **JSON Encoding**: Proto messages serialized as JSON for REST compatibility
* **Zero Code Duplication**: Same business logic serves both REST and gRPC
* **Compression Support**: Automatic response compression (deflate, gzip, zstd, brotli)
* **CORS Enabled**: Cross-origin requests supported by default

[cols="2,3", options="header"]
|===
| Property | Value
| Base URL | {base-url}
| API Version | {api-version}
| Default Port | 5678
| Protocol | HTTP/1.1, HTTP/2
| Content-Type | application/json
| Compression | deflate, gzip, zstd, brotli
| Max Request Size | 64MB (configurable)
| Authentication | Token-based (when enabled)
|===

== Quick Start

=== Health Check

[source,bash]
----
curl http://localhost:5678/health
----

**Response:**
[source,json]
----
{
  "status": "healthy",
  "timestamp": "2025-01-15T10:30:00Z",
  "version": "2.0.0",
  "services": {
    "rest_api": "operational",
    "storage": "operational",
    "indexing": "operational"
  }
}
----

=== Create Collection

[source,bash]
----
curl -X POST http://localhost:5678/api/v1/collections \
  -H "Content-Type: application/json" \
  -d '{
    "operation": 0,
    "collection_id": "my_vectors",
    "collection_config": {
      "dimension": 768,
      "storage_engine": "viper",
      "distance_metric": "cosine"
    }
  }'
----

=== Insert Vectors

[source,bash]
----
curl -X POST http://localhost:5678/api/v1/vectors/batch \
  -H "Content-Type: application/json" \
  -d '{
    "collection_id": "my_vectors",
    "operation": "insert",
    "vectors": [
      {
        "id": "vec_001",
        "vector": [0.1, 0.2, ...],
        "metadata": {
          "category": {"stringValue": "product"},
          "price": {"numberValue": 29.99}
        }
      }
    ]
  }'
----

=== Search Vectors

[source,bash]
----
curl -X POST http://localhost:5678/api/v1/search \
  -H "Content-Type: application/json" \
  -d '{
    "collection_id": "my_vectors",
    "query_vector": [0.1, 0.2, ...],
    "top_k": 10,
    "metadata_filters": [
      {
        "field": "category",
        "operator": "EQUALS",

=== Collection Management

==== POST /api/v1/collections

Unified endpoint for all collection operations (create, update, delete, get, list).

**Request Body (CollectionRequest):**
[source,json]
----
{
  "operation": 0,  // CollectionOperation enum
  "collection_id": "string",
  "collection_config": {
    "dimension": 768,
    "storage_engine": "viper",
    "distance_metric": "cosine",
    "quantization": {
      "enabled": true,
      "level": "pq8"
    }
  },
  "query_params": {},
  "options": {},
  "migration_config": {}
}
----

**CollectionOperation Enum:**
[cols="1,2,4"]
|===
| Value | Name | Description
| 0 | COLLECTION_CREATE | Create new collection
| 1 | COLLECTION_UPDATE | Update collection configuration
| 2 | COLLECTION_DELETE | Delete collection
| 3 | COLLECTION_GET | Get collection details
| 4 | COLLECTION_LIST | List all collections
| 5 | COLLECTION_STATS | Get collection statistics
|===

**CollectionConfig Fields:**
[cols="2,1,1,4"]
|===
| Field | Type | Required | Description
| dimension | uint32 | Yes | Vector dimensionality
| storage_engine | string | Yes | Engine: sst, viper, nova, swift, raptor, helix
| distance_metric | string | Yes | Metric: cosine, euclidean, dot_product
| quantization.enabled | bool | No | Enable quantization
| quantization.level | string | No | Level: binary, int8, pq4, pq8, pq16, pq32
| index_type | string | No | Index: hnsw, ivf, lsh, annoy
| replication_factor | uint32 | No | Replication count (default: 1)
|===

**Response (CollectionResponse):**
[source,json]
----
{
  "success": true,
  "collection": {
    "collection_id": "my_vectors",
    "config": { ... },
    "stats": {
      "vector_count": 10000,
      "size_bytes": 31457280,
      "created_at": 1704067200,
      "updated_at": 1704153600
    }
  },
  "message": "Collection created successfully"
}
----

**Status Codes:**
* `200 OK` - Operation successful
* `400 Bad Request` - Invalid request
* `404 Not Found` - Collection not found
* `409 Conflict` - Collection already exists
* `500 Internal Server Error` - Server error

**Example - Create Collection:**
[source,bash]
----
curl -X POST http://localhost:5678/api/v1/collections \
  -H "Content-Type: application/json" \
  -d '{
    "operation": 0,
    "collection_id": "product_embeddings",
    "collection_config": {
      "dimension": 1536,
      "storage_engine": "viper",
      "distance_metric": "cosine",
      "quantization": {
        "enabled": true,
        "level": "pq8"
      },
      "index_type": "hnsw"
    }
  }'
----

=== Vector Operations

==== POST /api/v1/vectors/batch

Batch vector operations (insert, update, delete, upsert).

**Request Body (VectorBatchRequest):**
[source,json]
----
{
  "collection_id": "my_vectors",
  "operation": "insert",
  "vectors": [
    {
      "id": "vec_001",
      "vector": [0.1, 0.2, 0.3, ...],
      "metadata": {
        "category": {"stringValue": "product"},
        "price": {"numberValue": 29.99},
        "in_stock": {"boolValue": true}
      },
      "timestamp": 1704067200,
      "version": 1
    }
  ],
  "options": {
    "skip_duplicates": false,
    "return_errors": true
  }
}
----

**Operation Types:**
* `insert` - Insert new vectors (fails if ID exists)
* `update` - Update existing vectors (fails if ID doesn't exist)
* `upsert` - Insert or update vectors
* `delete` - Delete vectors by ID

**VectorRecord Fields:**
[cols="2,1,1,4"]
|===
| Field | Type | Required | Description
| id | string | Yes | Unique vector identifier
| vector | float32[] | Yes* | Vector embeddings (*not required for delete)
| metadata | map | No | Key-value metadata
| timestamp | int64 | No | Unix timestamp (auto if not provided)
| version | uint32 | No | Version for MVCC (default: 1)
| expires_at | int64 | No | TTL expiration timestamp
|===

**Metadata Value Types:**
[source,json]
----
{
  "stringValue": "text",      // String type
  "numberValue": 123.45,       // Numeric type (f64)
  "boolValue": true,           // Boolean type
  "arrayValue": [...],         // Array of values
  "nullValue": null            // Null value
}
----

**Response (VectorOperationResponse):**
[source,json]
----
{
  "success": true,
  "vectors_affected": 1000,
  "vectors_inserted": 1000,
  "vectors_updated": 0,
  "vectors_deleted": 0,
  "errors": [],
  "execution_time_ms": 45,
  "message": "Batch insert completed successfully"
}
----

**Status Codes:**
* `200 OK` - Operation completed
* `400 Bad Request` - Invalid request
* `404 Not Found` - Collection not found
* `413 Payload Too Large` - Batch exceeds size limit
* `500 Internal Server Error` - Server error

**Example - Insert Batch:**
[source,bash]
----
curl -X POST http://localhost:5678/api/v1/vectors/batch \
  -H "Content-Type: application/json" \
  -d '{
    "collection_id": "product_embeddings",
    "operation": "insert",
    "vectors": [
      {
        "id": "product_001",
        "vector": [0.1, 0.2, ...],
        "metadata": {
          "name": {"stringValue": "Laptop"},
          "price": {"numberValue": 999.99},
          "category": {"stringValue": "electronics"}
        }
      }
    ]
  }'
----

**Example - Delete Batch:**
[source,bash]
----
curl -X POST http://localhost:5678/api/v1/vectors/batch \
  -H "Content-Type: application/json" \
  -d '{
    "collection_id": "product_embeddings",
    "operation": "delete",
    "vectors": [
      {"id": "product_001"},
      {"id": "product_002"}
    ]
  }'
----

==== POST /api/v1/search

Vector similarity search with metadata filtering.

**Request Body (VectorSearchRequest):**
[source,json]
----
{
  "collection_id": "my_vectors",
  "query_vector": [0.1, 0.2, 0.3, ...],
  "top_k": 10,
  "metadata_filters": [
    {
      "field": "category",
      "operator": "EQUALS",
      "value": {"stringValue": "product"}
    },
    {
      "field": "price",
      "operator": "LESS_THAN",
      "value": {"numberValue": 100.0}
    }
  ],
  "options": {
    "include_vectors": false,
    "include_metadata": true,
    "min_score": 0.7
  }
}
----

**Filter Operators:**
[cols="2,4"]
|===
| Operator | Description
| EQUALS | Exact match
| NOT_EQUALS | Not equal
| LESS_THAN | Less than (numeric)
| LESS_THAN_OR_EQUAL | Less than or equal (numeric)
| GREATER_THAN | Greater than (numeric)
| GREATER_THAN_OR_EQUAL | Greater than or equal (numeric)
| IN | Value in list
| NOT_IN | Value not in list
| CONTAINS | String contains substring
| STARTS_WITH | String starts with prefix
| ENDS_WITH | String ends with suffix
|===

**Response:**
[source,json]
----
{
  "results": [
    {
      "id": "vec_001",
      "score": 0.95,
      "vector": [...],  // Only if include_vectors=true
      "metadata": {
        "category": {"stringValue": "product"},
        "price": {"numberValue": 29.99}
      }
    }
  ],
  "total_results": 1,
  "execution_time_ms": 12,
  "search_stats": {
    "vectors_scanned": 10000,
    "vectors_filtered": 500,
    "index_type": "hnsw"
  }
}
----

**Status Codes:**
* `200 OK` - Search successful
* `400 Bad Request` - Invalid request
* `404 Not Found` - Collection not found
* `500 Internal Server Error` - Server error

**Example:**
[source,bash]
----
curl -X POST http://localhost:5678/api/v1/search \
  -H "Content-Type: application/json" \
  -d '{
    "collection_id": "product_embeddings",
    "query_vector": [0.1, 0.2, ...],
    "top_k": 5,
    "metadata_filters": [
      {
        "field": "category",
        "operator": "EQUALS",
        "value": {"stringValue": "electronics"}
      }
    ],
    "options": {
      "include_metadata": true,
      "min_score": 0.8
    }
  }'
----

== Authentication

When authentication is enabled, include a bearer token:

[source,http]
----
POST /api/v1/search HTTP/1.1
Host: localhost:5678
Authorization: Bearer <your-token>
Content-Type: application/json
----

**Token Format:**
* JWT (JSON Web Token) with ProximaDB claims
* Expires after configured duration
* Can be refreshed before expiration

== Compression

Responses are automatically compressed if client supports it.

**Request:**
[source,http]
----
GET /api/v1/collections HTTP/1.1
Accept-Encoding: gzip, deflate, br, zstd
----

**Compression Algorithms (priority order):**
1. **deflate** - Fastest, low CPU
2. **gzip** - Good balance
3. **zstd** - Best compression
4. **brotli** - Excellent for text

== Best Practices

=== Batch Operations

✅ **DO**: Use batch endpoints for multiple operations
[source,bash]
----
# Good: Single batch request
curl -X POST /api/v1/vectors/batch -d '{
  "vectors": [vec1, vec2, vec3, ...]
}'
----

❌ **DON'T**: Make individual requests
[source,bash]
----
# Bad: Multiple individual requests
for vec in vectors:
    curl -X POST /api/v1/vectors/batch -d '{"vectors": [vec]}'
----

=== Query Optimization

✅ **DO**: Use metadata filters to reduce search space
[source,json]
----
{
  "metadata_filters": [
    {"field": "category", "operator": "EQUALS", "value": {"stringValue": "active"}}
  ]
}
----

✅ **DO**: Set appropriate `top_k` values (10-100)

❌ **DON'T**: Request more results than needed

=== Error Handling

✅ **DO**: Implement retry logic with exponential backoff
[source,python]
----
for attempt in range(3):
    try:
        response = requests.post(url, json=data)
        response.raise_for_status()
        break
    except requests.exceptions.RequestException:
        time.sleep(2 ** attempt)
----

=== Connection Pooling

✅ **DO**: Reuse HTTP connections
[source,python]
----
session = requests.Session()
session.post(url, json=data)  # Reuses connection
----
