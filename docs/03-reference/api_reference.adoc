= REST API Reference

This document provides a reference for the ProximaDB REST API.

[NOTE]
====
This file is a summary. The canonical, full reference is link:rest-api-specification.adoc[REST API Specification].
====

== Collections

=== Create Collection

* **POST** `/api/v1/collections`

Creates a new collection.

.Request Body
[source,json]
----
{
  "operation": "COLLECTION_CREATE",
  "collection_config": {
    "name": "my_collection",
    "dimension": 1536,
    "distance_metric": "cosine",
    "storage_engine": "nova"
  }
}
----

=== List Collections

* **GET** `/api/v1/collections`

Lists all collections.

.Query Parameters
* `limit` (optional, integer): The maximum number of collections to return.
* `offset` (optional, integer): The number of collections to skip.

=== Get Collection

* **GET** `/api/v1/collections/{collection_id}`

Gets information about a single collection.

=== Delete Collection

* **DELETE** `/api/v1/collections/{collection_id}`

Deletes a collection.

== Vectors

=== Batch Operations

* **POST** `/api/v1/vectors/batch`

Inserts, updates, or deletes a batch of vectors.

.Request Body
[source,json]
----
{
  "collection_id": "my_collection",
  "vectors": [
    {
      "id": "vector_1",
      "vector": [0.1, 0.2, 0.3],
      "metadata": {"key": "value"}
    },
    {
      "id": "vector_2",
      "vector": [0.4, 0.5, 0.6],
      "metadata": {"key": "value2"}
    }
  ]
}
----

=== Get Vector

* **GET** `/api/v1/vectors/{collection_id}/{vector_id}`

Gets a single vector by its ID.

.Query Parameters
* `include_vector` (optional, boolean): Whether to include the vector data in the response. Defaults to `true`.
* `include_metadata` (optional, boolean): Whether to include the vector's metadata in the response. Defaults to `true`.

=== Delete Vector

* **DELETE** `/api/v1/vectors/{collection_id}/{vector_id}`

Deletes a single vector by its ID.

=== Search

* **POST** `/api/v1/search`

Performs a vector similarity search.

.Request Body
[source,json]
----
{
  "collection_id": "my_collection",
  "queries": [
    {
      "vector": [0.1, 0.2, 0.3],
      "filters": {"key": "value"}
    }
  ],
  "top_k": 10
}
----

== SQL

=== Execute SQL

* **POST** `/api/v1/sql/execute`

Executes an SQL query.

.Request Body
[source,json]
----
{
  "query": "SELECT id, metadata FROM my_collection WHERE metadata.key = 'value' LIMIT 10"
}
----

=== Explain SQL

* **POST** `/api/v1/sql/explain`

Explains an SQL query, showing the execution plan.

.Request Body
[source,json]
----
{
  "query": "SELECT id, metadata FROM my_collection WHERE metadata.key = 'value' LIMIT 10"
}
----

== Health

=== Health Check

* **GET** `/health`

Performs a comprehensive health check of the system.

=== Liveness Check

* **GET** `/health/live`

Performs a simple liveness check.

=== Readiness Check

* **GET** `/health/ready`

Performs a readiness check to see if the system is ready to accept traffic.
