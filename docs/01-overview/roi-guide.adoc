== ROI Guide: Lower TCO, Higher Impact

=== Cost Levers
- Progressive search: cut FP32 work by 60–80% via Binary/INT8/PQ staging.
- SIMD acceleration: 2–6× distance throughput on modern CPUs.
- Storage: columnar and compressed layouts reduce bytes scanned and stored.

=== Value Levers
- Faster answers → fewer escalations, higher CSAT, higher win rates.
- Explainability → better auditability and risk acceptance.
- Platform consolidation → lower integration and vendor costs.

=== Example Model (Illustrative)
[cols="1,1", options="header"]
|===
| Lever | Benefit
| Compute | 30–50% reduction via progressive search and SIMD
| Storage | 20–40% reduction via compression and pruning
| Support | 10–25% fewer escalations; faster resolution time
| Sales | 5–10% higher reuse → shorter cycle time
|===

=== Proving It (Pilot KPIs)
- Latency (P50/P95), $/1k queries, precision@k/recall@k
- CSAT/NPS changes in support/search portals
- Agent task time; content reuse/duplication rates

Start small, measure weekly, expand scope as gains persist.
