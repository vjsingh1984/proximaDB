= Testing & Development
:toc: left

Testing strategies, development workflows, and debugging guide for ProximaDB.

== Testing Strategy

**Test Coverage**: Core services 450+ tests (95%), storage engines 380+ tests (92%), API handlers 250+ tests (88%), Python SDK 170+ tests (64%).

**Unit Tests**: `cargo test --lib` for all, `cargo test storage::engines::sst` for specific modules, `cargo test -- --nocapture` for output.

**Integration Tests**: `cargo test --test '*'` for all, `cargo test --test vector_operations` for specific tests, `cargo test --release` for faster execution.

**Python SDK Tests**: `pytest tests/ -v` for testing, `pytest tests/ --cov=proximadb --cov-report=html` for coverage.

== Development Workflow

**Setup**: Clone repository, install Rust stable, cargo-watch, cargo-tarpaulin. Setup Python with `pip install -e ".[dev]"`.

**Development Server**: Use `cargo watch -x 'run --bin proximadb-server'` for auto-restart, `RUST_LOG=debug` for debug logging, `--config dev.toml` for custom config.

**Code Quality**: `cargo fmt` for formatting, `cargo clippy -- -D warnings` for linting, `cargo audit` for dependency checks.

== Debugging Guide

**Debug Logging**: Set `log_level = "debug"` in config.toml or use `RUST_LOG=proximadb=debug,tower_http=debug`.

**Memory Issues**: Use `valgrind --leak-check=full` for memory leak detection.

**Performance Issues**: Use `perf record/report` for CPU profiling, `cargo flamegraph` for flame graphs.

**Test Failures**: Use `RUST_BACKTRACE=1 cargo test test_name -- --exact` for detailed traces, `cargo test -- --test-threads=1` for sequential execution.

== Benchmarking

**Running**: `cargo bench` for all, `cargo bench vector_insert` for specific tests, `cargo bench -- --save-baseline main` for comparisons.

**Writing**: Use criterion crate with `black_box` for preventing optimizations, benchmark functions with `b.iter()` loops.

== CI/CD Pipeline

**GitHub Actions**: Automated testing on push/PR with `cargo test --all`, `cargo fmt --check`, `cargo clippy -- -D warnings`.

**Pre-commit Hooks**: Format check, linting, and lib tests before commits.

== Release Process

**Version Bumping**: Use `cargo set-version 1.0.1` for Rust, `poetry version 1.0.1` for Python SDK.

**Building**: `cargo build --release` for optimized binary, `docker build -t proximadb:latest` for container, `poetry build` for Python wheel.

**Testing**: Verify binary version, Docker image functionality, and Python package installation.
