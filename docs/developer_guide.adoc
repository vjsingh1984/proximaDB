=== Environment Setup

[source,bash]
----
# Clone repository
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb

# Install Rust toolchain
rustup toolchain install stable
rustup component add rustfmt clippy

# Install development tools
cargo install cargo-watch cargo-tarpaulin

# Setup Python development
cd clients/python
pip install -e ".[dev]"
cd ../..

# Build and test
cargo build --release
cargo test --all
----

=== Running Tests

**Rust Tests:**

[source,bash]
----
# All tests
cargo test --all

# Specific module
cargo test storage::engines::sst

# With debug output  
cargo test -- --nocapture

# Release mode (faster)
cargo test --release

# Integration tests only
cargo test --test '*'
----

**Python SDK Tests:**

[source,bash]
----
# All Python tests
PYTHONPATH=clients/python/src pytest clients/python/tests/ -v

# With coverage report
pytest clients/python/tests/ --cov=proximadb --cov-report=html

# Performance tests
pytest clients/python/tests/test_performance.py --benchmark-only
----

== APIs

=== gRPC Service
* CreateCollection, GetCollection, ListCollections
* InsertVector, SearchVectors, BatchInsert
* HealthCheck

=== REST Endpoints
* **Base URL**: `http://localhost:5678`
* **POST** `/collections` - Create collection
* **POST** `/collections/{id}/vectors` - Insert vectors
* **POST** `/collections/{id}/search` - Search vectors

== Client SDK

=== Python SDK
[source,bash]
----
cd clients/python
pip install -e .
----

[source,python]
----
from proximadb import ProximaDBClient

client = ProximaDBClient("localhost:5678")

# Create collection
collection_id = await client.create_collection({
    "name": "embeddings",
    "dimension": 768
})

# Insert vectors
await client.insert_vectors(collection_id, vectors)

# Search
results = await client.search_vectors(
    collection_id, query_vector, k=10
)
----

== SQL Interface

=== Supported Features
* Basic SELECT with WHERE
* Equality operators (=, IN)
* Vector similarity search
* JSON metadata extraction

[source,sql]
----
SELECT id, metadata
FROM my_collection  
WHERE metadata->>'category' = 'electronics'
ORDER BY VECTOR_SIMILARITY(vector, [0.1, 0.2], 'cosine')
LIMIT 10
----

== Deployment

----

[source,bash]

----
