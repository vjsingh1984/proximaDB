= Developer Guide
:toc: left

== Setup

=== Requirements
* Rust 1.75+
* Python 3.8+
* Docker 20.10+

=== Quick Start
[source,bash]
----
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb
cargo build --release
----

== Project Structure
```
proximadb/
├── src/           # Rust source code
├── clients/       # Client SDKs  
├── proto/         # Protocol buffer definitions
├── tests/         # Integration tests
└── config/        # Configuration files
```

== Development

=== Build Commands
[source,bash]
----
cargo build                    # Development build
cargo build --release         # Production build
cargo test                     # Run tests
cargo clippy                   # Linting
----

== APIs

=== gRPC Service
* CreateCollection, GetCollection, ListCollections
* InsertVector, SearchVectors, BatchInsert
* HealthCheck

=== REST Endpoints
* **Base URL**: `http://localhost:5678`
* **POST** `/collections` - Create collection
* **POST** `/collections/{id}/vectors` - Insert vectors
* **POST** `/collections/{id}/search` - Search vectors

== Client SDK

=== Python SDK
[source,bash]
----
cd clients/python
pip install -e .
----

[source,python]
----
from proximadb import ProximaDBClient

client = ProximaDBClient("localhost:5678")

# Create collection
collection_id = await client.create_collection({
    "name": "embeddings",
    "dimension": 768
})

# Insert vectors
await client.insert_vectors(collection_id, vectors)

# Search
results = await client.search_vectors(
    collection_id, query_vector, k=10
)
----

== SQL Interface

=== Supported Features
* Basic SELECT with WHERE
* Equality operators (=, IN)
* Vector similarity search
* JSON metadata extraction

[source,sql]
----
SELECT id, metadata
FROM my_collection  
WHERE metadata->>'category' = 'electronics'
ORDER BY VECTOR_SIMILARITY(vector, [0.1, 0.2], 'cosine')
LIMIT 10
----

== Testing

=== Run Tests
[source,bash]
----
cargo test                     # All tests
cargo test storage::           # Specific module
cargo test --test integration  # Integration tests
----

=== Python SDK Tests
[source,bash]
----
cd clients/python
pip install -r requirements.txt
pytest tests/
----

== Configuration

[source,toml]
----
[server]
host = "127.0.0.1"
port = 5678

[storage]
engine = "viper"
data_dir = "/data/proximadb"
----
