**Centralized Detection**: One-time hardware capability detection at server startup eliminates repeated overhead and provides consistent access across all modules.

[source,rust]
----
// Global hardware capabilities access
let caps = get_hardware_capabilities();
if caps.has_avx512() && caps.config.enable_simd {
    // Use AVX-512 acceleration
}
----

**Hardware Features**:
- **CPU Detection**: Physical/logical cores, vendor identification, model detection
- **SIMD Capabilities**: AVX-512, AVX2, SSE4.1, SSE, NEON, FMA support
- **GPU Backends**: CUDA, ROCm, MPS (Apple), OpenCL with automatic detection
- **Memory Information**: Total/available memory, cache size recommendations
- **Configuration Integration**: Respects TOML hardware configuration flags

**Performance Benefits**:
- **Initialization**: Single detection at startup vs repeated checks
- **Thread Safety**: `OnceLock` pattern for safe concurrent access
- **Fallback Logic**: Intelligent degradation when hardware unavailable
- **Testing Support**: Deterministic initialization for test environments

== Advanced SQL Processing

**GPU-Accelerated SQL Parser**: High-performance SQL parsing with GPU tokenization and intelligent CPU fallback for complex grammar processing.

**SIMD Vector Parser**: Multi-tier SIMD acceleration for large vector array parsing with comprehensive performance monitoring.

[source,rust]
----
// GPU SQL parsing
let mut parser = GpuSqlParser::new()?;
let query = parser.parse(sql)?; // GPU tokenization + CPU grammar

// SIMD vector parsing  
let mut simd_parser = SimdVectorParser::new();
let vectors = simd_parser.parse_vector_array(&input)?; // AVX2/SSE4.1/scalar
----

**SQL Acceleration Features**:
- **Multi-GPU Support**: CUDA, ROCm, MPS, OpenCL backends
- **Performance Statistics**: GPU vs CPU parsing metrics
- **Complex Query Support**: VECTOR_SIMILARITY with array literals
- **Global Parser Instances**: Thread-safe singleton patterns

== Key Design Patterns

**Proto-First Architecture**: REST/gRPC → Proto → DirectVectorService → Storage. Benefits: zero double serialization, consistent data model, efficient transport.

**Unified Interfaces**: Trait-based design with UnifiedMemtable, UnifiedSearchEngine, UnifiedAtomicCoordinator, BloomFilterStrategy.

**Memory Optimization**: Vector Memory Pool (30-50% allocation reduction), RAII pooling, zero-copy bytemuck, adaptive ZSTD compression.
