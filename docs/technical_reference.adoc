== API Reference

=== REST API

==== Collections

[source,http]
----
# Create collection
POST /collections
{
  "name": "my_collection",
  "dimension": 384,
  "engine": "viper"
}

# Get collection
GET /collections/{name}

# Delete collection
DELETE /collections/{name}

# List collections
GET /collections
----

==== Vectors

[source,http]
----
# Insert vectors
POST /collections/{name}/vectors
{
  "vectors": [
    {
      "id": "vec1",
      "vector": [0.1, 0.2, ...],
      "metadata": {"key": "value"}
    }
  ]
}

# Search vectors
POST /collections/{name}/search
{
  "vector": [0.1, 0.2, ...],
  "top_k": 10,
  "metadata_filter": {"key": "value"}
}

# Get vector
GET /collections/{name}/vectors/{id}

# Delete vector
DELETE /collections/{name}/vectors/{id}
----

=== gRPC API

[source,proto]
----
service ProximaDB {
  // Collection operations
  rpc CreateCollection(CreateCollectionRequest) returns (Collection);
  rpc GetCollection(GetCollectionRequest) returns (Collection);
  rpc DeleteCollection(DeleteCollectionRequest) returns (Empty);
  
  // Vector operations
  rpc InsertVectors(VectorBatchRequest) returns (VectorBatchResponse);
  rpc SearchVectors(VectorSearchRequest) returns (VectorSearchResponse);
  rpc GetVector(GetVectorRequest) returns (VectorRecord);
}
----

=== SQL Interface

[source,sql]
----
-- Create collection
CREATE COLLECTION my_collection (dimension=384, engine='viper');

-- Insert vectors
INSERT INTO my_collection (id, vector, metadata) 
VALUES ('vec1', [0.1, 0.2, ...], '{"key": "value"}');

-- Search vectors
SELECT id, metadata, similarity(vector, [0.1, 0.2, ...]) as score
FROM my_collection
WHERE metadata->>'key' = 'value'
ORDER BY score DESC
LIMIT 10;

-- Delete vectors
DELETE FROM my_collection WHERE id = 'vec1';
----

== Configuration Reference

=== Configuration

**Server**: REST port 5678, gRPC port 5679, configurable worker threads and connections

**Storage**: Dual engine (SST + VIPER), configurable data directory, write buffer settings

**Cloud Storage**: AWS S3, Azure Blob, Google Cloud Storage support with native authentication

== Distance Metrics

* **cosine**: Cosine similarity [0, 2]
* **euclidean**: L2 distance [0, ∞)  
* **dot_product**: Inner product (-∞, ∞)
* **manhattan**: L1 distance [0, ∞)
* **hamming**: Bit differences [0, n]
* **jaccard**: Set similarity [0, 1]

== Index Types

=== HNSW (Hierarchical Navigable Small World)
* Best for: High recall requirements
* Memory: O(M × N) where M is connections
* Build time: O(N log N)
* Search time: O(log N)

=== IVF (Inverted File)
* Best for: Large datasets
* Memory: O(N) + centroids
* Build time: O(N × K) clustering
* Search time: O(nprobe × N/K)

=== LSH (Locality Sensitive Hashing)
* Best for: Approximate matching
* Memory: O(L × N) where L is tables
* Build time: O(L × N)
* Search time: O(L)

=== Annoy (Approximate Nearest Neighbors)
* Best for: Memory-constrained
* Memory: O(N × n_trees)
* Build time: O(N × n_trees × log N)
* Search time: O(n_trees × log N)

== Error Codes

* **COLLECTION_NOT_FOUND**: Collection does not exist - Create collection first
* **DIMENSION_MISMATCH**: Vector dimension incorrect - Check collection dimension  
* **INVALID_METADATA**: Metadata parsing failed - Validate JSON format
* **STORAGE_ERROR**: Storage operation failed - Check disk space/permissions
* **TIMEOUT**: Operation timed out - Retry with backoff
