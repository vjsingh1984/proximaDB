== Executive Summary

RAPTOR (Row-Aligned Predicated Tensor Optimized Repository) is a high-performance storage engine for ProximaDB optimized for *HNSW locality*, *columnar tensor storage*, and *selective rowgroup loading*. It achieves sub-10ms search latency through intelligent data organization and SIMD acceleration.

| *1K Vector RowGroups*

| *Selective Loading*

=== HNSW Integration Strategy

==== Hybrid Approach (Implemented)

RAPTOR uses a *hybrid HNSW strategy* that combines:

1. **Local HNSW Segments**: Per-RowGroup graphs for locality
2. **Global HNSW Bridge**: Cross-RowGroup connectivity
3. **AXIS Integration**: Leverage existing in-memory infrastructure via EventLog

== Core Innovations

=== 1. Columnar Tensor Transformation

==== Row to Columnar Conversion

Traditional row storage wastes compression opportunities:
----
Vector_0: [d0, d1, d2, ..., d383]  // Poor compression
Vector_1: [d0, d1, d2, ..., d383]  // Similar values scattered
...
----

RAPTOR columnar storage maximizes compression:
----
Dimension_0: [v0_d0, v1_d0, ..., v999_d0]  // Delta encoding
Dimension_1: [v0_d1, v1_d1, ..., v999_d1]  // Frame-of-Reference
...
----

==== FastLanes Encoding Selection

[source,rust]
----
pub fn select_encoding(column: &[f32]) -> FastLanesScheme {
    let range = column.max() - column.min();
    let deltas = compute_deltas(column);
    
    if range < 1e-6 {
        FastLanesScheme::RunLength  // 50-100x compression
    } else if deltas.all_similar() {
        FastLanesScheme::Delta      // 10-20x compression
    } else if range < 10.0 {
        FastLanesScheme::FrameOfReference  // 4-8x compression
    } else {
        FastLanesScheme::BitPacked  // 2-4x compression
    }
}
----

==== Read Strategy Optimization

[source,rust]
----
pub enum ReadStrategy {
    Individual,     // 1-2 non-adjacent RGs
    Coalesced {     // Adjacent RGs within 1MB gap
        ranges: Vec<(u64, u64, Vec<u32>)>,
    },
    FullFile,       // >50% RGs needed
}

impl RowGroupCacheManager {
    fn optimize_read_strategy(&self, missing_ids: &[u32]) -> ReadStrategy {
        let missing_ratio = missing_ids.len() as f32 / total_rgs as f32;
        
        if missing_ratio > 0.5 {
            return ReadStrategy::FullFile;
        }
        
        // Coalesce adjacent RGs with <1MB gaps
        let ranges = self.coalesce_adjacent(missing_ids);
        
        if ranges.len() > 10 {
            return ReadStrategy::FullFile;
        }
        
        ReadStrategy::Coalesced { ranges }
    }
}

==== HNSW Locality Reorganization

[source,rust]
----
pub async fn reorganize_by_hnsw_locality(
    &self,
    vectors: Vec<VectorRecord>,
    hnsw_graph: &HnswGraph,
) -> Result<Vec<RowGroup>> {
    let mut row_groups = Vec::new();
    let adjacency = self.build_adjacency_map(hnsw_graph);
    
    // BFS traversal for locality
    for entry_point in &hnsw_graph.entry_points {
        let mut current_group = Vec::new();
        let mut queue = vec![entry_point];
        
        while let Some(node) = queue.pop() {
            current_group.push(vectors[node]);
            
            // Start new group at 1K vectors
            if current_group.len() >= 1000 {
                row_groups.push(RowGroup::from(current_group));
                current_group = Vec::new();
            }
            
            // Add neighbors for locality
            queue.extend(adjacency.get(node));
        }
    }
    
    Ok(row_groups)
}

==== SIMD Operations

[source,rust]
----
impl RaptorReader {
    fn compute_distances(&self, query: &[f32], vectors: &[Vec<f32>]) -> Vec<f32> {
        let hardware = HardwareCapabilities::get();
        
        match hardware {
            _ if hardware.has_avx512() => self.distance_avx512(query, vectors),
            _ if hardware.has_avx2() => self.distance_avx2(query, vectors),
            _ if hardware.has_sse4() => self.distance_sse4(query, vectors),
            _ if hardware.has_neon() => self.distance_neon(query, vectors),
            _ => self.distance_scalar(query, vectors),
        }
    }
}

== Integration Points

=== With ProximaDB Core

* Implements `UnifiedStorageEngine` trait
* Uses `VectorOperationsService` for direct memtable access
* Integrates with `TransactionCoordinator` for ACID guarantees
* Leverages `HardwareCapabilities` for SIMD detection

=== With Zero-Copy Filesystem

* Uses `ZeroCopyFilesystem` for optimized cloud I/O
* Integrates with `FileMetadataCache` for footer caching
* Supports S3/GCS/Azure with intelligent range reads

=== With AXIS Indexing

* EventLog integration for async index updates
* Provides quantized vectors to AXIS HNSW
* Maintains graph locality during compaction
* Falls back to AXIS for hot data

=== With Unified Components

* Uses `StorageQuantizationEngine` for vector quantization
* Leverages `UnifiedDistanceCompute` for similarity
* Integrates with `CompressionConfig` for adaptive compression
