= Compression Guide
:toc: left
:toclevels: 2

**SDK-driven compression for optimal storage efficiency.**

== Overview

ProximaDB compression is **100% SDK-controlled** - no server defaults. Configure compression per collection through the client SDK.

== Quick Start

=== Basic Compression
[source,python]
----
from proximadb import ProximaDBClient
from proximadb.models import CompressionConfig

client = ProximaDBClient("http://localhost:5678")

# Create collection with compression
collection = client.create_collection(
    name="compressed",
    dimension=1536,
    engine="viper",
    compression=CompressionConfig(
        algorithm="zstd",
        level=6
    )
)
----

=== Compression Levels
* **ZSTD**: 1-22 (default: 6)
  - 1-3: Write-optimized
  - 4-9: Balanced
  - 10+: Storage-optimized
* **LZ4**: 1-16 (default: 1)
* **Snappy**: No levels

== Engine-Specific Features

=== SST Engine (Row-Based)
[source,python]
----
# SST with block compression
config = CompressionConfig(
    algorithm="zstd",
    level=6,
    block_size_mb=16,      # SST-specific
    dynamic_block_sizing=True
)
----

**Features**:
* Block-level compression
* Dynamic block sizing
* Bloom filter optimization
* Fast decompression

=== VIPER Engine (Columnar)
[source,python]
----
# VIPER with quantization
config = CompressionConfig(
    algorithm="lz4",
    level=1,
    enable_quantization=True,     # VIPER-specific
    quantization_type="int8",     # or "pq8", "pq4"
    normalization_method="mean"
)
----

**Features**:
* Column compression
* Dual storage (FP32 + quantized)
* 100% vector fidelity
* Two-stage search

=== Types

| Type | Compression | Accuracy | Speed

| **INT8**
| 4:1

| 8-32:1

| Medium

| **PQ4**
| 16-64:1

=== Two-Stage Search
1. **Stage 1**: Search quantized vectors (fast)
2. **Stage 2**: Rerank with FP32 (accurate)
3. **Result**: 2x speed, 100% accuracy

== Advanced Configuration

=== Adaptive Compression
[source,python]
----
config = CompressionConfig(
    algorithm="zstd",
    level=6,
    adaptive=True,         # Auto-adjust level
    min_ratio=2.0         # Minimum compression ratio
)
----

=== Search Optimization
[source,python]
----
from proximadb.models import SearchOptimization

# Compression-aware search
optimization = SearchOptimization(
    enable_two_stage=True,
    prefer_compressed_search=True,
    decompression_budget_ms=100,
    use_decompression_cache=True
)

results = client.search_vectors(
    "compressed",
    query_vector,
    search_optimization=optimization
)
----

== Best Practices

=== Choosing Compression
```
Write-Heavy → LZ4 or Snappy
Storage-Optimized → ZSTD level 9+
Analytics → VIPER + Quantization
Real-time → No compression or Snappy
```

=== Configuration Tips
1. **Start with ZSTD-6** for balanced performance
2. **Enable quantization** for VIPER analytics
3. **Use adaptive compression** for mixed workloads
4. **Monitor compression ratios** via metrics
5. **Size decompression cache** based on working set

== Monitoring

=== Compression Metrics
```python
# Get compression stats
stats = client.get_collection_stats("compressed")
print(f"Compression ratio: {stats['compression_ratio']:.2f}x")
print(f"Compressed size: {stats['compressed_size_mb']:.1f} MB")
print(f"Original size: {stats['original_size_mb']:.1f} MB")
```

=== Cache Performance
```python
# Monitor decompression cache
cache_stats = client.get_cache_stats()
print(f"Cache hit rate: {cache_stats['hit_rate']:.1%}")
print(f"Cache size: {cache_stats['size_mb']:.1f} MB")
```

== Migration Guide

=== Enable Compression
```python
# Update existing collection
client.update_collection(
    "my_collection",
    compression=CompressionConfig(
        algorithm="zstd",
        level=6
    )
)
```

=== Disable Compression
```python
# Remove compression
client.update_collection(
    "my_collection",
    compression=CompressionConfig(
        algorithm="none"
    )
)
```
