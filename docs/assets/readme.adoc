=== Icon Generation

**Favicon Exports:**

[source,bash]
----
# Generate PNG favicons from SVG
inkscape logos/proximadb-symbol.svg -w 16 -h 16 -o icons/favicon-16.png
inkscape logos/proximadb-symbol.svg -w 32 -h 32 -o icons/favicon-32.png
inkscape logos/proximadb-symbol.svg -w 48 -h 48 -o icons/favicon-48.png

# Apple Touch Icon
inkscape logos/proximadb-symbol.svg -w 180 -h 180 -o icons/apple-touch-icon-180.png

# Generate ICO (requires ImageMagick)
convert icons/favicon-{16,32,48}.png icons/favicon.ico
----

== Brand Guidelines

=== Usage Standards

[IMPORTANT]
====
**Clear Space**: Maintain space around logo equal to ring thickness

**Background**: Avoid busy imagery that reduces logo visibility

**Size Limits**: Use symbol-only variant for sizes ≤32px

**Color Integrity**: Use inverted variant on dark backgrounds
====

== Asset Creation Guidelines

=== Logo Modifications

[NOTE]
====
**Approval Required**: Contact brand team before modifying core assets

**Derivative Works**: Follow brand guidelines for variations

**Quality Standards**: Maintain vector format for scalability

**Consistency**: Use established color palette and proportions
====

=== Custom Materials

For creating custom marketing materials:
1. Use provided logo variants in vector format
2. Follow brand color guidelines  
3. Maintain clear space requirements
4. Test across different backgrounds and sizes
5. Export in appropriate formats for intended use

[TIP]
====
**Vector First**: Always work with SVG sources when possible

**Export Strategy**: Generate raster formats from vector sources

**Quality Control**: Test assets at actual usage sizes

**Version Control**: Maintain source files for future modifications
====
