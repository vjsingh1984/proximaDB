== Best Practices Going Forward

1. **Inline Diagrams**: Use `[source,mermaid]` blocks directly in .adoc files
2. **No Separate Files**: Avoid separate .mmd files unless shared across multiple docs
3. **No Pre-rendered SVGs**: Let documentation renderers generate diagrams dynamically
4. **Version Control**: Diagrams in documentation are versioned with the docs

== Example of Proper Diagram Usage

[source,asciidoc]
----
[source,mermaid]
\----
graph LR
    A[Input] --> B[Process]
    B --> C[Output]
    
    style A fill:#e8f5e9
    style C fill:#e3f2fd
\----
----

This approach:
* Keeps diagrams with their documentation
* Ensures diagrams stay up-to-date
* Reduces file maintenance overhead
* Improves documentation portability
