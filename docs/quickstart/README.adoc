== Prerequisites

**System Requirements**:
- Docker and Docker Compose (recommended)
- OR: Rust 1.89+ for source compilation
- 8GB RAM minimum (16GB recommended for production)
- 20GB available storage

**Supported Platforms**:
- Linux (Ubuntu 20.04+, RHEL 8+, CentOS 8+)
- macOS (Intel and Apple Silicon)
- Windows (WSL2 recommended)

== Option 1: Docker Quick Start (Recommended)

=== Step 1: Download and Deploy (2 minutes)

```bash

git clone https://github.com/proximadb/proximadb.git
cd proximadb

# Start ProximaDB Enterprise with Docker
```

```json
  "version": "1.0.4",
```

== Option 2: Native Installation

=== Step 1: Build from Source

```bash
# Install Rust (if not already installed)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

git clone https://github.com/proximadb/proximadb.git
cd proximadb
```

=== Basic Usage

```python
import proximadb
import numpy as np

# Connect to ProximaDB
client = proximadb.Client(
    endpoint="http://localhost:5678",
    auth_method="api_key",
    api_key="your-enterprise-key"
)

# Create collection
collection = client.create_collection(
    name="business_intelligence",
    dimension=1536,
    distance_metric="cosine",
    storage_engine="NOVA"  # Best for mixed workloads
)

# Insert vectors with metadata
vectors = [
    {
        "id": f"doc_{i}",
        "vector": np.random.random(1536).tolist(),
        "metadata": {
            "title": f"Document {i}",
            "category": "business",
            "timestamp": "2025-09-14"
        }
    }
    for i in range(100)
]

collection.insert(vectors)

# Perform semantic search
query_vector = np.random.random(1536).tolist()
results = collection.search(
    vector=query_vector,
    top_k=10,
    include_metadata=True,
    filters={"category": "business"}
)

# Use unified search (vector + graph + knowledge)
unified_results = client.unified_search(
    collection="business_intelligence",
    query="strategic market opportunities",
    include_relationships=True,
    include_knowledge_context=True
)

print(f"Found {len(unified_results)} relevant insights")
```

== Production Configuration Examples

=== High-Availability Setup

```yaml
# docker-compose.prod.yml
version: '3.8'
services:
  proximadb-primary:
    image: proximadb/proximadb:latest
    environment:
      - PROXIMADB_ROLE=primary
      - PROXIMADB_CLUSTER_SIZE=3
    volumes:
      - proximadb_data_primary:/data
    ports:
      - "5678:5678"
      - "5679:5679"

  proximadb-replica-1:
    image: proximadb/proximadb:latest
    environment:
      - PROXIMADB_ROLE=replica
      - PROXIMADB_PRIMARY_HOST=proximadb-primary
    volumes:
      - proximadb_data_replica1:/data

  proximadb-replica-2:
    image: proximadb/proximadb:latest
    environment:
      - PROXIMADB_ROLE=replica
      - PROXIMADB_PRIMARY_HOST=proximadb-primary
    volumes:
      - proximadb_data_replica2:/data
```

== Troubleshooting Common Issues

=== Connection Issues

**Problem**: Cannot connect to ProximaDB
**Solution**:
```bash
# Check if service is running
docker ps | grep proximadb

# Check logs
docker logs proximadb

# Verify ports
netstat -tulpn | grep 5678
```

=== Performance Issues

**Problem**: Slow query performance
**Solution**:
```bash
# Check system resources
docker stats proximadb

# Optimize configuration
echo "storage.write_buffer.max_size_mb = 1024" >> config/config.toml

# Monitor cache efficiency
curl http://localhost:5678/metrics | grep cache_hit_rate
```

=== Memory Issues

**Problem**: High memory usage
**Solution**:
```toml
# Adjust cache settings
[compute.cache]
memory_limit_gb = 4
enable_memory_optimization = true

# Use memory-optimized storage engine
[storage]
default_engine = "PRISM"
```
