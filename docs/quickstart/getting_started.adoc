== Option 2: Binary Installation

=== **Step 1: Build from Source**

[source,bash]
----
# Install Rust toolchain (if needed)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env

# Clone and build ProximaDB
git clone https://github.com/proximadb/proximadb.git
cd proximadb

# Optimized production build
cargo build --release --features "cloud-full,gpu"

# Start the server
./target/release/proximadb-server --config config/production.toml
----

=== **Step 2: Production Configuration**

[source,toml]
----
# config/production.toml
[server]
host = "0.0.0.0"
rest_port = 5678
grpc_port = 5679
max_connections = 10000

[storage]
# Multi-engine optimization
default_engine = "nova"  # Best for mixed workloads
data_path = "/data/proximadb"

[storage.engines.nova]
quantization = "pq8"
compression = "zstd"
cache_size_mb = 8192

[ai]
# 8 LLM provider ecosystem
default_provider = "openai"
providers = ["openai", "anthropic", "azure_openai", "aws_bedrock"]

[security]
auth_enabled = true
tls_enabled = true
rbac_enabled = true

[performance]
enable_simd = true
enable_gpu = true
cache_optimization = true
threads = 16
----

== Your First AI-Powered Application

=== **Python SDK Integration**

[source,bash]
----
# Install ProximaDB Python client
pip install proximadb-client
----

[source,python]
----
import proximadb
import numpy as np

# Connect to ProximaDB
client = proximadb.Client(
    endpoint="http://localhost:5678",
    auth_token="your-api-key"  # Enterprise security
)

# Create intelligent collection
collection = await client.create_collection(
    name="enterprise_knowledge",
    dimension=1536,  # OpenAI embedding dimension
    distance_metric="cosine",
    storage_engine="nova",  # Multi-workload optimization
    ai_enabled=True  # Enable AI intelligence
)

# Insert business documents with automatic embeddings
documents = [
    {
        "id": "strategic_plan_2025",
        "text": "Our 2025 strategic plan focuses on AI transformation and market expansion",
        "metadata": {
            "department": "strategy",
            "priority": "high",
            "year": 2025
        }
    },
    {
        "id": "q3_performance",
        "text": "Q3 showed 25% growth driven by enterprise customer acquisition",
        "metadata": {
            "department": "sales",
            "period": "Q3",
            "metric": "growth"
        }
    }
]

# ProximaDB automatically generates embeddings
await collection.insert_documents(documents)

# Natural language business intelligence
insights = await client.ask_question(
    collection="enterprise_knowledge",
    question="What drove our Q3 growth and how does it relate to our strategic plan?",
    include_reasoning=True
)

print("AI Analysis:", insights.answer)
print("Supporting Evidence:", insights.sources)
print("Confidence Score:", insights.confidence)

# Vector similarity search
similar_docs = await collection.search(
    query="strategic growth initiatives",
    top_k=10,
    include_metadata=True,
    filters={"priority": "high"}
)

# Graph relationship discovery
relationships = await client.discover_relationships(
    collection="enterprise_knowledge",
    source_id="strategic_plan_2025",
    max_depth=3,
    relationship_types=["references", "supports", "influences"]
)

print(f"Found {len(relationships)} strategic relationships")
----

== Enterprise Security Setup

=== **Authentication Configuration**

[source,toml]
----
[security.authentication]
# Multiple authentication methods
methods = ["api_key", "jwt", "oauth2", "enterprise_sso"]

# Enterprise SSO integration
[security.authentication.sso]
provider = "azure_ad"  # or "aws_iam", "okta", "auth0"
domain = "your-company.com"
client_id = "your-azure-client-id"
tenant_id = "your-azure-tenant-id"

# API key management
[security.api_keys]
default_ttl = "30d"
rotation_enabled = true
rate_limiting = true
----

=== **Role-Based Access Control**

[source,toml]
----
[security.rbac]
enabled = true

# Default roles
[security.rbac.roles.admin]
permissions = ["*"]
description = "Full system access"

[security.rbac.roles.developer]
permissions = ["collections:*", "vectors:*", "search:*"]
description = "Development and integration access"

[security.rbac.roles.analyst]
permissions = ["search:*", "ai:query", "dashboard:view"]
description = "Business intelligence and analytics"

[security.rbac.roles.viewer]
permissions = ["search:read", "dashboard:view"]
description = "Read-only access"

== Troubleshooting Guide

=== **Common Issues & Solutions**

[cols="2,2,3", options="header"]
|===
| Issue | Symptoms | Solution

| **High Memory Usage**
| Memory consumption >80%
| Adjust cache settings, optimize queries

| **Slow Query Performance**
| Response time >100ms
| Check engine selection, add indexes

| **Connection Errors**
| TCP connection failures
| Verify ports, firewall configuration

| **Authentication Issues**
| 401/403 errors
| Check API keys, RBAC permissions

| **Storage Engine Issues**
| Engine-specific errors
| Review engine configuration, logs
|===

=== **Performance Optimization Checklist**

1. **Hardware Optimization**
   - Enable SIMD acceleration
   - Configure GPU if available
   - Optimize memory allocation

2. **Storage Engine Selection**
   - Match engines to workload patterns
   - Monitor engine performance metrics
   - Adjust engine-specific parameters

3. **Cache Configuration**
   - Set appropriate cache sizes
   - Monitor cache hit rates
   - Adjust eviction policies

4. **Query Optimization**
   - Use appropriate distance metrics
   - Optimize vector dimensions
   - Implement efficient filtering
