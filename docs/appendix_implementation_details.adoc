Essential implementation patterns and code examples for ProximaDB.

== Core Patterns

=== DirectVectorService

Main service handling vector operations with engine routing and atomic insertions.

=== Atomic Operations

Three-phase commit pattern: Prepare → Execute → Commit for consistency across operations.

=== Search Coordination

Parallel search across WriteBuffer, memtable, and storage layers with MVCC deduplication by version.

== Storage Engine Details

=== SST Engine

Row-based storage with block-based filtering, bloom filters for point lookups, and metadata indexing.

=== VIPER Engine

Columnar Parquet storage with predicate pushdown, row group statistics filtering, and batch processing.

== Key Algorithms

=== MVCC Deduplication

Version-based record deduplication using HashMap for latest version tracking.

=== Distance Computation

Hardware-accelerated metrics including AVX-optimized cosine similarity for x86_64 platforms.

== Configuration Examples

**Production**: 16 worker threads, 64MB flush threshold, ZSTD compression level 6, 50K row groups

**Development**: Debug logging, 1MB flush threshold for faster testing, 60s compaction interval

== Testing Patterns

**Setup**: TempDir isolation, DirectVectorService initialization, test context management

**Operations**: Collection creation, vector insertion, search validation with assertion checks
