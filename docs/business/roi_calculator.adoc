== Quick Savings Estimator

=== Calculate Your Potential Savings

[source,javascript]
----
// Input your current metrics
const currentMetrics = {
  vectors: 10_000_000,        // Number of vectors
  dimensions: 1536,            // Vector dimensions
  qps: 100,                    // Current queries per second
  storageGB: 600,              // Current storage used (GB)
  monthlyInfraCost: 2000,      // Current infrastructure cost ($)
  monthlyStorageCost: 150      // Current storage cost ($)
};

// Conservative estimates based on benchmarks
const proximaDBMetrics = {
  // Storage: 50-80% reduction (we'll use 60% for conservative estimate)
  storageReduction: 0.60,
  
  // Infrastructure: Support same QPS with 70% fewer servers
  infraReduction: 0.70,
  
  // Performance: 3.4x throughput (benchmarked)
  throughputMultiplier: 3.4
};

// Calculate potential improvements
const improvements = {
  newStorageGB: currentMetrics.storageGB * (1 - proximaDBMetrics.storageReduction),
  newStorageCost: currentMetrics.monthlyStorageCost * (1 - proximaDBMetrics.storageReduction),
  newInfraCost: currentMetrics.monthlyInfraCost * (1 - proximaDBMetrics.infraReduction),
  newQPSCapacity: currentMetrics.qps * proximaDBMetrics.throughputMultiplier
};

// Results (monthly)
console.log('=== POTENTIAL MONTHLY SAVINGS ===');
console.log(`Storage: ${currentMetrics.storageGB}GB → ${improvements.newStorageGB}GB`);
console.log(`Storage Cost: $${currentMetrics.monthlyStorageCost} → $${improvements.newStorageCost}`);
console.log(`Infrastructure Cost: $${currentMetrics.monthlyInfraCost} → $${improvements.newInfraCost}`);
console.log(`QPS Capacity: ${currentMetrics.qps} → ${improvements.newQPSCapacity}`);
console.log(`Monthly Savings: $${(currentMetrics.monthlyInfraCost - improvements.newInfraCost + currentMetrics.monthlyStorageCost - improvements.newStorageCost).toFixed(2)}`);

// Note: Actual results vary based on data characteristics and usage patterns
----

== Decision Framework

=== When ProximaDB Delivers Maximum ROI

✅ **Ideal Scenarios**:
* Vector datasets > 1M vectors
* Need for real-time search (<10ms)
* Storage costs > $1,000/month
* Multi-modal search requirements
* High ingestion rates (>1K vectors/sec)

⚠️ **Consider Alternatives If**:
* < 100K vectors
* Batch processing only
* No latency requirements
* Existing vendor lock-in with high switching costs
