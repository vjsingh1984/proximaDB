== User Journey

**New User Experience** (5 minutes):

1. **Install** (30 seconds):
+
[source,bash]
----
pip install proximadb-python
----

2. **Verify** (30 seconds):
+
[source,bash]
----
python docs/01-quick-start/legacy/verify_installation.py
----
Output: `🎉 Installation verified successfully!`

3. **Start Server** (1 minute):
+
[source,bash]
----
docker run -p 5678:5678 -p 5679:5679 ghcr.io/vjsingh1984/proximadb:latest
----

4. **Run First Query** (3 minutes):
+
[source,python]
----
from proximadb_sdk import connect

client = connect(url="http://localhost:5678")
collection = client.create_collection("docs", dimension=384)

client.insert_vectors("docs", [{
    "id": "doc1",
    "vector": [0.1] * 384,
    "metadata": {"category": "tech"}
}])

results = client.search(
    collection_id="docs",
    vector=[0.1] * 384,
    top_k=5
)
----

**Total Time**: ~5 minutes from installation to first query
