== 2. Gaps (Ordered by Severity)

=== Critical

[cols="1,3"]
|===
| Gap | Impact

| **No indexed search in parallel path**
| AXIS engine has HNSW/IVF but isn't wired into `search_vectors()`. All queries are exact scan+score. For >100K vectors, latency exceeds thresholds. Every competitor (Milvus, Weaviate, Pinecone) uses indexed search.

| **Full Outer Join incomplete**
| Graph executor line 641 falls back to Left Outer for Right/Full Outer. Limits complex graph query patterns.

| **gRPC OTLP transport missing**
| Observability ingestion only via HTTP/JSON. Standard OTLP deployments require gRPC.
|===

=== High

[cols="1,3"]
|===
| Gap | Impact

| **Durable 2PC not auto-wired to engines**
| Requires caller-provided callbacks. Not integrated with storage engine flush paths.

| **ibkrtrading production validation pending**
| Vision anchors credibility on production trading use but no documented 30-day results.

| **Generic relational scans not supported**
| `execute_scan()` returns error for non-function-backed sources.

| **Ingestion throughput unvalidated at scale**
| >10K logs/sec claimed but no benchmark evidence beyond 10K.
|===

=== Medium

[cols="1,3"]
|===
| Gap | Impact

| Approximate nearest neighbor search not available
| All results exact. For >1M vectors, approximate methods needed.

| SWIFT/RAPTOR experimental (23-41 tests)
| Insufficient coverage for production graduation.

| Code coverage 54.9% (target 80%)
| Below enterprise quality threshold.

| No cursor-based pagination
| Large result sets materialized fully in memory.

| New untracked modules not yet integrated
| `graph_subset.rs`, `hybrid_search.rs`, `security/auth/`, `multimodel/transaction/participants.rs` etc. need compilation fixes.
|===
