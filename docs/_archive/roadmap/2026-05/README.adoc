== How to read these now

These docs capture state-at-a-time. They are accurate for the date
they were written, NOT for current implementation truth. When
debugging or reasoning about historical decisions:

. Find the date the doc was written.
. Check whether a 2026-05-XX design doc covers the same area — if yes,
  the May doc is canonical for current truth.
. Use the archived report only for "why we made decision X at that
  time" context, not for "what is the system shape right now".
