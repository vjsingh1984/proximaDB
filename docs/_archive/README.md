| Area | Directory |
|---|---|
| Product and vision | `docs/00-product/` |
| Quick start | `docs/01-quick-start/` |
| User guides | `docs/02-guides/` |
| API reference | `docs/03-api-reference/` |
| Operations and release | `docs/04-operations/` |
| Concepts | `docs/05-concepts/` |

| Quality and support status | `docs/10-quality/` |
| Use cases | `docs/11-usecases/` |
| Architecture and ADRs | `docs/12-design/` |

Archive buckets:

| Directory | Contents |
