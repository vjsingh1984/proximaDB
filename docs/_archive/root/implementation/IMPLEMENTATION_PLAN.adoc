=== WS-2: Query Path Unification (P1 - HIGH)

*Owner:* Agent 2
*Estimated Time:* 3-4 days
*Can Run In Parallel:* Yes (after WS-1)

==== Analysis

Current state: 5 parallel query paths
Target state: Single unified path through UnifiedQueryOptimizer

==== Tasks

[source]
----
2.1 Audit current query entry points
    - Map all REST handlers that execute queries
    - Map all gRPC service methods that execute queries
    - Document which optimizer each uses

2.2 Create unified query router
    - File: src/query/router.rs (NEW)
    - Create UnifiedQueryRouter that dispatches to appropriate executor
    - All query types flow through single entry point

2.3 Integrate QueryEngine with UnifiedQueryOptimizer
    - File: src/query/execution/executor.rs
    - Before execution, call UnifiedQueryOptimizer.optimize()
    - Remove duplicate filter/index selection logic

2.4 Decide on Federated Query path
    - Option A: Wire FederatedExecutor to new REST/gRPC endpoints
    - Option B: Remove orphaned federated code (~2,000 lines)
    - Document decision and implement

2.5 Remove unused UnifiedQueryEngine
    - File: src/query/unified/mod.rs
    - Remove if truly orphaned (verify no callers)

2.6 Add query caching
    - File: src/query/cache.rs (NEW)
    - Implement LRU cache for optimized query plans
    - Key: hash(collection, query_params, filter)
    - TTL: 5 minutes default
----

==== Success Criteria
- Single query path for all operations
- SQL queries use UnifiedQueryOptimizer
- Query cache reduces repeated optimization
- ~500+ lines of duplicate code removed

== Risk Mitigation

=== High-Risk Changes
1. *Query Path Unification* - Could break existing APIs
   - Mitigation: Comprehensive integration tests before merge

2. *Dead Code Removal* - Could remove used code
   - Mitigation: Check all callers before removal, keep in branch until verified

3. *Feature Gates* - Could break existing builds
   - Mitigation: Default features include what was previously compiled

=== Rollback Plan
- Each workstream in separate branch
- Merge only after tests pass
- Tag current state before major changes
