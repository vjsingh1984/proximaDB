1. **Reorganize docs/ folder**
   ```
   docs/
   ├── quickstart.adoc       (entry point)
   ├── 01-overview/          (project overview)
   ├── 02-getting-started/   (tutorials)
   ├── 03-user-guide/        (how-to guides)
   ├── 04-api-reference/     (API docs)
   ├── 05-architecture/      (system design)
   ├── 06-storage-engines/   (engine specs)

   ├── 08-development/       (contributor guide)
   ├── 09-roadmap/          (future plans)
   └── assets/              (images/diagrams)
   ```

2. **Create Index Files**
   - Add README.adoc to each numbered folder
   - Include table of contents linking to sub-documents

3. **Standardize Cross-References**
   - Use relative paths consistently
   - Always use .adoc extensions
   - Test all links regularly

# Check for missing images

  file=$(echo $line | sed 's/.*image::\([^[]*\).*/\1/')
  [ ! -f "$file" ] && echo "Missing: $file"
done
