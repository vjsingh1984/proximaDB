| Unified query (federated SQL)
| **Beta**
| `VECTOR_SEARCH` / `GRAPH_QUERY` / `DOCUMENT_QUERY` / `LOGS` / `METRICS` function-backed sources work through the federated engine with cache + morsel-driven parallelism.
| Generic relational scans and remote distributed execution are incomplete. SUPPORTED_SURFACE "Beta".

| Hybrid retrieval
| **Beta**
| BM25 + RRF/weighted fusion functional on REST `/api/v1/hybrid/search`; production gRPC uses the same `RestHybridPortImpl` backend and shared in-process full-text indexes; filters/fusion params now flow through the port path.
| TD-008 resolved on REST. Remaining Beta hardening: optional live REST/gRPC smoke and quality benchmarks. SUPPORTED_SURFACE "Beta".

| Time-series (TST)
| **Beta**
| TST engine complete: ASOF joins, downsampling, OHLC.
| SUPPORTED_SURFACE "Beta" — product packaging, API parity, and at-scale production validation still in progress. TD-009 resolved on the engine itself.

| Event sourcing
| **Beta**
| Engine complete: append-only WAL, temporal queries, MiFID II audit trail.
| Grouped under SUPPORTED_SURFACE "Time-series and event foundations: Beta". TD-010 resolved on the engine; packaging/at-scale validation still in progress.

| Query execution layer (cost-based)
| **Production Ready**
| Vectorized executor wired into primary query path (TD-041 resolved). Cost-based optimization with adaptive model.
| pgwire SQL surface is the SEPARATE row below — that one's Beta. This row covers the vectorized executor only.

| pgwire / SQL parity
| **Beta**
| Phase 1 of ADR-018 complete (basic DML, DROP TABLE IF EXISTS, vector-distance syntax). Phase 2 (SQLite parity) in flight; Phase 3 (Postgres parity) planned.
| ADR-018 PARTIAL — see ADR for the explicit Phase 1/2/3 contract.

| Security runtime
| **Beta**
| JWT, API key, SSO hooks, mTLS identity, CRL-backed revocation reload/freshness checks present.
| SUPPORTED_SURFACE "Beta". Security admin/status APIs and stronger online revocation policy incomplete. RLS engine-layer enforcement only wired in SST + VIPER (NOVA / HELIX wiring is Tier-1 work). Multiple sub-features still marked ❌ in the feature-index section below.

| Distributed cluster execution
| **Experimental**
| Raft internals, shard planning, routing foundations exist (5,491 LOC across `src/cluster/`). Feature-gated behind the `cluster` flag.
| SUPPORTED_SURFACE "Experimental" — RPC transport and remote execution contain placeholder/partial implementations. Single-region deployment usable with operator validation; not a like-for-like distributed-DB replacement.

| Cloud Infrastructure
| **Production Ready**
| Terraform modules (3 environments), Kubernetes deployment (Helm), CI/CD pipeline, monitoring stack (Prometheus + Grafana + Alertmanager).
| Deploy/operate surface, not a database capability surface — keep Production Ready.

| Compliance
| **Beta**
| SOC 2 compliance plan complete (25 controls, 7-month roadmap). Policy templates and implementation checklist available.
| Beta = roadmap + scaffolding. Control implementation rolls out across v0.3+ minor releases.

| Go-to-Market
| **Production Ready**
| Pricing strategy (4 tiers), conference presence, DevRel team chartered, documentation complete.
| Marketing/operations surface — not a code claim.
