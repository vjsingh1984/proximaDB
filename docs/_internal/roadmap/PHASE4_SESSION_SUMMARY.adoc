## Technical Specifications

### Architecture

**Network**:
- VPC: 10.0.0.0/16
- Public subnets: 10.0.1.0/24, 10.0.2.0/24, 10.0.3.0/24
- Private subnets: 10.0.4.0/24, 10.0.5.0/24, 10.0.6.0/24
- Database subnets: 10.0.7.0/24, 10.0.8.0/24, 10.0.9.0/24

**Kubernetes**:
- Version: 1.29
- Control plane: Managed by AWS
- Node groups:
  * General purpose: t3.medium (on-demand)
  * Compute optimized: c5.xlarge (spot)
- Auto-scaling: 2-10 replicas (HorizontalPodAutoscaler)

**ProximaDB Application**:
- Replicas: 3 (auto-scales 2-10)
- Resources: 2-8 CPU, 1-4Gi memory
- Storage: 100Gi PVC (gp3-encrypted)
- Probes: Health checks on /health
