**Strategic roadmap aligned with the Vision document phases. This is the authoritative source for feature status and prioritization.**

== Vision Alignment

This roadmap implements the three-phase approach from link:../../concepts/vision.adoc[Vision Document]:

* **Phase 1**: Format and Catalog Contract (Foundation)
* **Phase 2**: Cross-Model Query and Indexing (Differentiation)
* **Phase 3**: Deployment and Ecosystem Integration (Scale)
* **Phase 4**: Context Database Evolution (Time-Series, Event Sourcing, Hybrid Search)

== MVP Definition (v1.0)

For v1.0 release, the following must be complete:

=== Required for MVP

* [x] All 6 storage engines
* [x] Core infrastructure (WAL, REST, gRPC)
* [x] Index algorithms (HNSW, IVF, AXIS)
* [x] Quantization (Binary, INT8, PQ)
* [x] Graph database (ORION)
* [x] Document store
* [x] Observability store
* [x] Unified query engine
* [x] Cross-model joins
* [x] Python SDK
* [x] Docker deployment
* [x] Basic security (JWT, RBAC)

=== Deferred Post-MVP

* [ ] External catalog integration
* [ ] Distributed operations (Raft, multi-region)
* [ ] Streaming/CDC
* [ ] Enterprise SSO
* [ ] Additional SDKs
