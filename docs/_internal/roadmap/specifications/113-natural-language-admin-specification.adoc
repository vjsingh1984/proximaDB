**Technical specification for natural language administration interface in ProximaDB**

== Overview

This specification defines an AI-powered natural language interface for ProximaDB administration, enabling operators to manage, query, and troubleshoot the database using conversational commands.

=== Goals

[source,text]
----
Primary Goals:
├── Natural language command interpretation
├── Intelligent query generation from descriptions
├── Automated troubleshooting assistance
├── Performance optimization recommendations
├── Safe operation execution with confirmation
└── Context-aware conversation management
----

=== Use Cases

1. **Operator Queries**: "Show me collections with more than 1M vectors"
2. **Performance Analysis**: "Why is search slow on the products collection?"
3. **Administration**: "Create a backup of all production collections"
4. **Troubleshooting**: "What's causing the high memory usage?"

==== Intent Classification

[source,rust]

/// Classifies user intent from natural language input
pub struct IntentClassifier {
    /// LLM client for classification
    llm: Arc<dyn LlmClient>,
    /// Intent patterns
    patterns: IntentPatterns,
    /// Classification cache
    cache: LruCache<String, ClassifiedIntent>,
}

#[derive(Debug, Clone)]
pub struct ClassifiedIntent {
    /// Primary intent category
    pub category: IntentCategory,
    /// Confidence score (0-1)
    pub confidence: f32,
    /// Sub-intents if applicable
    pub sub_intents: Vec<SubIntent>,
    /// Extracted entities
    pub entities: HashMap<String, Entity>,
    /// Required confirmations
    pub confirmations: Vec<Confirmation>,
}

#[derive(Debug, Clone, Copy)]
pub enum IntentCategory {
    /// Read-only queries about system state
    Query,
    /// Administrative operations
    Administration,
    /// Search/vector operations
    Search,
    /// Performance troubleshooting
    Troubleshoot,
    /// Optimization requests
    Optimize,
    /// Help and documentation
    Help,
    /// Conversation management
    Meta,
}

#[derive(Debug, Clone)]
pub enum SubIntent {
    // Query sub-intents
    ListCollections,
    CollectionStats,
    SystemMetrics,
    QueryHistory,

    // Admin sub-intents
    CreateCollection,
    DeleteCollection,
    CreateBackup,
    RestoreBackup,
    ConfigChange,

    // Search sub-intents
    VectorSearch,
    FilteredSearch,
    HybridSearch,

    // Troubleshoot sub-intents
    AnalyzeLatency,
    AnalyzeMemory,
    AnalyzeErrors,
    AnalyzeDiskUsage,

    // Optimize sub-intents
    SuggestIndexes,
    TuneParameters,
    OptimizeQueries,
}

impl IntentClassifier {
    pub async fn classify(&self, input: &str, context: &ConversationContext) -> Result<ClassifiedIntent> {
        // Check cache first
        let cache_key = format!("{}:{}", context.session_id, input);
        if let Some(cached) = self.cache.get(&cache_key) {
            return Ok(cached.clone());
        }

        // Build classification prompt
        let prompt = self.build_classification_prompt(input, context);

        // Call LLM for classification
        let response = self.llm.complete(&prompt).await?;

        // Parse classification response
        let intent = self.parse_classification_response(&response)?;

        // Cache result
        self.cache.put(cache_key, intent.clone());

        Ok(intent)
    }

    fn build_classification_prompt(&self, input: &str, context: &ConversationContext) -> String {
        format!(r#"
You are a ProximaDB assistant. Classify the user's intent.

User input: "{}"

Previous context:
{}

Classify into one of these categories:
- Query: Read-only information requests
- Administration: Database management operations
- Search: Vector search operations
- Troubleshoot: Performance/error investigation
- Optimize: Performance tuning requests
- Help: Documentation/usage questions
- Meta: Conversation management

Extract relevant entities:
- collection_name
- time_range
- metric_name
- threshold_value

Identify if confirmation is needed for destructive operations.

Respond in JSON format.
"#, input, context.summary())
    }
}

    MetricName(String),
    Threshold(Threshold),
    VectorId(String),
    Filter(FilterExpression),
    TopK(usize),
    EngineType(String),
    Dimension(usize),
    ConfigKey(String),
    ConfigValue(Value),
}

#[derive(Debug, Clone)]
pub struct TimeRange {
    pub start: Option<DateTime<Utc>>,
    pub end: Option<DateTime<Utc>>,
    pub duration: Option<Duration>,
}

impl EntityExtractor {
    pub fn extract(&self, input: &str, intent: &ClassifiedIntent) -> Result<Vec<Entity>> {
        let mut entities = Vec::new();

        // Run NER model
        let ner_results = self.ner.extract(input)?;
        entities.extend(self.convert_ner_results(ner_results));

        // Run custom extractors based on intent
        for extractor in &self.custom_extractors {
            if extractor.applies_to(&intent.category) {
                entities.extend(extractor.extract(input)?);
            }
        }

        Ok(entities)
    }
}

/// Manages conversation context and session state
pub struct ContextManager {
    /// Active sessions
    sessions: DashMap<SessionId, ConversationContext>,
    /// Session timeout
    session_timeout: Duration,
    /// Max history length
    max_history: usize,
}

#[derive(Debug, Clone)]
pub struct ConversationContext {
    /// Session identifier
    pub session_id: SessionId,
    /// User identifier
    pub user_id: UserId,
    /// Conversation history
    pub history: VecDeque<ConversationTurn>,
    /// Current working collection (if set)
    pub active_collection: Option<String>,
    /// User preferences
    pub preferences: UserPreferences,
    /// Last activity timestamp
    pub last_activity: Instant,
}

#[derive(Debug, Clone)]
pub struct ConversationTurn {
    pub timestamp: DateTime<Utc>,
    pub user_input: String,
    pub classified_intent: ClassifiedIntent,
    pub action_taken: Option<ActionResult>,
    pub response: String,
}

#[derive(Debug, Clone)]
pub struct UserPreferences {
    /// Preferred output format (table, json, prose)
    pub output_format: OutputFormat,
    /// Confirmation level (always, destructive, never)
    pub confirmation_level: ConfirmationLevel,
    /// Verbosity level
    pub verbosity: Verbosity,
    /// Default collections
    pub default_collections: Vec<String>,
}

impl ContextManager {
    pub fn get_or_create_session(&self, session_id: SessionId, user_id: UserId) -> ConversationContext {
        self.sessions
            .entry(session_id)
            .or_insert_with(|| ConversationContext {
                session_id,
                user_id,
                history: VecDeque::with_capacity(self.max_history),
                active_collection: None,
                preferences: UserPreferences::default(),
                last_activity: Instant::now(),
            })
            .clone()
    }

    pub fn update_context(&self, session_id: SessionId, turn: ConversationTurn) {
        if let Some(mut ctx) = self.sessions.get_mut(&session_id) {
            ctx.history.push_back(turn);
            if ctx.history.len() > self.max_history {
                ctx.history.pop_front();
            }
            ctx.last_activity = Instant::now();
        }
    }
}

==== Query Generator

[source,rust]
----
/// Generates executable queries from natural language
pub struct QueryGenerator {
    /// LLM for query generation
    llm: Arc<dyn LlmClient>,
    /// Schema information
    schema_cache: Arc<SchemaCache>,
    /// Query templates
    templates: QueryTemplates,
}

impl QueryGenerator {
    pub async fn generate(&self, intent: &ClassifiedIntent, context: &ConversationContext) -> Result<GeneratedQuery> {
        match intent.category {
            IntentCategory::Query => self.generate_info_query(intent, context).await,
            IntentCategory::Search => self.generate_search_query(intent, context).await,
            IntentCategory::Administration => self.generate_admin_command(intent, context).await,
            _ => Err(Error::UnsupportedIntent),
        }
    }

    async fn generate_search_query(&self, intent: &ClassifiedIntent, context: &ConversationContext) -> Result<GeneratedQuery> {
        // Extract search parameters
        let collection = intent.entities.get("collection")
            .or(context.active_collection.as_ref())
            .ok_or(Error::MissingCollection)?;

        let top_k = intent.entities.get("top_k")
            .map(|e| match e {
                Entity::TopK(k) => *k,
                _ => 10,
            })
            .unwrap_or(10);

        // Build search query
        let query = SearchQuery {
            collection: collection.to_string(),
            vector: self.resolve_vector(intent)?,
            top_k,
            filter: self.build_filter(intent)?,
            include_metadata: true,
        };

        Ok(GeneratedQuery::Search(query))
    }

    async fn generate_admin_command(&self, intent: &ClassifiedIntent, context: &ConversationContext) -> Result<GeneratedQuery> {
        match intent.sub_intents.first() {
            Some(SubIntent::CreateCollection) => {
                let name = intent.entities.get("collection_name")
                    .ok_or(Error::MissingEntity("collection_name"))?;
                let dimension = intent.entities.get("dimension")
                    .ok_or(Error::MissingEntity("dimension"))?;

                Ok(GeneratedQuery::Admin(AdminCommand::CreateCollection {
                    name: name.to_string(),
                    dimension: dimension.as_usize()?,
                    engine: intent.entities.get("engine")
                        .map(|e| e.to_string())
                        .unwrap_or_else(|| "sst".to_string()),
                }))
            }
            Some(SubIntent::CreateBackup) => {
                let collections = self.resolve_collections(intent, context)?;

                Ok(GeneratedQuery::Admin(AdminCommand::CreateBackup {
                    collections,
                    destination: intent.entities.get("destination")
                        .map(|e| e.to_string()),
                }))
            }
            _ => Err(Error::UnsupportedSubIntent),
        }
    }
}

#[derive(Debug)]
pub enum GeneratedQuery {
    /// Informational query
    Info(InfoQuery),
    /// Vector search
    Search(SearchQuery),
    /// Administrative command
    Admin(AdminCommand),
    /// Metrics query
    Metrics(MetricsQuery),
}

#[derive(Debug)]
pub enum InfoQuery {
    ListCollections { filter: Option<String> },
    CollectionDetails { name: String },
    SystemStatus,
    QueryHistory { time_range: TimeRange },
}

#[derive(Debug)]
pub enum AdminCommand {

    DeleteCollection { name: String },
    CreateBackup { collections: Vec<String>, destination: Option<String> },
    RestoreBackup { backup_id: String },
    UpdateConfig { key: String, value: Value },
}

[source,rust]

/// Formats responses for user consumption
pub struct ResponseFormatter {
    /// LLM for natural language responses
    llm: Arc<dyn LlmClient>,
    /// Templates for structured responses
    templates: ResponseTemplates,
}

impl ResponseFormatter {
    pub async fn format(&self, result: &ActionResult, context: &ConversationContext) -> Result<FormattedResponse> {
        match &result {
            ActionResult::QueryResult(data) => {
                self.format_query_result(data, &context.preferences).await
            }
            ActionResult::SearchResult(results) => {
                self.format_search_results(results, &context.preferences).await
            }
            ActionResult::AdminResult(outcome) => {
                self.format_admin_result(outcome, &context.preferences).await
            }
            ActionResult::Error(error) => {
                self.format_error(error, context).await
            }
        }
    }

    async fn format_query_result(&self, data: &QueryData, prefs: &UserPreferences) -> Result<FormattedResponse> {
        match prefs.output_format {
            OutputFormat::Table => {
                let table = self.render_table(data)?;
                Ok(FormattedResponse::Text(table))
            }
            OutputFormat::Json => {
                let json = serde_json::to_string_pretty(data)?;
                Ok(FormattedResponse::Code { content: json, language: "json".to_string() })
            }
            OutputFormat::Prose => {
                let narrative = self.generate_narrative(data).await?;
                Ok(FormattedResponse::Text(narrative))
            }
        }
    }

    async fn generate_narrative(&self, data: &QueryData) -> Result<String> {
        let prompt = format!(r#"
Summarize this data in a clear, concise way for a database administrator:

{}

Highlight any notable findings or potential issues.
Keep the response under 100 words.
"#, serde_json::to_string(data)?);

        self.llm.complete(&prompt).await
    }
}

#[derive(Debug)]
pub enum FormattedResponse {
    Text(String),
    Code { content: String, language: String },
    Table { headers: Vec<String>, rows: Vec<Vec<String>> },
    Chart { chart_type: String, data: Value },
    Interactive { component: String, data: Value },
}

== Summary

This specification enables natural language administration of ProximaDB:

1. **Intent Classification**: Understand user requests accurately
2. **Entity Extraction**: Parse collections, metrics, time ranges
3. **Query Generation**: Convert NL to executable commands
4. **Safety**: Confirmations, rate limiting, audit logging
5. **Integrations**: CLI, web, Slack, Discord

The system makes database administration accessible while maintaining security.
