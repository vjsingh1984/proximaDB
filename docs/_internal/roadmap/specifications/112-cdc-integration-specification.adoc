**Technical specification for Change Data Capture (CDC) integration in ProximaDB**

== Overview

This specification defines the architecture for CDC integration, enabling ProximaDB to capture and replay data changes from external databases and to emit its own changes for downstream consumers.

=== Goals

[source,text]
----
Primary Goals:
├── Capture changes from PostgreSQL, MySQL, MongoDB
├── Emit ProximaDB changes to external systems
├── Support exactly-once semantics
├── Enable point-in-time recovery
├── Provide schema evolution handling
└── Support bi-directional sync patterns
----

=== Use Cases

1. **Database Sync**: Keep ProximaDB in sync with primary OLTP database
2. **Event Sourcing**: Replay historical changes for debugging/audit
3. **Data Pipeline**: Feed changes to downstream analytics systems
4. **Multi-DC Replication**: Cross-datacenter synchronization

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ChangeEvent {
    /// Unique event ID
    pub id: Uuid,
    /// Source system identifier
    pub source: SourceInfo,
    /// Event timestamp
    pub timestamp: DateTime<Utc>,
    /// Logical sequence number
    pub lsn: u64,
    /// Operation type
    pub operation: Operation,
    /// Collection/table name
    pub collection: String,
    /// Primary key/ID
    pub key: String,
    /// Before state (for updates/deletes)
    pub before: Option<RecordState>,
    /// After state (for inserts/updates)
    pub after: Option<RecordState>,
    /// Transaction context
    pub transaction: Option<TransactionInfo>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SourceInfo {
    /// Connector type (postgresql, mysql, mongodb, proximadb)
    pub connector: String,
    /// Source database/cluster name
    pub database: String,
    /// Schema/namespace
    pub schema: Option<String>,
    /// Server ID for replication
    pub server_id: String,
}

#[derive(Debug, Clone, Copy, Serialize, Deserialize)]
pub enum Operation {
    Insert,
    Update,
    Delete,
    Truncate,
    SchemaChange,
    Snapshot,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RecordState {
    /// Vector data (if present)
    pub vector: Option<Vec<f32>>,
    /// Metadata fields
    pub metadata: HashMap<String, Value>,
    /// Raw source data

/// PostgreSQL logical replication connector
pub struct PostgresConnector {
    config: PostgresConfig,
    client: tokio_postgres::Client,
    replication_slot: String,
    publication: String,
    offset_store: Arc<dyn OffsetStore>,
}

pub struct PostgresConfig {
    /// Connection string
    pub connection_string: String,
    /// Replication slot name
    pub slot_name: String,
    /// Publication name
    pub publication: String,
    /// Tables to capture
    pub tables: Vec<TableConfig>,
    /// Snapshot mode
    pub snapshot_mode: SnapshotMode,
    /// Vector column configuration
    pub vector_columns: HashMap<String, VectorColumnConfig>,
}

pub struct TableConfig {
    /// Schema name
    pub schema: String,
    /// Table name
    pub table: String,
    /// Primary key columns
    pub primary_key: Vec<String>,
    /// Column to use as vector (if pgvector)
    pub vector_column: Option<String>,
    /// Text columns to embed
    pub embed_columns: Option<Vec<String>>,
    /// Metadata columns
    pub metadata_columns: Vec<String>,
}

#[derive(Clone)]
pub enum SnapshotMode {
    /// Full snapshot on start
    Initial,
    /// Snapshot when no offset exists
    WhenNeeded,
    /// Never snapshot, start from current
    Never,
    /// Export snapshot on demand
    OnDemand,
}

impl PostgresConnector {
    pub async fn start(&mut self, sender: mpsc::Sender<ChangeEvent>) -> Result<()> {
        // Create replication connection
        let repl_conn = self.create_replication_connection().await?;

        // Get starting LSN
        let start_lsn = self.get_start_position().await?;

        // Start streaming
        let mut stream = repl_conn
            .start_replication(&self.replication_slot, start_lsn)
            .await?;

        while let Some(message) = stream.next().await {
            match message? {
                ReplicationMessage::XLogData(data) => {
                    let events = self.parse_logical_message(&data)?;
                    for event in events {
                        sender.send(event).await?;
                    }
                    self.offset_store.save(data.wal_end).await?;
                }
                ReplicationMessage::PrimaryKeepAlive(keepalive) => {
                    if keepalive.reply_requested {
                        stream.standby_status_update(keepalive.wal_end).await?;
                    }
                }
            }
        }

        Ok(())
    }
}

/// MySQL binary log connector
pub struct MySqlConnector {
    config: MySqlConfig,
    binlog_client: BinlogClient,
    offset_store: Arc<dyn OffsetStore>,
}

pub struct MySqlConfig {
    /// MySQL connection string
    pub connection_string: String,
    /// Server ID for replication
    pub server_id: u32,
    /// Database to capture
    pub database: String,
    /// Tables to capture
    pub tables: Vec<String>,
    /// GTID mode
    pub gtid_mode: bool,
    /// Column mappings
    pub column_config: HashMap<String, ColumnConfig>,
}

impl MySqlConnector {
    pub async fn start(&mut self, sender: mpsc::Sender<ChangeEvent>) -> Result<()> {
        // Get starting position
        let position = self.get_start_position().await?;

        // Create binlog stream
        let mut stream = self.binlog_client
            .replicate_from(position)
            .await?;

        while let Some(event) = stream.next().await {
            let binlog_event = event?;

            match binlog_event.header.type_code {
                EventType::WriteRows |
                EventType::UpdateRows |
                EventType::DeleteRows => {
                    let change = self.parse_row_event(&binlog_event)?;
                    sender.send(change).await?;
                }
                EventType::Query => {
                    // Handle DDL
                    if let Some(ddl) = self.parse_ddl(&binlog_event)? {
                        sender.send(ddl).await?;
                    }
                }
                EventType::Gtid => {
                    self.update_gtid_set(&binlog_event)?;
                }
                _ => {}
            }

            self.offset_store.save(&binlog_event.position).await?;
        }

        Ok(())
    }
}

=== MongoDB Connector

[source,rust]
----
/// MongoDB change stream connector
pub struct MongoConnector {
    config: MongoConfig,
    client: mongodb::Client,
    offset_store: Arc<dyn OffsetStore>,
}

pub struct MongoConfig {
    /// MongoDB connection string
    pub connection_string: String,
    /// Database to watch
    pub database: String,
    /// Collections to watch (empty = all)
    pub collections: Vec<String>,
    /// Pipeline filters
    pub pipeline: Option<Vec<Document>>,
    /// Resume token handling
    pub resume_mode: ResumeMode,
}

impl MongoConnector {
    pub async fn start(&mut self, sender: mpsc::Sender<ChangeEvent>) -> Result<()> {
        let db = self.client.database(&self.config.database);

        // Build change stream options
        let mut options = ChangeStreamOptions::default();
        options.full_document = Some(FullDocumentType::UpdateLookup);

        // Get resume token if available
        if let Some(token) = self.offset_store.get_resume_token().await? {
            options.resume_after = Some(token);
        }

        // Create change stream
        let mut stream = db
            .watch(self.config.pipeline.clone(), options)
            .await?;

        while let Some(event) = stream.next().await {
            let change_event = event?;

            let proximadb_event = self.convert_change_event(&change_event)?;
            sender.send(proximadb_event).await?;

            // Store resume token
            if let Some(token) = change_event.id {
                self.offset_store.save_resume_token(&token).await?;
            }
        }

        Ok(())
    }

    fn convert_change_event(&self, event: &ChangeStreamEvent) -> Result<ChangeEvent> {
        let operation = match event.operation_type {
            OperationType::Insert => Operation::Insert,
            OperationType::Update => Operation::Update,
            OperationType::Replace => Operation::Update,
            OperationType::Delete => Operation::Delete,
            OperationType::Drop => Operation::Truncate,
            _ => return Err(Error::UnsupportedOperation),
        };

        Ok(ChangeEvent {
            id: Uuid::new_v4(),
            source: SourceInfo {
                connector: "mongodb".to_string(),
                database: self.config.database.clone(),
                schema: None,
                server_id: self.client.server_id().to_string(),
            },
            timestamp: Utc::now(),
            lsn: event.cluster_time.map(|t| t.timestamp as u64).unwrap_or(0),
            operation,
            collection: event.ns.coll.clone().unwrap_or_default(),
            key: event.document_key.get_str("_id").unwrap_or("").to_string(),
            before: None,
            after: event.full_document.map(|doc| self.doc_to_record_state(&doc)),
            transaction: None,
        })
    }
}

/// Transforms source schema to ProximaDB schema
pub struct SchemaTransformer {
    mappings: HashMap<String, TableMapping>,
    embedding_pipeline: Option<Arc<EmbeddingPipeline>>,
}

pub struct TableMapping {
    /// Source table identifier
    pub source: String,
    /// Target ProximaDB collection
    pub target_collection: String,
    /// ID field mapping
    pub id_field: FieldMapping,
    /// Vector field configuration
    pub vector_config: VectorConfig,
    /// Metadata field mappings
    pub metadata_mappings: Vec<FieldMapping>,
}

pub enum VectorConfig {
    /// Direct vector column
    Direct { column: String },
    /// Generate embedding from text columns
    Embed {
        columns: Vec<String>,
        model: String,
        concatenation: ConcatMode,
    },
    /// Use external embedding service
    External {
        service_url: String,
        columns: Vec<String>,
    },
}

pub struct FieldMapping {
    /// Source field name (supports dot notation)
    pub source: String,
    /// Target metadata field name
    pub target: String,
    /// Transform function
    pub transform: Option<TransformFn>,
}

pub enum TransformFn {
    /// Parse as specific type
    ParseAs(DataType),
    /// Extract JSON path
    JsonPath(String),
    /// Apply template
    Template(String),
    /// Custom UDF
    Custom(String),
}

impl SchemaTransformer {
    pub async fn transform(&self, event: ChangeEvent) -> Result<Option<TransformedEvent>> {
        let mapping = self.mappings.get(&event.collection)
            .ok_or(Error::NoMapping)?;

        // Transform metadata
        let metadata = self.transform_metadata(&event, mapping)?;

        // Get or generate vector
        let vector = match &mapping.vector_config {
            VectorConfig::Direct { column } => {
                self.extract_vector(&event, column)?
            }
            VectorConfig::Embed { columns, model, .. } => {
                let text = self.extract_text(&event, columns)?;
                self.embedding_pipeline
                    .as_ref()
                    .ok_or(Error::NoEmbeddingPipeline)?
                    .embed(&text, model)
                    .await?
            }
            VectorConfig::External { service_url, columns } => {
                let text = self.extract_text(&event, columns)?;
                self.call_embedding_service(service_url, &text).await?
            }
        };

        Ok(Some(TransformedEvent {
            collection: mapping.target_collection.clone(),
            id: self.extract_id(&event, &mapping.id_field)?,
            vector,
            metadata,
            operation: event.operation,
            timestamp: event.timestamp,
        }))
    }
}

/// Pipeline for generating embeddings from text
pub struct EmbeddingPipeline {
    models: HashMap<String, Box<dyn EmbeddingModel>>,
    cache: Option<Arc<EmbeddingCache>>,
    batch_size: usize,
}

pub trait EmbeddingModel: Send + Sync {
    fn embed(&self, text: &str) -> Result<Vec<f32>>;
    fn embed_batch(&self, texts: &[String]) -> Result<Vec<Vec<f32>>>;
    fn dimension(&self) -> usize;
}

impl EmbeddingPipeline {
    pub async fn embed(&self, text: &str, model_name: &str) -> Result<Vec<f32>> {
        // Check cache
        if let Some(cache) = &self.cache {
            if let Some(embedding) = cache.get(text, model_name).await? {
                return Ok(embedding);
            }
        }

        // Generate embedding
        let model = self.models.get(model_name)
            .ok_or(Error::ModelNotFound)?;

        let embedding = model.embed(text)?;

        // Cache result
        if let Some(cache) = &self.cache {
            cache.put(text, model_name, &embedding).await?;
        }

        Ok(embedding)
    }
}

/// Emits ProximaDB changes as CDC events
pub struct ProximaDBCDCEmitter {
    wal_reader: Arc<WalReader>,
    sinks: Vec<Box<dyn CdcSink>>,
    position: AtomicU64,
}

pub trait CdcSink: Send + Sync {
    fn emit(&self, event: &ChangeEvent) -> impl Future<Output = Result<()>> + Send;
    fn flush(&self) -> impl Future<Output = Result<()>> + Send;
    fn close(&self) -> impl Future<Output = Result<()>> + Send;
}

impl ProximaDBCDCEmitter {
    pub async fn start(&self) -> Result<()> {
        let start_lsn = self.position.load(Ordering::SeqCst);

        let mut reader = self.wal_reader.subscribe(start_lsn)?;

        while let Some(entry) = reader.next().await {
            let event = self.wal_to_change_event(&entry)?;

            // Emit to all sinks
            for sink in &self.sinks {
                sink.emit(&event).await?;
            }

            self.position.store(entry.lsn, Ordering::SeqCst);
        }

        Ok(())
    }

    fn wal_to_change_event(&self, entry: &WalEntry) -> Result<ChangeEvent> {
        Ok(ChangeEvent {
            id: Uuid::new_v4(),
            source: SourceInfo {
                connector: "proximadb".to_string(),
                database: "default".to_string(),
                schema: None,
                server_id: self.server_id.clone(),
            },
            timestamp: entry.timestamp,
            lsn: entry.lsn,
            operation: match entry.operation {
                WalOperation::Insert => Operation::Insert,
                WalOperation::Update => Operation::Update,
                WalOperation::Delete => Operation::Delete,
            },
            collection: entry.collection.clone(),
            key: entry.record_id.clone(),
            before: entry.before.map(|r| self.record_to_state(&r)),
            after: entry.after.map(|r| self.record_to_state(&r)),
            transaction: entry.transaction.map(|t| TransactionInfo {
                id: t.id.to_string(),
                begin_time: t.begin_time,
                commit_time: t.commit_time,
                total_events: t.total_events,
                event_position: entry.position_in_tx,
            }),
        })
    }
}

/// Kafka CDC sink
pub struct KafkaSink {

    topic_config: TopicConfig,

pub struct TopicConfig {
    /// Topic name pattern (supports {collection} placeholder)
    pub topic_pattern: String,
    /// Partitioning strategy
    pub partitioning: PartitionStrategy,
    /// Message key configuration
    pub key_config: KeyConfig,
}

pub enum PartitionStrategy {
    /// Round-robin
    RoundRobin,
    /// By collection
    ByCollection,
    /// By record key
    ByKey,
    /// Custom partitioner
    Custom(Box<dyn Fn(&ChangeEvent) -> i32 + Send + Sync>),
}

impl CdcSink for KafkaSink {
    async fn emit(&self, event: &ChangeEvent) -> Result<()> {
        let topic = self.get_topic(event);
        let key = self.get_key(event);
        let payload = self.serializer.serialize(event)?;

        let record = FutureRecord::to(&topic)
            .key(&key)
            .payload(&payload)
            .headers(self.build_headers(event));

        self.producer.send(record, Timeout::Never).await
            .map_err(|(e, _)| Error::KafkaError(e))?;

        Ok(())
    }

    async fn flush(&self) -> Result<()> {
        self.producer.flush(Duration::from_secs(30))?;
        Ok(())
    }
}

/// Exactly-once delivery coordinator
pub struct ExactlyOnceCoordinator {
    /// Offset storage
    offset_store: Arc<dyn OffsetStore>,
    /// Transaction log
    transaction_log: Arc<TransactionLog>,
    /// Deduplication window
    dedup_window: Duration,
    /// Seen event IDs
    seen_events: LruCache<Uuid, Instant>,
}

impl ExactlyOnceCoordinator {
    pub async fn process_event(
        &self,
        event: ChangeEvent,
        processor: &dyn EventProcessor,
    ) -> Result<()> {
        // Check for duplicate
        if self.is_duplicate(&event).await? {
            tracing::debug!("Skipping duplicate event: {}", event.id);
            return Ok(());
        }

        // Begin transaction
        let tx = self.transaction_log.begin().await?;

        // Process event
        match processor.process(&event).await {
            Ok(()) => {
                // Mark as seen
                self.mark_seen(&event).await?;
                // Update offset
                self.offset_store.save(event.lsn).await?;
                // Commit transaction
                tx.commit().await?;
            }
            Err(e) => {
                // Rollback transaction
                tx.rollback().await?;
                return Err(e);
            }
        }

        Ok(())
    }

    async fn is_duplicate(&self, event: &ChangeEvent) -> Result<bool> {
        // Check in-memory cache first
        if self.seen_events.contains(&event.id) {
            return Ok(true);
        }

        // Check transaction log
        self.transaction_log.contains(&event.id).await
    }
}

== Summary

This specification provides comprehensive CDC integration for ProximaDB:

1. **Source Connectors**: PostgreSQL, MySQL, MongoDB with full snapshot and streaming
2. **Transform Layer**: Schema mapping, embedding generation, filtering
3. **Outbound CDC**: Emit ProximaDB changes to Kafka, Pulsar, webhooks
4. **Exactly-Once Semantics**: Transaction log, deduplication, checkpointing

Implementation follows a phased approach to deliver incremental value.
