== Technical Specifications

### Architecture

**Network**:
* VPC: 10.0.0.0/16 (all environments)
* Public subnets: 10.0.1.0/24, 10.0.2.0/24, 10.0.3.0/24
* Private subnets: 10.0.4.0/24, 10.0.5.0/24, 10.0.6.0/24
* Database subnets: 10.0.7.0/24, 10.0.8.0/24, 10.0.9.0/24
* Multi-AZ: 3 availability zones

**Kubernetes**:
* Version: 1.29
* Control plane: Managed by AWS (EKS)
* Node groups:
  * General purpose: t3.medium/xlarge (on-demand)
  * Compute optimized: c5.xlarge/2xlarge (spot)
  * Memory optimized: r5.xlarge (on-demand, production only)
* Auto-scaling: 2-20 replicas (HPA)

**ProximaDB Application**:
* Replicas: 2-20 (auto-scaling)
* Resources: 500m-4 CPU, 512Mi-8Gi memory
* Storage: 50Gi-500Gi (gp3-encrypted)
* Probes: Health checks on /health
