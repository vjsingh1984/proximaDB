Sprint-board-ready subtask matrix for E1 through E3. This document converts the three execution tickets into assignable work chunks with sequencing, owner lanes, dependencies, and parallelization guidance.

== Scope

This matrix covers:

* link:E1_CAPABILITY_REGISTRY_EXECUTION_TICKET.adoc[E1 Capability Registry Execution Ticket]
* link:E2_FILTERED_ANN_EXECUTION_TICKET.adoc[E2 Filtered ANN Execution Ticket]
* link:E3_MULTIMODEL_PLAN_EXECUTION_TICKET.adoc[E3 Multi-Model Plan Execution Ticket]

This matrix assumes:

* 2-week sprints
* 4 owner lanes
* role-based ownership now, named assignees later
* E10 verification work begins in parallel but is tracked separately

== Sequencing Model

* Sprint 1 establishes the E1 skeleton and starts E2 filter normalization prep in parallel.
* Sprint 2 lands plan validation on canonical paths and starts E3 shared logical plan work.
* Sprint 3 completes AXIS candidate execution and canonical explain plus execution convergence.
* Sprint 4 closes scan-surface honesty, generated support docs, and release gating for the tranche.

Critical path:

`SB-01 -> SB-02 -> SB-03 -> SB-08 -> SB-09 -> SB-12 -> SB-14`

Parallel lanes:

* E1 registry modeling can run alongside E2 normalization prep after interfaces stabilize.
* E2 backend work on HNSW and IVF can run in parallel once candidate contracts are set.
* E3 explain unification can run in parallel with UQL and federated lowering after the plan contract is fixed.

== Capacity Guidance

Suggested minimum staffing to execute this board without serializing all work:

* 1 Query Fabric lead
* 1 Vector and Indexing lead
* 1 API and Protocol engineer
* 1 Quality and Release engineer shared across sprints

If only 2 engineers are available:

* combine Query Fabric plus API and Protocol
* combine Vector and Indexing plus Quality and Release
* expect 4 sprints to stretch to 5 or 6

== Board Usage Notes

* Replace lane owners with named engineers before moving tasks into active sprint columns.
* Keep SB-07, SB-13, and SB-20 visible even if they are deferred; they are the closure criteria for the tranche.
* Do not pull E4 work into the board until SB-18 and SB-19 are complete or explicitly descoped.
