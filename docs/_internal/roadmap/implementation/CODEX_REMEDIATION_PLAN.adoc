== Executive Summary

This document outlines a systematic remediation plan for issues identified in the Codex code review. Each issue has been verified through code analysis and is addressed using:

* **TDD-First Approach**: Tests are written before implementation
* **SOLID Principles**: Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, Dependency Inversion
* **Design Patterns**: Strategy, Facade, Adapter, Factory, Observer patterns as appropriate

== Issue 1: Query-Path Fragmentation (P1)

=== Current State

Five parallel query execution systems exist:

[source]
----
src/query/
├── unified/mod.rs          # UnifiedQueryOptimizer (2,342 LOC) - PRIMARY
├── federated/mod.rs        # FederatedQueryContext (2,483 LOC) - ORPHANED

├── distributed/mod.rs      # Distributed Query (1,863 LOC) - STUB
└── unified_multimodel/     # Multi-Model Query (8,769 LOC) - UNDERUSED

=== Root Cause

* No clear architectural decision on primary query path
* Feature additions without consolidation
* Multiple teams/iterations building parallel systems

==== Phase 2: Implement Facade Pattern

.Design: Single entry point with strategy dispatch
[source,rust]
----
// src/query/unified/facade.rs

/// Facade that routes all queries through unified execution path
/// Implements Strategy pattern for query type handling
pub struct UnifiedQueryFacade {
    vector_strategy: Arc<dyn QueryStrategy>,
    graph_strategy: Arc<dyn QueryStrategy>,
    sql_strategy: Arc<dyn QueryStrategy>,
    optimizer: UnifiedQueryOptimizer,
}

/// Strategy trait for query execution (Open/Closed Principle)
pub trait QueryStrategy: Send + Sync {
    fn can_handle(&self, query: &QueryRequest) -> bool;
    async fn execute(&self, query: QueryRequest, ctx: &QueryContext) -> Result<QueryResult>;
}
----

==== Phase 3: Deprecate Redundant Paths

1. Mark `FederatedQueryContext` as `#[deprecated]` with migration path
2. Inline distributed query logic into unified (when single-node)
3. Consolidate multi-model into unified facade

=== SOLID Principles Applied

* **Single Responsibility**: Each QueryStrategy handles one query type
* **Open/Closed**: New query types added without modifying UnifiedQueryFacade
* **Dependency Inversion**: Facade depends on QueryStrategy trait, not concrete implementations

=== Estimated Impact

* **Before**: ~20,258 LOC across 5 systems
* **After**: ~8,000 LOC in unified system + deprecated stubs
* **Code Reduction**: ~60%

== Issue 2: Graph REST/gRPC Response Mismatch (P2)

=== Current State

* REST wraps responses in `{"success": true, "data": {...}}`
* gRPC returns flat structures: `{nodes: [...], edges: [...]}`
* Python SDK has workarounds that mask server-side issues
* One endpoint returns 501: `PUT /api/v1/graph/graphs/:graph_id/schema`

=== Root Cause

* REST handlers added wrapper for consistency with other endpoints
* gRPC follows proto-first design without wrapper
* No shared response transformation layer

=== TDD-First Remediation

==== Phase 1: Define Response Contract

.Test First: `tests/api/response_parity_test.rs`
[source,rust]
----

mod response_parity_tests {

    #[tokio::test]
    async fn test_query_nodes_rest_matches_grpc_structure() {
        let rest_response: Value = rest_client.query_nodes(&query).await?;
        let grpc_response = grpc_client.query_nodes(&query).await?;

        // REST should return flat structure matching gRPC
        assert!(rest_response.get("nodes").is_some());
        assert!(rest_response.get("data").is_none()); // No wrapper
    }

    #[tokio::test]
    async fn test_traverse_rest_matches_grpc_structure() {
        let rest_response: Value = rest_client.traverse(&request).await?;
        let grpc_response = grpc_client.traverse(&request).await?;

        assert_eq!(
            rest_response["nodes"].as_array().unwrap().len(),

async fn test_full_backup_restore_cycle() {
    let db = ProximaDB::new(test_config()).await?;

    // Insert test data
    db.create_collection("test", 128).await?;
    db.insert_vectors("test", test_vectors()).await?;

    // Create backup
    let backup_id = db.backup().create_full().await?;
    assert!(backup_id.is_valid());

    // Verify backup metadata
    let metadata = db.backup().get_metadata(&backup_id).await?;
    assert_eq!(metadata.collection_count, 1);

    // Clear and restore
    db.delete_collection("test").await?;
    db.backup().restore(&backup_id).await?;

    // Verify restoration
    let coll = db.get_collection("test").await?;
    assert!(coll.is_some());
}
