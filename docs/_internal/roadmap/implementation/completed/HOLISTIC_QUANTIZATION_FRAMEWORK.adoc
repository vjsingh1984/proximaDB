== Core Principles

1. **Separation of Concerns**: Proto messages remain unchanged, quantization is internal
2. **Reuse Over Reinvention**: Leverage existing StorageQuantizationEngine, VectorMemoryPool, etc.
3. **Performance First**: SIMD, memory pooling, and batching at every level
4. **Engine Agnostic**: Single interface works for all 6 engines
5. **Correctness Critical**: Compaction must recalculate quantization

== Component Architecture

=== 1. QuantizationPrecomputeService (New)

[source,rust]
----
// Location: src/compute/quantization/precompute.rs

use crate::compute::quantization::storage_engine::StorageQuantizationEngine;
use crate::core::memory::pool::VectorMemoryPool;
use crate::compute::quantization::global_cache::GlobalQuantizationCache;
use crate::compute::quantization::selection::QuantizationSelector;

/// Unified service for quantization precomputation
/// This is the ONLY entry point for quantization in flush/compaction
pub struct QuantizationPrecomputeService {
    storage_engine: Arc<StorageQuantizationEngine>,
    memory_pool: Arc<VectorMemoryPool>,
    cache: Arc<GlobalQuantizationCache>,
    selector: Arc<QuantizationSelector>,
    simd_processor: Arc<SimdBatchProcessor>,
}

impl QuantizationPrecomputeService {
    /// Global singleton instance
    pub fn global() -> Arc<Self> {
        static INSTANCE: OnceCell<Arc<QuantizationPrecomputeService>> = OnceCell::new();
        INSTANCE.get_or_init(|| Arc::new(Self::new_with_config(Config::default())))
            .clone()
    }

    /// Main entry point for flush operations
    pub async fn quantize_for_flush(
        &self,
        records: Vec<VectorRecord>,
        collection_config: &Collection,
    ) -> Result<QuantizedBatch> {
        // 1. Check if quantization is enabled
        if !self.is_quantization_enabled(collection_config) {
            return Ok(QuantizedBatch::unquantized(records));
        }

        // 2. Select optimal quantization levels
        let levels = self.selector.select_for_collection(collection_config)?;

        // 3. Process in optimal batches
        let batch_size = self.calculate_optimal_batch_size(&records, &levels);
        let mut all_quantized = Vec::with_capacity(records.len());

        for chunk in records.chunks(batch_size) {
            let quantized = self.process_batch(chunk, &levels, collection_config).await?;
            all_quantized.extend(quantized);
        }

        Ok(QuantizedBatch {
            records,
            quantized: all_quantized,
        })
    }

    /// Main entry point for compaction operations
    pub async fn quantize_for_compaction(
        &self,
        merged_records: Vec<VectorRecord>,
        collection_config: &Collection,
    ) -> Result<QuantizedBatch> {
        // Compaction MUST recalculate quantization for merged data
        self.quantize_for_flush(merged_records, collection_config).await
    }

    async fn process_batch(
        &self,
        batch: &[VectorRecord],
        levels: &[QuantizationLevel],
        config: &Collection,
    ) -> Result<Vec<Option<QuantizedVector>>> {
        // 1. Get aligned memory from pool
        let mut buffer = self.memory_pool.vector_buffers.take().await;
        buffer.resize(batch.len() * config.dimension(), 0.0);

        // 2. Copy vectors to aligned memory for SIMD
        self.simd_processor.prepare_batch(batch, &mut buffer)?;

        // 3. Quantize using StorageQuantizationEngine
        let storage_config = self.build_storage_config(config, levels);
        let quantized = self.storage_engine
            .quantize_batch_simd(&buffer, &storage_config)
            .await?;

        // 4. Return buffer to pool
        self.memory_pool.vector_buffers.put(buffer).await;

        Ok(quantized)
    }
}

// Location: src/storage/formats/quantized_vector.rs

/// Pairs original records with their quantization
/// This is the standard format for all engines
#[derive(Debug, Clone)]
pub struct QuantizedBatch {
    /// Original vector records (unchanged)
    pub records: Vec<VectorRecord>,
    /// Quantized representations (parallel array)
    pub quantized: Vec<Option<QuantizedVector>>,
}

impl QuantizedBatch {
    /// Create unquantized batch
    pub fn unquantized(records: Vec<VectorRecord>) -> Self {
        let quantized = vec![None; records.len()];
        Self { records, quantized }
    }

    /// Iterator over paired items
    pub fn iter(&self) -> impl Iterator<Item = (&VectorRecord, &Option<QuantizedVector>)> {
        self.records.iter().zip(self.quantized.iter())
    }

    /// Convert to storage format for specific engine
    pub fn to_storage_format(&self, engine: EngineType) -> StorageFormat {
        match engine {
            EngineType::SST | EngineType::SWIFT | EngineType::RAPTOR => {
                StorageFormat::Inline(self.to_inline_format())
            },
            EngineType::VIPER | EngineType::NOVA | EngineType::HELIX => {
                StorageFormat::Columnar(self.to_columnar_format())
            },
        }
    }
}

pub struct QuantizedVector {
    pub vector_id: String,
    pub binary: Option<Vec<u8>>,
    pub int8: Option<Vec<i8>>,
    pub pq: Option<PQData>,
    pub metadata: QuantizationMetadata,
}

/// Extension trait for quantization-aware operations
#[async_trait]
pub trait QuantizationAware: UnifiedStorageEngine {
    /// Flush with quantization precomputation
    async fn flush_with_quantization(
        &self,
        records: Vec<VectorRecord>,
        collection: &Collection,
    ) -> Result<FlushResult> {
        // 1. Get global precompute service
        let service = QuantizationPrecomputeService::global();

        // 2. Quantize batch
        let batch = service.quantize_for_flush(records, collection).await?;

        // 3. Store using engine-specific format
        self.store_quantized_batch(batch, collection).await
    }

    /// Compact with quantization recalculation
    async fn compact_with_quantization(
        &self,
        files: Vec<String>,
        collection: &Collection,
    ) -> Result<CompactionResult> {
        // 1. Load ALL vectors (not just metadata!)
        let all_records = self.load_all_vectors_from_files(&files).await?;

        // 2. Merge and sort
        let merged = self.merge_and_deduplicate(all_records)?;

        // 3. Recalculate quantization for merged data
        let service = QuantizationPrecomputeService::global();
        let batch = service.quantize_for_compaction(merged, collection).await?;

        // 4. Write new compacted file
        self.write_compacted_batch(batch, collection).await
    }

    /// Engine-specific storage implementation
    async fn store_quantized_batch(
        &self,
        batch: QuantizedBatch,
        collection: &Collection,
    ) -> Result<FlushResult>;

    /// Engine-specific compaction write
    async fn write_compacted_batch(
        &self,
        batch: QuantizedBatch,
        collection: &Collection,
    ) -> Result<CompactionResult>;
}

=== 4. SIMD Batch Processor (Enhance Existing)

[source,rust]
----
// Location: src/compute/simd/batch_processor.rs

pub struct SimdBatchProcessor {
    hardware: Arc<HardwareCapabilities>,
}

impl SimdBatchProcessor {
    /// Prepare batch for SIMD processing
    pub fn prepare_batch(
        &self,
        records: &[VectorRecord],
        buffer: &mut Vec<f32>,
    ) -> Result<()> {
        // Ensure alignment for SIMD
        assert!(buffer.as_ptr() as usize % 32 == 0, "Buffer not aligned");

        // Copy vectors to aligned buffer
        let dimension = records[0].values.len();
        for (i, record) in records.iter().enumerate() {
            let offset = i * dimension;
            buffer[offset..offset + dimension].copy_from_slice(&record.values);
        }

        Ok(())
    }

    /// SIMD-accelerated quantization operations
    pub fn quantize_batch_simd(
        &self,
        buffer: &[f32],
        config: &StorageQuantizationConfig,
    ) -> Vec<QuantizedVector> {
        match self.hardware.simd_support {
            SimdSupport::Avx512 => self.quantize_avx512(buffer, config),
            SimdSupport::Avx2 => self.quantize_avx2(buffer, config),
            SimdSupport::Neon => self.quantize_neon(buffer, config),
            SimdSupport::None => self.quantize_scalar(buffer, config),
        }
    }
}

=== Dynamic Batch Sizing

[source,rust]
----
impl QuantizationPrecomputeService {
    fn calculate_optimal_batch_size(
        &self,
        records: &[VectorRecord],
        levels: &[QuantizationLevel],
    ) -> usize {
        let dimension = records[0].values.len();
        let vector_size = dimension * 4; // f32

        // Calculate memory per vector including quantization
        let mut memory_per_vector = vector_size;
        for level in levels {
            memory_per_vector += match level {
                QuantizationLevel::Binary => dimension / 8,
                QuantizationLevel::Int8 => dimension,
                QuantizationLevel::PQ(_) => dimension / 4,
            };
        }

        // Available memory from config
        let available_memory = self.config.memory_budget_mb * 1024 * 1024;

        // Optimal batch size with safety margin
        let batch_size = (available_memory / memory_per_vector / 2)
            .min(self.config.max_batch_size)
            .max(self.config.min_batch_size);

        batch_size
    }
}

== Engine-Specific Implementations

[IMPORTANT]
====
**Storage Format Groups**:

1. **Parquet-Based (Columnar)**: VIPER, NOVA - Add quantization columns
2. **ProximaDataBlock-Based (Columnar)**: SST, SWIFT, HELIX - Use existing QuantizedSection with columnar encoding
3. **Custom Encoding (Columnar)**: RAPTOR - Integrate with ProximaEncoder's columnar schemes
====

=== Group 1: Parquet-Based Engines (VIPER, NOVA)

[source,rust]
----
// Shared implementation for VIPER and NOVA
impl QuantizationAware for ViperEngine { // Same for NovaEngine
    async fn store_quantized_batch(
        &self,
        batch: QuantizedBatch,
        _collection: &Collection,
    ) -> Result<FlushResult> {
        let mut builder = ParquetBuilder::new();

        // Original vectors column
        builder.add_fixed_list_column(
            constants::FIELD_VECTOR_FP32,
            batch.records.iter().map(|r| &r.values).collect(),
        );

        // Add quantization columns if present
        if let Some(first) = batch.quantized.first() {
            if let Some(q) = first {
                if q.binary.is_some() {
                    builder.add_binary_column(
                        constants::FIELD_VECTOR_BINARY,
                        extract_binary(&batch.quantized),
                    );
                }
                if q.int8.is_some() {
                    builder.add_fixed_len_column(
                        constants::FIELD_VECTOR_INT8,
                        extract_int8(&batch.quantized),
                    );
                }
                if q.pq.is_some() {
                    builder.add_binary_column(
                        constants::FIELD_VECTOR_PQ,
                        extract_pq(&batch.quantized),
                    );
                }
            }
        }

        let parquet = builder.build()?;
        self.write_parquet(parquet).await
    }
}

=== Group 2: ProximaDataBlock-Based Engines (SST, SWIFT, HELIX)

[IMPORTANT]
====
**ProximaDataBlock Integration Strategy**:

ProximaDataBlock is a columnar format with multiple encoding strategies:
- `TransposeFieldEncodedAndCompressedVector`: RxD → DxR transpose, encode each dimension
- `GroupedFieldEncodedAndCompressedVector`: 32D groups for cache locality
- `FullVector`: Keep as RxD for very high dimensions

**Key Decision**: Quantized vectors use the SAME columnar encoding strategy as main vectors for consistency.
====

[source,rust]
----
// ProximaDataBlock already has QuantizedSection support!
// Location: src/storage/engines/core/formats/proximablocks/block_structures.rs

pub struct ProximaDataBlock {
    // ... existing fields ...
    pub quantized_section: Option<QuantizedSection>,  // Already exists!
    pub vector_layout: VectorEncodingLayout,         // Columnar encoding strategy
}

pub struct QuantizedSection {
    pub binary_vectors: Option<Vec<Vec<u8>>>,
    pub int8_vectors: Option<Vec<Vec<i8>>>,
    pub pq_vectors: Option<Vec<Vec<u8>>>,
    pub codebooks: Option<Vec<Vec<f32>>>,
}

// Shared implementation for SST, SWIFT, HELIX
impl QuantizationAware for SstEngine { // Same for SwiftEngine, HelixEngine
    async fn store_quantized_batch(
        &self,
        batch: QuantizedBatch,
        _collection: &Collection,
    ) -> Result<FlushResult> {
        let mut block = ProximaDataBlock::new();

        // 1. Store original vectors with chosen encoding layout
        block.records = batch.records;
        block.vector_layout = self.select_optimal_layout(&batch)?;

        // 2. Apply SIMD encoding to vectors based on layout
        self.apply_simd_encoding(&mut block)?;

        // 3. Store quantized vectors using SAME columnar strategy
        if batch.has_quantization() {
            block.quantized_section = Some(self.build_quantized_section(
                &batch,
                block.vector_layout  // Use same layout!
            )?);
        }

        self.write_proxima_block(block).await
    }

    fn build_quantized_section(
        &self,
        batch: &QuantizedBatch,
        layout: VectorEncodingLayout,
    ) -> Result<QuantizedSection> {
        let mut section = QuantizedSection::default();

        // Extract quantized vectors matching the layout strategy
        match layout {
            VectorEncodingLayout::TransposeFieldEncodedAndCompressedVector => {
                // Transpose quantized vectors to DxR columnar format
                section.binary_vectors = self.transpose_quantized_binary(&batch);
                section.int8_vectors = self.transpose_quantized_int8(&batch);
            },
            VectorEncodingLayout::GroupedFieldEncodedAndCompressedVector => {
                // Group quantized vectors into 32D chunks
                section.binary_vectors = self.group_quantized_binary(&batch, 32);
                section.int8_vectors = self.group_quantized_int8(&batch, 32);
            },
            _ => {
                // Default columnar storage
                section.binary_vectors = self.extract_quantized_binary(&batch);
                section.int8_vectors = self.extract_quantized_int8(&batch);
            }
        }

        // Add PQ vectors and codebooks if present
        if batch.has_pq() {
            section.pq_vectors = self.extract_quantized_pq(&batch);
            section.codebooks = self.get_codebooks_for_batch(&batch);
        }

        Ok(section)
    }

    fn select_optimal_layout(&self, batch: &QuantizedBatch) -> Result<VectorEncodingLayout> {
        let dimension = batch.records[0].values.len();

        if dimension <= 128 {
            // Small dimensions: transpose for better SIMD
            Ok(VectorEncodingLayout::TransposeFieldEncodedAndCompressedVector)
        } else if dimension <= 1024 {
            // Medium: use grouped for cache locality
            Ok(VectorEncodingLayout::GroupedFieldEncodedAndCompressedVector)
        } else {
            // High dimensions: keep as-is
            Ok(VectorEncodingLayout::FullVector)
        }
    }

=== Group 3: RAPTOR with Custom Columnar Encoding

[IMPORTANT]
====
**RAPTOR Columnar Integration**:

RAPTOR uses ProximaEncoder with columnar encoding schemes:
- `FrameOfReference`: Delta encoding from base value
- `BitPacking`: Dense packing using minimum bits
- `Dictionary`: Replace values with indices

Quantized vectors follow the same columnar encoding pattern.
====

[source,rust]
----
// RAPTOR uses ProximaEncoder with Matrix Trinity architecture
impl QuantizationAware for RaptorEngine {
    async fn store_quantized_batch(
        &self,
        batch: QuantizedBatch,
        collection: &Collection,
    ) -> Result<FlushResult> {
        // RAPTOR uses ProximaEncoder with columnar schemes
        let encoder = ProximaEncoder::new(
            ProximaScheme::FrameOfReference { reference: 0 }
        );

        // Build row groups with Matrix Trinity
        let mut writer = RaptorWriter::new(
            &self.file_path,
            self.filesystem.clone(),
            self.config.clone(),
        );

        // Process vectors with clustering for P²+K²+P×K matrices
        let clustered = writer.cluster_vectors(&batch.records)?;

        // Encode each cluster with quantization
        for (cluster_id, cluster_vectors) in clustered.iter() {
            // Original vectors with ProximaEncoder (columnar)
            let encoded_vectors = encoder.encode_columnar(cluster_vectors)?;

            // Add quantized representations using SAME columnar encoding
            if batch.has_quantization() {
                let cluster_quantized = self.get_cluster_quantization(
                    &batch,
                    cluster_vectors
                )?;

                // Store quantized data with Matrix Trinity metadata
                writer.add_quantized_cluster(
                    cluster_id,
                    encoded_vectors,
                    cluster_quantized,
                )?;
            } else {
                writer.add_cluster(cluster_id, encoded_vectors)?;
            }
        }

        // Build matrices and write file
        writer.build_matrices()?;
        writer.finalize().await
    }

    fn get_cluster_quantization(
        &self,
        batch: &QuantizedBatch,
        cluster_vectors: &[VectorRecord],
    ) -> Result<Vec<Option<QuantizedVector>>> {
        // Extract quantization for specific cluster vectors
        let mut result = Vec::new();
        for vector in cluster_vectors {
            let idx = batch.records.iter()
                .position(|r| r.id == vector.id)
                .ok_or_else(|| anyhow!("Vector not found"))?;
            result.push(batch.quantized[idx].clone());
        }
        Ok(result)
    }
}

=== Query-Time Usage

[source,rust]

impl UnifiedStorageEngine for ViperEngine {
    async fn search_vectors_unified(
        &self,
        request: &SearchRequest,
    ) -> Result<Vec<SearchResult>> {
        // 1. Check if quantized columns exist
        let schema = self.read_schema(&request.collection_id).await?;
        let has_quantization = schema.has_column(constants::FIELD_VECTOR_BINARY);

        if !has_quantization {
            // Fall back to full precision
            return self.search_full_precision(request).await;
        }

        // 2. Quantize query vector once
        let service = QuantizationPrecomputeService::global();
        let query_quantized = service.quantize_query_vector(
            &request.query_vector,
            &request.collection_config,
        ).await?;

        // 3. Progressive search with quantized vectors
        let candidates = self.search_quantized_progressive(
            request,
            query_quantized,
        ).await?;

        // 4. Rerank with full precision if needed
        if request.use_exact_reranking {
            self.rerank_full_precision(candidates, &request.query_vector).await
        } else {
            Ok(candidates)
        }
    }
}

== Conclusion

This holistic framework leverages a critical insight: **All ProximaDB storage formats are columnar**.

**Key Achievements**:

1. **Maximizes Reuse**:
   - StorageQuantizationEngine, VectorMemoryPool, GlobalCache all ready
   - ProximaDataBlock already has QuantizedSection support

2. **Unified Columnar Strategy**:
   - Parquet: Native columnar with quantization columns
   - ProximaDataBlock: Columnar encoding with QuantizedSection
   - ProximaEncoder: Columnar schemes for RAPTOR
   - **All use SAME encoding for vectors and quantization**

3. **Optimizes Performance**:
   - SIMD everywhere with aligned memory
   - Consistent columnar access patterns
   - Cache-friendly data locality

4. **Ensures Correctness**:
   - Compaction recalculates quantization
