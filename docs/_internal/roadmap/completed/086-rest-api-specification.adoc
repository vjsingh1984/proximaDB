**Complete REST API reference for ProximaDB v1 - 90+ endpoints across vector, graph, document, and observability domains**

== Overview

ProximaDB exposes a comprehensive REST API on port **5678** (configurable) supporting:

* **Vector Operations**: Search, batch insert, CRUD
* **Graph Database**: Nodes, edges, traversal, algorithms
* **Document Store**: MongoDB-like JSON document API
* **Observability**: Logs, metrics, traces ingestion and query
* **Unified Query**: Cross-model SQL-like queries
* **Administration**: Health, metrics, collections

=== Base URL

[source]
----
http://localhost:5678/api/v1
----

=== Authentication

[cols="2,3", options="header"]
|===
| Method | Description
| API Key | `X-API-Key` header or `api_key` query parameter
| JWT | `Authorization: Bearer <token>` header
| mTLS | Client certificate (when configured)
|===

[cols="2,3,1", options="header"]
|===

| `Content-Type` | `application/json` | Yes

== Vector Operations

=== Vector Search

[source,http]
----
POST /api/v1/search
----

Execute vector similarity search across a collection.

**Request Body:**
[source,json]
----
{
  "collection_id": "my_collection",
  "queries": [
    {
      "vector": [0.1, 0.2, 0.3, ...],
      "top_k": 10,
      "filter": {
        "must": [{"field": "category", "match": "technology"}],
        "must_not": [],
        "should": []
      }
    }
  ],
  "search_params": {
    "ef_search": 100,
    "metric": "cosine"
  }
}
----

**Response:**
[source,json]
----
{
  "results": [
    {
      "id": "vec_123",
      "score": 0.95,
      "vector": [0.1, 0.2, ...],
      "metadata": {"category": "technology", "title": "Example"}
    }
  ],
  "status": "success",
  "request_id": "req_abc123"
}
----

== SQL Query API

=== Execute SQL

[source,http]
----
POST /api/v1/sql/execute
----

Execute SQL queries with vector similarity functions.

**Request Body:**
[source,json]
----
{
  "query": "SELECT id, metadata, VECTOR_DISTANCE(vector, $1, 'cosine') as score FROM my_collection WHERE $.category = 'tech' ORDER BY score LIMIT 10",
  "parameters": [
    {"vector": [0.1, 0.2, 0.3, ...]}
  ],
  "timeout_ms": 30000
}
----

**Supported Functions:**
[cols="2,4", options="header"]
|===
| Function | Description
| `VECTOR_DISTANCE(col, vec, metric)` | Compute distance
| `VECTOR_SIMILAR(col, vec, threshold)` | Filter by similarity
| `VECTOR_KNN(col, vec, k)` | K-nearest neighbors
|===

**Response:**
[source,json]
----
{
  "rows": [
    {"id": "vec_1", "metadata": {...}, "score": 0.12}
  ],
  "columns": ["id", "metadata", "score"],
  "column_types": ["string", "json", "float"],
  "execution_time_ms": 15,
  "rows_returned": 10,
  "rows_scanned": 1000
}
----

=== Explain Query

[source,http]
----
POST /api/v1/sql/explain
----

Get execution plan for SQL query.

== Unified Multi-Model Query API

=== Execute Unified Query

[source,http]
----
POST /api/v1/unified/execute
----

Execute SQL-like queries across vector, document, graph, and observability data.

**Request Body:**
[source,json]
----
{
  "query": "SELECT v.*, d.title FROM vectors.embeddings v JOIN documents.metadata d ON v.id = d.embedding_id WHERE VECTOR_SIMILAR(v.embedding, $1, 0.7) AND $.status = 'active' ORDER BY v.score DESC LIMIT 50 FUSION RRF(60)",
  "query_vector": [0.1, 0.2, 0.3, ...],
  "fusion_strategy": "rrf",
  "limit": 50
}
----

**Fusion Strategies:** `intersection`, `union`, `ranked`, `rrf`

== Error Responses

All endpoints return consistent error responses:

[source,json]
----
{
  "error": {
    "code": "COLLECTION_NOT_FOUND",
    "message": "Collection 'my_collection' does not exist",
    "details": {
      "collection_id": "my_collection"
    }
  },
  "request_id": "req_abc123",
  "timestamp": 1703980800

----

=== Error Codes

[cols="2,1,3", options="header"]
|===
| Code | HTTP Status | Description
| `INVALID_REQUEST` | 400 | Malformed request body
| `UNAUTHORIZED` | 401 | Authentication required
| `FORBIDDEN` | 403 | Insufficient permissions
| `NOT_FOUND` | 404 | Resource not found
| `CONFLICT` | 409 | Resource already exists
| `RATE_LIMITED` | 429 | Too many requests
| `INTERNAL_ERROR` | 500 | Server error
| `SERVICE_UNAVAILABLE` | 503 | Service temporarily unavailable
|===

== Rate Limiting

When rate limiting is enabled:

**Headers:**
[cols="2,4", options="header"]
|===
| Header | Description
| `X-RateLimit-Limit` | Request limit per window
| `X-RateLimit-Remaining` | Remaining requests
| `X-RateLimit-Reset` | Window reset timestamp
| `Retry-After` | Seconds until retry (when limited)
|===
