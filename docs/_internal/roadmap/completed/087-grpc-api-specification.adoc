== Overview

ProximaDB exposes a comprehensive gRPC API on port **5679** (configurable) with the following services:

[cols="2,1,3", options="header"]
|===
| Service | Methods | Description
| VectorService | 4 | Vector similarity search and CRUD
| CollectionService | 4 | Collection management
| GraphService | 22 | Graph database operations
| EntityService | 4 | Multi-modal entity management
| SqlService | 1 | SQL query execution
| DocumentService | 10 | MongoDB-like document API
| ObservabilityService | 15 | Logs, metrics, traces
| CatalogService | 23 | Iceberg-compatible catalog
| **Total** | **104+** |
|===
