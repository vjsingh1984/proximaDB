== Overview

This guide covers migrating from Pinecone's managed vector database to ProximaDB. ProximaDB offers similar functionality with additional features like graph database, document store, and self-hosted deployment options.

=== Feature Comparison

[cols="2,2,2", options="header"]
|===
| Feature | Pinecone | ProximaDB
| Deployment | Managed cloud only | Self-hosted + Cloud
| Vector Search | ✅ | ✅
| Metadata Filtering | ✅ | ✅ (Enhanced)
| Namespaces | ✅ | ✅ (Collections)
| Sparse Vectors | ✅ | ✅
| Graph Database | ❌ | ✅
| Document Store | ❌ | ✅
| SQL Queries | ❌ | ✅
| Storage Engines | 1 | 6 (SST, HELIX, VIPER, etc.)
| Quantization | Limited | Full (Binary, INT8, PQ)
|===

=== Batch Export Script

For large indexes, use this paginated approach:

[source,python]
----
import pinecone
import json
from concurrent.futures import ThreadPoolExecutor

def export_large_index(index_name, output_file, id_list_file=None):
    """
    Export large Pinecone index.
    Requires a file with vector IDs (one per line).
    """
    pinecone.init(api_key="YOUR_API_KEY", environment="YOUR_ENV")
    index = pinecone.Index(index_name)

    # Load IDs from file
    if id_list_file:
        with open(id_list_file, 'r') as f:
            all_ids = [line.strip() for line in f]
    else:
        raise ValueError("Pinecone requires ID list for full export")

    vectors = []
    batch_size = 100

    def fetch_batch(ids):
        try:
            response = index.fetch(ids=ids)
            batch_vectors = []
            for id, data in response.get('vectors', {}).items():
                batch_vectors.append({
                    'id': id,
                    'vector': data['values'],
                    'metadata': data.get('metadata', {})
                })
            return batch_vectors
        except Exception as e:
            print(f"Error fetching batch: {e}")
            return []

    # Process in parallel
    with ThreadPoolExecutor(max_workers=10) as executor:
        batches = [all_ids[i:i+batch_size] for i in range(0, len(all_ids), batch_size)]
        results = list(executor.map(fetch_batch, batches))

        for batch_result in results:
            vectors.extend(batch_result)

    # Save
    with open(output_file, 'w') as f:
        for v in vectors:
            f.write(json.dumps(v) + '\n')

    print(f"Exported {len(vectors)} vectors to {output_file}")
    return len(vectors)
----

== Step 3: Import Data to ProximaDB

=== Basic Import

[source,python]
----
import json
from proximadb_sdk import ProximaDBClient, VectorRecord

client = ProximaDBClient(url="http://localhost:5678")

# Load exported data
with open('pinecone_export.json', 'r') as f:
    vectors = json.load(f)

# Convert to ProximaDB format
records = []
for v in vectors:
    records.append(VectorRecord(
        id=v['id'],
        vector=v['vector'],
        metadata=v.get('metadata', {})
    ))

# Batch insert
batch_size = 1000
for i in range(0, len(records), batch_size):
    batch = records[i:i+batch_size]
    client.insert_vectors("migrated_from_pinecone", batch)
    print(f"Imported {min(i+batch_size, len(records))}/{len(records)}")

print("Migration complete!")
----

=== High-Performance Import (NDJSON)

[source,python]

import json
from proximadb_sdk import ProximaDBClient

client = ProximaDBClient(url="http://localhost:5678")

def import_ndjson(file_path, collection_name, batch_size=5000):
    """Import from NDJSON file with batching."""
    batch = []
    total = 0

    with open(file_path, 'r') as f:
        for line in f:
            record = json.loads(line)
            batch.append({
                'id': record['id'],
                'vector': record['vector'],
                'metadata': record.get('metadata', {})
            })

            if len(batch) >= batch_size:
                client.batch_upsert(collection_name, batch)
                total += len(batch)
                print(f"Imported {total} vectors...")
                batch = []

    # Final batch
    if batch:
        client.batch_upsert(collection_name, batch)
        total += len(batch)

    print(f"Complete! Imported {total} vectors")
    return total

import_ndjson('pinecone_export.ndjson', 'migrated_from_pinecone')

== Step 5: Migrate Metadata Filters

=== Filter Syntax Mapping

[cols="2,2,3", options="header"]
|===
| Pinecone Filter | ProximaDB Filter | Notes
| `{"field": {"$eq": "value"}}` | `{"field": "field", "match": "value"}` | Equality
| `{"field": {"$ne": "value"}}` | Use `must_not` clause | Not equal
| `{"field": {"$gt": 10}}` | `{"field": "field", "range": {"gt": 10}}` | Greater than
| `{"field": {"$gte": 10}}` | `{"field": "field", "range": {"gte": 10}}` | Greater or equal
| `{"field": {"$lt": 10}}` | `{"field": "field", "range": {"lt": 10}}` | Less than
| `{"field": {"$lte": 10}}` | `{"field": "field", "range": {"lte": 10}}` | Less or equal
| `{"field": {"$in": [1,2,3]}}` | `{"field": "field", "in": [1,2,3]}` | In list
| `{"$and": [...]}` | `{"must": [...]}` | AND
| `{"$or": [...]}` | `{"should": [...]}` | OR
|===

=== Filter Conversion Function

[source,python]
----
def convert_pinecone_filter(pinecone_filter):
    """Convert Pinecone filter to ProximaDB format."""
    if not pinecone_filter:
        return None

    must = []
    must_not = []
    should = []

    def convert_condition(field, condition):
        if isinstance(condition, dict):
            for op, value in condition.items():
                if op == '$eq':
                    return {'field': field, 'match': value}
                elif op == '$ne':
                    return {'field': field, 'match': value, '_not': True}
                elif op in ('$gt', '$gte', '$lt', '$lte'):
                    range_op = op[1:]  # Remove $
                    return {'field': field, 'range': {range_op: value}}
                elif op == '$in':
                    return {'field': field, 'in': value}
        else:
            # Direct equality
            return {'field': field, 'match': condition}

    for field, condition in pinecone_filter.items():
        if field == '$and':
            for sub in condition:
                converted = convert_pinecone_filter(sub)
                must.extend(converted.get('must', []))
        elif field == '$or':
            for sub in condition:
                converted = convert_pinecone_filter(sub)
                should.extend(converted.get('must', []))
        else:
            cond = convert_condition(field, condition)
            if cond.pop('_not', False):
                must_not.append(cond)
            else:
                must.append(cond)

    result = {}
    if must:
        result['must'] = must
    if must_not:
        result['must_not'] = must_not
    if should:
        result['should'] = should

    return result
----

== Rollback Plan

If migration issues occur:

# Keep Pinecone index running during migration
# Use feature flag to switch traffic

def search_with_fallback(query_vector, collection, fallback_to_pinecone=True):
    try:
        return client.search(collection, query_vector, top_k=10)
    except Exception as e:
        if fallback_to_pinecone:
            print(f"Falling back to Pinecone: {e}")
            return pinecone_index.query(vector=query_vector, top_k=10)

== Summary

Migration from Pinecone to ProximaDB involves:

1. **Export**: Use Pinecone fetch API with your ID list
2. **Create Collection**: Map pod type to storage engine
3. **Import**: Batch insert with progress tracking
4. **Migrate Code**: Update query syntax
5. **Validate**: Compare results between systems
6. **Optimize**: Tune index parameters for workload

=== Key Differences

* ProximaDB offers 6 storage engines vs Pinecone's single backend
* Full SQL support with vector functions
* Graph database integration for relationship queries
* Self-hosted option with no vendor lock-in
* Additional quantization options (Binary, INT8, PQ4-32)
