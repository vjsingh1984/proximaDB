== What is ProximaDB?

ProximaDB unifies vector embeddings and graph relationships, enabling you to perform semantic similarity searches and traverse relationship networks in one query. Whether you're building RAG applications, recommendation systems, or knowledge graphs, ProximaDB eliminates the complexity of coordinating separate vector and graph databases.

**Key capabilities**: Vector similarity search, graph traversal, hybrid queries combining vectors + graphs, multiple storage engines optimized for different workloads.

== Prerequisites

* **Operating System**: Linux, macOS, or Windows (WSL2)
* **For source build**: Rust 1.88+ (Edition 2024)
* **For Docker**: Docker installed
* **Memory**: 4GB available (8GB+ recommended)
* **Ports**: 5678 (REST), 5679 (gRPC) available

== Installation

Choose one of three installation methods:

=== Option 1: Build from Source

Best for development and getting the latest features.

[source,bash]
----
# Install Rust if needed
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env

# Clone and build
git clone https://github.com/vjsingh1984/proximaDB
cd proximaDB
cargo build --release

# Start server
cargo run --bin proximadb-server
----

Server starts in ~2-5 seconds on port 5678 (REST) and 5679 (gRPC).

=== Option 2: Docker (Recommended for Production)

[source,bash]
----
# Pull and run
docker pull proximadb/proximadb:latest
docker run -d -p 5678:5678 -p 5679:5679 proximadb/proximadb:latest

# Verify
curl http://localhost:5678/health
----

=== Option 3: Pre-built Binary (Coming Soon)

== Your First Query: Semantic Search in 60 Seconds

Complete example creating a vector collection, inserting data, and searching.

=== Step 1: Create a Collection

[source,bash]
----
curl -X POST http://localhost:5678/api/v1/collections \
  -H "Content-Type: application/json" \
  -d '{
    "name": "documents",
    "dimension": 128
  }'
----

=== Step 2: Insert Vectors

Using Python SDK (install: `pip install numpy` and set `PYTHONPATH=/path/to/proximaDB/clients/python/src`):

[source,python]
----
from proximadb import ProximaDBClient, VectorRecord
import numpy as np

# Connect
client = ProximaDBClient(url="http://localhost:5678", protocol="rest")

# Create normalized vectors
vectors = []
for i in range(10):
    vec = np.random.randn(128).astype(np.float32)
    vec = vec / np.linalg.norm(vec)

    vectors.append(VectorRecord(
        id=f"doc_{i}",
        vector=vec.tolist(),
        metadata={"title": f"Document {i}", "category": "demo"}
    ))

# Insert
result = client.insert_vectors("documents", records=vectors)
print(f"Inserted {result.metrics.successful_count} vectors")
----

=== Step 3: Search

[source,python]
----
# Create query vector
query = np.random.randn(128).astype(np.float32)
query = query / np.linalg.norm(query)

# Search
results = client.search(
    collection_id="documents",
    vector=query.tolist(),
    top_k=3,
    include_metadata=True
)

# Print results
for i, result in enumerate(results, 1):
    print(f"{i}. {result.metadata['title']} (score: {result.score:.4f})")
----

=== Step 4: Add Graph Relationships (Optional)

Connect your vectors with relationships:

[source,python]
----
import httpx

graph = httpx.Client(base_url="http://localhost:5678")

# Create graph
graph.post("/api/v1/graphs", json={
    "graph_id": "default",
    "name": "Document Network"
})

# Add edge (doc_1 references doc_0)
graph.post("/api/v1/graphs/default/edges", json={
    "edge_id": "ref_1_0",
    "from_node_id": "doc_1",
    "to_node_id": "doc_0",
    "edge_type": "REFERENCES"
})

# Hybrid query: Find similar + traverse relationships
search_result = client.search("documents", query.tolist(), top_k=1)
edges = graph.get(f"/api/v1/graphs/default/nodes/{search_result[0].id}/edges")
print(f"Found {len(edges.json())} relationships")
----
