= Configuration Reference
:toc: left
:toclevels: 3
:icons: font

Complete specification of ProximaDB configuration options in TOML format. All parameters, types, defaults, and constraints.

== Overview

Configuration file location: `config/config.toml`

Command-line override:
[source,bash]
----
proximadb-server --config /path/to/config.toml
----

Environment variable override:
[source,bash]
----
export PROXIMADB_CONFIG=/path/to/config.toml
----

== [server] Section

[cols="2,1,1,1,3"]
|===
| Parameter | Type | Required | Default | Description

| `node_id`
| string
| No
| `"proximadb-local"`
| Unique node identifier

| `bind_address`
| string
| No
| `"127.0.0.1"`
| Server bind IP address

| `port`
| integer
| Yes
| `5678`
| REST API port

| `data_dir`
| string
| Yes
| `"/tmp/proximadb/data"`
| Base directory for internal data
|===

**Example:**
[source,toml]
----
[server]
node_id = "proximadb-prod-01"
bind_address = "0.0.0.0"
port = 5678
data_dir = "/var/lib/proximadb/data"
----

=== [[storage.storage_locations]]

Array of storage location definitions. At least one required.

[cols="2,1,1,1,3"]
|===
| Parameter | Type | Required | Default | Description

| `url`
| string
| Yes
| None
| Storage URL (file://, s3://, azure://, gcs://)

| `weight`
| integer
| No
| `1`
| Relative weight for distribution

| `tags`
| string[]
| No
| `[]`
| Labels for filtering/selection
|===

**Example:**
[source,toml]
----
[[storage.storage_locations]]
url = "file:///mnt/ssd1/proximadb"
weight = 1
tags = ["ssd", "primary"]

[[storage.storage_locations]]
url = "file:///mnt/ssd2/proximadb"
weight = 2
tags = ["ssd", "secondary"]

[[storage.storage_locations]]
url = "s3://bucket/proximadb/"
weight = 1
tags = ["cloud", "backup"]
----

== [storage.wal_config] Section

Write-Ahead Log configuration.

[cols="2,1,1,1,3"]
|===
| Parameter | Type | Required | Default | Description

| `global_manifest_url`
| string
| Yes
| None
| Global WAL manifest location

| `memory_flush_size_bytes`
| integer
| No
| `16777216`
| Write buffer size (16MB)

| `global_flush_threshold`
| integer
| No
| `4294967296`
| Total WAL threshold (4GB)

| `enable_wal`
| bool
| No
| `true`
| Enable/disable WAL

| `distribution_strategy`
| string
| No
| `"LoadBalanced"`
| WAL distribution: `LoadBalanced`, `Local`

| `collection_affinity`
| bool
| No
| `true`
| Keep collection WAL together
|===

**Example:**
[source,toml]
----
[storage.wal_config]
global_manifest_url = "file:///var/lib/proximadb/manifest"
memory_flush_size_bytes = 67108864
global_flush_threshold = 8589934592
enable_wal = true
distribution_strategy = "LoadBalanced"
collection_affinity = true
----

== [storage.sst_config] Section

SST engine configuration (optional).

[cols="2,1,1,1,3"]
|===
| Parameter | Type | Required | Default | Description

| `block_size_kb`
| integer
| No
| `4096`
| Block size in KB

| `compression`
| string
| No
| `"zstd"`
| Compression: `zstd`, `lz4`, `snappy`, `none`

| `compression_level`
| integer
| No
| `3`
| Compression level (1-22)

| `vector_encoding_strategy`
| string
| No
| `"FullVector"`
| Encoding: `FullVector`, `TransposeFieldEncoded`, `GroupedFieldEncoded`

| `bloom_filter_fp_rate`
| float
| No
| `0.01`
| Bloom filter false positive rate

| `compaction_threshold`
| integer
| No
| `10`
| Files before compaction
|===

**Example:**
[source,toml]
----
[storage.sst_config]
block_size_kb = 2048
compression = "zstd"
compression_level = 3
vector_encoding_strategy = "TransposeFieldEncoded"
bloom_filter_fp_rate = 0.01
compaction_threshold = 10
----

== Environment Variables

Configuration can be overridden via environment variables:

[cols="2,3"]
|===
| Variable | Description

| `PROXIMADB_CONFIG`
| Configuration file path

| `PROXIMADB_PORT`
| Override server port

| `PROXIMADB_BIND_ADDRESS`
| Override bind address

| `PROXIMADB_DATA_DIR`
| Override data directory

| `PROXIMADB_METADATA_URL`
| Override metadata URL

| `RUST_LOG`
| Override log level (module-specific)

| `AWS_ACCESS_KEY_ID`
| AWS credentials for S3

| `AWS_SECRET_ACCESS_KEY`
| AWS secret key

| `AWS_REGION`
| AWS region

| `AZURE_STORAGE_ACCOUNT`
| Azure storage account

| `AZURE_STORAGE_KEY`
| Azure storage key

| `GOOGLE_APPLICATION_CREDENTIALS`
| GCP credentials file path
|===

== Validation

Validate configuration without starting:

[source,bash]
----
proximadb-server --config config.toml --validate
----

Print effective configuration:

[source,bash]
----
proximadb-server --config config.toml --print-config
----

== Minimal Configuration

Minimum required configuration:

[source,toml]
----
[server]
port = 5678
data_dir = "/data/proximadb"

[storage]
metadata_url = "file:///data/proximadb/metadata"

[[storage.storage_locations]]
url = "file:///data/proximadb/storage"
weight = 1
----
