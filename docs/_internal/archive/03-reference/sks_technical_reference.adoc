= Semantic Knowledge Store (SKS) API Reference
:toc: left
:toclevels: 3
:icons: font

Complete API specification for ProximaDB's Semantic Knowledge Store. Defines entity storage, relationship management, and hybrid query operations.

== Overview

SKS extends ProximaDB with entity-centric storage, graph relationships, and provenance tracking.

**Base URL:** `http://localhost:5678/api/v1/sks`

**Content-Type:** `application/json`

**Proto Definitions:** `proto/proximadb/v1/sks.proto`

== Data Types

=== Entity

[source,json]
----
{
  "id": "string",
  "entity_type": "string",
  "collection_id": "string",
  "metadata": {
    "key": "value"
  },
  "embedding": {
    "vector": [0.1, 0.2, 0.3],
    "model": "string",
    "version": 1
  },
  "content": "string",
  "source": {
    "url": "string",
    "extracted_at": "2025-01-15T10:30:00Z"
  },
  "created_at": "2025-01-15T10:30:00Z",
  "updated_at": "2025-01-15T10:30:00Z",
  "version": 1
}
----

[cols="2,1,1,3"]
|===
| Field | Type | Required | Description

| `id` | string | Yes | Unique entity identifier
| `entity_type` | string | Yes | Entity type (e.g., "document", "user")
| `collection_id` | string | Yes | Collection identifier
| `metadata` | object | No | Flexible key-value metadata
| `embedding.vector` | float32[] | No | Vector embedding
| `embedding.model` | string | No | Embedding model name
| `embedding.version` | int32 | No | Model version
| `content` | string | No | Entity content/text
| `source.url` | string | No | Source URL
| `source.extracted_at` | string | No | Extraction timestamp
| `version` | uint32 | No | Entity version (MVCC)
|===

== Entity Operations

=== POST /api/v1/sks/entities

Create or update entity.

**Request Body:**
[source,json]
----
{
  "id": "doc_123",
  "entity_type": "document",
  "collection_id": "papers",
  "metadata": {
    "title": "Vector Database Research",
    "authors": ["Smith, J.", "Doe, A."],
    "year": 2025
  },
  "embedding": {
    "vector": [0.1, 0.2, 0.3],
    "model": "text-embedding-ada-002",
    "version": 1
  },
  "content": "Full document text...",
  "source": {
    "url": "https://example.com/paper.pdf",
    "extracted_at": "2025-01-15T10:00:00Z"
  }
}
----

**Response 200:**
[source,json]
----
{
  "success": true,
  "entity_id": "doc_123",
  "version": 1,
  "created_at": "2025-01-15T10:30:00Z"
}
----

**Status Codes:**

* `200` - Success
* `400` - Invalid request
* `500` - Server error

== Hybrid Query Operations

=== POST /api/v1/sks/hybrid/search

Hybrid vector + graph search.

**Request Body:**
[source,json]
----
{
  "collection_id": "papers",
  "vector_component": {
    "query_vector": [0.1, 0.2, 0.3],
    "k": 50,
    "threshold": 0.7
  },
  "graph_component": {
    "start_entities": ["doc_123"],
    "relation_types": ["CITES", "REFERENCES"],
    "max_depth": 2
  },
  "fusion_strategy": "balanced",
  "result_limit": 10
}
----

**Fusion Strategies:**

* `balanced` - Equal weight (0.5 vector, 0.5 graph)
* `vector_first` - Prioritize similarity (0.7 vector, 0.3 graph)
* `graph_first` - Prioritize relationships (0.3 vector, 0.7 graph)

**Response 200:**
[source,json]
----
{
  "results": [
    {
      "entity_id": "doc_456",
      "vector_score": 0.92,
      "graph_distance": 2,
      "combined_score": 0.85,
      "explanation": {
        "vector_contribution": 0.46,
        "graph_contribution": 0.39
      }
    }
  ],
  "execution_time_ms": 15
}
----

**Status Codes:**

* `200` - Success
* `400` - Invalid request
* `500` - Server error

== SQL Extensions

=== SIMILAR Operator

Find entities with similar embeddings.

**Syntax:**
[source,sql]
----
SELECT * FROM entities
WHERE embedding SIMILAR TO [0.1, 0.2, 0.3]
WITH THRESHOLD 0.8;
----

**Parameters:**

* `THRESHOLD` - Minimum similarity score (0.0-1.0)

=== FOLLOW Operator

Traverse relationships from entity.

**Syntax:**
[source,sql]
----
SELECT * FROM entities e
FOLLOW citations FROM 'doc_123'
WITH MAX_DEPTH 3
WHERE e.metadata->>'year' >= '2020';
----

**Parameters:**

* `MAX_DEPTH` - Maximum traversal depth
* `WHERE` - Filter traversed entities

=== ASSEMBLE Operator

Build context from related entities.

**Syntax:**
[source,sql]
----
SELECT * FROM entities
WHERE embedding SIMILAR TO [0.1, 0.2, 0.3]
ASSEMBLE CONTEXT FROM citations, references
WITH MAX_DEPTH 2, THRESHOLD 0.8;
----

**Parameters:**

* `MAX_DEPTH` - Relationship depth
* `THRESHOLD` - Minimum similarity

== Error Responses

All errors follow consistent format:

[source,json]
----
{
  "error": {
    "code": "ENTITY_NOT_FOUND",
    "message": "Entity with ID 'doc_123' does not exist",
    "details": {
      "entity_id": "doc_123",
      "operation": "get_entity"
    }
  },
  "timestamp": "2025-01-15T10:30:00Z"
}
----

=== Error Codes

[cols="2,3,2"]
|===
| Code | Description | HTTP Status

| `ENTITY_NOT_FOUND` | Entity does not exist | 404
| `ENTITY_ALREADY_EXISTS` | Entity ID already exists | 409
| `RELATION_NOT_FOUND` | Relation does not exist | 404
| `INVALID_EMBEDDING_VERSION` | Invalid embedding version | 400
| `COLLECTION_NOT_FOUND` | Collection does not exist | 404
| `INVALID_METADATA` | Malformed metadata | 400
|===

== Configuration

=== [sks] Section

[cols="2,1,1,1,3"]
|===
| Parameter | Type | Required | Default | Description

| `enabled` | bool | No | `true` | Enable SKS features
| `default_collection` | string | No | `"knowledge_store"` | Default collection
|===

=== [sks.entity_store] Section

[cols="2,1,1,1,3"]
|===
| Parameter | Type | Required | Default | Description

| `storage_engine` | string | No | `"viper"` | Storage engine: `viper`, `sst`
| `enable_versioning` | bool | No | `true` | Enable multi-version embeddings
| `max_versions` | uint32 | No | `5` | Maximum versions to retain
|===

=== [sks.relations] Section

[cols="2,1,1,1,3"]
|===
| Parameter | Type | Required | Default | Description

| `max_traversal_depth` | uint32 | No | `10` | Maximum BFS depth
| `enable_bidirectional_index` | bool | No | `true` | Index both directions
| `relation_cache_size_mb` | uint32 | No | `512` | Relation cache size (MB)
|===

=== [sks.provenance] Section

[cols="2,1,1,1,3"]
|===
| Parameter | Type | Required | Default | Description

| `enable_tracking` | bool | No | `true` | Enable provenance tracking
| `retention_days` | uint32 | No | `365` | Provenance retention
| `detail_level` | string | No | `"full"` | Detail: `minimal`, `standard`, `full`
|===

**Example Configuration:**
[source,toml]
----
[sks]
enabled = true
default_collection = "knowledge_store"

[sks.entity_store]
storage_engine = "viper"
enable_versioning = true
max_versions = 5

[sks.relations]
max_traversal_depth = 10
enable_bidirectional_index = true
relation_cache_size_mb = 512

[sks.provenance]
enable_tracking = true
retention_days = 365
detail_level = "full"
----
