= Graph Database API Reference
:toc: left
:toclevels: 3
:icons: font

Complete API specification for ProximaDB graph database operations. Defines exact request/response formats for all node, edge, and traversal operations.

== Overview

ProximaDB graph database provides native graph storage with CSR format and three engine implementations:

[cols="2,2,2,2"]
|===
| Engine | Architecture | Insert Throughput | Traversal Latency

| ORION | In-memory CSR | 63K-414K ops/sec | <10μs
| PULSAR | Distributed sharded | 254K-381K ops/sec | ~6-10μs
| QUASAR | Hot/cold tiered | 345K-471K ops/sec | ~6-10μs
|===

**Base URL:** `http://localhost:5678/api/v1/graph`

**Content-Type:** `application/json`

== Data Types

=== Node

[source,json]
----
{
  "id": "string",
  "labels": ["string"],
  "properties": {
    "key": "value"
  },
  "embedding": {
    "vector": [0.1, 0.2, 0.3],
    "model": "string",
    "version": 1
  },
  "created_at": "2025-01-15T10:30:00Z",
  "updated_at": "2025-01-15T10:30:00Z"
}
----

[cols="2,1,1,3"]
|===
| Field | Type | Required | Description

| `id` | string | Yes | Unique node identifier
| `labels` | string[] | No | Node type labels
| `properties` | object | No | Key-value properties
| `embedding.vector` | float32[] | No | Vector embedding
| `embedding.model` | string | No | Embedding model name
| `embedding.version` | int32 | No | Model version
|===

=== Edge

[source,json]
----
{
  "id": "string",
  "from_node_id": "string",
  "to_node_id": "string",
  "edge_type": "string",
  "properties": {
    "key": "value"
  },
  "weight": 0.8,
  "created_at": "2025-01-15T10:30:00Z"
}
----

[cols="2,1,1,3"]
|===
| Field | Type | Required | Description

| `id` | string | No | Edge identifier (auto-generated if not provided)
| `from_node_id` | string | Yes | Source node ID
| `to_node_id` | string | Yes | Target node ID
| `edge_type` | string | Yes | Relationship type
| `properties` | object | No | Edge properties
| `weight` | float64 | No | Edge weight (default: 1.0)
|===

== Node Operations

=== POST /api/v1/graph/graphs/:graph_id/nodes

Create node.

**Path Parameters:**

* `graph_id` (string, required)

**Request Body:**
[source,json]
----
{
  "node": {
    "id": "user_123",
    "labels": ["User", "Customer"],
    "properties": {
      "name": "John Doe",
      "age": 35,
      "email": "john@example.com"
    },
    "embedding": {
      "vector": [0.1, 0.2, 0.3],
      "model": "text-embedding-ada-002",
      "version": 1
    }
  }
}
----

**Response 200:**
[source,json]
----
{
  "success": true,
  "node_id": "user_123",
  "created_at": "2025-01-15T10:30:00Z"
}
----

**Status Codes:**

* `200` - Success
* `400` - Invalid request
* `409` - Node exists
* `500` - Server error

=== GET /api/v1/graph/graphs/:graph_id/nodes/:node_id

**Path Parameters:**

* `graph_id` (string, required)

== Traversal Operations

=== POST /api/v1/graph/graphs/:graph_id/traverse

Graph traversal (BFS/DFS/Parallel BFS).

**Path Parameters:**

* `graph_id` (string, required)

**Request Body:**
[source,json]
----
{
  "start_node_id": "user_123",
  "max_depth": 3,
  "edge_types": ["FOLLOWS", "CONNECTS"],
  "node_labels": ["User"],
  "algorithm": "BFS",
  "return_path": true
}
----

**Parameters:**

[cols="2,1,1,3"]
|===
| Field | Type | Required | Description

| `start_node_id` | string | Yes | Starting node ID
| `max_depth` | uint32 | No | Maximum traversal depth (default: 3)
| `edge_types` | string[] | No | Filter edge types
| `node_labels` | string[] | No | Filter node labels
| `algorithm` | string | No | Algorithm: `BFS`, `DFS`, `PARALLEL_BFS` (default: `BFS`)
| `return_path` | bool | No | Include paths (default: false)
|===

**Response 200:**
[source,json]
----
{
  "nodes": [
    {"id": "user_123"},
    {"id": "user_456"}
  ],
  "edges": [
    {"id": "follows_456"}
  ],
  "paths": [
    ["user_123", "user_456"]
  ],
  "stats": {
    "nodes_visited": 2,
    "edges_traversed": 1,
    "execution_time_ms": 5
  }
}
----

**Status Codes:**

* `200` - Success
* `400` - Invalid request
* `404` - Start node not found
* `500` - Server error

== Hybrid Operations

=== POST /api/v1/graph/hybrid/search

Hybrid vector + graph search.

**Request Body:**
[source,json]
----
{
  "graph_id": "my_graph",
  "vector_component": {
    "collection": "documents",
    "query_vector": [0.1, 0.2, 0.3],
    "k": 50,
    "threshold": 0.7
  },
  "graph_component": {
    "start_nodes": ["doc_123"],
    "edge_types": ["CITES", "REFERENCES"],
    "max_depth": 3
  },
  "fusion_strategy": "balanced",
  "result_limit": 10
}
----

**Fusion Strategies:**

* `balanced` - Equal weight to vector and graph
* `vector_first` - Prioritize vector similarity
* `graph_first` - Prioritize graph relationships

**Response 200:**
[source,json]
----
{
  "results": [
    {
      "node_id": "doc_456",
      "vector_score": 0.92,
      "graph_distance": 2,
      "combined_score": 0.85
    }
  ],
  "execution_time_ms": 15
}
----

**Status Codes:**

* `200` - Success
* `400` - Invalid request
* `500` - Server error

== Error Responses

All errors follow consistent format:

[source,json]
----
{
  "error": {
    "code": "NODE_NOT_FOUND",
    "message": "Node with ID 'user_123' does not exist",
    "details": {
      "node_id": "user_123",
      "operation": "get_node"
    }
  },
  "timestamp": "2025-01-15T10:30:00Z"
}
----

=== Error Codes

[cols="2,3,2"]
|===
| Code | Description | HTTP Status

| `NODE_NOT_FOUND` | Node does not exist | 404
| `EDGE_NOT_FOUND` | Edge does not exist | 404
| `NODE_ALREADY_EXISTS` | Node ID already exists | 409
| `EDGE_ALREADY_EXISTS` | Edge already exists | 409
| `INVALID_PROPERTY_TYPE` | Property type not supported | 400
| `TRAVERSAL_DEPTH_EXCEEDED` | Max depth exceeded | 400
| `QUERY_TIMEOUT` | Query execution timeout | 500
| `GRAPH_NOT_FOUND` | Graph does not exist | 404
|===

== Performance Metrics

=== Operation Latencies

[cols="2,2,3"]
|===
| Operation | Latency | Throughput

| Node lookup | <10μs | 63K+ ops/sec
| Edge insert | 2-3μs | 381K-471K ops/sec
| 1-hop traversal | ~6-10μs | 103K-159K ops/sec
| Semantic search | 0.09ms | 11K+ ops/sec
| Shortest path (depth 3) | 1-5ms | Variable
|===

=== Scalability

[cols="2,2,2,2"]
|===
| Graph Size | Node Lookup | 1-hop Traversal | Multi-hop (depth 3)

| 1K nodes | 0.3ms | 0.4ms | 1.5ms
| 10K nodes | 0.4ms | 0.6ms | 2.8ms
| 100K nodes | 0.6ms | 1.2ms | 5.2ms
| 1M nodes | 1.2ms | 2.1ms | 8.7ms
|===
