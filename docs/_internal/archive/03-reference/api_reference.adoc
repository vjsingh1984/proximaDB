= REST API Reference
:toc: left
:toclevels: 3
:icons: font

Complete reference for ProximaDB REST API endpoints. This document specifies exact request/response formats, parameters, and error codes for all operations.

[NOTE]
====
For comprehensive specifications including request body schemas, see link:rest-api-specification.adoc[REST API Specification].
====

== Base Configuration

[cols="2,3"]
|===
| Property | Value

| Base URL | `http://localhost:5678`
| API Version | v1
| Content-Type | `application/json`
| Protocol | HTTP/1.1, HTTP/2
| Max Request Size | 64MB (configurable)
|===

== Health Endpoints

=== GET /health

Comprehensive health check.

**Response 200:**
[source,json]
----
{
  "status": "healthy",
  "timestamp": "2025-01-15T10:30:00Z",
  "version": "0.2.0",
  "services": {
    "rest_api": "operational",
    "storage": "operational",
    "indexing": "operational"
  }
}
----

**Status Codes:**

* `200` - System healthy
* `503` - System unhealthy

=== GET /health/live

Liveness probe (Kubernetes).

**Response 200:**
[source,json]
----
{
  "alive": true
}
----

**Status Codes:**

* `200` - Process alive
* `500` - Process should restart

=== GET /health/ready

Readiness probe (Kubernetes).

**Response 200:**
[source,json]
----
{
  "ready": true,
  "checks": {
    "storage": "ready",
    "index": "ready"
  }
}
----

**Status Codes:**

* `200` - Ready for traffic
* `503` - Not ready

== Collection Endpoints

=== POST /api/v1/collections

Create collection.

**Request Body:**
[source,json]
----
{
  "operation": 0,
  "collection_id": "string",
  "collection_config": {
    "dimension": 1536,
    "distance_metric": "cosine",
    "storage_engine": "viper"
  }
}
----

**Response 200:**
[source,json]
----
{
  "success": true,
  "collection": {
    "collection_id": "string",
    "config": {...},
    "stats": {
      "vector_count": 0,
      "size_bytes": 0
    }
  }
}
----

**Status Codes:**

* `200` - Success
* `400` - Invalid request
* `409` - Collection exists
* `500` - Server error

=== GET /api/v1/collections

List all collections.

**Query Parameters:**

[cols="2,1,1,3"]
|===
| Parameter | Type | Required | Description

| `limit` | uint32 | No | Max results (default: 100)
| `offset` | uint32 | No | Skip N results (default: 0)
| `include_stats` | bool | No | Include statistics (default: false)
|===

**Response 200:**
[source,json]
----
{
  "collections": [
    {
      "collection_id": "string",
      "config": {...},
      "stats": {...}
    }
  ],
  "total_count": 5,
  "has_more": false
}
----

**Status Codes:**

* `200` - Success
* `500` - Server error

=== GET /api/v1/collections/:collection_id

Get collection by ID.

**Path Parameters:**

* `collection_id` (string, required)

**Response 200:**
[source,json]
----
{
  "success": true,
  "collection": {
    "collection_id": "string",
    "config": {
      "dimension": 768,
      "storage_engine": "viper",
      "distance_metric": "cosine"
    },
    "stats": {
      "vector_count": 10000,
      "size_bytes": 31457280
    }
  }
}
----

**Status Codes:**

* `200` - Success
* `404` - Not found
* `500` - Server error

=== DELETE /api/v1/collections/:collection_id

Delete collection.

**Path Parameters:**

* `collection_id` (string, required)

**Response 200:**
[source,json]
----
{
  "success": true,
  "message": "Collection deleted",
  "vectors_deleted": 10000
}
----

**Status Codes:**

* `200` - Deleted
* `404` - Not found
* `500` - Server error

== Vector Endpoints

=== POST /api/v1/vectors/batch

Batch vector operations (insert/update/delete/upsert).

**Request Body:**
[source,json]
----
{
  "collection_id": "string",
  "operation": "insert",
  "vectors": [
    {
      "id": "vec_001",
      "vector": [0.1, 0.2, 0.3],
      "metadata": {
        "key": {"stringValue": "value"},
        "num": {"numberValue": 42}
      }
    }
  ]
}
----

**Operation Values:**

* `insert` - Insert new (fails if exists)
* `update` - Update existing (fails if not exists)
* `upsert` - Insert or update
* `delete` - Delete by ID

**Response 200:**
[source,json]
----
{
  "success": true,
  "vectors_affected": 1,
  "vectors_inserted": 1,
  "vectors_updated": 0,
  "vectors_deleted": 0,
  "execution_time_ms": 45
}
----

**Status Codes:**

* `200` - Success
* `400` - Invalid request
* `404` - Collection not found
* `413` - Payload too large
* `500` - Server error

=== GET /api/v1/vectors/:collection_id/:vector_id

Get vector by ID.

**Path Parameters:**

* `collection_id` (string, required)
* `vector_id` (string, required)

**Query Parameters:**

[cols="2,1,1,3"]
|===
| Parameter | Type | Required | Description

| `include_vector` | bool | No | Include vector data (default: true)
| `include_metadata` | bool | No | Include metadata (default: true)
|===

**Response 200:**
[source,json]
----
{
  "id": "vec_001",
  "vector": [0.1, 0.2, 0.3],
  "metadata": {...}
}
----

**Status Codes:**

* `200` - Success
* `404` - Not found
* `500` - Server error

=== DELETE /api/v1/vectors/:collection_id/:vector_id

Delete vector by ID.

**Path Parameters:**

* `collection_id` (string, required)
* `vector_id` (string, required)

**Response 200:**
[source,json]
----
{
  "success": true,
  "message": "Vector deleted"
}
----

**Status Codes:**

* `200` - Deleted
* `404` - Not found
* `500` - Server error

=== POST /api/v1/search

Vector similarity search.

**Request Body:**
[source,json]
----
{
  "collection_id": "string",
  "query_vector": [0.1, 0.2, 0.3],
  "top_k": 10,
  "metadata_filters": [
    {
      "field": "category",
      "operator": "EQUALS",
      "value": {"stringValue": "product"}
    }
  ],
  "options": {
    "include_vectors": false,
    "include_metadata": true,
    "min_score": 0.7
  }
}
----

**Filter Operators:**

* `EQUALS`, `NOT_EQUALS`
* `LESS_THAN`, `LESS_THAN_OR_EQUAL`
* `GREATER_THAN`, `GREATER_THAN_OR_EQUAL`
* `IN`, `NOT_IN`
* `CONTAINS`, `STARTS_WITH`, `ENDS_WITH`

**Response 200:**
[source,json]
----
{
  "results": [
    {
      "id": "vec_001",
      "score": 0.95,
      "metadata": {...}
    }
  ],
  "total_results": 1,
  "execution_time_ms": 12
}
----

**Status Codes:**

* `200` - Success
* `400` - Invalid request
* `404` - Collection not found
* `500` - Server error

== SQL Endpoints

=== POST /api/v1/sql/execute

Execute SQL query.

**Request Body:**
[source,json]
----
{
  "query": "SELECT id, metadata FROM collection WHERE metadata.key = 'value' LIMIT 10"
}
----

**Response 200:**
[source,json]
----
{
  "columns": ["id", "metadata"],
  "rows": [
    ["vec_001", {...}]
  ],
  "row_count": 1,
  "execution_time_ms": 23
}
----

**Status Codes:**

* `200` - Success
* `400` - Invalid SQL
* `500` - Server error

=== POST /api/v1/sql/explain

Get query execution plan.

**Request Body:**
[source,json]
----
{
  "query": "SELECT id FROM collection WHERE metadata.key = 'value'"
}
----

**Response 200:**
[source,json]
----
{
  "plan": {
    "operator": "VectorSearch",
    "estimated_cost": 1000,
    "estimated_rows": 10
  },
  "optimizations_applied": ["index_scan"]
}
----

**Status Codes:**

* `200` - Success
* `400` - Invalid SQL
* `500` - Server error

== Error Response Format

All errors follow consistent format:

[source,json]
----
{
  "error": {
    "code": "INVALID_ARGUMENT",
    "message": "Collection ID is required",
    "details": {
      "field": "collection_id",
      "constraint": "non_empty"
    }
  },
  "timestamp": "2025-01-15T10:30:00Z"
}
----

=== Error Codes

[cols="2,1,4"]
|===
| Code | HTTP | Description

| `INVALID_ARGUMENT` | 400 | Invalid parameters
| `NOT_FOUND` | 404 | Resource not found
| `ALREADY_EXISTS` | 409 | Resource exists
| `PERMISSION_DENIED` | 403 | Insufficient permissions
| `UNAUTHENTICATED` | 401 | Authentication required
| `RESOURCE_EXHAUSTED` | 429 | Rate limit exceeded
| `INTERNAL` | 500 | Server error
| `UNAVAILABLE` | 503 | Service unavailable
|===

== Rate Limits

[cols="2,2,3"]
|===
| Tier | Limit | Scope

| Free | 1000 req/min | Per IP
| Standard | 10000 req/min | Per API key
| Enterprise | Unlimited | Per API key
|===

**Headers:**
[source,http]
----
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 950
X-RateLimit-Reset: 1704067260
----

== Compression

**Supported Encodings:**

* `deflate` - Fastest
* `gzip` - Balanced
* `zstd` - Best compression
* `brotli` - Best for text

**Request Header:**
[source,http]
----
Accept-Encoding: gzip, deflate, br, zstd
----

== Authentication

When enabled, include bearer token:

[source,http]
----
Authorization: Bearer <your-token>
----

Token format: JWT with ProximaDB claims
