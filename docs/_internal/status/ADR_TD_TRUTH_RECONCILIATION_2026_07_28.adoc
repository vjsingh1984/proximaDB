= ADR/TD truth reconciliation — canonical PAX read strategy
:date: 2026-07-28

== Purpose

This note reconciles the RDSTRAT design lineage with merged `develop` through
#1294. It is a status map, not a new storage decision. Historical documents are
retained because their measurements and rejected alternatives remain useful;
their status fields now say whether they are current, superseded, partially
resolved, or rejected.

The authoritative design remains
link:../../12-design/adr/ADR-062-coalesced-rabitq-header-self-describing-footer-pax-layout.adoc[ADR-062]
plus
link:../../12-design/adr/ADR-065-clustered-tier-regions-single-segment.adoc[ADR-065].

== Current physical and serving contract

----
one immutable segment object
  header prefix (v1 or mixed-safe v3)
  Region A0: optional persisted compaction IVF plan/cell directory
  Region A : coalesced RaBitQ rank tier
  Region B : coalesced SQ8 rerank tier
  Region D : current row blocks, including optional exact-f32 stripes
  footer    : schema/block/region/encoding metadata and optional sections
  footer length + segment magic
----

The contract on `develop` is:

* coalesced Regions A/B are the canonical PAX vector path;
* compaction-time PCA/IVF/Hilbert ordering is reused by the persisted v3/A0
  directory; no second quantizer is trained;
* trained v3/A0 writes and selective reads are default ON
  (`PROXIMADB_PAX_WRITE_A0_TRAIN=0` and
  `PROXIMADB_PAX_READ_COARSE_PROBE=0` are kill-switches);
* v1, v3, and A0-less segments remain mixed-read-safe; the reader never assumes
  A0 and records whether the probe engaged or fell back;
* Region C has not shipped, and Region D is not yet a pure vector-free result
  region;
* the segment remains one atomic object. A temperature split into multiple
  objects is not authorized by the accepted ADRs;
* segment-invariants and survivor-range caches are byte-budgeted live surfaces.
  #1227 routes probe-path Region-A reads and whole-Region-B fallbacks through the
  survivor cache. #1294 does not change caching: the cache cold-sweep exposed an
  L0-admission bug, and #1294 makes WAL recovery bypass live-ingest watermarks.

== Evidence that controls current status

[cols="2,4", options="header"]
|===
| Ledger claim | Interpretation

| `nprobe_sweep_trained_1m`
| Current flip evidence: recall `0.986-0.987`; default nprobe arm `81.4`
  GETs/query and `92 ms`, versus unprobed `108.5` and `144 ms`.

| `rdstrat8_ivf2_layout_coalescing_sift1m`
| #1153 component proof: single- and four-file geometry preserved recall and
  improved the joint request/byte score. Its component gates remain opt-in.

| `async_compaction_1m_e2e`
| Post-async 1M ingest held recall `0.9875`, completed six background
  compactions, and bounded L0.

| `cache_hot_vs_cold_1m_post_compaction`
| Trained v3/A0 cache trace: invariants `99.96%`, survivor `38.2%`; the repeat
  result-cache latency is a separate layer. The run discovered the #1294 bug.
|===

Earlier 100k/default-OFF and pre-async entries remain valid measurements of
their recorded code states. They must not be read as the current rollout
default.

== Next work, in system order

1. Keep TD-RDSTRAT-8's recall/probe-engagement ratchet while measuring 10M,
   high-dimensional, cosine/dot, multi-file, and production object-store
   distributions. Recalibrate only from those measurements.
2. Implement TD-RDSTRAT-9 first in observe/recommend mode: join physical
   per-query region/GET/cache traces with live-file geometry and compaction
   write-amplification/payback. Fixed L0 watermarks are not a substitute.
3. Close TD-RDSTRAT-6's OID Bloom only as a point-lookup index; do not conflate
   it with vector coarse probing or the delete-vector OID resolver.
4. Advance TD-RDSTRAT-7 only with an end-to-end lossless winner on the current
   region layout. Quantization is the only permitted lossy storage boundary;
   exact representations must reconstruct bit-for-bit when retained. Treat the
   missing metric-epoch/normalization descriptor contract as explicit work; do
   not infer it from a representation tag.
5. Do not implement TD-RDSTRAT-10 or a new VOE/block-prune serving path without
   a new accepted decision that supersedes the current contract.
