  adversarial gate. Spec'd precisely in #1152 (invariant at
  `recovery_manager.rs:586-600`); needs the `ServerProcess` crash harness
  (now on develop via #1140) or a direct WAL-batch harness.

  *increases* GETs at N=100k (fragmentation); the GET win is hypothesized only
  at 1M (baseline ~51 GETs). That run is the definitive default-on decision;
  the probe stays default-OFF until it lands.
. **ADR-066 governance (#5)** — operator-stream ACL/encryption + tenant-root
  integration tests. This is now the **only** acceptance condition between
  ADR-066 and Accepted (lifecycle duplicate-install/shutdown is unit-tested;
  hot-path #3 + S4b are done).
. **ADR-068 full generated-oracle migration (S3–S5)** — the round-trip is
  blocking (#1149); relocating `_generated/` out of the shipped wheel + type
  narrowing is the deferred follow-up (the high-leverage subset shipped).
. **TD-OBJSTORE-2 live three-store rerun** — still external closure evidence
  (ADLS/S3/GCS creds required); emulator conformance is green.
