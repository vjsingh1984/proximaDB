== What this proves
The PAX RaBitQ→SQ8 cold-scan cascade (stage-1 binary rank → stage-2 SQ8 rerank,
no f32 GET) holds `recall@10 ≥ 0.93` at both small and production scale. This is
the recall gate the storage-format mandate (#8) requires before PAX quantization
is flipped default-on (rollout Phase 2). The qa-gate `pax-recall-ratchet` job
enforces it on every develop→qa promotion; the ratchet only goes up (#10).

NOTE: An earlier sweep found `REFINE=200` at N=100k yielded 0.708 (< 0.90) — a
wider stage-1 pool (1_000, 1% of the corpus) recovers to 0.932. Recorded so the
ratchet tracks the measured floor; widening REFINE or adding an f32 rerank tier
remain the levers if recall regresses.
