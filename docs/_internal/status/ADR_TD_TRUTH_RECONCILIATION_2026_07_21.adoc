== Lifecycle rule used by this audit

ADR lifecycle and implementation progress are deliberately separate. Shipped code does not make a
Proposed decision Accepted when its safety/evidence conditions remain open. Conversely, a TD is
closed when its bounded finding is resolved even if a broader successor initiative continues. A
superseded ADR remains historical rationale and must not masquerade as current implementation
direction.
