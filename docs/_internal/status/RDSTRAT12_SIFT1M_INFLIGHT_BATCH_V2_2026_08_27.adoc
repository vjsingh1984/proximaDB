== What changed (rewiring)

`coarse_probe_survivors` (src/storage/engines/sst/segment_format.rs):

. Classify pass resolves cache layers once each: region Arc → prefix slice
  → invariants `get_region_range`. Past those, a NEW side-effect-free
  residency probe (`SurvivorRangeCache::peek_memory_exact`, backed by
  `TenantCache::peek_memory`: pinned+L1 only, no counters, NO persistent-L2
  promotion) splits "would be served without its loader" from TRUE COLD.
. ONE `fs.read_ranges_prefetch(path, cold_ranges)` bounded-concurrent round
  covers every true-cold range — gated by `PROXIMADB_READ_RANGES_INFLIGHT`
  (unset ⇒ defers to `PROXIMADB_FS_READ_RANGES_PARALLEL`; ≤1 ⇒ unchanged
  sequential shape). Per-buffer `record_pax_region_bytes`/`record_get` fire
  here, once per physical GET.
. Consume pass replays the ORIGINAL consumers in order: `get_or_fetch`
  loaders receive the pre-batched bytes (TD-CACHE-6 tracking/LRU/admission/
  counters untouched); survivor-resident ranges consume via get_or_fetch
  with the loader provably skipped; LRU-race between peek and consume fails
  safe to the baseline loader (never panics).

v1 flaw caught before measuring: gating batching on `survivor_cache.is_none()`
was dead — core.rs always constructs the survivor cache (`Some`). The v2 probe
design exists precisely because of that.

== Mechanism-fired proof (positive control)

`probe_cold_tail_records_read_ranges_metrics_when_inflight_armed`
(segment_format tests): INFLIGHT=4 armed ⇒ after one cold search,
`drain_read_ranges_metrics()` = Some{max_inflight ≥ 1, fetch_rounds ≥ 1};
identical repeat search adds none (cache seam serves it). With prefix/gap
layers absorbing the fixture the drain is None — which is exactly the fixture
lesson: those layers must be disarmed to reach the cold queue.

== Verdict against acceptance ("cold p50 ≥ 2× at equal GETs")

NOT MET ON THIS BED — and structurally unevaluable here: file:// reads carry
≈0 RTT, so waves-not-sums has no first term to collapse. Equal-GET and equal-
recall parity hold bit-for-bit across arms; the treatment's I/O issue pattern
differs (control proves it) yet e2e moves only single-digit %. To evaluate
the criterion as written, rerun this pair against a high-RTT backend — real
Azure/S3, or Azurite behind the artificial-latency proxy used by the
TD-SEARCH-2 codesign arc (CODESIGN_MEASURE_ARC_SIFT1M_AZURITE_2026_07_26).
