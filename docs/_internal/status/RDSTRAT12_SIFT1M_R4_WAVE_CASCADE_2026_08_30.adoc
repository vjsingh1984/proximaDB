== Findings

. **GET-parity A1 pair is measurement-perfect**: GETs, bytes, recall AND
   result-identity hash all identical across arms; wave observably fired
   (297 rounds, width 8) vs the sequential arm's 0/0.
. **Measured win: 1.61× aggregate p50, 1.54× cold-cohort** — below the 2×
   acceptance. The run did not persist a compute/I/O phase decomposition;
   compute dominance and the ratio attainable at a higher RTT are hypotheses
   for the next bed, not conclusions from this campaign.
. **Split arm has one parity-positive rep and one semantic divergence.**
   a2/1 matched identity and GETs; a2/2 changed membership for query 23.
   Host load can invalidate its latency, but does not explain different
   results from the same binary and geometry. A2 needs reproduction and
   root-cause analysis before its correctness can be called validated.
