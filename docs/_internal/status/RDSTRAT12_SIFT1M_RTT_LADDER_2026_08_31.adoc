== Model confirmation

Sequential A0 tracks 14.4 GETs x RTT + transfers + ~0.9 s compute at every
level. The waved arm saturates at ~1.8 s (compute + 1-2 waves) — the
compute-bound asymptote the waves-not-sums model predicts. Crossover
between 50 and 100 ms; >=2x holds for all real-object-store latencies
>= ~75-100 ms.

== Campaign-environment findings (this ladder)

* TD-BENCH-2 fix validated end-to-end: footer-only ranged materialize
  (az --start-range/--end-range, bounded 300 s) reads rows=1,000,000 in
  5.2 s where whole-segment downloads timed out (4/4 high-RTT settle
  failures before the fix).
* Deterministic settle config: --explicit-flush-every-rows 250000
  --flush-vector-threshold 250000 --max-segments 2. Root cause of the
  earlier stuck settles: a lone final-flush L0 (76k rows) stranded below
  the 5-file compaction trigger; the settle gate deliberately rejects L0
  artifacts, so such a bed can never quiesce. Exact-boundary explicit
  flushes eliminate the lottery.
