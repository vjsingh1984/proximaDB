= Lexical query contract evidence gate — 2026-08-22
:toc:

== Outcome

The natural-language contract eliminates the strict-parser failures previously observed on
NFCorpus: document Tantivy and canonical hybrid BM25 each completed all 324 development and 323
held-out queries with exactly 100 source candidates and zero query errors.

Do not replace canonical hybrid BM25 with Tantivy from this evidence. On held-out test, Recall@100
is a tie (`-0.000079`, paired 95% interval `[-0.011129, +0.008930]`), while canonical BM25 improves
NDCG@10 by `+0.019002` (`[+0.009360, +0.029213]`) and NDCG@100 by `+0.012716`
(`[+0.006104, +0.019871]`). The safe convergence boundary is query semantics and capability
routing, not yet one physical engine.

== Fixed protocol

* Official NFCorpus source documents and qrels: 3,633 documents, 324 development queries and 323
  held-out test queries.
* Development results were inspected before the single held-out comparison.
* Both arms receive the same title/body source inputs and natural-language query text.
* Document Tantivy uses separate title/body fields and configured field analyzers. Canonical BM25
  uses its production keyword-search tokenizer over combined title/body text.
* Each engine returns matches from its production component. The runner deterministically fills the
  remaining source universe to exactly 100 candidates, ordered by score descending then source ID.
* Metrics are macro source-level linear-gain NDCG and binary Recall over every qrels query.
* Comparisons use 10,000 paired query-bootstrap samples, seed 17 and 95% percentile intervals.
* No timing or cross-engine score calibration is claimed.

== Product gate

Natural text is now safe at both component seams. Advanced syntax is explicit and supported only by
the document Tantivy component. A public query-mode field, projection capability routing and
explainability remain follow-up work. The next quality gate is an open cross-encoder reranker against
the canonical natural-language baseline, including citation and answer-quality evidence.
