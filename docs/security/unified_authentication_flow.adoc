== Overview

ProximaDB implements a unified authentication system supporting multiple authentication methods while maintaining consistency across all API endpoints and service layers.

=== Supported Authentication Methods

1. **Enterprise SSO**: AWS IAM, Azure AD integration
2. **JWT Tokens**: Access + refresh token pairs
3. **API Keys**: Service account authentication
4. **mTLS**: Client certificate authentication

=== Authentication Components

#### 1. Authentication Middleware (`src/network/middleware/auth.rs`)

**Purpose**: HTTP request authentication and credential extraction

**Supported Header Formats**:
```http
# Bearer token (JWT or SSO)
Authorization: Bearer <token>

# API Key authentication
Authorization: API-Key <key>
X-API-Key: <key>

# Client certificate (mTLS)
# Handled at TLS layer
```

**Implementation**:
```rust
pub async fn auth_middleware<B>(
    State(config): State<AuthConfig>,
    mut request: Request<B>,
    next: Next<B>,
) -> Result<Response, StatusCode> {
    // Extract credentials from headers
    let auth_header = request.headers().get("authorization");

    // Validate and resolve user context
    let user_info = match auth_header {
        Some(header) => validate_credentials(header, &config).await?,
        None if !config.enabled => default_user(),
        None => return Err(StatusCode::UNAUTHORIZED),
    };

    // Inject user context into request
    request.extensions_mut().insert(user_info);
    Ok(next.run(request).await)
}
```

**Purpose**: High-level enterprise authentication coordination

**Integration Flow**:
```rust
pub async fn authenticate_and_authorize(
    &self,
    sso_token: &SSOToken,
    tenant_id: &str,
    operation: AuthorizedOperation,
) -> Result<AuthorizedContext> {
    // 1. Validate SSO token
    let enterprise_user = self.sso_manager
        .validate_and_resolve_token(sso_token).await?;

    // 2. Check RBAC permissions
    let authorization_result = self.rbac_manager
        .check_operation_permission(&enterprise_user, tenant_id, &operation)
        .await?;

    // 3. Create authorized context
    Ok(AuthorizedContext {
        user: enterprise_user,
        permissions: authorization_result.permissions,
        tenant_context: authorization_result.tenant_context,
    })
}
```

=== 1. Enterprise SSO Authentication

#### Supported Providers

**AWS IAM Integration**:
```rust
// AWS IAM STS token validation
pub struct AWSIAMIntegration {
    sts_client: aws_sdk_sts::Client,
    role_arn: String,
    session_duration: Duration,
}

impl AWSIAMIntegration {
    pub async fn validate_token(&self, token: &str) -> Result<EnterpriseUserContext> {
        // Validate STS token and extract user information
        let caller_identity = self.sts_client
            .get_caller_identity()
            .send()
            .await?;

        // Map AWS identity to ProximaDB user context
        Ok(EnterpriseUserContext {
            user_id: caller_identity.arn().unwrap().to_string(),
            tenant_id: extract_tenant_from_arn(caller_identity.arn().unwrap()),
            roles: extract_roles_from_iam(caller_identity.arn().unwrap()),
            provider: SSOProvider::AWSIam,
        })
    }
}
```

**Azure AD Integration**:
```rust
// Azure AD SAML/OAuth integration
pub struct AzureADIntegration {
    client_id: String,
    client_secret: String,
    tenant_id: String,
    graph_client: GraphServiceClient,
}

impl AzureADIntegration {
    pub async fn validate_token(&self, token: &str) -> Result<EnterpriseUserContext> {
        // Validate Azure AD token and get user profile
        let user_profile = self.graph_client
            .me()
            .get()
            .await?;

            tenant_id: self.tenant_id.clone(),
            roles: extract_azure_roles(&user_profile),
            provider: SSOProvider::AzureAd,
        })
    }
}
```

=== 2. JWT Token Authentication

#### Token Structure

**JWT Claims**:
```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Claims {
    pub sub: String,           // User ID
    pub iat: i64,             // Issued at
    pub exp: i64,             // Expiration
    pub nbf: i64,             // Not before
    pub iss: String,          // Issuer
    pub aud: String,          // Audience
    pub jti: String,          // JWT ID
    pub tenant_id: Option<String>,
    pub roles: Vec<String>,
    pub typ: TokenType,       // Access or Refresh
}
```

**Token Pair Generation**:
```rust
pub async fn generate_token_pair(
    &self,
    user_id: &str,
    tenant_id: Option<&str>,
    roles: Vec<String>,
) -> Result<TokenPair> {
    let now = Utc::now();

    // Access token (short-lived)
    let access_claims = Claims {
        sub: user_id.to_string(),
        iat: now.timestamp(),
        exp: (now + Duration::minutes(15)).timestamp(),
        nbf: now.timestamp(),
        iss: self.config.issuer.clone(),
        aud: self.config.audience.clone(),
        jti: Uuid::new_v4().to_string(),
        tenant_id: tenant_id.map(|t| t.to_string()),
        roles: roles.clone(),
        typ: TokenType::Access,
    };

    // Refresh token (long-lived)
    let refresh_claims = Claims {
        // ... similar fields ...
        exp: (now + Duration::days(7)).timestamp(),
        typ: TokenType::Refresh,
    };

    Ok(TokenPair {
        access_token: encode(&Header::default(), &access_claims, &self.encoding_key)?,
        refresh_token: encode(&Header::default(), &refresh_claims, &self.encoding_key)?,
        expires_in: 900, // 15 minutes
        token_type: "Bearer".to_string(),
    })
}
```

#### Certificate Validation

**Client Certificate Validation**:
```rust
pub fn validate_client_certificate(
    cert_chain: &[Certificate],
    ca_cert: &Certificate,
) -> Result<ClientIdentity> {
    // Validate certificate chain
    let cert = &cert_chain[0];
    verify_certificate_chain(cert_chain, ca_cert)?;

    // Extract client identity from certificate
    let subject = cert.subject();
    let common_name = extract_common_name(&subject)?;

    // Map certificate to user context
    Ok(ClientIdentity {
        user_id: common_name,
        tenant_id: extract_tenant_from_cert(cert)?,
        roles: extract_roles_from_cert(cert)?,
    })
}
```

== Authorization Integration

=== RBAC Permission Checking

**Permission Validation Flow**:
```rust
pub async fn check_operation_permission(
    &self,
    user_context: &UserContext,
    tenant_id: &str,
    operation: &Operation,
) -> Result<AuthorizationResult> {
    // 1. Validate tenant access
    self.validate_tenant_access(user_context, tenant_id).await?;

    // 2. Check operation permissions
    let required_permissions = operation.required_permissions();
    let user_permissions = self.get_effective_permissions(
        user_context,
        tenant_id
    ).await?;

    // 3. Validate permissions
    for permission in required_permissions {
        if !user_permissions.contains(permission) {
            return Err(AuthorizationError::InsufficientPermissions);
        }
    }

    Ok(AuthorizationResult::Allowed {
        permissions: user_permissions,
        tenant_context: self.get_tenant_context(tenant_id).await?,
    })
}
```

=== Audit Integration

**Authentication Event Logging**:
```rust
pub async fn log_authentication_event(
    &self,
    auth_result: &AuthResult,
    request_info: &RequestInfo,
) -> Result<()> {
    let audit_event = AuditEvent {
        event_type: AuditEventType::Authentication,
        user_id: auth_result.user_id.clone(),
        tenant_id: auth_result.tenant_id.clone(),
        timestamp: Utc::now(),
        source_ip: request_info.client_ip,
        user_agent: request_info.user_agent.clone(),
        auth_method: auth_result.auth_method.clone(),
        result: if auth_result.permissions.is_empty() {
            "failure"
        } else {
            "success"
        },
        metadata: json!({
            "permissions": auth_result.permissions,
            "token_expires_at": auth_result.token_expires_at,
        }),
    };

    self.audit_logger.log_event(audit_event).await
}
```

== Security Best Practices

=== Authentication Security

1. **Token Security**:
   - Use short-lived access tokens (15 minutes)
   - Implement secure refresh token rotation
   - Store JWT secrets in environment variables

2. **API Key Security**:
   - Generate cryptographically secure API keys
   - Implement key rotation policies
   - Use IP restrictions where possible

3. **SSO Security**:
   - Validate tokens with identity providers
   - Implement token caching with appropriate TTL
   - Use secure communication channels

4. **mTLS Security**:
   - Use strong certificate validation
   - Implement certificate revocation checks
   - Regular certificate rotation

=== Configuration Security

1. **Secrets Management**:
   - Use environment variables for secrets
   - Implement secret rotation
   - Audit secret access

2. **TLS Configuration**:
   - Enable TLS by default
   - Use strong cipher suites
   - Implement HSTS headers

3. **RBAC Configuration**:
   - Use principle of least privilege
   - Enable default deny policies
   - Regular permission audits

== Troubleshooting

=== Common Authentication Issues

1. **Token Validation Failures**:
   ```
   Error: JWT signature verification failed
   Solution: Check JWT secret configuration and token format
   ```

2. **SSO Integration Issues**:
   ```
   Error: Unable to validate SSO token
   Solution: Verify SSO provider configuration and network connectivity
   ```

3. **API Key Authentication**:
   ```
   Error: Invalid API key
   Solution: Check API key configuration and ensure key is not expired
   ```

4. **mTLS Certificate Issues**:
   ```
   Error: Client certificate validation failed
   Solution: Verify certificate chain and CA configuration
   ```
