== Usage Guidelines

=== Quick Reference

[cols="2,2,1", options="header"]
|===
| Need | Documentation | Diagrams

| Quick Start | getting_started.adoc | Abstract only
| Architecture | architecture.adoc | Abstract → Modular
| Component Dev | developer_guide.adoc | Detail-modular
| Debugging | technical_reference.adoc | Detail-monolithic
| Performance | performance_reference.adoc | Abstract metrics
|===

=== Documentation Strategy

1. **Start Simple**: Begin with abstract diagrams
2. **Dive Deep**: Move to detail-modular for specific work
3. **Full Context**: Use detail-monolithic for debugging
4. **Cross-Reference**: Links between related docs

== Maintenance

=== Update Process
1. Edit `.mmd` source files
2. Run `npx mmdc -i file.mmd -o images/file.svg`
3. Update relevant `.adoc` documentation
4. Verify cross-references

=== Quality Checks
* Version consistency (0.1.4)
* Collection names (8+ characters)
* Block sizes in KB not MB
* Theme consistency in SVGs
