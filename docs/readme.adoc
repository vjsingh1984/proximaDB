== Quick Start

=== 5-Minute Setup

[source,mermaid]
----

    A[Install<br/>Docker/Binary] --> B[Configure<br/>Engine Selection]
    B --> C[Start Server<br/>Ports 5678/5679]
    C --> D[Verify Health<br/>Dashboard Access]

    style A fill:#4caf50,stroke:#2e7d32,stroke-width:2px,color:#ffffff
    style B fill:#2196f3,stroke:#1565c0,stroke-width:2px,color:#ffffff
    style C fill:#ff9800,stroke:#f57c00,stroke-width:2px,color:#ffffff

----

```bash
# Quick Docker setup
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb
cargo build --release

# Start production server
./target/release/proximadb-server --config config/config.toml

# Verify health
curl http://localhost:5678/health
```
