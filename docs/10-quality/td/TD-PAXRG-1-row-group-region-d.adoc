== Problem statement

Measured on this branch (TD-OLAP-1 promotion harness): Region D's per-block framing
(64 B block header + 32 B/row RowDirectory + ~1 KB ColumnMeta frame + VectorParamBlock
+ sub-index + 32 B footer ≈ 1.2 KB fixed per block) **amplifies catastrophically at
small block targets** — a 400-byte target produced ~400 micro-blocks whose *pruned*
fetch totalled **1.25 MB for a 38 KB-Parquet-equivalent dataset** (~15× Parquet whole-file).
Even at sane 64 KiB blocks, pruned bytes beat the micro-block case by ~18× but the
segment total still exceeded Parquet's on narrow data: per-granule framing, not stripe
encoding, was the dominant byte term.

Simultaneously, ADR-065's Region C (exact fp32) remained an *in-block* stripe — the
one vector payload still framing per block — and its two open regions (C, D) were
explicitly evidence-gated targets.

== Decision

Close ADR-065's open regions with **Parquet-style row-group Region D + hoisted Region
C**, per the working-backwards insight that the PAX segment serves the vector+OLAP
wedge (pure relational stays on Parquet per ADR-033) and must therefore be cheap for
BOTH access paths: coalesced RaBitQ/SQ8 regions for ANN (shipped, untouched) and
row-group granules for row data.

[cols="2,3", options="header"]
|===
| Item | Decision
| Region D granule | **Row group** = an Olap-framed PAX block: RowDirectory + in-block rgdir suppressed (`with_suppress_rgdir`), stats moved to the segment footer. Zero schema change to `footer.blocks` — an RG *is* a footer block entry.
| Per-RG stats | Footer block table's opaque stats payload (`StatsKind::MinMax`): `[BlockZoneSummary 85 B][oid_chunk_rel_off u32][oid_chunk_len u32][oid_encoding_id u8][oid_is_lz4 u8]`. Old parsers skip stats wholesale; v1/v3-era writers emitted zero-length payloads — additive both directions.
| Amplification guard | `RG_TARGET_MIN_BYTES = 256 KiB` floor clamp in `with_rg_layout` — the 400 B pathology is structurally impossible (measured: fixed cost ≤ ~1% of payload at the floor; 64 KiB+ RGs verified ≥ 64 KiB).
| Region C | Hoisted raw-f32 region `[n u32][dim u32][validity bitmap][n·dim·f32]`, same ordinal space as A/B, built from the same coalesced buffer before its drop (no extra pass). Extent declared in the header prefix AND mirrored as footer section 6. **Activation stays behind the existing `pax_f32_tier` opt-in** (ADR-065 Q4 evidence gate governs per-collection activation).
| Point lookups | RowDirectory is GONE from RGs — the OID resolver region (TD-DELVEC-1) is the sole authority. Fail-safe: `rg_layout` without the resolver **bails at finish** in both writer twins.
| ANN top-k | v4 fetches ONLY the per-RG OID chunks (footer-addressed) instead of whole RGs — same GET count class, strictly fewer bytes (pinned: parity + ≥32 KiB win vs whole-block on identical corpus).
| DataFusion | Ranged arm locates the header-declared footer (no PAXZ probe), renders it as the layout-neutral `SegmentIndex`, reuses the shared RG zone-prune + ranged-fetch stages. `v4_floor_kills_microgranule_amplification` pins the win: v4 reads < ¼ of the v3 micro-block baseline on the same dataset.
| Cells | Coarse-cell boundaries (A0) cut at RG boundaries — cells are whole RGs; `d_block_begin/end` hold RG ordinals. Pinned by `v4_cells_never_straddle_row_groups`.
|===

== 🔑 Single-layout collapse (2026-08, reviewer direction)

Nothing is released — there is no serialized legacy data to stay read-compatible
with — so the pre-collapse **v1/v3/v4 version sprawl was deleted rather than
maintained**: ONE `SEG_LAYOUT_VERSION = 1` with an 88 B prefix whose region extents
(`a0_off/len`, `c_off/len`) are ALWAYS serialized (zero = region absent). This is
ADR-065's own decision invariant — *region presence is declared by the serialized
header/footer, never a version or flag* — the version byte was redundantly encoding
region-set combinations the table already declares. The version byte is RESERVED for
the first post-GA successor layout; re-introduce parse arms + freeze tests then, not
before. The `PBLK`-vs-`PXH1` magic stays (format-*family* detection, not versioning),
and the PAXZ trailer probe remains only for the legacy non-coalesced block family.

== Spill twin

`finish_coalesced_spill` duplicates the geometry assembly — every change lands in
both writers, pinned by `spill_and_memory_rg_writers_produce_identical_footers`
(byte-identical RG tables + stats + region extents). Spill keeps the f32 tier OFF
(the disk spool does not retain f32 for a Region C emit); `rg_layout ∧ f32_tier` on
the spill path bails loudly.

== Phase G evidence (complete 2026-08-28 — flip executed)

1. **SIFT1M recall** (local bed, N=100k, 1000 queries, floor 0.90): rg_layout arm
   recall@10 = **0.9896**, byte-identical to the legacy-baseline arm's 0.9896 —
   Regions A/B byte-identity confirmed at scale. Arms live as
   `sift_pax_cascade_recall_at_10_ratchet` (legacy, kill-switch pinned) and
   `..._rg_layout` (default path) in `tests/sift_pax_recall_ratchet_test.rs`;
   the paired exact/ANN cost line: ANN 19.2 MB / 52 ms vs exact 74.9 MB /
   ~1000 ms per query. The `BAKE_METRIC` ledger already carries
   `region_d_gets/bytes_per_query` — no extension needed.
2. **At-rest size**: same-corpus rg = **80.3% of legacy** (521,693 vs 649,713 B;
   RowDirectory removal dominates) — the +5% criterion is beaten inverted.
   `rg_layout_at_rest_is_not_larger_than_legacy_blocks` pins it.
3. **Resolver un-gated**: the OID-resolver capture left the
   `cold-deletion-vectors` feature gate — it is additive + mixed-read-safe and
   the rg fail-safe requires it; the gate would have made default-ON rg
   unwritable in feature-off builds. `with_rg_layout(true)` now AUTO-enables
   the resolver (format invariant, not a caller obligation); the finish-time
   bails are gone.
4. **Flip executed**: `rg_layout_enabled()` default ON; `=0|off|false|no` is the
   kill-switch; the flush `pax_rg_layout:on|off` tag still opts a collection
   out. ENV_GATE_REGISTRY row updated with the dated evidence.

== Known pre-existing issue (not this TD)

The ratchet's paired-evidence cohort gate rejects every pair with
`outcome=unknown` when caches are disabled — the classification code is
byte-identical to develop (zero diff in the vector-query/observability chains)
and the failure hits the legacy-baseline arm identically. Belongs to the
observability owners; it gates the paired-COST evidence, not the recall result.

== Closeout (2026-08-29) — deferred items resolved

* **Region C on the spill twin: SHIPPED.** The spool's raw-f32 file IS the
  Region C payload; `DiskVectorSpool::finish(seed, emit_exact)` materializes
  it by header + copy (the `finish_oid_resolver` pattern). Twin byte-identity
  extended to rg+f32 (`rg_spill_with_f32_region_c_round_trips_and_matches_
  memory_twin`); A0 per-cell C extents populated on spill.
* **Spill exact-tier downgrade fixed**: `pax_spill_compaction_writer` resolves
  `f32_tier` from `pax_inputs_have_f32_tier(&task.input_files)` (intersection
  rule) instead of hardcoding off — an all-exact input set no longer loses the
  tier when the spill executor runs.
* **Compaction `pax_rg_layout` tag threading: SHIPPED** — `SstCompactionTask
  ::rg_layout: Option<bool>` (mirror of `precision_hint`), resolved by both
  producers (flush + trait_impl) via `resolve_pax_rg_layout`, carried through
  training follow-ups, honored at both executors.
* **Cohort gate `outcome=unknown`: FIXED** (`VectorCacheOutcome::from_snapshot`
  policy-aware Bypass: `Disabled` policy + physical GETs ⇒ `Bypass`,
  feature-independent; qa-gate sift job aligned to the `--features io-trace`
  build contract ci.yml already documented). Pre-existing — control-verified
  byte-identical classification on develop.
* **Slice-2 route-dispatch design record**: added to TD-OLAP-1 (WAL-delta
  reconciliation, path reconciliation, `pax_backed` refinement, dispatch
  wiring, EXPLAIN alignment). `PROXIMADB_DF_PAX_READER` stays default-OFF with
  explicit attribution-poisoning warnings on both gate definitions.

Still open (measure-then-decide or independent tracks): wedge-payload at-rest
promotion vs export-duplicate; RG target-size raise (post-flip traces);
RG-granular compaction rewrite; HELIX/SWIFT format ports (bespoke writers —
a per-engine format decision, not configuration); TD-CACHE-10.
