== Why

`src/graph/catapult.rs` (**11 tests**) is the Catapult shortcut-edge optimization for graph ANN search
(LLD 6.3, CatapultDB arXiv 2603.02164): it observes successful search trajectories and injects shortcut
edges from query regions to frequently-visited destination nodes, so future similar queries skip
redundant hops. Truly self-contained: zero `crate::` climb-out, zero real `super::`, **`tokio`-only** dep,
**0 external consumers** (just the `pub mod` decl). Not feature-gated (default binary).

== What moved (behavior-neutral)

* `src/graph/catapult.rs` → `crates/horizontal/proximadb-catapult/src/catapult.rs`.
* Root `src/graph/mod.rs`: `pub mod catapult;` → `pub use proximadb_catapult::catapult;`.
* New horizontal-tier crate, dep `tokio`. No `CAPABILITY_MATRIX.toml` pointer.
