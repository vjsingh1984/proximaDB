== Evidence ledger

* #1743 (2026-08-27): VIPER point-read was broken for its own writer's format
  (`FixedSizeList` written vs `ListArray` read) — zero production exposure
  proven; fixed only because the embedded flush-routing correction exposed it.
* #1768: viper `factory.rs` hardcodes `vector_fp32: FixedSizeList(Float32,
  128)` with a deferred-dimension note — subsumed by retirement (do not fix).
* SUPPORTED_SURFACE at time of filing: Beta, "no per-engine conformance
  ratchet published — do not market above Beta by name".
* Niche redundancy: analytics = DataFusion/Parquet (ADR-052); ANN default =
  SST (Supported); columnar-analytics vector = NOVA (Beta, active: TD-040,
  ADR-089).
