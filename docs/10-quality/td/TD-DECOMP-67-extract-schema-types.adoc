== Problem
The last grandfathered control-layer coupling edge: `proximadb-storage-common → proximadb-catalog`
(storage→control). TD-DECOMP-63 closed the boundary checker blind spot; TD-DECOMP-66 resolved 3 of
4 edges via port-traits. This TD resolves the final edge.

== What moved
Created new foundation crate `proximadb-catalog-schema` (~2500 lines) with:
- **CatalogColumn** + **CatalogTableSchema** (the anchor types) — struct definitions + pure impl blocks
- **16 Tier B types** (CatalogEmbeddingConfig, CatalogStorageLayout, CatalogProjection, etc.)
- **~19 Tier C transitive types** (CatalogAuthorityMode, CatalogPhysicalFormat, etc.)
- **3 embedding-precision-policy types** (RecallSlo, RecallTargets, PrecisionMigrationState)
- **object_store_bridge module** (307 lines, fully pure)
- Pure helpers: `same_column_set`, `catalog_arrow_type`, `validate_contract_digest`

Catalog lib.rs shrank from **4917 → 2578 lines**. All moved types are re-exported so the ~31
external consumers keep compiling unchanged.

== The mlops_asset field

(wire-compatible). Catalog provides a `CatalogMlopsAssetExt` extension trait with typed accessors
(`mlops_asset_as_typed`/`set_mlops_asset_typed`). 3 internal call sites + 1 test updated.
