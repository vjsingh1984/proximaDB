= TD-NS-1: Namespace isolation boundary — implementation slices for ADR-074
:status: Open
:dim: D5
:pillar: SEC

[cols="1,3", options="header"]
|===
| Field | Value
| Status | **Open.** Design decided in ADR-074 (Proposed); no slice started.
| Priority | **P1** — every tenant in a deployment currently shares one hardcoded `namespace_id`, so the namespace tier of the isolation tree is inert.
| Component | `src/network/middleware/tenant.rs` (ingress context), `src/storage/trait_components/path_resolver.rs` (path types), `src/services/dml/mod.rs:94` + `src/services/record_store.rs:305` (the constants to delete), `crates/foundation/proximadb-tenant/src/rbac_context.rs` (authz dimension), `crates/control/proximadb-catalog/src/native.rs` (registry).
| Evidence | `DEFAULT_NAMESPACE_ID = "ns_default"` and a literal `mock_namespace` under `#[allow(clippy::expect_used)]` supply the path segment that `DrPathBuilder` requires; nothing in the identity flow resolves it. `MiddlewareTenantContext` carries `account_id` and `tenant_stable_id` but no namespace.
|===

== Slices

**S1 — structural, zero behavior change (no ADR dependency).**
Split `DrResolvedPath` into `DrCollectionPath` / `DrTenantSystemPath`
(also fixes link:TD-CACHE-5-warm-manifest-invalid-path.adoc[TD-CACHE-5] by
construction); add `namespace_id` to `MiddlewareTenantContext` and thread it to
the I/O boundaries; delete `DEFAULT_NAMESPACE_ID`, the `mock_namespace`
literal, and the `expect`, resolving single-tenant to the literal `ns_default`.
Gate: rendered paths **byte-identical** before/after.

**S2 — the resolution seam.** Registry `(tenant_id, alias) → namespace_id` with
CAS uniqueness and retired-id reservation; `Namespace*` permission variants on
`UnifiedPermission` (authority designated in ADR-074 D8 — do **not** repurpose
`Domain*`); per-tenant default bound at tenant create; bounded tenant-keyed
resolution cache with **negative caching** and rename/delete invalidation of
both the resolution cache and the `(tenant, namespace, query)` caches.

**S3 — wire surface.** `X-ProximaDB-Namespace` inheriting `HeaderTrustPolicy`
plus a `NamespaceIdSource` provenance enum; then the pgwire (`search_path`) /
gRPC (metadata) / Arrow Flight (descriptor) follow-up ADR, with SDK
regeneration in the same PR.

**S4 — typed-id fence (prerequisite for `PROXIMADB_TYPED_PATHS` in production).**
`CatalogIdService::mint_namespace_id` is an unchecked `AtomicU16::fetch_add`
per account in a never-reuse allocator (`id_allocator.rs:139-144`): at 65,536
namespaces it wraps onto a live id and two namespaces collide on one typed
path. Widen or fence before enabling typed paths.
