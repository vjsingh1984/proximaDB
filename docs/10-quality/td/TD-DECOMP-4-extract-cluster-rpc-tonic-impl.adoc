== Why

Continues the cluster `rpc/` extraction started in TD-DECOMP-3 (which moved the
self-contained abstraction core `error`/`types`/`traits`/`retry`, 37 tests). This slice
moves the **tonic-backed client impl** — `connection` (connection-pool/`tonic::transport`)
and `grpc_client` (the gRPC client over the pool) — into `proximadb-runtime`, carrying
**19 more tests** out of the root lib binary. `connection` has zero `crate::` climb-out;
`grpc_client` only references `crate::proto::proximadb_cluster_v1` (a `proximadb_proto`
re-export → swapped). Both are platform-tier-legal in the runtime.

`grpc_server` is deliberately **left root-side**: it references
`crate::cluster::consensus::RaftConsensus` and `crate::cluster::replication::EngineReplication`
(root modules), so it can't move until those do. It consumes the moved types via the root
re-export, unchanged.

== What moved (behavior-neutral)

* `src/cluster/rpc/{connection,grpc_client}.rs` →
  `crates/platform/proximadb-runtime/src/cluster_rpc/` (verbatim except `grpc_client`'s
  `crate::proto::` → `proximadb_proto::`).
* `proximadb-runtime/src/cluster_rpc/mod.rs` declares `pub mod connection; pub mod grpc_client;`.
* `proximadb-runtime/Cargo.toml` gains `tonic` + `dashmap` (workspace deps; `proximadb-proto`,
  `futures`, `rand`, `proximadb-distance-types` already present from TD-DECOMP-3).
* Root `src/cluster/rpc/mod.rs` drops `pub mod {connection,grpc_client};` and adds them to the
  existing `pub use proximadb_runtime::cluster_rpc::{...};` — so the root-side `grpc_server`
  and all external `crate::cluster::rpc::*` callers resolve unchanged.

== Verification

* `cargo check -p proximadb-runtime` green (moved impl + tonic/dashmap deps compile).
* `cargo check -p proximadb` green (root compiles through the re-export; `grpc_server`
  resolves the moved types via `super::`).
* `cargo nextest run -p proximadb-runtime --lib` — runtime gains the 19 tests (54→73).
* `cargo nextest run -p proximadb --lib` green — root lib test binary shed the 19 tests.
* `python3 scripts/check_workspace_boundaries.py` + `scripts/check-layering.sh` green.
* `cargo build -p proximadb-server` + `cargo clippy --lib --bins -- -D warnings` +
  `cargo fmt --check` + `make work-commit-check` green.

== Follow-ups (out of scope here)

* Then the rest of `src/cluster/` (consensus/replication/sharding/distributed_ops/routing,
  ~236 tests) submodule-by-submodule — the richest remaining test-payoff target, all
