== Why

After completing the cdc module extraction (TD-DECOMP-7..13, 303 tests), the next clean-leaf
scan found `src/core/resilience/` — a 5-file cohesive submodule (**24 tests**) with zero
`crate::` climb-out and zero `proximadb_*` deps. It's genuinely standalone resilience
infrastructure (retry, circuit breaker, health aggregator) that belongs in the horizontal layer.

== What moved (behavior-neutral)

* New `crates/horizontal/proximadb-resilience/` (Cargo.toml + lib.rs).
* `src/core/resilience/{circuit_breaker,health_aggregator,mod,retry,tests}.rs` →
  `crates/horizontal/proximadb-resilience/src/{circuit_breaker,health_aggregator,lib,retry,tests}.rs`.
* Deps: parking_lot, rand, serde, thiserror, tokio, tracing, anyhow (all workspace).
* Root `src/core/mod.rs`: `pub mod resilience;` → `pub use proximadb_resilience;`.
