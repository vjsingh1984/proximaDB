== Scope (the four operators — ADR-054 §6.1)

All four live behind the one `ExecutionOperator` contract, consume the same Arrow
`RecordBatch`, and co-execute in one pipeline — the co-design that no incumbent owns:

[cols="2,4", options="header"]
|===
| Operator | Why it must be native (not expressible in DataFusion)
| `VectorSearchOperator` | The SQL filter must constrain the ANN *search*, not post-filter its results — post-filter loses >30% recall (arXiv 2506.23071). DataFusion has no ANN operator and cannot express pre-filter semantics.
| `FusedAnnFilterAggregate` | One operator: ANN candidates → filter → aggregate, **no materialization between**. The TD-OLAP-7 wedge; structurally unhostable in DataFusion.
| `GraphTraversalOperator` | BFS/DFS/shortest-path over a PAX edge table — iterative, data-dependent termination, not a fixed relational plan; joins back to relational in the same plane.
| `DocumentProjectionOperator` | Project a JSON path as a typed Arrow column once (columnar), avoiding the per-row `serde_json` tax; downstream operators see a normal column.
|===

== Gate (ADR-052 mandate #4 — measured, not asserted)

Ships behind a flag, default-off, shadow-compared, demoted on regression. Promotion
requires the **TD-OLAP-4 ledger**:

* **Correctness (the load-bearing claim):** a vector+SQL join returns **>99% recall@k**
  vs the >30% loss cited for the CDC/replica post-filter stack (arXiv 2506.23071). This
  is the shared gate with TD-OLAP-11 Phase 5.
* **Performance:** per-query ledger vs DataFusion (which cannot serve the fused shape at
  all) + vs a naive post-filter baseline, on the same object store, in CI.
* **Conformance unchanged:** TPC-H (22) / TPC-DS (16) ratchets stay green (the multimodal
  operators are additive; they do not touch the relational conformance path).

== Non-goals

* **No new external surface** — the multimodal operators are internal verticality behind
  the Arrow / `LogicalNode` / pgwire seams (ADR-054 §10 "vertical inside, standard outside").
* **No overclaim of five-mode parity** — vector + OLAP + lakehouse is the defensible niche;
  graph/document are stretch modes served by the same plane (ADR-052/054 non-goal).
* **No build before the plane** — depends on TD-OLAP-10/11 (operators + join) and benefits
  from TD-OLAP-12 (scheduler); building the wedge on a borrowed engine is the anti-pattern
  this ADR exists to avoid.
