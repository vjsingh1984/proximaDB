== Why

Continues the cdc vein after TD-DECOMP-7 seeded the `proximadb-cdc` crate with `event`.
This slice moves the **transform** subsystem (filter/schema/embedding + their `mod.rs`
parent) and `error` into the crate — the cohesive subgraph whose only non-self deps are
`event` + `error` (now siblings in the crate). **~56 tests** relocate.

== What moved (behavior-neutral)

* `src/cdc/transform/` (`mod.rs` + `filter.rs` 24t + `schema.rs` 16t + `embedding.rs` 13t) →
  `crates/integrations/proximadb-cdc/src/transform/` (whole subdir, verbatim).
* `src/cdc/error.rs` (3t) → `crates/integrations/proximadb-cdc/src/error.rs` (verbatim; pure
  `std::fmt`, no deps).
* The only rewrite: `crate::cdc::event` → `crate::event` and `crate::cdc::error` →
  `crate::error` in the moved files (event + error are now siblings under the cdc crate).
* `proximadb-cdc/src/lib.rs` declares `pub mod error; pub mod transform;`.
* Root `src/cdc/mod.rs`: `pub mod error;` + `pub mod transform;` → `pub use proximadb_cdc::{error, transform};`
  — so `crate::cdc::error::*` / `crate::cdc::transform::*` paths (source/coordinator/
  connectors/sinks/outbound) resolve unchanged.
