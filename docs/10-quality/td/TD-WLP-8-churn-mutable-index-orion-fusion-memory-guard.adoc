== Why

TD-WLP-5 delivered freshness by reusing the bounded WAL/memtable delta. This TD measured and
surfaced the bound. That evidence invalidated the proposed mutable-index premise: adding a second
projection would optimize a large-unflushed-set state the write path prevents. The graph fusion
premise was also stale because the canonical `/rag` flow already correlates by `oid`.

== Shipped scope

* Per-collection working-set gauge + soft ceiling. It samples and emits at
  the `Churn` *read* seam (where the profile is already resolved and WLP-5/6 live, keeping it disjoint
  from the PAX layout) and warns on breach.

== Retired scope — do not implement

Part 8b's mutable AXIS index, duplicate fusion path, and write-boundary memory enforcement are
closed. TD-WLP-10 may adjust the existing flush threshold only after a measured Churn trace; a new
mutable index requires a new TD proving the bounded-delta assumption no longer holds.

== Gating

Keyed on `workload_profile:churn` (opt-in — Churn is never the default even under the ADR-061
arm-defaults amendment). `AppendBulk` untouched (asserted). WAL stays the sole durable authority
(D2). The shipped metric is advisory and creates no write-path or query-routing authority.
