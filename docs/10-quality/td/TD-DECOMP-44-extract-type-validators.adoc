== What moved
`src/core/types/validators.rs` (7 tests) → new horizontal crate `proximadb-type-validators`.
Root `core/types/mod.rs` re-exports it (`pub use proximadb_type_validators::validators;`), so the
existing glob `pub use validators::*;` resolves unchanged for every consumer (GeoPointValidator,
UuidValidator, JsonValidator, etc., via the type-registry). Deps: anyhow + regex + serde_json + uuid
(zero `proximadb_*` deps, zero `crate::` climb-out, `super::` test-only). NOTE: `uuid` is declared
inline (`uuid = { version = "1.0", features = ["v4","serde"] }`) because it is NOT in
`[workspace.dependencies]`. Verified: standalone + clippy -D warnings + root lib all pass. SIFT
recall ratchet SKIPS (core/types is core_changes, not storage_changes).
