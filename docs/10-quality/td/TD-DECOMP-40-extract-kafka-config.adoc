== What moved
`src/streaming/kafka/config.rs` (7 tests) → new horizontal crate `proximadb-kafka-config`.
Root `streaming/kafka/mod.rs` re-exports it (`pub use proximadb_kafka_config::config;`), so the
existing `pub use config::{CommitStrategy, ConsumerGroupConfig, DeserializationFormat, DlqConfig,
KafkaConsumerConfig};` and every `config::Type` reference resolve unchanged. Deps: serde + serde_json
(zero `proximadb_*` deps; the heavy `rdkafka` consumer/deserializer impls stay root-side). Verified:
standalone + root lib both pass. Carries the Kafka consumer config types (broker list, consumer-group,
commit strategy, DLQ, deserialization format).
