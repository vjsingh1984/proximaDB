== What moved
`src/streaming/subscriptions/subscription.rs` (6 tests: base subscription state + shared
`ScoredResult` / `ResultChange` types) → new horizontal crate `proximadb-subscription`. Root
`streaming/subscriptions/mod.rs` re-exports it (`pub use proximadb_subscription::subscription;`),
so the existing `pub use subscription::{...};` resolves unchanged — including for the sibling
`evaluator.rs` / `result_set.rs` which consume `ScoredResult`/`ResultChange` via the shim.
Deps: serde + tokio (zero `proximadb_*` deps, zero `crate::` climb-out, `super::` test-only).
Verified: standalone + clippy -D warnings + root lib all pass. SIFT recall ratchet SKIPS
(streaming/** is not storage_changes).
