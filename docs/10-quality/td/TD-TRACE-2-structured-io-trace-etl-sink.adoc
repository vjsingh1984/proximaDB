== The finding

The external landing now exists, but its delivery semantics are weaker than its former “durable
spool” label. Records can disappear before sealing; sealed fallback files can remain stranded forever;
retries have no conditional-create/digest protocol; operators cannot alert from counters. The data
model is still flat and there is no committed warehouse table.

== Direction (per ADR-066)

Keep the separate, gated observer, but name the layers precisely: bounded **memory ingress** →
immutable local **pending segment** → conditional-create object PUT → Iceberg-managed Parquet
warehouse. The sink remains best-effort at ingress. Once a record is sealed, retry is idempotent and
crash-aware. Billing stays always-on/untouched (ADR-027).

== Slices

* **S1 — shipped #1084: sink skeleton + local sealing.** New `set_trace_observer` seam (mirroring
  `set_billing_observer` but SEPARATE); mint a stable `query_id` at `instrument()` entry (if none
  exists); a bounded memory queue and background JSONL+zstd sealer; config + env overrides;
  default-OFF. It serializes the existing flat snapshot on query completion. “Local spool” in the
  original slice name is not a durability claim.
* **S2 — shipped #1087: direct object-store dispatch.** Background task seals on
  `segment_bytes` OR `flush_interval_s` (whichever first), zstd-compress, PUT via
  `proximadb-object-store` under `DrPathBuilder` keys
  `_operator/io_trace/` with `ObjectAccessTier = Cold`; PUT failure writes a local fallback.
  Compression/PUT remain off the query path. Tenant/date/host partitioning and retention are not
  implemented.
* **S2b — delivery hardening (next).** Seal an immutable pending file before upload; startup retry;
  writer-incarnation UUID + monotonic sequence + content digest; conditional create and
  AlreadyExists digest verification; retire local pending only after verified PUT. Add counters/gauges
  for dropped records/bytes, seal/upload failures, retries, pending files/bytes, and last success.
  Bound pending bytes without deleting sealed files: at the cap, stop draining ingress and account
  subsequent ingress drops. Duplicate install must drain/reject rather than abort the prior worker;
  shutdown timeout state is observable.
  Reject unsupported compression/format config. Add operator ACL/encryption and structural tenant-mode
  integration tests. Keep the ingress delivery label best-effort.
* **S3 — envelope refactor.** Migrate `IoTraceSnapshot` → **header + modality-tagged
  payload** (ADR-066 D1) at a stable seam — billing continues to read only header-class fields
  (`compute_ms`, `egress_bytes`), so meter behavior is byte-identical. Header includes
  `schema_version`, writer UUID, sequence, query ID, and event time. Unknown payload variants are
  skippable; bounded user strings and no raw data/query/vector are enforced.
* **S4 — Iceberg-managed Parquet warehouse.** Async compactor produces star-schema Parquet
  (`trace_header` + modality satellites; `exec[]` flattened), commits through Iceberg, deduplicates by
  source event identity, and advances a source-retirement watermark only after manifest commit.

== Resolved decisions / current caveats

* **Envelope migration ordering:** sink-first on the **flat** snapshot (S1–S2), envelope refactor later
  (S3). The durable stream does not block on the data-model change.
* **Identity:** `query_id` joins analytical rows; `{writer_uuid,sequence}` identifies ingestion events
  and prevents retry duplicates.
* **Object-size math:** `segment_bytes` is uncompressed JSONL bytes. Record compressed bytes and PUT
  count; tune from traces. Do not claim 4 MiB is a multipart part.
* **Retention/GC:** lifecycle may retire raw JSONL only after the S4 watermark covers it. The currently
  parsed `retention_days` is inert.
* **Isolation:** default operator stream is cross-tenant and operator-only. Tenant mode means one
  tenant per object under a tenant root, not a cosmetic key partition.

== Gate

Observe-only—no served-result change. In addition to existing JSONL round-trip, bounded-ingress, and
billing-never-gated tests, require:

* kill after local seal / before PUT, then restart → exactly one verified object and pending file retired;
* repeated PUT/AlreadyExists → digest match is no-op, mismatch fails closed;
* two writers with identical wall clock never collide; sequence/digest round-trip;
* object-store outage → pending metrics rise, recovery drains them; cap behavior is explicit;
* duplicate install and shutdown timeout never silently discard a sealed/pending segment;
* unsupported config rejected; active-vs-reserved config test;
* sink OFF/ON representative query p50/p95 + allocation budget, proving no filesystem/network/compress on query path;
* envelope unknown-payload/back-compat and billing input parity;
* S4 Iceberg crash/retry/dedup/schema-evolution/source-watermark round-trip;
* operator-only and tenant-root path/ACL integration tests.

== Non-goals

Recall@k / ranking / quality-eval (stays on the sampled `predicate_diagnostics` bus); OpenTelemetry
span export; a Kafka/Avro streaming bus (ADR-066 D2/D3 rejected Avro); any change to the billing meters.
