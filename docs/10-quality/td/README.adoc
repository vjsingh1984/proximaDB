= Per-File Technical Debt (TD) Entries

**New TD items are filed here, one file per TD** — `TD-<id>-<slug>.adoc` — to
avoid the textual merge conflicts that a single shared registry causes between
concurrent agent sessions.

The id is declared in each file's title heading (`= TD-<id>: short title`), which
is authoritative for the uniqueness guard.

Prefer a **topic-scoped id** (`TD-<TOPIC>-N`, e.g. `TD-CAT-3`, `TD-SC-2`) for
initiative work — it is collision-free across sessions. Use a global `TD-NNN` only
for standalone one-offs, claiming the next free number.

The canonical, full convention (id scheme, the CI guard, ADR filing) lives in
`docs/12-design/HOW_TO_FILE_TD_AND_ADR.adoc`. The legacy monolithic table at
`docs/10-quality/TECHNICAL_DEBT.adoc` remains the home of the ~100 existing TDs
(not migrated — they are referenced ~900× across the codebase); the
`td-adr-unique` CI guard treats those rows as declarations too, so ids stay unique
across both.
