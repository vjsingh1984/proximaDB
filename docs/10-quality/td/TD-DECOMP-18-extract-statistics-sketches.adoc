== Why

`src/core/statistics/sketches/` (5 files: mod.rs + frequent/hyperloglog/quantiles/reservoir,
**19 tests**) is a self-contained streaming-sketches subsystem. Only dep: `serde` (already in
kernel). The FNV-1a hash is defined in mod.rs (cohesive — moves with the subdir). Moves to
`proximadb-kernel` (foundation tier — the natural home for hash/sketch primitives alongside
`stable_id` and `checksum`).

== What moved (behavior-neutral)

* Whole `src/core/statistics/sketches/` subdir → `crates/foundation/proximadb-kernel/src/sketches/`.
* Root `src/core/statistics/mod.rs`: `pub mod sketches;` → `pub use proximadb_kernel::sketches;`.
* Kernel crate gains 19 tests (143→162). Deps: serde (already present).
