== Why

The connectors subgraph (`{mongodb,mysql,postgres}/*`, **93 tests**) is the last big cdc
subgraph. It references `crate::cdc::{config,error,event,offset,source}` (all now in the cdc
crate via TD-DECOMP-7..11). DB-driver code (mongodb/bson/tokio_postgres/mysql_async) is behind
`#[cfg(feature = "experimental-cdc-connectors")]` (never enabled in CI) so the default build
compiles without those heavy deps.

== What moved (behavior-neutral)

* `src/cdc/connectors/` (whole subdir: mod + mongodb/{mod,change_event,config,connector} +
  mysql/{mod,config,connector,decoder} + postgres/{mod,config,connector,decoder,replication,
  snapshot}) → `crates/integrations/proximadb-cdc/src/connectors/`.
* Rewrite: `crate::cdc::` → `crate::` (all refs — config/error/event/offset/source become
  siblings; connectors self-refs stay valid).
* cdc crate: + `experimental-cdc-connectors` feature (`["dep:tokio-postgres"]`), + deps
  `anyhow` (workspace), `base64` (inline `"0.22"`), `tokio-postgres` (inline `{ version =
  "0.7", optional = true }`).
* cdc crate 199→292 tests.
