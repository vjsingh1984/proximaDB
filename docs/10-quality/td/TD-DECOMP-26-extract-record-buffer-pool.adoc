== Why

`src/storage/cache/record_buffer_pool.rs` (**11 tests**) is the record-granularity buffer-pool
primitive (LLD §4, VeloANN arXiv 2602.22805): a generic clock admission/eviction pool that caches at
record granularity (vs page-level) to avoid the ~47% wasted residency DiskANN's page mismatch causes.
It is a truly self-contained leaf — zero `crate::` climb-out, zero real `super::`, **`tokio`-only** dep
(`tokio::sync::Mutex`) — so it moves to a new tiny storage-tier crate (a generic primitive, distinct
from the L2 block-cache `proximadb-cache` crate).

== What moved (behavior-neutral)

* `src/storage/cache/record_buffer_pool.rs` → `crates/storage/proximadb-record-buffer-pool/src/`.
* Root `src/storage/cache/mod.rs`: `pub mod record_buffer_pool;` →
  `pub use proximadb_record_buffer_pool::record_buffer_pool;` (single consumer = the `pub mod` decl).
* New storage-tier crate, dep `tokio` (workspace). No `CAPABILITY_MATRIX.toml` pointer.
