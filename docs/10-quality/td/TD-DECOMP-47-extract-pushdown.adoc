== What moved
`src/connectors/pushdown.rs` (7 tests) → new horizontal crate `proximadb-pushdown`. Root
`connectors/mod.rs` re-exports it (`pub use proximadb_pushdown::pushdown;`), so the existing
`pub use pushdown::{AggExpr, Expr, GraphTraversalPushdown, PushdownRequest, PushdownResponse, VectorSearchPushdown, ...};`
resolves unchanged. Deps: serde + hex (zero `proximadb_*` deps, zero `crate::` climb-out,
`super::` test-only). NOTE: `hex` declared inline (`hex = "0.4"`) — it is NOT in
`[workspace.dependencies]` (same gotcha as uuid in TD-DECOMP-44). Carries the pushdown negotiation
protocol (predicate/projection/aggregate/vector-search/graph-traversal request+response). Verified:
standalone + clippy -D warnings + root lib all pass. SIFT recall ratchet SKIPS (connectors/** is not
storage_changes).
