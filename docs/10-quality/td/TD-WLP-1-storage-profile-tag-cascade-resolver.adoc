== Why

ADR-061 makes the storage-projection strategy a first-class per-collection attribute. This slice
defines the attribute and its resolution and nothing else, so it is trivially safe to land and
unblocks WLP-2..6.

== Scope

* Define `enum StorageProfile { AppendBulk, Churn }` (default `AppendBulk`).
* Add `resolve_storage_profile(config: &CollectionConfig) -> StorageProfile`, mirroring
  `resolve_pax_vector_quant` exactly: **tag `workload_profile:append|bulk|churn` > env
  `PROXIMADB_STORAGE_PROFILE` > default `append`**; `append` and `bulk` both map to `AppendBulk`;
  unknown/absent → `AppendBulk`; last-matching tag wins (parity with the quant resolver).
* Do **not** consume the resolver from any read/write path in this slice (inert).
* Do **not** extend `CatalogWorkloadProfile` (ADR-061 D6 — distinct concern).

== TDD gate

Unit test `test_resolve_storage_profile_tag_env_default_cascade` (`#[cfg(test)]`, `cargo nextest run --lib`):

* `workload_profile:churn` tag → `Churn`.
* env `PROXIMADB_STORAGE_PROFILE=churn`, no tag → `Churn`; tag beats env.
* `append` and `bulk` tags → `AppendBulk`.
* unknown value / absent → `AppendBulk` default.
* last-matching-tag-wins parity with `resolve_pax_vector_quant`.

== Gating

Default-OFF by construction — the resolver exists but no path calls it, so behaviour is unchanged.
