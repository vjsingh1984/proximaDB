== Why

These three modules are prerequisites for the connectors subgraph (which references
`crate::cdc::{config, offset, source}`). Moving them unblocks the ~80-test connectors
extraction (TD-DECOMP-12). config (0t, thin), offset (9t, zero `crate::` refs), source
(6t, refs `crate::cdc::{event,offset}` → rewrite to `crate::*`).

* cdc crate +`proximadb-config` dep (config.rs references it). Root re-exports all three.
* cdc crate 184→199 tests.
