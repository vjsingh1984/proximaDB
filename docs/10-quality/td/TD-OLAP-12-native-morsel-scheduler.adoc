== Scope (what Phase 4 delivers)

A single-node, NUMA-aware, work-stealing morsel scheduler (Leis/Boncz/Kemper/Neumann,
SIGMOD 2014) that drives the Phase-2/3 native operators across cores:

. **`MorselScheduler` contract** (ADR-054 §3.2) — dispatch a `Pipeline` as morsel-sized
  units of work over a fixed worker pool; the operators are already morsel-shaped
  (`ExecutionOperator` consumes/produces Arrow `RecordBatch`), so this is additive.
. **Morsel size** — const default **2048** (DuckDB/Velox `STANDARD_VECTOR_SIZE`), with a
  per-operator override hook (ADR-054 §12 Q3 recommendation). Tunable, not hard-coded.
. **NUMA affinity** — dedicated OS worker threads pinned via `core_affinity`, morsels
  routed to the socket that owns the input pages; explicitly not Tokio's default pool
  (which is unaware of NUMA and would defeat the locality this phase exists to buy).
. **Generalize the join scheduler** — Phase 3 (TD-OLAP-11) ships a *local* join-scoped
  scheduler for the build+probe pipelines; this phase promotes it to all pipelines.

== Non-goals

* **No distributed execution.** The scheduler is single-node; a morsel/hash-partition
  exchange for MPP is a separate future ADR (ADR-054 §7.2). Ballista remains the
  DataFusion-only distributed path (ADR-054 §7.3).
* **No codegen** (ADR-052 non-goal, inherited).
* **No promotion without the ledger.** Gate = end-to-end ClickBench + TPC-H/TPC-DS at
  parity-or-better vs the single-threaded native path *and* vs DataFusion, on the same
  object store, in CI (ADR-054 §8 Phase-4 gate). Ships behind a flag, default-off,
  demoted on regression.
