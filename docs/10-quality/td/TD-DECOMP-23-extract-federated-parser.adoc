= TD-DECOMP-23: Extract federated parser → proximadb-query-fusion (existing crate)

[cols="1,3", options="header"]
|===
| Field | Value
| Status | Landing
| Severity | Low — behavior-neutral re-export into an existing crate
| Component | `crates/query/proximadb-query-fusion`; root `src/query/federated/mod.rs`
| Relates to | [[TD-DECOMP-1]] (recipe); [[TD-DECOMP-17]] (query-fusion precedent)
|===

== Why

`src/query/federated/parser.rs` (**20 tests**) is the Federated SQL-extension parser — it extends SQL
with multi-model query surfaces (`VECTOR_SEARCH`, `GRAPH_QUERY`, `DOCUMENT_QUERY`, `RERANK`,
`LOGS`/`METRICS`/`TRACES`, the pgvector-compatible `<->` distance operator). It is a clean leaf:

* **zero `crate::` climb-out**, single `super::` (the `#[cfg(test)]` block only);
* **`anyhow`-only** external dep;
* self-contained (8 types/fns in-file: `FederatedParser`, `FederatedQuery`, `QueryType`,
  `SqlExtension`, ...).

It moves into the **existing** `proximadb-query-fusion` crate, which already holds the federated
optimizer (`plan_calibration`, `gls`) from TD-DECOMP-17 and is de facto the "federated query utilities"
home — so no new crate is created.

== What moved (behavior-neutral)

* `src/query/federated/parser.rs` → `crates/query/proximadb-query-fusion/src/parser.rs`.
* Root `src/query/federated/mod.rs`: `pub mod parser;` → `pub use proximadb_query_fusion::parser;`
  (the existing `pub use parser::{FederatedParser, FederatedQuery, QueryType};` re-export keeps working
  off the shimmed module). Consumers — `optimizer/{mod,tests}` via `super::parser` and
  `crate::query::federated::parser` — resolve unchanged.
* `anyhow` added to `proximadb-query-fusion` deps (parser uses `anyhow::Result`).
* No `CAPABILITY_MATRIX.toml` evidence pointer referenced this file.

== Follow-ups

* **Running total once merged: ~857 tests out of root** (837 + 20).
* `query-fusion` now holds fusion + optimizer + parser — its doc-comment frames it as "federated query
  utilities"; a future rename to `proximadb-federated-query` is possible if the breadth grows further.
