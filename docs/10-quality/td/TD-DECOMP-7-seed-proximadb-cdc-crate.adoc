== Why

After the cluster vein's clean leaves were exhausted (TD-DECOMP-2..6 relocated 125 tests;
remaining cluster residue is tangled with root `network`/`storage`/`catalog`), a coupling scan
of `src/cdc/` (~305 tests) found the most clean-leaf fuel remaining in the monolith — but cdc
had **no target crate**. This slice creates `proximadb-cdc` (integration tier) and seeds it
with the standalone `event` module, establishing the crate so the rest of cdc (connectors/
sinks/transform/coordinator) can follow as cohesive subgraphs.

`src/cdc/event.rs` (773 LOC, **13 tests**) is fully self-contained: zero `crate::` refs, deps
only `serde`/`serde_json`/`rand` (no `proximadb_*`) — a verbatim move.

== What moved (behavior-neutral)

* Created `crates/integrations/proximadb-cdc/` (`Cargo.toml` + `src/lib.rs`) — integration tier
  (may depend only on foundation/horizontal/contracts; this crate's deps are external only).
* `git mv src/cdc/event.rs` → `crates/integrations/proximadb-cdc/src/event.rs` (verbatim — no
  path rewrites; `event` has zero `crate::` refs).
* Root `Cargo.toml`: added `proximadb-cdc` to `[workspace.members]`, `[workspace.dependencies]`
  (path), and root `[dependencies]` (`workspace = true`).
* Root `src/cdc/mod.rs`: `pub mod event;` → `pub use proximadb_cdc::event;` — so the 10 root
  cdc callers (`source`/`coordinator`/`connectors`/`sinks`/`outbound`) resolve
  `crate::cdc::event::{ChangeEvent, Operation, RecordState, SourceInfo, TransactionInfo,
  ConnectorType}` unchanged.
