== What moves
`src/index/geo/types.rs` (4 tests: `GeoPoint`, `GeoBoundingBox`, `GeoCircle`, `GeoPolygon`,
`GeoDistanceUnit` + haversine/contains/centroid helpers) → new horizontal crate `proximadb-geo-types`.
Root `index/geo/mod.rs` re-exports it (`pub use proximadb_geo_types::types;`), so the existing
`pub use types::{GeoBoundingBox, GeoCircle, GeoDistanceUnit, GeoPoint, GeoPolygon};` resolves unchanged
— including for the sibling geohash/index/queries modules which consume these types via the shim.
Deps: serde only (zero `proximadb_*` deps, zero `crate::` climb-out, `super::` test-only). This is the
**hub** of the index/geo subsystem; extracting it unblocks geohash/index/queries to follow individually.
Verified: standalone + clippy -D warnings + root lib all pass. SIFT recall ratchet SKIPS (index/** is
not storage_changes).
