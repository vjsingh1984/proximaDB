== What landed

* `DeltaCatalog::new_with_filesystem` — object-store mode routes ALL persistence
  (`_delta_catalog.json`, `{ns}/{table}/_delta_log/{v:020}.json`) through the
  injected `FileSystem` with scheme-qualified URLs; local mode is byte-identical
  to before. `CatalogManager::create_delta_catalog` resolves the backend via the
  same `CatalogFilesystemResolver` port the native catalog uses (no new
  catalog→storage dependency edge).
* `CatalogManager::resolve_object_store_fs` — ONE scheme predicate
  (`contains("://") && !file:// && !memory://`) shared by native + delta creation;
  replaces the `s3://|gs://|az://` allowlist that silently temp-cached
  `adls://`/`abfs://`/`azure://`/`gcs://` catalogs.
* Round-trip test: create namespace+table over an injected in-memory object
  store (`adls://` URL), assert object keys, reopen fresh instance, state
  survives (`delta.rs::object_store_backend_round_trips`; shared `testfs::MemFs`).

== Follow-ups (open)

[cols="3,3", options="header"]
|===
| Item | Rationale

| **CAS on `_delta_catalog.json`** (ETag `If-Match` / versioned pointer)
| Current semantics are last-writer-wins on one JSON object — parity with the
  pre-existing local layout and safe under the single-writer-per-deployment
  warehouse model. Multi-writer deployments should commit the catalog pointer
  through `ManifestCommitter` (put-if-absent versioned log + generation fence,
  the primitive the SystemCatalog snapshot already uses) or ETag CAS once the
  `FileSystem` port exposes conditional writes. This is the Iceberg-REST /
  Boring-Catalog commit model; see the catalog design review
  (`CATALOG_OBJECT_STORE_DESIGN_REVIEW_2026_07_14.adoc`).

| **Rename does not relocate data objects**
| Object stores have no rename; the catalog pointer is updated and a loud warn
  is emitted. A copy-based relocation (or Iceberg-style location-independent
  table ids) is the durable fix.

| **`_delta_log` checkpointing**
| The per-table log is append-only JSON commits; a `_last_checkpoint`-style
  collapse (Parquet checkpoint every N commits) bounds cold-load reads. Low
  urgency: our Delta catalog currently rebuilds state from
  `_delta_catalog.json`, not by log replay.
|===
