== Why

Continuing the root-monolith decomposition (the 850K-LOC root lib test binary bundles
9,538 inline tests → OOMs the 16 GB runner → `CARGO_BUILD_JOBS=1`). TD-DECOMP-2 proved
the recipe on `rank_metrics`; this slice applies it to the **cluster `rpc/` abstraction
layer** — the second clean, self-contained leaf found after exhausting observability's
and catalog's residue (both are facades whose remaining local code is cross-coupled to
layering-forbidden tiers).

The cluster `rpc/` core (`error`/`types`/`traits`/`retry`, ~2.6K LOC, **37 inline
tests**) is fully self-contained: deps only `serde`/`async-trait`/`futures`/`rand` +
`proximadb-distance-types` (foundation), with **zero `crate::` climb-out**. It moves to
`proximadb-runtime` (platform tier) — layering-legal because platform may depend on every
layer except root/application/binding.

== What moved (behavior-neutral)

* `src/cluster/rpc/{error,types,traits,retry}.rs` →
  `crates/platform/proximadb-runtime/src/cluster_rpc/` (verbatim — no `crate::` paths to
  rewrite; the files' `super::` sibling refs stay valid under the new `cluster_rpc/` parent).
* `proximadb-runtime/src/lib.rs` declares `pub mod cluster_rpc;` (sibling to the existing
  `cluster_port`).
* `proximadb-runtime/Cargo.toml` gains `futures`, `rand`, `proximadb-distance-types`
  (all workspace deps; `serde`/`async-trait` already present).
* Root `src/cluster/rpc/mod.rs` replaces `pub mod {error,types,traits,retry};` with
  `pub use proximadb_runtime::cluster_rpc::{error, retry, traits, types};` — so the
  root-side tonic impl (`connection`, `grpc_client`, `grpc_server`) and the ~7 external
  `crate::cluster::rpc::*` / `proximadb::cluster::rpc::*` callers resolve **unchanged**.

Behavior-neutrality is structural: every `crate::cluster::rpc::{error,types,traits,retry}`
path resolves to the same items via the re-export; the runtime crate gains no dependency
on the root (verified by `check_workspace_boundaries.py`), so no cycle is possible.

== Verification

* `cargo check -p proximadb-runtime` green (moved module + new deps compile).
* `cargo check -p proximadb` green (root compiles through the re-export shim; the
  tonic-backed `connection`/`grpc_*` resolve the moved types via `super::`).
* `cargo nextest run -p proximadb-runtime --lib` — the 37 rpc tests now run in the
  runtime's own binary.
* `cargo nextest run -p proximadb --lib` green — root lib test binary shed the 37 tests.
* `python3 scripts/check_workspace_boundaries.py` + `scripts/check-layering.sh` green.
* `cargo build -p proximadb-server` + `cargo clippy --lib --bins -- -D warnings` +
  `cargo fmt --check` + `make work-commit-check` green.
