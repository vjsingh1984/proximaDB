=== **Level 3: Query Processing Pipeline**

[source,mermaid]
----
%%{init: {"theme": "neutral"}}}%%
sequenceDiagram
    participant User
    participant API
    participant NLProcessor
    participant SecurityValidator
    participant LLMRouter
    participant SchemaContext
    participant QueryEngine
    participant BusinessIntelligence

    User->>API: "Show me our top customers this quarter"
    API->>NLProcessor: Parse natural language
    NLProcessor->>SecurityValidator: Validate user permissions
    SecurityValidator->>SchemaContext: Get accessible tables
    SchemaContext-->>NLProcessor: Schema information + permissions
    NLProcessor->>LLMRouter: Generate SQL with context

    alt Primary LLM Available
        LLMRouter->>LLMRouter: Use OpenAI/Anthropic
    else Primary LLM Unavailable
        LLMRouter->>LLMRouter: Fallback to alternative provider
    end

    LLMRouter-->>SecurityValidator: Generated SQL query
    SecurityValidator->>SecurityValidator: Validate for SQL injection
    SecurityValidator->>QueryEngine: Execute validated query
    QueryEngine-->>BusinessIntelligence: Raw results
    BusinessIntelligence->>BusinessIntelligence: Generate insights
    BusinessIntelligence-->>User: Formatted business insights + visualizations
----

=== AI Security State Machine

----
%%{init: {"theme": "neutral"}}}%%
stateDiagram-v2
    [*] --> QueryReceived
    QueryReceived --> AuthenticationCheck

    AuthenticationCheck --> AuthenticationFailed : Invalid credentials
    AuthenticationCheck --> TenantValidation : Valid user

    TenantValidation --> AccessDenied : Invalid tenant
    TenantValidation --> InputValidation : Valid tenant

    InputValidation --> MaliciousInputDetected : Suspicious patterns
    InputValidation --> PermissionCheck : Clean input

    PermissionCheck --> InsufficientPermissions : Restricted access
    PermissionCheck --> SQLGeneration : Authorized

    SQLGeneration --> SQLValidation
    SQLValidation --> SQLInjectionDetected : Malicious SQL
    SQLValidation --> QueryExecution : Safe SQL

    QueryExecution --> AuditLog
    AuditLog --> [*]

    AuthenticationFailed --> [*]
    AccessDenied --> [*]
    MaliciousInputDetected --> [*]

    SQLInjectionDetected --> [*]
