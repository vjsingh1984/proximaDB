== Engine-Specific Layout Diagrams

=== SST Engine: Linear Sequential Layout

**Format**: Custom binary with LSM-tree structure
**Complexity**: Medium (Hierarchical blocks)
**Tool**: Mermaid Block Diagram

[source,mermaid]
----
%%{init: {"theme": "base", "themeVariables": {"primaryColor": "#1e88e5", "primaryTextColor": "#ffffff", "primaryBorderColor": "#0d47a1", "lineColor": "#1976d2"}}}%%
block-beta
    columns 5

    block:Header:1
        Magic["Magic Bytes<br/>SST1"]
        Version["Format Version"]
        Metadata["File Metadata"]
    end

    block:BloomFilter:1
        BFHeader["Bloom Filter<br/>Header"]
        BFData["Filter Bits<br/>95% Reduction"]
        BFIndex["Block Index"]
    end

    block:QuantizedData:1
        QHeader["Quantization<br/>Parameters"]
        QBlocks["Quantized Blocks<br/>INT8/PQ Encoded"]
        QIndex["Block Offsets"]
    end

    block:FullPrecision:1
        FPHeader["Full Precision<br/>Header"]
        FPBlocks["FP32 Vector<br/>Blocks"]
        FPMeta["Block Metadata"]
    end

    block:Footer:1
        Checksum["File Checksum"]
        Offsets["Section Offsets"]
        Stats["File Statistics"]
    end

    Header --> BloomFilter
    BloomFilter --> QuantizedData
    QuantizedData --> FullPrecision
    FullPrecision --> Footer
----

**Three-Stage Filtering Pipeline:**
```
Query → Bloom Filter (95% reduction) → Quantized Search → Full Precision → Results
```

    Level1 --> Level2
    Level2 --> Level3
----

**Hardware Adaptation Strategy:**
```
CPU Detection → Encoding Selection → SuperBlock Layout → DataBlock Optimization → Vector Storage
```

**Encoding Markers:**
- `0x80-0x8F`: SuperBlock-level encoding schemes
- `0xFF`: Child blocks inherit parent encoding
- Hardware-specific optimization for AVX512/AVX2/SSE/Scalar

```
PRISM Multi-Resolution Storage:
Progressive Marker: [0xB0-0xBF] + Resolution Count

Resolution 1 (Binary):    [0xB0] [1-bit per dimension]
Resolution 2 (INT8):      [0xB2] [8-bit quantized]
Resolution 3 (PQ4):       [0xB4] [4-bit product codes]
Resolution 4 (PQ8):       [0xB6] [8-bit product codes]

Medium Press. → Load Resolution 1-4 (up to PQ8)
Low Pressure  → Load all resolutions (full quality)
```
