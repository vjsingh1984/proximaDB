==== CUDA Implementation (NVIDIA)

**Kernels**:

* ✅ Delta Encoding/Decoding (GPU accelerated)
* ✅ Frame-of-Reference Encoding/Decoding (GPU accelerated)
* ⚠ BitPack Encoding/Decoding (CPU fallback)

**Kernels**:

* ✅ Zigzag Encoding/Decoding

**Infrastructure**:

=== Phase 3: ROCm & OpenCL 📋 PLANNED

==== ROCm (AMD GPUs)

**Target**: Linux systems with AMD GPUs

**Plan**:

* HIP kernel implementation (similar to CUDA)
* FFI via `hip-rs` or direct hipcc integration
* Automatic AMD GPU detection

==== OpenCL (Universal Fallback)

**Target**: Any GPU with OpenCL support

**Plan**:

* OpenCL C kernel implementation
* FFI via `opencl3` crate
* Fallback for unsupported GPU vendors

== Building with GPU Support

=== Prerequisites

==== NVIDIA CUDA

[source,bash]
----
# Install CUDA Toolkit (Linux/Windows)
# Download from: https://developer.nvidia.com/cuda-downloads

# Verify installation
nvcc --version

# macOS: CUDA not officially supported
----

==== Apple Metal/MPS

[source,bash]
----
# Comes pre-installed on macOS with Apple Silicon
# Verify Metal support
system_profiler SPDisplaysDataType | grep Metal
----

==== AMD ROCm (Future)

[source,bash]
----
# Install ROCm (Linux only)
# https://rocm.docs.amd.com/
----

=== Build Commands

==== Basic Build (No GPU)

[source,bash]
----
cargo build --release
----

==== Build with CUDA

[source,bash]
----
# Ensure CUDA_PATH is set
export CUDA_PATH=/usr/local/cuda

# Build with CUDA feature
cargo build --release --features gpu
----

==== Build with Metal (macOS)

[source,bash]
----
# Automatic on Apple Silicon
cargo build --release --features gpu
----

==== Build with All GPU Backends

[source,bash]
----
cargo build --release --features "gpu,cuda,metal,rocm,opencl"
----

Add to `config/config.toml`:

[source,toml]
----

batch_size = 8192
memory_pool_size_mb = 512

[compute.gpu.cuda]
device_id = 0
stream_count = 4
use_pinned_memory = true

[compute.gpu.metal]
device_id = 0
command_queue_count = 4
----

== Runtime Usage

=== Automatic GPU Detection

[source,rust]
----
use proximadb::storage::engines::core::ops::proximacodec::ProximaCodec;

let codec = ProximaCodec::global();

// GPU automatically used if available and enabled
let values = vec![1.0f32; 1_000_000];
let encoded = codec.encode(&values, ProximaScheme::Delta { base: 0 })?;
let decoded: Vec<f32> = codec.decode(&encoded)?;
----

=== Force Specific Backend

[source,rust]
----
use proximadb::storage::engines::core::ops::proximacodec::impls::gpu::GpuBackend;

// Force CUDA (will fail if unavailable)
let backend = GpuBackend::Cuda;
let encoder = backend.get_encoder()?;

// Force Metal (macOS only)
let backend = GpuBackend::Metal;
let encoder = backend.get_encoder()?;
----

=== Fallback Behavior

[source,rust]
----
// Automatic fallback to CPU if GPU unavailable
let codec = ProximaCodec::global();

// Will use GPU if available, CPU otherwise
let encoded = codec.encode(&values, scheme)?;
----

== Troubleshooting

=== CUDA Build Fails

**Error**: `nvcc: command not found`

**Solution**:

[source,bash]
----
export PATH=/usr/local/cuda/bin:$PATH
export CUDA_PATH=/usr/local/cuda
----

**Error**: `libcuda.so.1: cannot open shared object file`

**Solution**:

[source,bash]
----
export LD_LIBRARY_PATH=/usr/local/cuda/lib64:$LD_LIBRARY_PATH
----

=== Metal Build Fails (macOS)

**Error**: `Metal backend not available`

**Solution**: Ensure you're on Apple Silicon (M1/M2/M3):

[source,bash]
----
uname -m  # Should show "arm64"
system_profiler SPHardwareDataType | grep "Chip"
----

=== GPU Not Detected at Runtime

**Check GPU availability**:

[source,rust]
----
use proximadb::storage::engines::core::ops::proximacodec::impls::gpu::detect_gpus;

let gpus = detect_gpus();
println!("Available GPUs: {:?}", gpus);
----

== Architecture Details

=== Module Structure

----
src/storage/engines/core/ops/proximacodec/impls/gpu/
├── mod.rs              # Platform abstraction layer
├── memory.rs           # GPU memory management
├── cuda/               # NVIDIA CUDA backend
│   ├── mod.rs
│   ├── kernels.cu      # CUDA C kernels
│   └── ffi.rs          # cudarc bindings
├── metal/              # Apple Metal backend
│   ├── mod.rs
│   ├── kernels.metal   # Metal shaders
│   └── ffi.rs          # metal-rs bindings
├── rocm/               # AMD ROCm backend (future)
│   └── mod.rs
└── opencl/             # OpenCL backend (future)
    └── mod.rs
----

=== Kernel Implementation

All GPU kernels implement the same interface:

[source,rust]
----
pub trait GpuKernel {
    fn encode(&self, input: &[f32], output: &mut [u8]) -> Result<()>;
    fn decode(&self, input: &[u8], output: &mut [f32]) -> Result<()>;
}
----

=== Memory Management

**Batching Strategy**:

* Default batch size: 8192 values
* Configurable via `GpuBatchConfig`
* Automatic power-of-2 alignment for optimal performance

**Memory Pools**:

* Pre-allocated GPU buffers
* Pinned host memory for faster transfers
* Configurable pool size (default: 512 MB)
