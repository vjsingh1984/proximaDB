== Key Features

=== Core Capabilities
* **6 Index Types**: HNSW, IVF, PQ, FLAT, ANNOY, LSH
* **13 Distance Metrics**: Cosine, Euclidean, Dot Product, Manhattan, Hamming, Jaccard, and more
* **13 Compression Algorithms**: ZSTD, LZ4, Snappy, Gzip, Brotli, and more
* **Query Interfaces**: SQL, REST API, gRPC, Python SDK
* **Cloud Storage**: S3, Azure Blob, Google Cloud Storage, MinIO

== Architecture Highlights

image::system-data-flow-abstract.svg[Data Flow Architecture, width=900]

=== Production-Ready Components
* **Hierarchical SST**: 85% S3 cost reduction with smart bloom filters
* **Zero-Copy Compaction**: Direct SstRecord streaming with MVCC
* **Unified Compression**: Single module for all compression contexts
* **Dual Storage Engines**: SST (row-based) + VIPER (columnar)
* **Hardware Acceleration**: Automatic GPU/SIMD detection and usage

== Quick Start Examples

=== Docker Deployment
[source,bash]
----
docker run -d \
  -p 5678:5678 \
  -p 5679:5679 \
  -v proximadb_data:/data \
  proximadb/proximadb:latest
----

=== Python SDK
[source,python]
----
from proximadb import ProximaDBClient

client = ProximaDBClient("http://localhost:5678")
client.create_collection("my_vectors", dimension=384)
client.insert_vectors("my_vectors", data)
results = client.search("my_vectors", query_vector, top_k=10)
----
