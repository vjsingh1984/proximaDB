=== Dual Storage Architecture
**Magic Bytes** for automatic format detection:

[cols="1,1,2", options="header"]
|===
| Engine | Magic Bytes | Purpose

| **SST Engine**
| `SST1` (header)
| Row-based storage for OLTP workloads

| **VIPER Engine**
| `PAR1` (footer)
| Columnar storage for analytics
|===

=== SDK-Driven Compression
**Full Client Control** - No server defaults:

* **Algorithms**: ZSTD (2-10x), LZ4 (1.5-3x), Snappy (1.5-2x)
* **Quantization**: INT8, PQ8, PQ4 with 100% FP32 fidelity
* **Cache**: Intelligent decompression cache with auto-invalidation
