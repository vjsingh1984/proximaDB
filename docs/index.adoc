== Architecture

=== Core Components
* **VectorOperationsService**: Proto-first, zero-copy operations
* **Dual Storage**: SST (row-based) + VIPER (columnar)
* **Hardware Acceleration**: Automatic GPU/SIMD detection
* **Compression**: SDK-driven ZSTD/LZ4/Snappy

=== Supported Features
* **6 Index Types**: HNSW, IVF, PQ, FLAT, ANNOY, LSH
* **13 Distance Metrics**: Cosine, Euclidean, Dot Product, Manhattan, etc.
* **Query Options**: SQL, REST, gRPC, Python SDK
* **Cloud Storage**: S3, Azure Blob, Google Cloud Storage

== Quick Examples

=== Docker Setup
```bash
docker run -d \
  -p 5678:5678 \
  -p 5679:5679 \
  -v proximadb_data:/data \
  proximadb/proximadb:latest
```

=== Python Client
```python
from proximadb import ProximaDBClient

client = ProximaDBClient("http://localhost:5678")
client.create_collection("my_vectors", dimension=384)
client.insert_vectors("my_vectors", vectors)
results = client.search("my_vectors", query_vector, top_k=10)
```
