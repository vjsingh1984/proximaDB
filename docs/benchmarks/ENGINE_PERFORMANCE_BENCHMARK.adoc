= Engine Performance Benchmarks
:toc: left
:toclevels: 2
:icons: font

[.lead]
Developer-facing benchmark notes for vector engines. For detailed reports, see `benchmarks/` and `tools/benchmarks/`.

== What These Benchmarks Measure

* Vector insert throughput
* Search latency (avg and p99)
* Recall under different engine strategies

== How To Run

[source,bash]
----
make benchmark
make benchmark-vector
----

== Interpreting Results

* **SST**: best for streaming ingestion and balanced read/write
* **HELIX**: best for clustered vectors and read-heavy workloads
* **VIPER**: best for analytics scans (Parquet)
* **SWIFT/NOVA/RAPTOR**: balanced or adaptive strategies

== Notes

* Results depend on hardware, dataset, and config.
* Use `config/config.toml` to align benchmark settings with your workload.
