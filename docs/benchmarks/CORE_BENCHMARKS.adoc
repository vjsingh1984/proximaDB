.Foundation Performance Measurements
--
Core benchmarks measure fundamental operations that affect all workloads using **realistic embedding generators** that accurately simulate production embedding models. These establish baseline performance for distance computation, memory management, hardware acceleration, and query processing with:

* **BERT-style embeddings** (768D): Normal distribution (μ=0, σ=1.5), range [-5, 5]
* **OpenAI Ada patterns** (1536D): Positive-skewed (mean ~0.3), <20% negative values
* **Sparse embeddings**: 0-95% sparsity for real-world scenarios
--

toc::[]

== Test Environment
**Hardware**: Apple M4 Pro, 48GB RAM, macOS ARM64 +
**Realistic Embedding Generators**: +

* **BERT Model** (768D): Box-Muller normal distribution (μ=0, σ=1.5), range [-5, 5], ~50% negative values, slight dimensional correlations
* **OpenAI Ada Model** (1536D): Shifted positive distribution (mean ~0.3), <20% negative tail, 5% high-magnitude components
* **Normalized Embeddings**: Unit L2 norm for cosine similarity
* **Sparse Patterns**: 0-95% sparsity simulation for efficiency testing

**Implementation**: Pure Rust using Box-Muller transform, no external dependencies

[cols="2,3"]

|**Distribution** |Positive-skewed
|**Mean** |~0.3

|===

=== Implementation

[source,rust]
----
// Box-Muller transform for normal distribution
let u1: f32 = rng.gen_range(0.0001..1.0);
let u2: f32 = rng.gen_range(0.0..1.0);
let normal = (-2.0f32 * u1.ln()).sqrt() *
             (2.0 * PI * u2).cos();

// BERT: Normal with σ=1.5
let bert_val = normal * 1.5;
let clamped = bert_val.max(-5.0).min(5.0);

// OpenAI Ada: Positive-skewed
let ada_val = if normal < -1.5 {
    normal * 0.2  // Small negative tail
} else {
    (normal * 0.8 + 0.3).abs() *
    (1.0 + normal * 0.1)  // Positive skew
};
----

* Performance within 10% of baseline
