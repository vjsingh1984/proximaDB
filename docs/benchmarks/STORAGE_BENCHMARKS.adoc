.Storage Layer Performance Analysis
--
Comprehensive benchmarks for all 7 storage engines (SST, VIPER, NOVA, SWIFT, RAPTOR, PRISM, HELIX), including comparison, optimization, lifecycle, and specialized features. **Uses realistic embedding generators** that simulate:

* **BERT embeddings** (768D): Normal distribution with mean=0, std=1.5, range [-5, 5]
* **OpenAI Ada embeddings** (1536D): Positive-skewed distribution, >80% positive values, mean ~0.3
* **Sparse embeddings**: 0-95% sparsity patterns for real-world scenarios
--

== Realistic Embedding Generators

All storage benchmarks use production-accurate embedding generators:

=== BERT Model (768D)
* **Generation**: Box-Muller transform for normal distribution
* **Statistics**: Mean=0, StdDev=1.5, Range=[-5, 5]
* **Characteristics**: ~50% negative values, slight dimensional correlations (0.2 factor)
* **Performance Impact**: Optimized for bidirectional context patterns

=== OpenAI Ada Model (1536D)
* **Generation**: Shifted normal with positive skew transformation
* **Statistics**: Mean~0.3, <20% negative values
* **Characteristics**: 5% dimensions with 2.5x magnitude boost
* **Performance Impact**: Optimized for transformer-based patterns

[cols="2,4"]
|===
|Choose |When You Have

|**SST**
|High write volume, real-time requirements, row-based access

|**VIPER**
|Analytics workload, sparse vectors, columnar queries

|**NOVA**
|Balanced read/write, progressive search needs

|**SWIFT**
|Latency-critical reads, point queries, caching

|**RAPTOR**
|Variable workload, need auto-tuning

|Memory constraints, can trade speed for compression

|Time-series data, temporal access patterns

== Configuration Examples

=== Write-Heavy Workload
[source,toml]
----
[storage]
engine = "sst"
write_buffer_size = "2GB"
flush_threshold = 50000

[storage.wal]
enabled = true
sync_interval = "1s"
----

=== Read-Heavy Workload
[source,toml]
----
[storage]
engine = "swift"
cache_size = "8GB"
prefetch_enabled = true

[storage.read]
parallel_reads = 16
read_ahead = "10MB"
----

=== Analytics Workload
[source,toml]
----
[storage]
engine = "viper"
compression = "zstd"
columnar_batch_size = 10000

[storage.parquet]
enable_statistics = true
dictionary_encoding = true
----

=== Memory-Constrained
[source,toml]
----
[storage]
engine = "prism"
compression = "aggressive"

[compute.quantization]
level = "pq4"
sparse_optimization = true
