== 5-Minute Optimization Paths

=== Path 1: Optimize for Speed (< 1ms)

[cols="1,3,2"]
|===
|Step |Action |Command

|1
|Baseline measurement
|`cargo bench --bench core_distance_computation`

|2
|Configure for speed
|Edit config.toml (see below)

|3
|Validate improvement
|`cargo bench --bench query_progressive_search`
|===

**Configuration**:
[source,toml]
----
[storage]
engine = "swift"
cache_size = "8GB"
prefetch_enabled = true

[compute]
simd_enabled = true
batch_size = 1

[search]
progressive_enabled = false
----

**Expected Results**: 5-10x latency reduction, < 1ms P99

== Common Scenarios

=== "My queries are too slow"

**Diagnosis**:
```bash
cargo bench --bench core_distance_computation
cargo bench --bench query_progressive_search
```

**Solutions**:
[cols="2,3,2"]
|===
|Cause |Solution |Impact

|No SIMD
|Enable hardware acceleration
|10x speedup

|Wrong engine
|Switch to SWIFT/NOVA
|2-5x speedup

|No caching
|Enable cache + prefetch
|3x speedup

|Too many stages
|Reduce progressive stages
|2x speedup
|===

=== "I'm running out of memory"

**Diagnosis**:
```bash
cargo bench --bench memory_vector_optimization
cargo bench --bench storage_sparsity_compression
```

**Solutions**:
[cols="2,3,2"]
|===
|Cause |Solution |Impact

|No quantization
|Enable PQ8/PQ16
|4x reduction

|Wrong engine
|Switch to PRISM/VIPER
|2-5x reduction

|Dense storage
|Enable sparsity compression
|10x for sparse

|Large cache
|Reduce cache size
|Direct savings
|===

=== "Search results aren't accurate"

**Diagnosis**:
```bash
cargo bench --bench query_progressive_search -- high_recall
```

**Solutions**:
[cols="2,3,2"]
|===
|Cause |Solution |Impact

|Over-quantization
|Reduce to INT8 or FP32
|+5-10% recall

|Aggressive filtering
|Increase candidates
|+3-5% recall

|Wrong metric
|Verify distance metric
|Varies

|Data quality
|Check normalization
|Varies
|===

=== "Ingestion is too slow"

**Diagnosis**:
```bash
cargo bench --bench storage_flush_optimization
cargo bench --bench storage_engine_comparison
```

**Solutions**:
[cols="2,3,2"]
|===
|Cause |Solution |Impact

|Synchronous writes
|Enable async flush
|10x speedup

|Wrong engine
|Switch to SST
|2-3x speedup

|Small batches
|Increase batch size
|5x speedup

|No WAL tuning
|Configure WAL properly
|2x speedup
|===

== Troubleshooting Guide

=== Performance Diagnostics

[cols="3,4"]
|===
|Check |Command

|SIMD status
|`cargo bench --bench hardware_simd_acceleration`

|Memory usage
|`cargo bench --bench memory_vector_optimization`

|Engine performance
|`cargo bench --bench storage_engine_comparison`

|Query pipeline
|`cargo bench --bench query_progressive_search`

|System bottlenecks
|`cargo bench --bench system_optimization_suite`
|===

=== Common Issues

[cols="2,3,3"]
|===
|Symptom |Cause |Solution

|Latency spikes
|GC pauses, cold cache
|Tune GC, pre-warm cache

|Memory leaks
|Unbounded pools
|Set pool limits, enable GC

|Poor recall
|Over-optimization
|Reduce compression, increase candidates

|Slow startup
|Large index loading
|Enable lazy loading, use mmap

|High CPU usage
|Inefficient batching
|Optimize batch size, enable SIMD

|Disk I/O bottleneck
|Small writes
|Increase buffer, batch operations
|===

== Emergency Optimization

When performance suddenly degrades:

1. **Quick Check** (30 seconds):
```bash
cargo bench --bench hardware_simd_acceleration | grep "Throughput"
```

2. **Identify Bottleneck** (2 minutes):
```bash
cargo bench --bench complete_benchmark_suite -- --warm-up-time 1 --measurement-time 2
```

3. **Apply Quick Fix**:
[cols="2,3"]
|===
|Issue |Quick Fix

|High latency
|`echo 'cache_size = "8GB"' >> config.toml && restart`

|Memory pressure
|`echo 'level = "pq8"' >> config.toml && restart`

|Low throughput
|`echo 'batch_size = 1000' >> config.toml && restart`

|Poor accuracy
|`echo 'progressive_enabled = false' >> config.toml && restart`
|===

4. **Validate** (1 minute):
```bash
cargo bench --bench query_progressive_search -- --warm-up-time 0.5 --measurement-time 1
```
