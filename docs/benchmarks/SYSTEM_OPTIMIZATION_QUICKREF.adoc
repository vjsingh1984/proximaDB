|===

== Configuration Presets

=== Optimal (Recommended for M4 Pro) ⭐

[source,toml]
----
[search.optimization.memory_sharing]
enable_arc_cloning = true
# CORRECTED: Arc always faster, set to max
arc_max_dimension = 999999      # Always use Arc
arc_max_clones = 999999         # Always use Arc
force_deep_clone_threshold = 999999  # Never force deep clone

[search.optimization]
enable_smart_aggregation = true
heap_select_threshold = 1000
heap_select_max_ratio = 0.1

enable_sparse_kernels = true
sparse_l2_threshold = 0.5

# CORRECTED: Sparse cosine impact is minimal
[search.optimization.cosine_warning]
enable_warnings = false         # DISABLED: < 10% impact
auto_fallback = false           # DISABLED: not needed
log_warnings = false            # DISABLED: not needed

[batch.processing]
parallel_threshold = 5000
preallocate_buffers = true
rayon_threads = 8

[storage.metadata]
enable_projection = true
max_inline_fields = 5
lazy_load_threshold = 20
----

**Use when**: Default configuration for most workloads
**Performance**: 10-15x overall improvement
**Memory**: Reduced by 50-70% with Arc sharing

=== High-Dimension Workload (768D-1536D)

[source,toml]
----
[search.optimization]
use_arc_cloning = false         # Avoid inversion
force_deep_clone = true

enable_smart_aggregation = true
heap_select_threshold = 500     # Lower threshold

enable_sparse_kernels = false   # Usually dense at high-D

[batch.processing]
parallel_threshold = 2000       # More parallel
rayon_threads = 12
----

**Use when**: Working with 768D-1536D embeddings
**Performance**: 2-3x from aggregation only
**Memory**: Higher due to deep clones

=== Sparse Vector Workload (50-90% sparsity)

[source,toml]
----
[search.optimization]
use_arc_cloning = true
arc_max_dimension = 2048

enable_sparse_kernels = true
sparse_l2_threshold = 0.5
avoid_cosine_for_sparse = true  # Critical!
cosine_sparse_fallback = "L2"

[compute]
enable_simd_sparse = true
sparse_detection_sample = 100
----

**Use when**: NLP embeddings with masked tokens
**Performance**: 2-3x from sparse L2 kernels
**Memory**: 7.6x compression with sparse encoding

=== Batch Insert Workload (Large batches)

[source,toml]
----
[batch.processing]
parallel_threshold = 3000       # Lower for batches
preallocate_buffers = true
rayon_threads = 16              # More threads
rayon_chunk_size = 500

[storage.metadata]
enable_projection = true
batch_metadata_load = true
----

**Use when**: Bulk data ingestion
**Performance**: 2.5x from parallelization
**Memory**: 13% reduction with preallocation

== Monitoring Checklist

✅ **Track clone strategy distribution** - Alert if >20% using suboptimal

✅ **Monitor aggregation performance** - Expect 5-7x with heap at n>1000

✅ **Watch sparsity distribution** - Enable sparse kernels if >30% sparse

✅ **Check parallel utilization** - Sequential should dominate for n<5000

✅ **Profile metadata overhead** - Should be <10% of total time

✅ **Validate Arc performance** - Alert if 1536D shows degradation

== Troubleshooting

[cols="2,3,2"]
|===
|Symptom |Cause |Solution

|Clone performance degraded
|Large dimensions (>1536D)
|Force deep clone

|Top-K slower than expected
|Using heap for k/n > 0.1
|Switch to partial_sort

|Parallel slower than sequential
|Batch size < 5000
|Increase parallel_threshold

|Cosine similarity very slow
|High sparsity vectors
|Use L2 distance fallback

|High memory usage
|Deep clones for small dims
|Enable Arc cloning

|Inconsistent performance
|CPU frequency scaling
|Pin CPU frequency
|===

== Quick Tuning Guide

=== Step 1: Profile Your Workload

[source,bash]
----
# Analyze actual usage patterns
cargo run --bin proximadb-bench -- analyze-workload \
  --input production.log \
  --output workload_profile.json

# Check key metrics
{
  "avg_dimension": 768,
  "avg_result_count": 1000,
  "avg_top_k": 10,
  "avg_sparsity": 0.15,
  "avg_batch_size": 500
}
----

=== Step 2: Select Configuration

```
If avg_dimension > 1536:
  → Disable Arc cloning (avoid inversion)

If avg_result_count > 1000 && top_k/result_count < 0.1:
  → Enable heap select (5-7x faster)

If avg_sparsity > 0.5:
  → Enable sparse L2 kernels (2-3x faster)
  → Avoid cosine similarity

If avg_batch_size < 5000:
  → Disable parallel processing (2-3x faster)
```

=== Step 3: Apply and Monitor

[source,yaml]
----
# Prometheus alerts
proximadb_clone_strategy_inefficient > 0.2
proximadb_aggregation_time_seconds{n="10000",k="10"} > 0.0005
proximadb_cosine_sparse_warnings > 100
proximadb_parallel_overhead_ratio > 2.0
----

=== Step 4: Validate Performance

[source,bash]
----
# Run before/after benchmark
cargo bench --bench bench_12_system_optimization

# Compare results
Before: 10,000 searches/sec
After:  150,000 searches/sec → 15x improvement ✓
----

== Normalization Calculator

Use these formulas to estimate performance on your hardware:

[source,rust]
----
// Clone performance (clock-dependent)
let normalized_clone_time = m4_time * (3.75 / target_ghz);

// Example: Intel Xeon @ 2.5 GHz
// Arc clone 97.29ns on M4 Pro
// = 97.29 × (3.75/2.5) = 145.9ns

// Memory bandwidth operations
let normalized_bandwidth_time = m4_time * (300.0 / target_bandwidth_gbps);

// Example: AMD Ryzen @ 60 GB/s
// Deep clone 6.91µs on M4 Pro
// = 6.91 × (300/60) = 34.55µs

// SIMD operations
let simd_factor = (128.0 / target_simd_width) * (3.75 / target_ghz);
let normalized_simd_time = m4_time * simd_factor;

// Example: Intel AVX512 @ 2.5 GHz
// L2 distance 133.22µs on M4 Pro
// = 133.22 × (128/512) × (3.75/2.5)
// = 133.22 × 0.25 × 1.5 = 49.96µs (2.67x faster)

// Parallel operations (core-count dependent)
let core_speedup = min(
    target_cores / 10.0,
    target_bandwidth / 300.0
);
let normalized_parallel = serial_time + (parallel_time / core_speedup);

// Example: AMD EPYC 64 cores @ 200 GB/s
// Speedup = min(64/10, 200/300) = min(6.4, 0.67) = 0.67 (BW limited)
----
