== Executive Summary

This report presents comprehensive benchmarking results for ProximaDB's progressive quantization-aware search system, which implements staged refinement using the formula `k_binary = k · n_b · n_int8 · n_pq`. The progressive search demonstrates **13.6x to 280x speedup** over brute force search, with sub-millisecond latencies for 100K vectors across all dimensions tested (128-1536).
