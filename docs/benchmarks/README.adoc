== Embedding Generator Architecture

=== Implementation Overview
ProximaDB benchmarks use statistically accurate embedding generators that simulate production models:

[source,rust]
----
// Located: benches/common/embedding_generator.rs
pub enum EmbeddingModel {
    Bert,        // Normal distribution, μ=0, σ=1.5
    OpenAIAda,   // Positive-skewed, mean ~0.3
    Normalized,  // Unit L2 norm
    RandomUniform // Legacy compatibility
}
----

=== Statistical Properties

[cols="3,2,2,2"]
|===
|Model |Distribution |Key Characteristics |Use Case

|**BERT (768D)**
|Normal (μ=0, σ=1.5)
|50% negative, correlations
|NLP, semantic search

|**OpenAI Ada (1536D)**
|Positive-skewed
|<20% negative, 5% boosted
|Text embeddings

|**Normalized**
|Gaussian + L2 norm
|Unit length vectors
|Cosine similarity

|**Sparse**
|Model + zero mask
|0-95% sparsity patterns
|Efficiency testing
|===

=== Generation Method
* **Box-Muller Transform**: Mathematically correct normal distribution
* **No External Dependencies**: Pure Rust implementation
* **Reproducible**: Consistent results across runs
* **Validated**: Statistical tests ensure accuracy

== Test Environment

* **Hardware**: Apple M4 Pro, 48GB RAM
* **Platform**: macOS ARM64
* **SIMD**: NEON (ARM), AVX2/AVX512 (x86)
* **Realistic Embedding Generators**:
  - **BERT Model** (768D): Normal distribution (μ=0, σ=1.5), range [-5, 5]
    * Mimics actual BERT embeddings with slight correlations
    * ~50% negative values, centered around 0
  - **OpenAI Ada** (1536D): Shifted positive distribution
    * Mostly positive values (>80%) with slight negative tail
    * Mean ~0.3, with ~5% high-magnitude components
    * Matches text-embedding-ada-002 characteristics
  - **Normalized**: Unit L2 norm embeddings
  - **Sparse Support**: 0% to 95% sparsity simulation
* **Dataset Sizes**: 1K to 100K vectors
* **Distance Metrics**: Euclidean, Cosine, DotProduct, Manhattan
