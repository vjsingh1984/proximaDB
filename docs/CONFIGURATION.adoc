== Configuration File

ProximaDB uses TOML format for configuration. Default location: `config/server.toml`

== Complete Configuration Reference

[source,toml]
----
# Server Configuration
[server]
rest_port = 5678                    # REST API port
grpc_port = 5679                    # gRPC API port
host = "0.0.0.0"                    # Bind address
max_connections = 10000              # Maximum concurrent connections
request_timeout_ms = 30000          # Request timeout in milliseconds
enable_tls = false                   # Enable TLS/SSL
tls_cert_path = "/path/to/cert.pem" # TLS certificate path
tls_key_path = "/path/to/key.pem"   # TLS private key path

# Storage Configuration
[storage]
data_dir = "/var/lib/proximadb/data"     # Data directory
wal_dir = "/var/lib/proximadb/wal"       # Write-ahead log directory
default_engine = "VIPER"                  # Default storage engine
max_file_size_mb = 1024                   # Maximum file size
compression = "zstd"                      # Compression algorithm
compression_level = 3                     # Compression level (1-9)
enable_mmap = true                        # Enable memory-mapped files
sync_writes = false                       # Sync writes to disk
flush_interval_ms = 1000                  # Flush interval

# Performance Configuration
[performance]
enable_simd = true                        # Enable SIMD acceleration
enable_gpu = true                         # Enable GPU acceleration
gpu_memory_fraction = 0.8                 # GPU memory to use (0.0-1.0)
num_search_threads = 0                    # Search threads (0 = auto)
num_index_threads = 0                     # Index threads (0 = auto)
vector_cache_size_mb = 1024               # Vector cache size
metadata_cache_size_mb = 512              # Metadata cache size
query_cache_size_mb = 256                 # Query result cache size
prefetch_size = 32                        # Prefetch size for sequential reads

# Memory Management
[memory]
max_memory_gb = 0                         # Max memory (0 = unlimited)
buffer_pool_size_mb = 512                 # Buffer pool size
enable_huge_pages = false                 # Enable huge pages
gc_interval_seconds = 300                 # Garbage collection interval

# Index Configuration
[index]
default_algorithm = "HNSW"                # Default index algorithm
auto_index = true                         # Auto-create indexes
index_threshold = 10000                   # Min vectors before indexing
background_index = true                   # Build indexes in background

# HNSW Specific Settings
[index.hnsw]
M = 16                                    # Number of connections
ef_construction = 200                     # Construction parameter
ef_search = 100                           # Default search parameter
max_M = 32                                # Maximum connections
seed = 42                                 # Random seed

# IVF Specific Settings
[index.ivf]
nlist = 100                               # Number of clusters
nprobe = 10                               # Clusters to search
train_size = 100000                       # Training set size

# LSH Specific Settings
[index.lsh]
num_tables = 8                            # Number of hash tables
hash_width = 4.0                          # Hash width parameter

# Quantization Configuration
[quantization]
enabled = false                           # Enable by default
type = "PQ"                              # Quantization type
auto_tune = true                         # Auto-tune parameters

[quantization.pq]
num_subvectors = 64                      # Number of subvectors
bits_per_code = 8                        # Bits per code
train_size = 100000                      # Training set size

# Monitoring Configuration
[monitoring]
enable_metrics = true                     # Enable metrics collection
metrics_port = 9090                       # Metrics endpoint port
enable_tracing = true                     # Enable distributed tracing
tracing_endpoint = "http://localhost:4317" # OpenTelemetry endpoint
log_level = "info"                       # Log level (trace/debug/info/warn/error)
log_format = "json"                      # Log format (json/text)
log_file = "/var/log/proximadb/server.log" # Log file path
max_log_size_mb = 100                    # Max log file size
max_log_files = 10                       # Max number of log files

# Security Configuration
[security]
enable_auth = false                      # Enable authentication
auth_type = "jwt"                        # Auth type (jwt/basic)
jwt_secret = "your-secret-key"           # JWT secret key
enable_rbac = false                      # Enable role-based access
enable_audit = false                      # Enable audit logging
audit_file = "/var/log/proximadb/audit.log" # Audit log path

# Replication Configuration (Future)
[replication]
mode = "none"                            # Replication mode (none/master/slave)
replica_count = 1                        # Number of replicas
sync_interval_ms = 1000                  # Sync interval
master_url = ""                          # Master node URL

# Cluster Configuration (Future)
[cluster]
enabled = false                          # Enable clustering
node_id = "node-1"                       # Node identifier
cluster_name = "proximadb-cluster"       # Cluster name
seed_nodes = ["node1:5679", "node2:5679"] # Seed nodes
gossip_port = 5680                       # Gossip protocol port
----

== Environment Variables

All configuration options can be overridden with environment variables:

[source,bash]
----
# Format: PROXIMADB_<SECTION>_<KEY>
export PROXIMADB_SERVER_REST_PORT=8080
export PROXIMADB_STORAGE_DATA_DIR=/data/proximadb
export PROXIMADB_PERFORMANCE_ENABLE_GPU=false
export PROXIMADB_MONITORING_LOG_LEVEL=debug
----

== Storage Engine Selection

Choose the right engine for your workload:

[source,toml]
----
[storage]
# For analytics and batch operations
default_engine = "VIPER"

# For high write throughput
default_engine = "SST"

# For graph-based similarity search
default_engine = "RAPTOR"

# For experimental features
default_engine = "NOVA"    # Zone maps
default_engine = "SWIFT"   # Adaptive blocks
default_engine = "PRISM"   # Progressive search
----

== Performance Profiles

=== High Throughput Profile

[source,toml]
----
[performance]
enable_simd = true
enable_gpu = true
num_search_threads = 16
vector_cache_size_mb = 4096
prefetch_size = 64

[storage]
enable_mmap = true
sync_writes = false
compression = "lz4"  # Fast compression
----

=== Low Latency Profile

[source,toml]
----
[performance]
enable_simd = true
vector_cache_size_mb = 8192
query_cache_size_mb = 1024
prefetch_size = 128

[storage]
enable_mmap = true
sync_writes = false

[index.hnsw]
ef_search = 200  # Higher for better accuracy
----

=== Memory Constrained Profile

[source,toml]
----
[memory]
max_memory_gb = 4
buffer_pool_size_mb = 256

[performance]
vector_cache_size_mb = 512
metadata_cache_size_mb = 256
query_cache_size_mb = 128

[quantization]
enabled = true
type = "PQ"
[quantization.pq]
bits_per_code = 4  # More compression
----

== Hardware-Specific Configuration

=== CPU-Only Systems

[source,toml]
----
[performance]
enable_gpu = false
enable_simd = true
num_search_threads = 0  # Use all cores
----

=== GPU-Accelerated Systems

[source,toml]
----
[performance]
enable_gpu = true
gpu_memory_fraction = 0.9
# Larger batches for GPU
prefetch_size = 256
----

=== ARM/NEON Systems

[source,toml]
----
[performance]
enable_simd = true  # Will use NEON
enable_gpu = false
----

== Collection-Specific Configuration

Configure individual collections via API:

[source,python]
----
client.create_collection(
    name="custom_collection",
    dimension=1536,
    config={
        "storage_engine": "VIPER",
        "compression": "zstd",
        "quantization": {
            "enabled": True,
            "type": "PQ",
            "bits": 8
        },
        "index": {
            "type": "HNSW",
            "M": 32,
            "ef_construction": 400
        },
        "cache": {
            "enabled": True,
            "size_mb": 512
        }
    }
)
----

== Docker Configuration

.Dockerfile environment variables
[source,dockerfile]
----
ENV PROXIMADB_SERVER_REST_PORT=5678
ENV PROXIMADB_STORAGE_DATA_DIR=/data
ENV PROXIMADB_PERFORMANCE_ENABLE_GPU=true
----

.docker-compose.yml
[source,yaml]
----
version: '3.8'
services:
  proximadb:
    image: proximadb/proximadb:latest
    ports:
      - "5678:5678"
      - "5679:5679"
    volumes:
      - ./config:/config
      - ./data:/data
    environment:
      - PROXIMADB_CONFIG=/config/server.toml
      - PROXIMADB_PERFORMANCE_ENABLE_GPU=false
----

== Kubernetes Configuration

[source,yaml]
----
apiVersion: v1
kind: ConfigMap
metadata:
  name: proximadb-config
data:
  server.toml: |
    [server]
    rest_port = 5678
    grpc_port = 5679
    
    [storage]
    data_dir = "/data"
    
    [performance]
    enable_simd = true
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: proximadb
spec:
  replicas: 3
  template:
    spec:
      containers:
      - name: proximadb
        image: proximadb/proximadb:latest
        volumeMounts:
        - name: config
          mountPath: /config
        - name: data
          mountPath: /data
      volumes:
      - name: config
        configMap:
          name: proximadb-config
----

== Validation

Validate configuration before starting:

[source,bash]
----
./proximadb-server --config config/server.toml --validate

# Output:
# ✓ Configuration valid
# ✓ Data directory accessible
# ✓ Ports available
# ✓ Memory requirements met
----

== Best Practices

. *Start with defaults* - ProximaDB has sensible defaults
. *Monitor and adjust* - Use metrics to guide configuration
. *Test changes* - Benchmark before and after changes
. *Version control* - Keep configurations in git
. *Document changes* - Note why each setting was changed
