== Progressive Search Optimization

This diagram illustrates the multi-stage progressive search pipeline, which intelligently narrows down search results from coarse to fine-grained matching, optimizing for both speed and accuracy.

[source,mermaid]
----
graph TD
    subgraph Progressive Search Pipeline
        A[Initial Candidates] --> B{Binary Filter (1-bit)}
        B -- Reduced Candidates --> C{INT8 Ranking (8-bit)}
        C -- Further Reduced Candidates --> D{PQ Scoring (4/8-bit)}
        D -- Top Candidates --> E[FP32 Reranking (Full Precision)]
        E --> F[Final Results]
    end
