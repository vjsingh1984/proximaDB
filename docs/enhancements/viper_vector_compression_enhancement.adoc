== Executive Summary

This document outlines a comprehensive enhancement for the VIPER storage engine to achieve 4-12x compression ratios on vector data while maintaining 99.9% accuracy. The proposal introduces median-normalized vector storage with adaptive central tendency selection, optimized for both compression and search performance.

=== Key Benefits

* **4-12x compression ratio** compared to raw FP32 storage
* **99.9% accuracy preservation** through proper denormalization
* **2-3x faster I/O operations** due to reduced data size
* **Adaptive optimization** based on data characteristics
* **Backward compatible** with existing VIPER infrastructure

== Problem Statement

Current VIPER engine stores vectors as FP32 arrays in Parquet files, achieving only 1.5-2x compression with ZSTD. This limits:

1. **Storage efficiency**: Large deployments require excessive disk space
2. **I/O performance**: More data to read/write impacts latency
3. **Memory usage**: Larger files mean less effective caching
4. **Network transfer**: Replication and backup costs increase

== Proposed Solution

=== Core Concept

Transform vectors before storage using central tendency normalization:

[source,rust]
----
// Transform: original_value = (stored_value * scale) + central_tendency
// This concentrates values around 0, improving compression

Store vectors in two columns:

1. **Original vectors**: `FLOAT[]` array with ZSTD compression

=== Detailed Implementation

==== Mean-Based Normalization (Fastest)

[source,rust]
----
// FASTEST: Single pass, SIMD-friendly
pub fn mean_normalize(vectors: &[Vec<f32>]) -> NormParams {
let sum: Vec<f32> = vectors.iter()
.fold(vec![0.0; dim], |mut acc, v| {
acc.iter_mut().zip(v.iter())
.for_each(|(a, &b)| *a += b);
acc
});
let mean = sum.iter().map(|&s| s / vectors.len() as f32).collect();

// Pros: O(n), cache-friendly, vectorizable
// Cons: Outliers skew normalization
}
----

==== Median-Based Normalization (Most Robust)

[source,rust]
----
// MOST ROBUST: But requires sorting
pub fn median_normalize(vectors: &[Vec<f32>]) -> NormParams {
let mut dim_values: Vec<Vec<f32>> = vec![vec![]; dim];

// Transpose for per-dimension processing
for v in vectors {
for (d, &val) in v.iter().enumerate() {
dim_values[d].push(val);
}
}

// Sort each dimension (expensive!)
let median: Vec<f32> = dim_values.iter_mut()
.map(|vals| {
vals.sort_by(|a, b| a.partial_cmp(b).unwrap());
vals[vals.len() / 2]
})
.collect();

// Pros: Outlier-robust, best compression
// Cons: O(n log n), memory intensive
}
----

==== Trimmed Mean (RECOMMENDED - Best Balance)

[source,rust]
----
// BEST BALANCE: Fast + Robust
pub fn trimmed_mean_normalize(vectors: &[Vec<f32>], trim_pct: f32) -> NormParams {
// Only sort once to find trim boundaries
let trim_count = (vectors.len() as f32 * trim_pct) as usize;

let mut dim_values: Vec<Vec<f32>> = transpose(vectors);

let trimmed_mean: Vec<f32> = dim_values.par_iter_mut()
.map(|vals| {
// Partial sort for efficiency
vals.select_nth_unstable(trim_count);
vals.select_nth_unstable(vals.len() - trim_count);

// Mean of middle values only
let sum: f32 = vals[trim_count..vals.len()-trim_count]
.iter().sum();
sum / (vals.len() - 2 * trim_count) as f32
})
.collect();

// Pros: O(n) after boundary selection, outlier-robust
// Cons: Slightly more complex than mean
}

=== Normalization Pipeline

[source,rust]

impl VectorNormalizer {
/// Normalize a batch of vectors around median with clamping
pub fn normalize_batch(&self, vectors: &[Vec<f32>]) -> NormalizedBatch {
let dim = vectors[0].len();
let mut stats = DimensionStats::new(dim);

// 1. Calculate per-dimension statistics
for vector in vectors {
for (d, &value) in vector.iter().enumerate() {
stats.update(d, value);
}
}

// 2. Compute normalization parameters
let params = stats.compute_normalization_params(
self.config.clamp_percentile // e.g., 99.5%
);

// 3. Transform vectors
let normalized = vectors.iter().map(|vec| {
vec.iter().enumerate().map(|(d, &val)| {
let normalized = (val - params.median[d]) / params.scale[d];
let clamped = normalized.clamp(-1.0, 1.0);
(clamped * 32767.0) as i16 // Convert to INT16
}).collect()
}).collect();

NormalizedBatch {
params,
vectors: normalized,
}
}
}

=== Automatic Method Selection

pub struct AdaptiveVectorNormalizer {

impl AdaptiveVectorNormalizer {
/// Automatically select best method based on data characteristics
pub fn auto_normalize(&self, vectors: &[Vec<f32>]) -> (NormalizedBatch, Method) {
// 1. Quick sample analysis (1% of data)
let sample_stats = self.analyze_sample(&vectors[..vectors.len()/100]);

// 2. Choose method based on distribution
let method = match sample_stats {
Stats { outlier_ratio } if outlier_ratio > 0.05 => {
// >5% outliers: Use trimmed mean
Method::TrimmedMean(0.05)
},
Stats { skewness } if skewness.abs() > 2.0 => {
// Highly skewed: Use median
Method::Median
},
Stats { kurtosis } if kurtosis > 10.0 => {
// Heavy-tailed: Use winsorized mean
Method::WinsorizedMean(0.02)
},
_ => {
// Normal-ish: Use mean (fastest)
Method::Mean
}
};

// 3. Apply selected method
let normalized = match method {
Method::Mean => self.mean_normalize(vectors),
Method::TrimmedMean(p) => self.trimmed_mean_normalize(vectors, p),
Method::Median => self.approximate_median_normalize(vectors),
Method::WinsorizedMean(p) => self.winsorized_mean_normalize(vectors, p),
};

(normalized, method)
}
}

== Technical Implementation Architecture

=== Core Normalization Pipeline

```rust
pub struct NormalizationPipeline {
    // Stage 1: Analysis
    analyzer: DistributionAnalyzer,
    
    // Stage 2: Transform
    transformer: VectorTransformer,
    
    // Stage 3: Quantization
    quantizer: AdaptiveQuantizer,
    
    // Stage 4: Storage
    storage_writer: CompressedWriter,
}

impl NormalizationPipeline {
    pub fn process_batch(&mut self, vectors: &[Vec<f32>]) -> CompressedBatch {
        // Analyze distribution characteristics
        let stats = self.analyzer.analyze(vectors);
        
        // Select optimal transform
        let transform = self.select_transform(&stats);
        
        // Apply normalization
        let normalized = self.transformer.apply(vectors, &transform);
        
        // Quantize based on precision requirements
        let quantized = self.quantizer.quantize(normalized, &stats);
        
        // Write with optimal compression
        self.storage_writer.write(quantized)
    }
}
```

=== SIMD-Optimized Operations

```rust
pub struct SimdNormalizer {
    // AVX-512 for 16 floats at once
    avx512_enabled: bool,
    
    // Fallback to AVX2 (8 floats)
    avx2_enabled: bool,
}

impl SimdNormalizer {
    #[target_feature(enable = "avx512f")]
    unsafe fn normalize_avx512(
        &self,
        vectors: &mut [f32],
        central: f32,
        scale: f32,
    ) {
        let central_vec = _mm512_set1_ps(central);
        let scale_vec = _mm512_set1_ps(scale);
        
        for chunk in vectors.chunks_exact_mut(16) {
            let v = _mm512_loadu_ps(chunk.as_ptr());
            let normalized = _mm512_mul_ps(
                _mm512_sub_ps(v, central_vec),
                scale_vec
            );
            _mm512_storeu_ps(chunk.as_mut_ptr(), normalized);
        }
    }
}
```
