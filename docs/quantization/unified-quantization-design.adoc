== Executive Summary

ProximaDB's unified quantization architecture provides a single, collection-driven quantization system that automatically optimizes vector storage and search across all components. The system achieves 50-80% storage savings and 95% I/O reduction through progressive multi-level quantization.

== Implementation Architecture

=== Storage Quantization Engine

[source,rust]
----
// Core implementation: /src/compute/quantization/storage_engine.rs
pub struct StorageQuantizationEngine {
    dimension: usize,
    config: Arc<StorageQuantizationConfig>,
    quantizers: DashMap<UnifiedQuantizationLevel, Arc<dyn VectorQuantizer>>,
    distance_calculator: Arc<dyn UnifiedDistanceCompute>,
    hardware: Arc<HardwareCapabilities>,
}

impl StorageQuantizationEngine {
    /// Quantize vectors based on collection config
    pub fn quantize_batch(
        &self,
        vectors: &[Vec<f32>],
        levels: &[UnifiedQuantizationLevel],
    ) -> Result<QuantizationResult> {
        // Multi-level quantization for progressive search
        let mut results = HashMap::new();
        
        for level in levels {
            match level {
                Binary => self.quantize_binary(vectors),
                INT8 => self.quantize_int8(vectors),
                PQ(config) => self.quantize_pq(vectors, config),
                _ => self.quantize_default(vectors),
            }
        }
        
        Ok(QuantizationResult { 
            levels: results,
            metadata: self.compute_metadata(),
        })
    }
}

=== SST Adapter Implementation

[source,rust]
----
// /src/storage/quantization/sst_adapter.rs
pub struct SstQuantizationAdapter {
    engine: Arc<StorageQuantizationEngine>,
}

impl SstQuantizationAdapter {
    /// Integrate with SST's DataBlock structure
    pub fn quantize_for_datablock(
        &self,
        records: &[VectorRecord],
        block_config: &DataBlockConfig,
    ) -> Result<QuantizedDataBlock> {
        // Extract vectors
        let vectors = records.iter()
            .map(|r| r.vector.clone())
            .collect();
        
        // Apply quantization based on collection config
        let quantized = self.engine.quantize_batch(
            &vectors,
            &block_config.quantization_levels,
        )?;
        
        // Pack into SST-specific format
        Ok(QuantizedDataBlock {
            original_records: records.to_vec(),
            binary_section: quantized.get_binary()?,
            int8_section: quantized.get_int8()?,
            pq_section: quantized.get_pq()?,
            metadata: quantized.metadata,
        })
    }
}

=== PQ Distance Computation

[source,rust]
----
pub struct PQQuantizer {
    subvectors: usize,      // m (typically 8-64)
    bits_per_subvector: u8, // Usually 8 (256 centroids)
    codebooks: Vec<Codebook>,
    distance_tables: Arc<RwLock<DistanceTableCache>>,
}

impl PQQuantizer {
    /// Precompute distance table for query (O(m*k) time)
    pub fn precompute_distances(&self, query: &[f32]) -> DistanceTable {
        let mut table = vec![vec![0.0; 256]; self.subvectors];
        
        for (m, codebook) in self.codebooks.iter().enumerate() {
            let query_subvec = &query[m * self.subvec_dim..(m + 1) * self.subvec_dim];
            
            for (k, centroid) in codebook.centroids.iter().enumerate() {
                // Compute distance once per centroid
                table[m][k] = self.compute_distance(query_subvec, centroid);
            }
        }
        
        DistanceTable(table)
    }
    
    /// Fast distance lookup using precomputed table (O(m) time)
    pub fn lookup_distance(&self, pq_code: &[u8], table: &DistanceTable) -> f32 {
        pq_code.iter()
            .enumerate()
            .map(|(m, &idx)| table.0[m][idx as usize])
            .sum()
    }
}

== Integration Points

=== With Storage Engines

[source,mermaid]
----
sequenceDiagram
    participant C as Collection
    participant Q as QuantizationEngine
    participant A as StorageAdapter
    participant S as Storage (SST/VIPER)
    
    C->>Q: Get quantization config
    Q->>Q: Parse levels & strategy
    
    Note over S: During flush/compaction
    S->>A: Request quantization
    A->>Q: Quantize batch
    Q->>Q: Apply multi-level quantization
    Q-->>A: Return quantized data
    A->>S: Pack into storage format
    S->>S: Write to disk
----

=== With Search Pipeline

[source,mermaid]
----
sequenceDiagram
    participant U as User Query
    participant P as ProgressiveSearch
    participant Q as QuantizationEngine
    participant S as Storage
    
    U->>P: Search request
    P->>Q: Quantize query vector
    Q-->>P: Multi-level query
    
    loop Progressive Stages
        P->>S: Fetch quantized level
        S-->>P: Return candidates
        P->>P: Filter by distance
    end
    
    P->>S: Fetch FP32 for final candidates
    S-->>P: Return full vectors
    P->>P: Final reranking
    P-->>U: Return results
----
