== License Tiers and Features

=== Free Tier (30-Day Trial)

**Trial experience with core capabilities**:
- **Duration**: 30 days with 7-day grace period
- **Usage Limits**: 10 collections, 100K vectors, 1000 API calls/day, 50 AI queries/day
- **Features**: Basic vector search, natural language queries, single tenant
- **Support**: Community forum support
- **Privacy**: Complete offline validation, no phone home required

=== Professional Tier ($299/month)

**Advanced capabilities for growing businesses**:
- **Usage Limits**: 1000 collections, 100M vectors, 100K API calls/day, 10K AI queries/day
- **AI Features**: Executive dashboards, advanced AI capabilities, 3 LLM providers
- **Multi-Tenant**: Up to 10 tenants with enhanced isolation
- **Security**: SSO integration, audit logging, SOC 2 compliance
- **Support**: Email support with SLA

=== Enterprise Tier (Custom Pricing)

**Unlimited enterprise capabilities**:
- **Usage**: Unlimited collections, vectors, API calls, AI queries
- **AI Features**: All 9 LLM providers, custom AI development, advanced business intelligence
- **Multi-Tenant**: Unlimited tenants with complete isolation and custom configuration
- **Security**: All compliance frameworks, advanced encryption, security monitoring
- **Support**: Dedicated customer success manager, 24/7 support, SLA guarantees

== Privacy-Conscious Deployment Support

**Complete offline operation** for maximum privacy:

== License Management APIs

=== Customer License APIs

**Self-service license management**:
- **GET /license/status**: Current license status and usage information
- **GET /license/usage**: Usage analytics and limit tracking
- **POST /license/upgrade**: License upgrade request and payment processing
- **GET /license/features**: Available features and entitlements

=== Admin License APIs

**Administrative license management**:
- **POST /admin/licenses**: Create new customer license
- **PUT /admin/licenses/:id**: Update license terms or entitlements
- **GET /admin/licenses/analytics**: License usage analytics across customers
- **POST /admin/licenses/validate**: Validate customer license tokens
