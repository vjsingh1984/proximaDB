== API Endpoints

=== Customer-Facing APIs

**Self-service trial management**:
- **POST /sales/trials**: Create new enterprise trial with automated provisioning
- **GET /sales/trials/:id**: Trial status, progress, and usage analytics
- **POST /sales/trials/:id/extend**: Trial extension with approval workflow
- **POST /sales/demos/ai-showcase**: Execute AI capability demonstrations

=== Sales Team APIs

**Sales acceleration endpoints**:
- **GET /sales/analytics/pipeline**: Sales pipeline insights and conversion tracking
- **GET /sales/competitive-analysis**: Real-time competitive positioning data
- **POST /sales/outreach/trigger**: Manual sales outreach trigger for specific trials
