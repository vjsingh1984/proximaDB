== Core API Services

=== REST API Endpoints

**Comprehensive RESTful interface** for enterprise applications:
- **Collection Management**: Create, update, delete, and query vector collections
- **Vector Operations**: Insert, search, and manage vector data with metadata
- **AI Intelligence**: Natural language querying and business intelligence generation
- **Administration**: Tenant management, user administration, and system configuration

=== gRPC High-Performance API

**Binary protocol efficiency** for high-throughput applications:
- **Low Latency**: Optimized binary protocol for performance-critical applications
- **Streaming Support**: Real-time data streaming and bulk operations
- **Type Safety**: Strongly-typed interfaces with protocol buffer definitions
- **Scalability**: High-performance RPC for enterprise-scale applications

=== AI-Powered Endpoints

**Natural language and business intelligence APIs**:
- **Natural Language Query**: `/api/v1/ai/natural-language/query`
- **Executive Dashboard**: `/api/v1/ai/executive-dashboard`
- **Business Insights**: `/api/v1/ai/business-insights`
- **Provider Management**: `/api/v1/ai/providers/status`
