== Production Engines (100% Complete)

=== SST Engine
**Location**: `/src/storage/engines/impls/sst/`

**Key Implementation Facts**:
* **47,406 lines** of production code
* **No embedded MemTable** - pure SSTable storage
* **Zero-copy compaction** with 80% memory reduction
* **Three-stage filtering**: Bloom → Quantized → Full precision
* **EventLog integration** for async AXIS indexing
* **14 compression algorithms** via unified module
* **Hardware acceleration** with automatic SIMD detection

**Core Components**:
```rust
SstStorage {
    compaction_manager: Arc<Compaction>,
    sstable_reader: Arc<UnifiedSstableReader>,
    decompression_cache: Arc<DecompressionCache>,
    quantization_engine: Arc<UnifiedQuantizationEngine>,
    universal_optimizer: UniversalPerformanceOptimizer,
}
```

=== VIPER Engine
**Location**: `/src/storage/engines/impls/viper/`

**Key Implementation Facts**:
* **13,604 lines** of production code
* **Shared columnar infrastructure** instead of direct Parquet
* **Progressive search pipeline**: 7-phase optimization
* **Predicate pushdown**: 60-90% I/O reduction
* **EventLog integration** with ~600 line queue system
* **BinaryArray serialization** with bytemuck for zero-copy
* **Footer cache**: 70-90% cloud API reduction

**Core Files**:
* `engine.rs` - 2,117 lines (main engine)
* `pipeline.rs` - 3,538 lines (data processing)
* `flush.rs` - 1,608 lines (Parquet operations)
* `compaction.rs` - 1,954 lines (file compaction)

== Architecture Evolution

=== Key Design Decisions

1. **Proto-First**: VectorRecord flows natively without conversions
2. **No Embedded MemTables**: SST/HELIX use external WAL
3. **Shared Infrastructure**: Moved from engine-specific to unified modules
4. **EventLog Integration**: Async indexing with queue-aware compaction
5. **Hardware Acceleration**: Automatic SIMD/GPU detection and usage

=== Migration from Standalone to Shared

Several components have migrated from engine-specific to shared:
* ML Clustering: Moved from VIPER to AXIS service
* Quantization: Unified compute module instead of per-engine
* Search: IntegratedSearchOptimizer from core
* Schema: Shared ColumnarSchema for consistency
