== Quick Start Commands

=== Docker (Fastest)
[source,bash]
----
# Pull and run ProximaDB
docker run -d \
  --name proximadb \
  -p 5678:5678 -p 5679:5679 \
  -v proximadb_data:/data \
  proximadb/proximadb:latest

# Verify it's running
curl http://localhost:5678/health
----

=== From Source
[source,bash]
----
# Clone and build
git clone https://github.com/proximadb/proximadb
cd proximadb
cargo build --release

# Run server
./target/release/proximadb-server

# Verify
curl http://localhost:5678/health
----

=== Python Client
[source,bash]
----
# Install client
pip install proximadb

# Test connection
python -c "from proximadb import ProximaDBClient; \
           client = ProximaDBClient('http://localhost:5678'); \
           print(client.health())"
----

== Common Issues

=== Port Already in Use
If ports 5678 or 5679 are occupied:
[source,bash]
----
# Change ports in config
PROXIMADB_REST_PORT=6678 \
PROXIMADB_GRPC_PORT=6679 \
./target/release/proximadb-server
----

=== Permission Denied (Docker)
[source,bash]
----
# Add your user to docker group
sudo usermod -aG docker $USER
# Log out and back in
----

=== Out of Memory
Adjust memory limits:
[source,toml]
----
# config.toml
[memory]
memtable_size = "1GB"  # Reduce from default 2GB
cache_size = "512MB"    # Reduce from default 1GB
----
