 = Graph Engine Selection
 :toc:

== Purpose
Choose the graph engine (ORION/PULSAR/QUASAR) per deployment or per collection.

== Config (Global)

[source,toml]
----
[graph]
engine = "orion"   # or "pulsar" | "quasar"
----

Note: Use ORION for in‑memory speed; PULSAR/QUASAR for larger graphs (single‑process MVP). Future builds will support per‑collection overrides.

== SQL/Hybrid Behavior
- Engine selection is transparent to SQL; traversal and hybrid flows route through GraphService which delegates to the configured engine.

== Observability
- Metrics should include: traversal latency by engine, nodes visited, cache hit rates.
