----
@startuml
start
:Fork Repository;
:Clone Locally;
:Create Feature Branch;
:Write Code;
:Add Tests;
:Run Tests Locally;
if (Tests Pass?) then (yes)
  :Commit Changes;
  :Push to Fork;
  :Create Pull Request;
  if (CI Passes?) then (yes)
    :Code Review;
    if (Approved?) then (yes)
      :Merge to Main;
      stop
    else (no)
      :Address Feedback;
    endif
  else (no)
    :Fix CI Issues;
  endif
else (no)
  :Fix Tests;
endif
@enduml
----

= Agent Guide: Implementing SKS + Hybrid Query
:toc:

== Purpose
Concrete steps for coding agents to implement Semantic Knowledge Store (SKS) and federated Hybrid Query in a modular, testable way.

== Prerequisites
- Build: `make build` or `make build-server`
- Tests: `make test`
- Style: `make fmt && make clippy`

== Tasks (Ordered)
1) Hybrid Orchestrator (Federated)
   - Files: `src/query/execution/{planner.rs,executor.rs,mod.rs}`
   - Actions: Parallel VectorSearch + GraphTraversal; seed handoff both ways; Fusion (RRF) with weights; pagination/streaming; EXPLAIN.
2) SQL Frontend Wiring
   - Files: `src/query/sql_frontend/{parser.rs,lowering.rs}`
   - Actions: Ensure SIMILAR/FOLLOW lower to ExecutionOperation; add tests in `sql_frontend/tests.rs`.
3) SKS v1 Storage Coupling
   - Files: `src/storage/entity_store.rs`
   - Actions: Implement persistence for headers/embeddings; add `CsrRelationsStore`; add `InMemoryProvenanceRegistry`.
4) API Exposure
   - Files: `src/api_handlers/unified_handlers.rs`, `src/network/rest/v1/entities.rs`, `src/network/grpc/entity_service.rs`
   - Actions: Expose pagination/streaming; add SKS routes as needed.

== Design Patterns
- Interfaces first: Traits (`EntityStore`, `RelationsStore`) with minimal stable methods
- Zero-copy: Share headers via Arc; avoid cloning large vectors in hot paths
- Fusion strategy pattern: Enum + pluggable scoring functions
- Backpressure: Stream fused rows with bounded buffers
- Seeding strategy: Control graph→vector seeding via SQL hints or REST field (AVERAGE | PER_SEED | NONE)

== Tests
- Unit: fusion, CSR adjacency, keying
- Integration: SIMILAR→FOLLOW and FOLLOW→SIMILAR pipelines; pagination stability
- Bench: Compare federated vs SKS on sample datasets
- Deep traversal (feature `deep_traversal_tests`): BFS up to `max_depth` for richer coverage

== Feature Flags
- `sql_frontend` (default on): use new frontend path
- `sks_coupled` (future): route hybrid to SKS when available; fallback to federated

== Environment Setup

=== Clone Repository

[source,bash]
----
# Clone the repository
git clone https://github.com/proximadb/proximadb
cd proximadb

# Add upstream remote
git remote add upstream https://github.com/proximadb/proximadb.git
git fetch upstream
----

=== Rust Setup

[source,bash]
----
# Install Rust stable
rustup default stable
rustup update

# Install nightly for benchmarks
rustup install nightly

# Add required components
rustup component add rustfmt
rustup component add clippy
rustup component add rust-src

# Install cargo extensions
cargo install cargo-watch
cargo install cargo-expand
cargo install flamegraph
cargo install cargo-audit
cargo install cargo-outdated
----

== Git Configuration

=== Git Hooks

[source,bash]
----
#!/bin/bash
# .git/hooks/pre-commit

# Format code
cargo fmt --all -- --check
if [ $? -ne 0 ]; then
    echo "Please run 'cargo fmt --all' before committing"
    exit 1
}

# Run clippy
cargo clippy --all-targets --all-features -- -D warnings
if [ $? -ne 0 ]; then
    echo "Please fix clippy warnings before committing"
    exit 1
}

# Run tests
cargo test --lib --bins
if [ $? -ne 0 ]; then
    echo "Tests failed. Please fix before committing"
    exit 1
}
----

== Troubleshooting

=== Common Issues

[cols="2,3", options="header"]
|===
| Issue | Solution

| Protobuf compilation errors
| Ensure `protoc` is in PATH and version 3.20+

| SIMD compilation errors
| Add `RUSTFLAGS=\"-C target-cpu=native\"`

| Linking errors
| Install `pkg-config` and development libraries

| Out of memory during compilation
| Reduce parallel jobs: `cargo build -j 2`

| Slow compilation
| Use `sccache` or `cargo-chef` for caching
|===
