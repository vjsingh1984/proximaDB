== Executive Summary

ProximaDB is engineered for **exceptional performance and efficiency** in vector search. Our innovative architecture and hardware-aware optimizations enable high throughput and low latency across diverse workloads and vector dimensions.

== Performance Overview

ProximaDB is designed to deliver **high throughput** for distance computations and **low latency** for search queries across a wide range of vector dimensions and metrics. Our system performance is characterized by efficient vector operations, optimized indexing, robust memory management, and rapid hardware detection.

Our architecture ensures that operations are performed with **minimal overhead**, leveraging underlying hardware capabilities for maximum efficiency.

== Overview

This guide covers various deployment options for ProximaDB, from single-node installations to distributed clusters.

== Deployment Options

=== Single Node Deployment

==== Binary Installation

[source,bash]
----
# Download latest release
wget https://github.com/proximadb/releases/latest/proximadb-server
chmod +x proximadb-server

# Create configuration
cat > config.toml <<EOF
[server]
rest_port = 5678
grpc_port = 5679

[storage]
data_dir = "/var/lib/proximadb/data"
default_engine = "VIPER"

[performance]
enable_simd = true
enable_gpu = false
EOF

# Start server
./proximadb-server --config config.toml
----

==== Systemd Service

[source,ini]
----
# /etc/systemd/system/proximadb.service
[Unit]
Description=ProximaDB Vector Database
After=network.target

[Service]
Type=simple
User=proximadb
Group=proximadb
ExecStart=/usr/local/bin/proximadb-server --config /etc/proximadb/config.toml
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal
LimitNOFILE=65536

[Install]
WantedBy=multi-user.target
----

=== Kubernetes Deployment

==== Basic Deployment

[source,yaml]
----
# proximadb-deployment.yaml
apiversion: apps/v1
kind: Deployment
metadata:
  name: proximadb
  namespace: proximadb
spec:
  replicas: 3
  selector:
    matchLabels:
      app: proximadb

      labels:
        app: proximadb
    spec:
      containers:

        - containerPort: 5678

        - containerPort: 5679
          name: grpc
        - containerPort: 9090
          name: metrics

          value: "/data"
        volumeMounts:
        - name: data
          mountPath: /data
        - name: config
          mountPath: /config
        resources:
          requests:
            memory: "4Gi"
            cpu: "2"
          limits:
            memory: "8Gi"
            cpu: "4"
        livenessProbe:
          httpGet:
            path: /health
            port: 5678
          initialDelaySeconds: 30
          periodSeconds: 10
        readinessProbe:
          httpGet:
            path: /ready
            port: 5678
          initialDelaySeconds: 10
          periodSeconds: 5
      volumes:
      - name: data
        persistentVolumeClaim:
          claimName: proximadb-data-pvc
      - name: config
        configMap:
          name: proximadb-config
----

== Network Configuration

=== Load Balancing

==== HAProxy Configuration

[source,conf]
----
# /etc/haproxy/haproxy.cfg
global
    maxconn 4096
    
defaults
    mode tcp
    timeout connect 5s
    timeout client 30s
    timeout server 30s

frontend proximadb_rest
    bind *:5678
    default_backend proximadb_rest_nodes

backend proximadb_rest_nodes
    balance roundrobin
    server node1 10.0.1.10:5678 check
    server node2 10.0.1.11:5678 check
    server node3 10.0.1.12:5678 check

frontend proximadb_grpc
    bind *:5679
    default_backend proximadb_grpc_nodes

backend proximadb_grpc_nodes
    balance leastconn
    server node1 10.0.1.10:5679 check
    server node2 10.0.1.11:5679 check
    server node3 10.0.1.12:5679 check
----

==== NGINX Configuration

[source,nginx]

# /etc/nginx/nginx.conf

upstream proximadb_grpc {

server {

    }
}

server {

    location / {
        grpc_pass grpc://proximadb_grpc;
    }
}
----

== Storage Configuration

=== Local Storage

[source,bash]
----
# Prepare local storage
sudo mkdir -p /var/lib/proximadb/data
sudo chown -R proximadb:proximadb /var/lib/proximadb

# Mount dedicated disk
sudo mkfs.ext4 /dev/nvme1n1
sudo mount /dev/nvme1n1 /var/lib/proximadb/data
echo "/dev/nvme1n1 /var/lib/proximadb/data ext4 defaults 0 0" | sudo tee -a /etc/fstab
----

== Security Hardening

=== TLS Configuration

[source,bash]
----
# Generate certificates
openssl req -x509 -newkey rsa:4096 \
  -keyout server.key \
  -out server.crt \
  -days 365 \
  -nodes \
  -subj "/CN=proximadb.example.com"

# Configure TLS in config.toml
cat >> config.toml <<EOF
[server]
enable_tls = true
tls_cert_path = "/certs/server.crt"
tls_key_path = "/certs/server.key"
EOF
----
