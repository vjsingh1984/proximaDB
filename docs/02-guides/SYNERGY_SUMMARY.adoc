## Low-Effort, High-Impact Demos

### Demo 1: Market Regime Detection (2 hours)

**Scenario**: "What happened last time the market was like this?"

```bash
# ibkrtrading detects market conditions
[INFO] Current market: VIX=18.5, 10Y2Y=0.35, ATR=2.3
[INFO] Found similar period: 2020-03-15 (COVID crash)
[INFO]   Similarity: 94%
[INFO]   Historical outcome: -12% over 2 weeks
[INFO] Recommendation: Reduce position by 20%
```

**Implementation**:
- Extract 8 features from market data
- Store as vectors in ProximaDB
- Search for similar historical periods
- Display outcomes

### Demo 2: Correlation Risk Analysis (4 hours)

**Scenario**: "Are my holdings too correlated?"

```bash
# Graph traversal finds correlated stocks
[INFO] Portfolio concentration risk detected
[INFO]   Cluster: AAPL, MSFT, GOOGL, NVDA, META
[INFO]   Average correlation: 0.85
[INFO]   Total exposure: $250,000
[INFO]   Risk: HIGH - consider reducing tech exposure
```

**Implementation**:
- Build correlation graph from historical data
- Find connected components
- Calculate cluster exposure
- Alert on high concentration

### Demo 3: Multi-Model Query (6 hours)

**Scenario**: "What strategies work best in this market?"

```sql
-- Single SQL query across vectors, relational, and time-series
SELECT s.strategy_name, s.avg_return, m.regime_timestamp, m.similarity_score
FROM strategy_performance s
JOIN LATERAL VECTOR_SEARCH('market_regimes', '[current_features]', 10) m
WHERE s.trades > 50
ORDER BY s.avg_return DESC
LIMIT 5;
```

**Result**:
```
+------------------+-------------+------------------+------------------+
| strategy_name    | avg_return  | regime_timestamp  | similarity_score |
+------------------+-------------+------------------+------------------+
| MeanReversion    | +12.5%      | 2023-10-01       | 0.92             |
| Momentum         | +8.3%       | 2022-06-10       | 0.89             |
| VolBreakout      | +6.1%       | 2020-03-15       | 0.87             |
+------------------+-------------+------------------+------------------+
```

### Demo 4: Victor AI Agents (Full Day)

**Scenario**: "AI analyzes stock and recommends trade"

1. ibkrtrading detects market event (volume spike)

## Quick Start Commands

### For ProximaDB

```bash
# Clone and build
git clone https://github.com/vjsingh1984/proximadb
cd proximaDB
cargo build --release

# Start server
./target/release/proximadb-server --config config/config.toml

# Test metrics endpoint
curl http://localhost:5678/metrics
```

### For Victor

```bash
# Clone and build
git clone https://github.com/[victor-repo]
cd victor
cargo build --release

# Start agents
./target/release/victor-server \
    --proximadb-url http://localhost:5678 \
    --agent-mode analysis

# Analyze a stock
curl "http://localhost:8081/api/analyze?symbol=AAPL"
```

### For ibkrtrading

```bash
# Clone develop branch
git clone https://github.com/[ibkr-repo]
cd ibkrtrading
git checkout develop

# Add ProximaDB
cargo add proximadb --features embedded

# Run with regime detection
cargo run --features proximadb --bin trading-server \
    --enable-regime-detection \
    --enable-correlation-graph
```

## Configuration Examples

### ProximaDB (`config/config.toml`)

```toml
[observability.metrics_export]
enabled = true
endpoint = "/metrics"

[observability.ingestion.otlp]
enabled = true
grpc_port = 4317
http_port = 4318
```

### ibkrtrading (`config/trading.toml`)

```toml
[proximadb]
enabled = true
data_dir = "data/proximadb"

[proximadb.regimes]
enabled = true
collection = "market_regimes"
dimension = 8
update_interval_seconds = 3600

[proximadb.correlations]
enabled = true
graph = "market_correlations"
update_interval_seconds = 86400
correlation_threshold = 0.7
```
