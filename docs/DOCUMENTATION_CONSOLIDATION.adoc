== Documentation Standards

=== Format Requirements (from CLAUDE.md)

1. **AsciiDoc Only** - All docs must be `.adoc`, not Markdown
2. **Mermaid Diagrams** - Use `[source,mermaid]` blocks with neutral theme
3. **Theme Compatibility** - Diagrams must work in light and dark mode
4. **Professional Icons** - Use geometric shapes, avoid casual emojis
5. **Consistent Structure** - TOC, heading hierarchy, code highlighting

=== Mermaid Theme Standards

[source,asciidoc]
----
[source,mermaid]
----
%%{init: {"theme": "neutral"}}%%
graph TB
    A[Component] --> B[Component]

    style A fill:#4a90e2,stroke:#2e5c8a,stroke-width:2px,color:#000
    style B fill:#5ba3f5,stroke:#3d7ab8,stroke-width:2px,color:#000
----
----

**Color Palette**:

* Primary: `#4a90e2` (ProximaDB Blue)
* Secondary: `#5ba3f5`, `#7db8f7`
* Accent: `#2e5c8a`, `#3d7ab8`
* Text: `#000000` (on colored fills)
* Borders: Medium tones for theme compatibility
