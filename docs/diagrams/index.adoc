=== Design Principles

. **Clarity**: Each diagram focuses on one aspect to avoid information overload
. **Hierarchy**: Clear visual hierarchy with headers, sections, and connections
. **Consistency**: Uniform color scheme and styling across all diagrams
. **Accessibility**: High contrast colors and clear text for readability
. **Navigation**: Interconnected diagrams with clear relationships

== Maintenance Guidelines

=== Adding New Diagrams
. Create `.mmd` file with consistent theme header
. Follow naming convention: `category-purpose.mmd`
. Generate SVG with appropriate dimensions
. Update this index with diagram information

=== Updating Existing Diagrams
. Modify the `.mmd` source file
. Regenerate SVG using mermaid-cli
. Verify rendering in both light and dark modes
. Update documentation if structure changes

=== Best Practices
* Keep diagrams focused on single concepts
* Use consistent color coding across related diagrams
* Maintain visual hierarchy with clear sections
* Test readability at different zoom levels
* Include descriptive titles and labels
