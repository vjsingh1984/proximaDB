== Generating SVG Files

To regenerate SVG files from Mermaid sources:

```bash
# Install Mermaid CLI
npm install -g @mermaid-js/mermaid-cli

# Generate single diagram
mmdc -i diagram.mmd -o images/diagram.svg -t neutral -b transparent

# Generate all diagrams
for mmd in *.mmd; do
    mmdc -i "$mmd" -o "images/${mmd%.mmd}.svg" -t neutral -b transparent
done
```

== Diagram Standards

### Color Scheme
We use neutral colors that work well in both light and dark themes:

* **Client Layer**: `#f0f4f8` (light blue-gray)
* **Service Layer**: `#f9fafb` (light gray)
* **Storage Layer**: `#fef3c7` (light amber)
* **Cache Layer**: `#ede9fe` (light purple)
* **Compression**: `#e0e7ff` (light indigo)

### Best Practices
1. Use descriptive node labels
2. Include relevant metrics/numbers where applicable
3. Keep diagrams focused on single concepts
4. Provide both MMD source and SVG output
5. Use consistent styling across all diagrams

== Usage in Documentation

To include a diagram in ADOC documentation:

```asciidoc
image::diagram-name.svg[Description, align=center, width=800]
_link:../diagrams/diagram-name.mmd[View source diagram]_
```

Note: Adjust the path based on the location of your ADOC file relative to the diagrams directory.
