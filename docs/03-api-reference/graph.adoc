= Graph API Reference
:toc: left
:toclevels: 2
:icons: font

[.lead]
Graph API for nodes, edges, and traversal. Current REST graph routes are v1
compatibility facades under `/api/v1/graph`; they remain available for existing
clients while graph durability converges on canonical `ProximaRecord` and shared
query surfaces.

== Status Notes

* ORION engine is the default (in‑memory CSR).
* Graph metadata persistence and schema updates are in progress.
* REST `/api/v1/graph/*` responses emit deprecation metadata. New cross-model
  query work should prefer SQL/pgwire and record-backed graph projections.

== Quick Reference

|===
| Operation | Method | Endpoint

| Create graph | POST | `/graphs`
| List graphs | GET | `/graphs`
| Create node | POST | `/graphs/:id/nodes`
| Create edge | POST | `/graphs/:id/edges`
| Traverse | POST | `/graphs/:id/traverse`
| Agentic walk (BFS bounded) | POST | `/graphs/:id/walk`
| Agentic single-step | POST | `/graphs/:id/step`
|===

NOTE: `/walk` and `/step` are agentic GraphWalk primitives (TD-046,
arXiv:2604.01610). `/walk` returns up to `limit` nodes within `max_depth`
hops in one call; `/step` returns the immediate neighbors of a single node
so the agent can drive traversal step by step. Choose `/step` when the
graph is too large to materialize subgraphs in the agent's context window.

== Legacy Endpoint Deprecation And Migration

Legacy compatibility endpoints are deprecated and redirect to explicit multi-graph routes inside the v1 compatibility namespace.

* Effective deprecation: March 2, 2026
* Redirect behavior: `308 Permanent Redirect`
* Sunset: `Sunset: 2026-06-30`
* Canonical route hint header: `X-ProximaDB-Canonical-Route`

|===
| Legacy Route | Canonical Route

| `/api/v1/graph/nodes`
| `/api/v1/graph/graphs/default/nodes`

| `/api/v1/graph/edges`
| `/api/v1/graph/graphs/default/edges`

| `/api/v1/graph/nodes/:id`
| `/api/v1/graph/graphs/default/nodes/:id`

| `/api/v1/graph/stats`
| `/api/v1/graph/graphs/default/stats`
|===

Example redirect response for a legacy route:

[source,bash]
----
curl -i -X POST http://localhost:5678/api/v1/graph/nodes

# HTTP/1.1 308 Permanent Redirect
# Location: /api/v1/graph/graphs/default/nodes
# Deprecation: true
# Sunset: 2026-06-30
# X-ProximaDB-Canonical-Route: /api/v1/graph/graphs/default/nodes
----

Direct multi-graph compatibility request (preferred when using the v1 graph facade):

[source,bash]
----
curl -X POST http://localhost:5678/api/v1/graph/graphs/default/nodes \
  -H "Content-Type: application/json" \
  -d '{
    "node": {
      "id": "node-1",
      "labels": ["Entity"],
      "properties": {"name": "example"}
    }
  }'
----

== Create Graph

[source,bash]
----
curl -X POST http://localhost:5678/api/v1/graph/graphs \
  -H "Content-Type: application/json" \
  -d '{"graph_id": "topology"}'
----

---

== Create Node

[source,bash]
----
curl -X POST http://localhost:5678/api/v1/graph/graphs/topology/nodes \
  -H "Content-Type: application/json" \
  -d '{
    "node": {
      "id": "service-api",
      "labels": ["Service"],
      "properties": {"name": "api"}
    }
  }'
----

---

== Create Edge

[source,bash]
----
curl -X POST http://localhost:5678/api/v1/graph/graphs/topology/edges \
  -H "Content-Type: application/json" \
  -d '{
    "edge": {
      "from_node_id": "service-api",
      "to_node_id": "service-db",
      "edge_type": "DEPENDS_ON",
      "weight": 1.0
    }
  }'
----

---

== Traverse

[source,bash]
----
curl -X POST http://localhost:5678/api/v1/graph/graphs/topology/traverse \
  -H "Content-Type: application/json" \
  -d '{"start_node_id": "service-api", "max_depth": 2}'
----
