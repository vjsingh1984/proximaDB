== Endpoints Overview

- REST base: `http://localhost:5678`
- gRPC base: `localhost:5679`

=== Vector + Collections

- REST
  - `POST /api/v1/collections` (create), `GET /api/v1/collections` (list), `DELETE /api/v1/collections/:id`
  - `POST /api/v1/search` (vector search), `POST /api/v1/vectors/batch` (batch upsert)
- gRPC
  - Service `proximadb.v1.VectorService` → `VectorBatch`, `VectorSearch`, `VectorGet`
  - See: link:02-vector-api.adoc[Vector API]

=== Collections

- REST
  - `POST /api/v1/collections` (create), `GET /api/v1/collections` (list), `DELETE /api/v1/collections/:id`
- gRPC (v1)
  - Service `proximadb.v1.CollectionService` → `CreateCollection`, `GetCollection`, `ListCollections`, `DeleteCollection`
  - See: link:04-collection-api.adoc[Collection API]

=== Graph

- REST: `/v1/graph/*` — nodes, edges, `traverse`, `shortest_path`, `stats`, constraints
- gRPC: Service `proximadb.v1.GraphService` — CRUD, traversal, streaming, analysis

=== SQL

- REST: `POST /api/v1/sql/execute`, `POST /api/v1/sql/explain`
- gRPC: `proximadb.v1.SqlService/ExecuteSql`
