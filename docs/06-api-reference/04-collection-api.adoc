 = Collection API (v1)
 :toc:
 :icons: font

== Overview

Manage collections via REST or gRPC v1.

REST base: `http://localhost:5678/api/v1`
gRPC base: `localhost:5679`

== REST

Create:
[source,json]
----
POST /api/v1/collections
{ "name": "docs", "dimension": 768, "distance_metric": "cosine", "storage_engine": "VIPER" }
----

List:
[source,bash]
----
GET /api/v1/collections
----

Delete:
[source,bash]
----
DELETE /api/v1/collections/:collection_id
----

== gRPC (v1)

Service: `proximadb.v1.CollectionService`

RPCs:
- CreateCollection(CollectionConfig) → Collection
- GetCollection(GetCollectionRequest) → Collection
- ListCollections(ListCollectionsRequest) → ListCollectionsResponse
- DeleteCollection(DeleteCollectionRequest) → DeleteCollectionResponse

Python example:
[source,python]
----
import grpc
from proximadb.v1 import collection_pb2_grpc, collection_types_pb2

channel = grpc.insecure_channel('localhost:5679')
stub = collection_pb2_grpc.CollectionServiceStub(channel)
cfg = collection_types_pb2.CollectionConfig(name='docs', dimension=768, distance_metric=1, storage_engine=1)
resp = stub.CreateCollection(cfg)
print(resp.id)
----
