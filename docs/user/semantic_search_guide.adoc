**Build powerful semantic search applications with ProximaDB.**

== Overview

Semantic search finds results based on meaning rather than exact keywords, using vector embeddings to represent concepts in high-dimensional space.

== Quick Start

=== 1. Generate Embeddings

**Using OpenAI:**
```python
import openai

def get_embeddings(texts):
    response = openai.Embedding.create(
        input=texts,
        model="text-embedding-ada-002"
    )
    return [r["embedding"] for r in response["data"]]
```

**Using Sentence Transformers:**
```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')
embeddings = model.encode(texts)
```

=== 2. Create Collection

```python
from proximadb import ProximaDBClient

client = ProximaDBClient("http://localhost:5678")

collection = client.create_collection(
    name="documents_search",
    dimension=384,  # Match your embedding model
    distance_metric="cosine",  # Best for semantic similarity
    storage_engine="viper"  # Optimized for search
)
```

=== 3. Index Documents

```python
# Prepare documents with metadata
documents = [
    {
        "id": "doc_001",
        "vector": embeddings[0],
        "metadata": {
            "title": "Introduction to AI",
            "content": "Full text content...",
            "category": "tutorial",
            "author": "John Doe"
        }
    }
]

# Insert with batching for performance
client.insert_vectors("documents_search", documents, batch_size=100)
```

=== 4. Search

```python
# Generate query embedding
query_text = "How does machine learning work?"
query_embedding = model.encode([query_text])[0]

# Search with filters
results = client.search_vectors(
    collection_id="documents_search",
    query_vector=query_embedding,
    top_k=10,
    metadata_filter={"category": "tutorial"},
    include_metadata=True
)

# Display results
for result in results:
    print(f"Score: {result['score']:.3f}")
    print(f"Title: {result['metadata']['title']}")
    print(f"Content: {result['metadata']['content'][:200]}...")
```

=== Preprocessing Best Practices

1. **Text Cleaning**
   - Remove HTML tags
   - Normalize whitespace
   - Handle special characters

2. **Chunking Strategy**
   - Sentence-level: Precise matching
   - Paragraph-level: Context preservation
   - Fixed-size: Consistent performance

3. **Metadata Enrichment**
   - Add timestamps
   - Include source references
   - Tag with categories

== Advanced Techniques

=== Hybrid Search

Combine vector similarity with keyword matching:

```python
# Vector search
vector_results = client.search_vectors(
    collection_id="documents_search",
    query_vector=query_embedding,
    top_k=20
)

# Filter by keywords in metadata
keyword_filtered = [
    r for r in vector_results
    if keyword in r['metadata']['content'].lower()
]
```

=== Re-ranking

Improve relevance with two-stage search:

```python
# Stage 1: Fast approximate search
initial_results = client.search_vectors(
    collection_id="documents_search",
    query_vector=query_embedding,
    top_k=100
)

# Stage 2: Precise re-ranking
reranked = rerank_with_cross_encoder(
    query_text,
    initial_results,
    top_k=10
)
```

=== Query Expansion

Improve recall with synonym expansion:

```python
# Expand query with synonyms
expanded_queries = [
    "machine learning",
    "artificial intelligence",
    "deep learning",
    "neural networks"
]

# Search with multiple queries
all_results = []
for query in expanded_queries:
    embedding = model.encode([query])[0]
    results = client.search_vectors(
        "documents_search",
        embedding,
        top_k=5
    )
    all_results.extend(results)

# Deduplicate and merge scores
final_results = merge_and_deduplicate(all_results)
```

== Performance Optimization

=== Collection Configuration

```python
# Optimized for search quality
config = {
    "name": "high_quality_search",
    "dimension": 768,
    "storage_engine": "viper",
    "compression": {
        "algorithm": "zstd",
        "level": 6,
        "enable_quantization": False  # Keep full precision
    }
}

# Optimized for scale
config = {
    "name": "large_scale_search",
    "dimension": 384,
    "storage_engine": "viper",
    "compression": {
        "algorithm": "zstd",
        "level": 9,
        "enable_quantization": True,  # Trade precision for scale
        "quantization_type": "pq8"
    }
}
```

=== Indexing Strategy

* **HNSW**: Best quality, <10M vectors
* **IVF**: Scalable, >10M vectors
* **LSH**: Fast approximate, >100M vectors

== Troubleshooting

=== Common Issues

**Poor Search Results**
* Check embedding model consistency
* Verify distance metric (cosine for normalized)
* Increase top_k parameter
* Review preprocessing pipeline

**Slow Performance**
* Use gRPC instead of REST
* Enable caching
* Batch operations
* Consider quantization

**High Memory Usage**
* Enable compression
* Use tiering for cold data
* Reduce cache size
* Switch to VIPER engine
