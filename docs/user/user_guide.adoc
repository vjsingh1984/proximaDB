= ProximaDB User Guide
:toc: left
:toclevels: 2

**Complete operations guide for ProximaDB.**

== Collections

=== Create Collection
[source,python]
----
from proximadb import ProximaDBClient

client = ProximaDBClient("http://localhost:5678")

# Basic collection
collection = client.create_collection(
    name="vectors",
    dimension=384,
    engine="viper"  # or "sst"
)

# With compression
from proximadb.models import CompressionConfig

collection = client.create_collection(
    name="compressed",
    dimension=1536,
    compression=CompressionConfig(
        algorithm="zstd",
        level=6,
        enable_quantization=True
    )
)
----

=== Manage Collections
[source,python]
----
# List all
collections = client.list_collections()

# Get details
info = client.get_collection("vectors")

# Delete
client.delete_collection("vectors")
----

== Vector Operations

=== Insert
[source,python]
----
# Single vector
vector = {
    "id": "vec1",
    "vector": [0.1, 0.2, ...],  # must match dimension
    "metadata": {"category": "A", "score": 0.95}
}
client.insert_vectors("vectors", [vector])

# Batch insert (faster)
vectors = [...]  # list of vector objects
client.insert_vectors("vectors", vectors, batch_size=100)

# Upsert (insert or update)
client.upsert_vectors("vectors", vectors)
----

=== Search
[source,python]
----
# Basic search
results = client.search_vectors(
    collection_id="vectors",
    query_vector=[0.1, 0.2, ...],
    top_k=10
)

# With filters
results = client.search_vectors(
    collection_id="vectors",
    query_vector=query,
    metadata_filter={
        "category": "A",
        "score": {">=": 0.8}
    },
    top_k=10
)
----

=== Update/Delete
[source,python]
----
# Update vector
client.update_vector("vectors", "vec1", new_vector)

# Delete vector
client.delete_vector("vectors", "vec1")

# Get vector
vector = client.get_vector("vectors", "vec1")
----

== SQL Queries

[source,sql]
----
-- Vector similarity search
SELECT id, metadata->>'title',
       VECTOR_SIMILARITY(vector, [...], 'cosine') as score
FROM vectors
WHERE score > 0.8
ORDER BY score DESC
LIMIT 10;

-- Complex filtering
SELECT * FROM vectors
WHERE metadata->>'category' = 'A'
  AND metadata->>'score' > 0.9
  AND VECTOR_SIMILARITY(vector, [...], 'euclidean') < 1.0;
----

== Performance Tips

=== Choose the Right Engine
[cols="1,1,1", options="header"]
|===
| Engine | Best For | Characteristics

| **SST**
| Write-heavy, OLTP
| Row storage, bloom filters

| **VIPER**
| Analytics, compression
| Columnar, quantization
|===

=== Optimization Guidelines
* **Batch Size**: 100-500 vectors per request
* **Protocol**: Use gRPC for 3x better performance
* **Compression**: ZSTD level 6 for balance
* **Index**: HNSW for quality, IVF for scale

== Integration Examples

=== With Embeddings
[source,python]
----
# Sentence Transformers
from sentence_transformers import SentenceTransformer
model = SentenceTransformer('all-MiniLM-L6-v2')
embeddings = model.encode(texts)

# OpenAI
import openai
response = openai.Embedding.create(
    input=texts,
    model="text-embedding-ada-002"
)
embeddings = [r["embedding"] for r in response["data"]]
----

=== RAG Pipeline
[source,python]
----
# 1. Embed query
query_embedding = model.encode(query)

# 2. Search vectors
results = client.search_vectors(
    "documents",
    query_embedding,
    top_k=5
)

# 3. Use results as context
context = [r["metadata"]["text"] for r in results]
prompt = f"Context: {context}\nQuestion: {query}"
----
