== Collections

=== Creating Collections

[source,python]
----
from proximadb import ProximaDBClient
from proximadb.models import CompressionConfig

client = ProximaDBClient("http://localhost:5678")

# Basic collection
collection = client.create_collection(
    name="my_vectors",  # Min 8 characters
    dimension=384,
    distance_metric="cosine",
    storage_engine="viper"  # or "sst"
)

# With compression
collection = client.create_collection(
    name="compressed_vecs",
    dimension=1536,
    storage_engine="viper",
    compression=CompressionConfig(
        algorithm="zstd",
        level=6,
        enable_quantization=True,
        quantization_type="pq8"
    )
)
----

=== Managing Collections

[source,python]
----
# List all collections
collections = client.list_collections()

# Get collection details
info = client.get_collection("my_vectors")

# Delete collection
client.delete_collection("my_vectors")
----

== Vector Operations

=== Inserting Vectors

[source,python]
----
# Single vector
vector = {
    "id": "vec_001",
    "vector": [0.1, 0.2, ...],  # Must match dimension
    "metadata": {"category": "A", "score": 0.95}
}
client.insert_vector("my_vectors", vector)

# Batch insert (recommended)
vectors = [...]  # List of vector objects
client.insert_vectors("my_vectors", vectors, batch_size=100)

# Upsert (insert or update)
client.upsert_vectors("my_vectors", vectors)
----

=== Searching Vectors

[source,python]
----
# Basic search
results = client.search_vectors(
    collection_id="my_vectors",
    query_vector=[0.1, 0.2, ...],
    top_k=10
)

# With metadata filters
results = client.search_vectors(
    collection_id="my_vectors",
    query_vector=query,
    metadata_filter={
        "category": "A",
        "score": {"$gte": 0.8}
    },
    top_k=10,
    include_metadata=True
)

# Multi-query search
results = client.batch_search(
    collection_id="my_vectors",
    queries=[query1, query2, query3],
    top_k=10
)
----

=== Managing Vectors

[source,python]
----
# Get vector by ID
vector = client.get_vector("my_vectors", "vec_001")

# Update vector
client.update_vector("my_vectors", "vec_001", new_vector)

# Delete vector
client.delete_vector("my_vectors", "vec_001")

# Delete multiple vectors
client.delete_vectors("my_vectors", ["vec_001", "vec_002"])
----

== SQL Interface

image::sql-acceleration-abstract.svg[SQL Architecture, width=900]

[source,sql]
----
-- Vector similarity search
SELECT id, metadata->>'title' as title,
       VECTOR_SIMILARITY(vector, [...], 'cosine') as score
FROM my_vectors
WHERE metadata->>'category' = 'A'
  AND score > 0.8
ORDER BY score DESC
LIMIT 10;

-- Complex queries
SELECT COUNT(*) as count, 
       metadata->>'category' as category
FROM my_vectors
WHERE VECTOR_SIMILARITY(vector, [...], 'euclidean') < 1.0
GROUP BY category;
----

== Performance Optimization

=== Engine Selection

[cols="2,2,2", options="header"]
|===
| Criteria | Choose SST | Choose VIPER

| Write Pattern | Streaming/real-time | Batch inserts
| Query Pattern | Point lookups | Range scans
| Dataset Size | <100K vectors | >100K vectors
| Compression Need | Low | High
|===

=== Best Practices

1. **Batch Operations**
   - Insert: 100-500 vectors per batch
   - Search: Use batch_search for multiple queries

2. **Protocol Selection**
   - gRPC: 3x faster than REST
   - REST: Better for debugging

3. **Compression Settings**
   - LZ4: Fast, 2-3x compression
   - ZSTD: Balanced, 3-5x compression
   - With quantization: 16-64x compression

4. **Index Selection**
   - HNSW: Best quality, <10M vectors
   - IVF: Scalable, >10M vectors
   - PQ: Maximum compression

== Configuration

=== Python SDK Configuration

[source,python]
----
from proximadb import ProximaDBClient, Protocol

# Force specific protocol
client = ProximaDBClient(
    "http://localhost:5678",
    protocol=Protocol.GRPC,
    timeout=30,
    max_retries=3
)

# Connection pooling
client = ProximaDBClient(
    "http://localhost:5678",
    pool_size=10,
    max_connections=50
)
----

== Troubleshooting

=== Common Issues

**Collection name too short:**
- Error: "Collection name must be at least 8 characters"
- Solution: Use names like "my_vectors" instead of "vectors"

**Dimension mismatch:**
- Error: "Vector dimension 384 doesn't match collection dimension 768"
- Solution: Ensure all vectors match collection dimension

**Out of memory:**
- Error: "Cannot allocate memory"
- Solution: Reduce batch size or increase server memory
