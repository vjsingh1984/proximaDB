== 📚 Collection Management

=== Creating Collections

**Basic Collection Creation:**

[source,python]
----
from proximadb import ProximaDBClient

# Connect to ProximaDB
client = ProximaDBClient("http://localhost:5678")

# Create a collection for document embeddings
collection = client.create_collection(
    name="documents",
    dimension=384,                    # BERT-base embedding size
    distance_metric="cosine",        # Best for normalized embeddings
    engine="viper",                  # Columnar storage for analytics
    description="Document embeddings for RAG system"
)
print(f"✅ Created collection: {collection.name}")
----

**Advanced Collection Configuration:**

[source,python]
----
from proximadb.models import CollectionConfig, StorageEngine, DistanceMetric

# Enterprise configuration with optimizations
config = CollectionConfig(
    name="enterprise_vectors",
    dimension=1536,                   # OpenAI ada-002 size
    distance_metric=DistanceMetric.COSINE,
    storage_engine=StorageEngine.VIPER,
    
    # Performance tuning
    index_config={
        "algorithm": "hnsw",          # Best for similarity search
        "ef_construction": 200,       # Higher = better recall
        "m": 16                       # Higher = better connectivity
    },
    
    # Storage optimization
    compression={
        "enabled": True,
        "algorithm": "zstd",          # Best compression ratio
        "level": 6                    # Balance speed vs size
    }
)

collection = client.create_collection(config=config)
----

=== Searching Vectors

**Basic Similarity Search:**

[source,python]
----
# Simple vector search
query_vector = [0.1, 0.2, 0.3] * 128  # Your query embedding

results = client.search_vectors(
    collection_id="documents",
    query_vector=query_vector,
    top_k=10,  # Return top 10 most similar
    include_metadata=True,
    include_vectors=False  # Don't return vectors to save bandwidth
)

print("🔍 Search Results:")
for i, result in enumerate(results, 1):
    print(f"{i}. {result.metadata['title']} (score: {result.score:.3f})")
----

**Advanced Search with Filtering:**

[source,python]
----
# Search with complex metadata filtering
filtered_results = client.search_vectors(
    collection_id="documents",
    query_vector=query_vector,
    top_k=20,
    
    # Metadata filters
    metadata_filter={
        "category": "research",           # Exact match
        "priority": "high",              # Exact match  
        "word_count": {">=": 1000},       # Numeric comparison
        "published_date": {">=": "2024-01-01"}  # Date comparison
    },
    
    # Distance threshold
    distance_threshold=0.8,  # Only return results with similarity > 0.8
    
    # Include additional data
    include_metadata=True,
    include_distances=True
)

for result in filtered_results:
    metadata = result.metadata
    print(f"📄 {metadata['title']}")
    print(f"   Category: {metadata['category']}, Score: {result.score:.3f}")
    print(f"   Words: {metadata['word_count']}, Date: {metadata['published_date']}")
    print()
----

**Multi-Vector Search (Batch Queries):**

[source,python]
----
# Search multiple queries efficiently
query_vectors = [
    [0.1, 0.2, 0.3] * 128,  # Query 1

== 🔍 SQL Query Engine

ProximaDB includes a complete SQL engine optimized for vector operations with metadata filtering.

=== Basic SQL Queries

[source,python]
----
# Simple vector similarity search with SQL
results = client.execute_sql("""
    SELECT 
        id,
        metadata->>'title' as title,
        VECTOR_SIMILARITY(vector, [0.1, 0.2, 0.3, ...], 'cosine') as score
    FROM documents
    WHERE score > 0.8
    ORDER BY score DESC
    LIMIT 10
""")

for doc in results:
    print(f"{doc['title']}: {doc['score']:.3f}")
----

=== Advanced SQL Features

**Complex Metadata Filtering:**

[source,python]
----
# Full AND/OR/NOT operator support
complex_query = """
    SELECT id, metadata->>'title', metadata->>'category'
    FROM documents  
    WHERE (
        (metadata->>'category' = 'research' AND metadata->>'priority' = 'high')
        OR metadata->>'author' IN ('Dr. Smith', 'Prof. Johnson')
    )
    AND NOT metadata->>'archived' = 'true'
    AND metadata->>'word_count' BETWEEN 1000 AND 5000
    ORDER BY VECTOR_SIMILARITY(vector, [...], 'cosine') DESC
    LIMIT 20
"""

results = client.execute_sql(complex_query)
----

**Supported SQL Operators:**
- **Logical**: `AND`, `OR`, `NOT` with proper precedence
- **Comparison**: `=`, `!=`, `<`, `>`, `<=`, `>=`
- **Set Operations**: `IN`, `BETWEEN`
- **JSON Access**: `->>'field'` for metadata access
- **Vector Functions**: `VECTOR_SIMILARITY(vector, query, metric)`

=== Distance Metrics (13 Supported)

[cols="2,3"]
|===
|**Metric** |**Best For**

|`cosine` |Normalized embeddings (most common)
|`euclidean` |Spatial data, image features
|`dot_product` |Raw embeddings, recommendation systems
|`manhattan` |High-dimensional sparse data
|`hamming` |Binary vectors, fingerprints
|`jaccard` |Set similarity, document comparison
|===

Plus 7 additional metrics: Chebyshev, Canberra, Minkowski, Angular, Bray-Curtis, Hellinger, Chi-squared.

=== Integration Examples

**With Sentence Transformers:**

[source,python]
----
from sentence_transformers import SentenceTransformer
from proximadb import ProximaDBClient

# Initialize embedding model
model = SentenceTransformer('all-MiniLM-L6-v2')
client = ProximaDBClient("http://localhost:5678")

# Create collection
collection = client.create_collection(
    name="embeddings",
    dimension=384,  # MiniLM dimension
    engine="viper"
)

# Embed and store documents
documents = ["AI is transforming industries", "Machine learning enables automation"]
embeddings = model.encode(documents)

vectors = []
for i, (doc, embedding) in enumerate(zip(documents, embeddings)):
    vectors.append({
        "id": f"doc_{i}",
        "vector": embedding.tolist(),
        "metadata": {"text": doc, "source": "demo"}
    })

client.insert_vectors("embeddings", vectors)

# Search with natural language
query = "artificial intelligence applications"
query_embedding = model.encode([query])[0]
results = client.search_vectors("embeddings", query_embedding.tolist(), top_k=5)
----

**With OpenAI Embeddings:**

[source,python]
----
import openai
from proximadb import ProximaDBClient

# Setup clients
openai.api_key = "your-api-key"
client = ProximaDBClient("http://localhost:5678")

# Create collection for OpenAI embeddings
collection = client.create_collection(
    name="openai_docs",
    dimension=1536,  # OpenAI ada-002 dimension
    engine="viper"
)

def embed_and_store(texts, metadata_list):
    # Get embeddings from OpenAI
    response = openai.Embedding.create(
        input=texts,
        model="text-embedding-ada-002"
    )
    
    vectors = []
    for i, (text, metadata, embedding_data) in enumerate(zip(texts, metadata_list, response['data'])):
        vectors.append({
            "id": f"openai_{i}",
            "vector": embedding_data['embedding'],
            "metadata": {**metadata, "text": text}
        })
    
    return client.insert_vectors("openai_docs", vectors)

# Usage
texts = ["ProximaDB is fast", "Vector search is powerful"]
metadata = [{"category": "product"}, {"category": "technology"}]
embed_and_store(texts, metadata)
----

=== Compression Configuration

ProximaDB supports transparent compression for bandwidth optimization:

**Server Configuration:**
[source,toml]
----
# Server-side compression settings in config.toml
[rest]
enable_compression = false  # Default: false (better debugging)
max_request_size_mb = 64

[grpc]
enable_compression = true   # Default: true (better performance)
max_frame_size_mb = 16

# Storage compression (always recommended)
[storage.sst_config]
compression_enabled = true  # Default: true
compression = "zstd"
compression_level = 3

[storage.viper_config]
compression_enabled = true  # Default: true
compression = "zstd"
compression_level = 3
----

**Automatic Codec Support:**
- REST: deflate, gzip, zstd, brotli (in priority order)
- gRPC: gzip compression (tonic limitation)
- Content negotiation handled automatically

**Python Client Configuration:**
[source,python]
----
from proximadb import ProximaDBClient, ClientConfig, CompressionConfig

# Configure compression with separate REST/gRPC settings
config = ClientConfig(
    url="http://localhost:5678",
    compression=CompressionConfig(
        # REST compression settings
        rest_enabled=False,       # Default: False (better debugging)
        rest_algorithm="gzip",    # Options: deflate, gzip, zstd, br
        
        # gRPC compression settings
        grpc_enabled=True,        # Default: True (better performance)
        grpc_algorithm="gzip",    # Currently only gzip supported
        
        # Common settings
        threshold_bytes=1024,     # Only compress if larger than 1KB
        level=6                   # Compression level 1-9
    )
)
client = ProximaDBClient(config=config)

# Or use protocol-specific clients with compression
from proximadb import connect_grpc, connect_rest

# gRPC with compression enabled by default
grpc_client = connect_grpc("localhost:5679")  # Compression ON

# REST without compression by default  
rest_client = connect_rest("http://localhost:5678")  # Compression OFF
----

**Compression Performance:**
- **Bandwidth Savings**: 50-80% for vector data
- **Latency Impact**: < 3% overhead
- **Best Algorithms**: 
  - deflate: Fastest, lowest CPU
  - gzip: Best compatibility
  - zstd/brotli: Maximum compression

== 🚀 BERT Integration

=== Basic Setup
[source,python]
----
from transformers import AutoTokenizer, AutoModel
from proximadb import ProximaDBClient

# BERT embedding service
class BERTEmbeddings:
    def __init__(self, model="bert-base-uncased"):
        self.tokenizer = AutoTokenizer.from_pretrained(model)
        self.model = AutoModel.from_pretrained(model)
    
    def encode(self, text):
        inputs = self.tokenizer(text, return_tensors="pt", truncation=True)
        outputs = self.model(**inputs)
        return outputs.last_hidden_state[:, 0, :].squeeze().tolist()

# Usage
bert = BERTEmbeddings()
client = ProximaDBClient("http://localhost:5678")

# Create collection for BERT
collection = client.create_collection({
    "name": "bert_docs",
    "dimension": 768,
    "distance_metric": "cosine"
})

# Generate and insert embeddings
text = "Machine learning is transforming data processing"
embedding = bert.encode(text)
client.insert_vector("bert_docs", "doc_1", embedding, {"text": text})
----
