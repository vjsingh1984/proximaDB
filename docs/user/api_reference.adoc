= REST API Reference
:toc: left

== Overview

ProximaDB REST API with unified handlers and proto-first architecture.

* **Base URL**: `http://localhost:5678`
* **Content-Type**: `application/json`
* **Authentication**: None (API keys planned)

== Endpoints

=== Health Check
* **GET** `/health` - Service health status

=== Collections
* **POST** `/api/v1/collection` - Unified collection operations

==== Create Collection
[source,json]
----
{
  "operation": "create",
  "config": {
    "name": "ai_documents",
    "dimension": 384,
    "distance_metric": "cosine",
    "storage_engine": "viper"
  }
}
----

==== Get Collection
[source,json]
----
{
  "operation": "get",
  "collection_id": "uuid"
}
----

=== Vectors

==== Insert Batch
* **POST** `/api/v1/vector/batch` - Insert vectors

[source,json]
----
{
  "collection_id": "uuid",
  "vectors": [
    {
      "id": "vec1",
      "vector": [0.1, 0.2, 0.3],
      "metadata": {"category": "electronics"}
    }
  ]
}
----

==== Search
* **POST** `/api/v1/vector/search` - Search similar vectors

[source,json]
----
{
  "collection_id": "uuid",
  "queries": [{
    "vector": [0.1, 0.2, 0.3],
    "metadata_filter": {
      "conditions": [{
        "field_name": "category",
        "operation": "equals",
        "value": "electronics"
      }]
    }
  }],
  "top_k": 10
}
----

==== Get Vector
* **GET** `/api/v1/vector/:collection_id/:vector_id`

==== Delete Vector  
* **DELETE** `/api/v1/vector/:collection_id/:vector_id`

== Error Responses

[source,json]
----
{
  "success": false,
  "error_message": "Collection not found",
  "error_code": "NOT_FOUND"
}
----

== Status Codes
* **200** - Success
* **400** - Bad Request  
* **404** - Not Found
* **500** - Server Error

== Examples

=== Create Collection
[source,bash]
----
curl -X POST http://localhost:5678/api/v1/collection \
  -H "Content-Type: application/json" \
  -d '{"operation": "create", "config": {"name": "products", "dimension": 384}}'
----

=== Insert Vectors
[source,bash]
----
curl -X POST http://localhost:5678/api/v1/vector/batch \
  -H "Content-Type: application/json" \
  -d '{"collection_id": "uuid", "vectors": [{"vector": [0.1, 0.2]}]}'
----

=== Search Vectors
[source,bash]
----
curl -X POST http://localhost:5678/api/v1/vector/search \
  -H "Content-Type: application/json" \
  -d '{"collection_id": "uuid", "queries": [{"vector": [0.1, 0.2]}], "top_k": 10}'
----
