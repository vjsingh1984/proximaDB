== REST API

**Base URL**: `http://localhost:5678`
**Content-Type**: `application/json`

=== Health Check

```http
GET /health
```

Response:
```json
{
  "status": "healthy",
  "version": "0.1.4"
}
```

=== Collections

==== Create Collection

```http
POST /api/v1/collection
```

Request:
```json
{
  "operation": "create",
  "config": {
    "name": "my_vectors",
    "dimension": 384,
    "distance_metric": "cosine",
    "storage_engine": "viper",
    "compression": {
      "algorithm": "zstd",
      "level": 6,
      "enable_quantization": true
    }
  }
}
```

==== List Collections

```http
GET /api/v1/collections
```

Response:
```json
{
  "collections": [
    {
      "id": "my_vectors",
      "dimension": 384,
      "vector_count": 10000
    }
  ]
}
```

==== Delete Collection

```http
DELETE /api/v1/collection/{name}
```

=== Vector Operations

==== Insert Vectors

```http
POST /api/v1/vector/batch
```

Request:
```json
{
  "collection_id": "my_vectors",
  "vectors": [
    {
      "id": "vec_001",
      "vector": [0.1, 0.2, ...],
      "metadata": {"key": "value"}
    }
  ]
}
```

==== Search Vectors

```http
POST /api/v1/vector/search
```

Request:
```json
{
  "collection_id": "my_vectors",
  "queries": [{
    "vector": [0.1, 0.2, ...],
    "metadata_filter": {
      "conditions": [{
        "field_name": "category",
        "operation": "equals",
        "value": "A"
      }]
    }
  }],
  "top_k": 10,
  "include_metadata": true
}
```

==== Get Vector

```http
GET /api/v1/vector/{collection_id}/{vector_id}
```

==== Delete Vector

```http
DELETE /api/v1/vector/{collection_id}/{vector_id}
```

== gRPC API

**Endpoint**: `localhost:5679`

=== Service Definition

```protobuf
service ProximaDB {
  // Collections
  rpc CreateCollection(CreateCollectionRequest) 
      returns (Collection);
  rpc ListCollections(Empty) 
      returns (ListCollectionsResponse);
  rpc DeleteCollection(DeleteCollectionRequest) 
      returns (Empty);
  
  // Vectors
  rpc InsertVectors(VectorBatchRequest) 
      returns (VectorBatchResponse);
  rpc SearchVectors(VectorSearchRequest) 
      returns (VectorSearchResponse);
  rpc GetVector(GetVectorRequest) 
      returns (VectorRecord);
  rpc DeleteVector(DeleteVectorRequest) 
      returns (Empty);
}
```

=== Python gRPC Example

```python
from proximadb import ProximaDBClient, Protocol

# Use gRPC for 3x performance
client = ProximaDBClient(
    "localhost:5679",
    protocol=Protocol.GRPC
)

# Create collection
collection = client.create_collection(
    name="my_vectors",
    dimension=384,
    storage_engine="viper"
)

# Insert vectors
vectors = [{"id": "v1", "vector": [...]}]
client.insert_vectors("my_vectors", vectors)

# Search
results = client.search_vectors(
    "my_vectors",
    query_vector=[...],
    top_k=10
)
```

== SQL API

```sql
-- Create collection
CREATE COLLECTION my_vectors (
  dimension=384,
  engine='viper',
  distance_metric='cosine'
);

-- Insert with SQL
INSERT INTO my_vectors (id, vector, metadata)
VALUES ('vec_001', [...], '{"category": "A"}');

-- Vector search
SELECT id, 
       VECTOR_SIMILARITY(vector, [...], 'cosine') as score
FROM my_vectors
WHERE score > 0.8
ORDER BY score DESC
LIMIT 10;
```

== Error Codes

[cols="1,2,2", options="header"]
|===
| Code | Status | Description

| 200 | OK | Request successful
| 400 | Bad Request | Invalid parameters
| 404 | Not Found | Resource not found
| 409 | Conflict | Resource already exists
| 429 | Too Many Requests | Rate limit exceeded
| 500 | Internal Error | Server error
|===

== Distance Metrics

[cols="1,2,2", options="header"]
|===
| Metric | Use Case | Formula

| cosine | Text embeddings | 1 - (A·B)/(‖A‖‖B‖)
| euclidean | Spatial data | √Σ(Ai - Bi)²
| dot_product | Recommendations | Σ(Ai × Bi)
| manhattan | Sparse data | Σ│Ai - Bi│
| hamming | Binary vectors | Σ(Ai ≠ Bi)
|===

Plus 8 additional metrics: jaccard, chebyshev, canberra, minkowski, angular, bray_curtis, hellinger, custom

Default limits per client:
* 1000 requests/minute
* 100 concurrent connections
* 100MB max request size
