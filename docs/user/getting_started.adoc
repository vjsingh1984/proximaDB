|===

|**Memory** |4GB RAM minimum, 8GB+ recommended

== 🚀 Installation Options

=== Option 1: Docker (Recommended)

**Fastest way to get started:**

[source,bash,subs="attributes"]
----
# Clone and start ProximaDB
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb
docker compose up -d

# Verify it's running
curl http://localhost:5678/health
# Expected: {"status": "healthy", "version": "0.1.0"}
----

=== Option 2: From Source

**For development or custom builds:**

[source,bash]
----
# Install Rust 1.70+
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Build ProximaDB
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb
cargo build --release

# Run server
cargo run --release --bin proximadb-server
----

== 🎯 Your First ProximaDB Application

=== Step 1: Install Client Library

[source,bash]
----
pip install proximadb-client
----

=== Step 2: Connect and Create Collection

[source,python]
----
from proximadb import ProximaDBClient

# Connect to ProximaDB
client = ProximaDBClient("http://localhost:5678")

# Create your first collection
collection = client.create_collection(
    name="ai_documents",
    dimension=384,  # For BERT-like embeddings
    engine="viper", # Columnar storage for analytics
    distance_metric="cosine"
)
print(f"✅ Created collection: {collection}")
----

=== Step 3: Insert Your First Vectors

[source,python]
----
# Sample document embeddings with metadata
documents = [
    {
        "id": "doc_001",
        "vector": [0.1, 0.2, 0.3, 0.4] * 96,  # 384-dim vector
        "metadata": {
            "title": "Introduction to AI",
            "category": "tutorial",
            "author": "Dr. Smith",
            "published": "2024-01-15"
        }
    },
    {
        "id": "doc_002", 
        "vector": [0.5, 0.6, 0.7, 0.8] * 96,  # 384-dim vector
        "metadata": {
            "title": "Machine Learning Basics",
            "category": "guide",
            "author": "Prof. Johnson",
            "published": "2024-02-20"
        }
    }
]

# Insert vectors
result = client.insert_vectors("ai_documents", documents)
print(f"✅ Inserted {len(documents)} documents")
----

=== Step 4: Search with Vectors

[source,python]
----
import numpy as np

# Create a query vector (in practice, this would be your query embedding)
query_vector = [0.2, 0.3, 0.4, 0.5] * 96  # 384-dim query

# Basic vector search
results = client.search_vectors(
    collection_id="ai_documents",
    query_vector=query_vector,
    top_k=10
)

print("🔍 Search Results:")
for result in results:
    print(f"- {result['metadata']['title']} (score: {result['score']:.3f})")
----

=== Step 5: Search with SQL (Advanced)

[source,python]
----
# Use SQL for complex queries with metadata filtering
sql_results = client.execute_sql("""
    SELECT 
        id,
        metadata->>'title' as title,
        metadata->>'author' as author,
        VECTOR_SIMILARITY(vector, [0.2,0.3,0.4,0.5,...], 'cosine') as similarity_score
    FROM ai_documents
    WHERE metadata->>'category' = 'tutorial'
    AND metadata->>'published' > '2024-01-01'
    ORDER BY similarity_score DESC
    LIMIT 5
""")

print("📊 SQL Query Results:")
for doc in sql_results:
    print(f"- {doc['title']} by {doc['author']} (similarity: {doc['similarity_score']:.3f})")
----

**Basic config.toml**: Set ports (REST 5678, gRPC 5679), data directory, compaction intervals, compression settings.

**Storage Engines**: SST (write-heavy), VIPER (analytics/complex queries).

**Hardware Acceleration**: ProximaDB automatically detects and optimizes for:

* **CPU Features**: SIMD support (AVX-512, AVX2, SSE4.1, NEON)
* **GPU Backends**: CUDA, ROCm, MPS (Apple Silicon), OpenCL
* **Memory Layout**: Cache-aware data structures and processing
* **SQL Acceleration**: GPU/SIMD parsing with intelligent CPU fallbacks

All hardware detection runs once at startup with zero runtime overhead.

== Troubleshooting

**Port conflicts**: Change ports with `REST_PORT=5680 GRPC_PORT=5681 docker compose up`

**Memory issues**: Increase Docker limit with `docker run -m 8g`

**Connection refused**: Check with `docker ps | grep proximadb` and `curl http://localhost:5678/health`
