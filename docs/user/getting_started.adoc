== Installation

=== Docker (Recommended)

[source,bash]
----
# Quick start
docker run -d \
  -p 5678:5678 -p 5679:5679 \
  -v proximadb_data:/data \
  proximadb/proximadb:latest

# Verify
curl http://localhost:5678/health
----

=== Build from Source

[source,bash]
----
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb
cargo build --release
./target/release/proximadb-server --config demo/config.toml
----

== First Steps

=== Install Python SDK

[source,bash]
----
pip install proximadb
----

=== Create Your First Collection

[source,python]
----
from proximadb import ProximaDBClient

# Connect (auto-detects best protocol)
client = ProximaDBClient("http://localhost:5678")

# Create collection
collection = client.create_collection(
    name="my_vectors",  # Min 8 characters
    dimension=384,
    distance_metric="cosine",
    storage_engine="viper"  # or "sst"
)

# Insert vectors
vectors = [
    {
        "id": "vec_001",
        "vector": [0.1, 0.2, ...],
        "metadata": {"category": "A", "score": 0.95}
    }
]
client.insert_vectors("my_vectors", vectors)

# Search
results = client.search_vectors(
    collection_id="my_vectors",
    query_vector=[0.1, 0.2, ...],
    top_k=10,
    metadata_filter={"category": "A"}
)

print(f"Found {len(results)} matches")
----

== Storage Engine Selection

[cols="1,2,2", options="header"]
|===
| Engine | Use When | Example

| **SST**
| Real-time ingestion, frequent updates
| Chat applications, live data

| **VIPER**
| Analytics, batch processing
| Data warehouses, archives
|===

== Performance Tips

. Use gRPC for 3x better performance
. Batch inserts with 100-500 vectors
. Enable compression for 50-80% storage savings
. Choose right engine based on workload
