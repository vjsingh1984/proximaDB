== Step 1: Deploy ProximaDB (60 seconds)

=== Option A: One-Line Docker Deploy

[source,bash]
----
# Production-ready deployment with persistent storage
curl -fsSL https://raw.githubusercontent.com/vjsingh1984/proximadb/main/docker-compose.yml | docker compose -f - up -d

# Verify both endpoints are live
curl http://localhost:5678/health && echo "✅ REST API ready"
grpcurl -plaintext localhost:5679 proximadb.ProximaDB/Health && echo "✅ gRPC API ready"
----

== Step 2: Build Your First AI Search (3 minutes)

=== Install Python SDK

[source,bash]
----
# Install with all optional dependencies
pip install "proximadb[all]"

# Or minimal installation
pip install proximadb
----

=== Create Your Search Pipeline

[source,python]
----
from proximadb import ProximaDBClient
import numpy as np

# Connect (automatically detects best protocol)
client = ProximaDBClient("http://localhost:5678")

# Create collection optimized for your use case
collection = client.create_collection(
    name="semantic_search",
    dimension=1536,                    # OpenAI ada-002 embeddings
    distance_metric="cosine",          # Best for semantic similarity
    storage_engine="viper",            # Columnar for analytics
    enable_compression=True            # 50-80% storage reduction
)
print("✅ Collection created")

# Insert vectors with metadata
vectors = [
    {
        "id": "doc_1",
        "vector": np.random.random(1536).tolist(),
        "metadata": {
            "title": "Introduction to AI",
            "category": "education",
            "price": 99.99
        }
    },
    {
        "id": "doc_2", 
        "vector": np.random.random(1536).tolist(),
        "metadata": {
            "title": "Advanced Machine Learning",
            "category": "education", 
            "price": 149.99
        }
    }
]

# High-performance batch insert
result = client.insert_vectors("semantic_search", vectors)
print(f"✅ Inserted {len(vectors)} vectors")

# Search with filters and metadata
query_vector = np.random.random(1536).tolist()
results = client.search_vectors(
    collection_id="semantic_search",
    query_vector=query_vector,
    top_k=10,
    filters={"category": "education"},    # Metadata filtering
    include_metadata=True                 # Return metadata with results
)

print(f"✅ Found {len(results)} results")
for result in results:
    print(f"  📄 {result['metadata']['title']} (score: {result['score']:.3f})")
----

== Step 3: Production Deployment (2 minutes)

=== Multi-Cloud Deployment

[source,bash]
----
# AWS deployment with EFS storage
docker run -d \
  --name proximadb-prod \
  -p 5678:5678 -p 5679:5679 \
  -v /mnt/efs/proximadb:/data \
  -e PROXIMADB_CONFIG=/data/production.toml \
  proximadb/proximadb:latest

# Azure deployment with Azure Files
docker run -d \
  --name proximadb-prod \
  -p 5678:5678 -p 5679:5679 \
  -v /mnt/azure/proximadb:/data \
  -e PROXIMADB_STORAGE_TYPE=azure \
  proximadb/proximadb:latest

# GCP deployment with Cloud Storage
docker run -d \
  --name proximadb-prod \
  -p 5678:5678 -p 5679:5679 \
  -v /mnt/gcs/proximadb:/data \
  -e PROXIMADB_STORAGE_TYPE=gcs \
  proximadb/proximadb:latest
----

=== High Availability Setup

[source,yaml]
----
# docker-compose.ha.yml
version: '3.8'
services:
  proximadb-primary:
    image: proximadb/proximadb:latest
    ports: ["5678:5678", "5679:5679"]
    volumes: ["./data/primary:/data"]
    environment:
      PROXIMADB_NODE_TYPE: primary
      PROXIMADB_REPLICATION_ENABLED: true
    
  proximadb-replica:
    image: proximadb/proximadb:latest
    ports: ["5680:5678", "5681:5679"]  
    volumes: ["./data/replica:/data"]
    environment:
      PROXIMADB_NODE_TYPE: replica
      PROXIMADB_PRIMARY_HOST: proximadb-primary
    depends_on: [proximadb-primary]

  nginx:
    image: nginx:alpine
    ports: ["80:80", "443:443"]
    volumes: ["./nginx.conf:/etc/nginx/nginx.conf"]
    depends_on: [proximadb-primary, proximadb-replica]
----
