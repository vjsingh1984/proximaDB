== Prerequisites

* **Docker**: 20.10+ with Docker Compose v2
* **Memory**: 4GB minimum (8GB recommended)
* **Ports**: 5678 (REST), 5679 (gRPC)

== Installation

=== Docker (Recommended)

[source,bash]
----
# Clone and start
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb
docker compose up -d

# Verify
curl http://localhost:5678/health
# Expected: {"status": "healthy", "version": "1.0.0"}
----

=== From Source

[source,bash]
----
# Install Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Build and run
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb
cargo build --release
cargo run --release --bin proximadb-server
----

== Quick Start Example

=== 1. Install Python Client

[source,bash]
----
pip install proximadb-client
----

=== 2. Create Collection

[source,python]
----
from proximadb import ProximaDBClient

# Connect
client = ProximaDBClient("http://localhost:5678")

# Create collection
collection = client.create_collection(
    name="my_vectors",
    dimension=384,
    engine="viper"  # or "sst"
)
----

=== 3. Insert Vectors

[source,python]
----
# Insert with metadata
vectors = [
    {
        "id": "vec1",
        "vector": [0.1, 0.2, ...],  # 384-dim
        "metadata": {"category": "A", "score": 0.95}
    }
]

client.insert_vectors("my_vectors", vectors)
----

=== 4. Search

[source,python]
----
# Vector search
results = client.search_vectors(
    collection_id="my_vectors",
    query_vector=[0.2, 0.3, ...],  # 384-dim
    top_k=10
)

# Print results
for result in results:
    print(f"{result['id']}: {result['score']:.3f}")
----

== Configuration

=== Basic config.toml

[source,toml]
----
[server]
rest_port = 5678
grpc_port = 5679

[storage]
data_directory = "/data"
engine = "viper"  # or "sst"

[performance]
enable_gpu = true
enable_simd = true
----

=== Storage Engines

[cols="1,2,1", options="header"]
|===
| Engine | Use Case | Characteristics

| **SST**
| Write-heavy, OLTP
| Row-based, bloom filters

| **VIPER**
| Analytics, complex queries
| Columnar, compression
|===

== Hardware Acceleration

ProximaDB automatically detects and uses:

* **SIMD**: AVX-512, AVX2, SSE4.1, NEON
* **GPU**: CUDA, ROCm, MPS, OpenCL
* **Optimizations**: Cache-aware, zero-copy
