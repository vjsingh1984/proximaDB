= API Architecture
:toc: left
:toclevels: 2
:imagesdir: ../diagrams/images

The API layer provides the external interface to ProximaDB. It consists of a RESTful HTTP API and a high-performance gRPC API.

- *REST API* (Port 5678): A traditional HTTP/JSON API for web clients and easy integration.
- *gRPC API* (Port 5679): A high-performance API based on Protocol Buffers, suitable for low-latency communication between services.
- *Unified Handlers*: A single implementation of the business logic that serves both the REST and gRPC APIs, ensuring consistency and reducing code duplication.
