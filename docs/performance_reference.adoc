== Hardware Requirements

=== Minimum Specifications
* CPU: 4 cores
* RAM: 8GB
* Storage: 100GB SSD
* Network: 1Gbps

=== Recommended Production
* CPU: 16+ cores
* RAM: 64GB+
* Storage: NVMe SSD
* Network: 10Gbps
* GPU: Optional (10x speedup)

== Optimization Guide

=== Protocol Selection
* **REST**: Good for debugging, 6K vec/s
* **gRPC**: Production use, 17K vec/s (2.9x faster)

=== Batch Size Tuning
* **Small batches** (10-50): Lower latency
* **Medium batches** (100-500): Balanced
* **Large batches** (1000+): Maximum throughput

=== Engine Selection

[cols="2,2,2", options="header"]
|===
| Workload | Choose SST | Choose VIPER

| Write-heavy | ✓ Best | Limited
| Read-heavy | Good | ✓ Best
| Mixed | ✓ Balanced | Good
| Analytics | Limited | ✓ Optimal
|===

=== Compression Strategy

[cols="2,1,1,1", options="header"]
|===
| Priority | Algorithm | Level | Result

| Speed | LZ4 | 1 | 2-3x, fastest
| Balanced | ZSTD | 6 | 3-5x, good speed
| Size | ZSTD | 9 | 5-8x, slower
| Maximum | ZSTD+PQ | - | 16-64x, complex
|===

== Performance Tuning

=== Memory Configuration
```toml
[memory]
cache_size_mb = 4096      # 25% of RAM
memtable_size_mb = 1024   # Larger = better write performance
block_cache_mb = 2048     # Frequently accessed blocks
```

=== Thread Configuration
```toml
[performance]
num_threads = 0           # Auto-detect CPU cores
read_threads = 16         # 2x CPU cores
write_threads = 8         # 1x CPU cores
compaction_threads = 4    # Background work
```

=== Storage Configuration
```toml
[sst]
block_size_kb = 3072      # 3MB cloud-optimized
enable_bloom_filter = true # 95% skip rate
compression = "lz4"       # Fast compression

[viper]
compression = "zstd"      # High compression
enable_quantization = true # Additional compression
```

== Scaling Guidelines

=== Vertical Scaling
* **<10M vectors**: 8GB RAM, 4 cores
* **10-100M vectors**: 32GB RAM, 8 cores
* **100M-1B vectors**: 128GB RAM, 16 cores
* **>1B vectors**: 256GB+ RAM, 32+ cores

=== Storage Tiering
* **Hot (10%)**: Memory/NVMe
* **Warm (30%)**: NVMe/SSD
* **Cold (60%)**: HDD/Cloud

== Monitoring Metrics

=== Key Performance Indicators
* **Insert rate**: vectors/second
* **Query latency**: p50, p99, p999
* **Cache hit rate**: >80% target
* **Memory usage**: <70% for stability
* **Disk I/O**: Monitor for bottlenecks

=== Health Checks
```bash
# Check performance
curl http://localhost:5678/metrics

# Key metrics to watch
- proximadb_insert_rate
- proximadb_query_latency_p99
- proximadb_cache_hit_rate
- proximadb_memory_usage_percent
```

== Troubleshooting

=== Common Issues

**High Latency**
* Check cache hit rate
* Increase memory allocation
* Switch to gRPC protocol

**Low Throughput**
* Increase batch size
* Use multiple connections
* Enable connection pooling

**Memory Pressure**
* Reduce cache size
* Enable tiering
* Increase swap space
