= Security Guide
:toc: left
:toclevels: 2
:icons: font

[.lead]
Security settings for developers running ProximaDB in local or single-node environments.

== Status Notes

* Auth, TLS, and audit hooks exist.
* RBAC and tenant enforcement are still evolving in some code paths.

== Basic Auth Setup

[source,toml]
----
[security]
auth_enabled = true
token_secret = "your-32-char-secret"
token_expiry_hours = 24
----

== TLS (Optional)

[source,toml]
----
[security.tls]
enabled = true
cert_path = "/etc/proximadb/cert.pem"
key_path = "/etc/proximadb/key.pem"
----

== Recommended Defaults For Builders

* Bind to `127.0.0.1` unless you need external access.
* Use a reverse proxy for TLS in development.
* Keep auth enabled if exposing the service externally.
