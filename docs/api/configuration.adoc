= Configuration Reference
:toc: left
:toclevels: 2
:icons: font

[.lead]
Configuration reference for developers running ProximaDB locally or in a single‑node environment.

== Minimal Config

[source,toml]
----
[server]
bind_address = "127.0.0.1"
port = 5678
data_dir = "/var/lib/proximadb"
log_level = "info"

[api]
grpc_port = 5679

[storage]
default_engine = "sst"
----

== Server

[source,toml]
----
[server]
bind_address = "127.0.0.1"
port = 5678
log_level = "info"
data_dir = "/var/lib/proximadb"
----

`data_dir` is used for WAL and model data (vectors, documents, observability).

== API

[source,toml]
----
[api]
rest_port = 5678
grpc_port = 5679
arrow_flight_port = 5680
max_request_size = 67108864
rate_limit = 1000
----

== Storage (Vectors)

[source,toml]
----
[storage]
default_engine = "sst"
metadata_url = "file:///var/lib/proximadb/metadata"

[[storage.storage_locations]]
url = "file:///var/lib/proximadb/data"
weight = 1
----

== WAL

WAL backs vector, document, and observability writes.

[source,toml]
----
[storage.wal_config]
enable_wal = true
global_manifest_url = "file:///var/lib/proximadb/manifest"
memory_flush_size_bytes = 16777216
sync_mode = "async"
----

== Graph

[source,toml]
----
[graph]
default_engine = "orion"
wal_enabled = true
----

== Security (Optional)

[source,toml]
----
[security]
auth_enabled = false
token_secret = "change-me"
----

== Notes For Builders

* Use `sst` for general‑purpose vector workloads.
* Document and observability WAL files live under `data_dir`.
* Observability storage is partitioned and currently in‑memory.
