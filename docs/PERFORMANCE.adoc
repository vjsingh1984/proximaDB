* **1-10 vectors**: Pre-allocation (no pooling benefit)
* **10-100 vectors**: 2-3x improvement with basic pooling
* **100-1K vectors**: 4-5x improvement with arena allocation
* **1K-10K vectors**: 6-8x improvement with memory mapping
* **>10K vectors**: 10x+ improvement with streaming

== Performance Troubleshooting

=== Common Issues

[cols="2,3,3", width="100%"]
|===
|Symptom |Likely Cause |Solution

|High latency
|Cold cache, wrong engine
|Warm cache, optimize engine selection

|Low throughput
|Serial processing
|Enable batching, increase parallelism

|High memory
|No pooling, memory leaks
|Enable pooling, check for leaks

|CPU spikes
|No SIMD, inefficient queries
|Enable SIMD, optimize query patterns
|===
