== 🔄 Operations Procedures

=== Operations Guide

=== Backup & Recovery

==== Automated Backup Script
[source,bash]
----
#!/bin/bash
# backup.sh - Automated ProximaDB backup

BACKUP_DIR="/backups/proximadb"
DATA_DIR="/data"
RETENTION_DAYS=7

# Create timestamped backup
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
BACKUP_PATH="$BACKUP_DIR/backup_$TIMESTAMP"

echo "Starting ProximaDB backup to $BACKUP_PATH"

# Stop writes (optional - for consistent backup)
curl -X POST http://localhost:5678/admin/readonly

# Create backup
mkdir -p "$BACKUP_PATH"
cp -r "$DATA_DIR"/* "$BACKUP_PATH/"

# Resume writes  
curl -X POST http://localhost:5678/admin/readwrite

# Compress backup
tar -czf "$BACKUP_PATH.tar.gz" -C "$BACKUP_DIR" "backup_$TIMESTAMP"
rm -rf "$BACKUP_PATH"

# Cleanup old backups
find "$BACKUP_DIR" -name "backup_*.tar.gz" -mtime +$RETENTION_DAYS -delete

echo "Backup completed: $BACKUP_PATH.tar.gz"
----

==== Recovery Procedure
[source,bash]
----
#!/bin/bash  
# recovery.sh - ProximaDB recovery from backup

BACKUP_FILE="$1"
DATA_DIR="/data"

if [ -z "$BACKUP_FILE" ]; then
  echo "Usage: $0 <backup_file.tar.gz>"
  exit 1
fi

echo "Starting ProximaDB recovery from $BACKUP_FILE"

# Stop ProximaDB service
systemctl stop proximadb  # or docker stop proximadb

# Backup current data
mv "$DATA_DIR" "${DATA_DIR}.old.$(date +%Y%m%d_%H%M%S)"

# Extract backup
mkdir -p "$DATA_DIR"
tar -xzf "$BACKUP_FILE" -C "$DATA_DIR" --strip-components=1

# Set permissions
chown -R proximadb:proximadb "$DATA_DIR"

# Start ProximaDB service  
systemctl start proximadb  # or docker start proximadb

echo "Recovery completed"
----

global
    daemon
    
defaults
    mode http
    timeout connect 5000ms
    timeout client 50000ms
    timeout server 50000ms

frontend proximadb_frontend
    bind *:80
    bind *:443 ssl crt /etc/ssl/proximadb.pem
    redirect scheme https if !{ ssl_fc }
    default_backend proximadb_backend

backend proximadb_backend
    balance roundrobin
    option httpchk GET /health

    server standby1 10.0.1.11:5678 check backup
    server standby2 10.0.1.12:5678 check backup

== 🔒 Security & Compliance  

=== Security Hardening Checklist

==== Network Security
- [ ] **TLS Encryption**: Enable TLS for all client connections
- [ ] **Internal Communication**: Use TLS for cluster communication  
- [ ] **Firewall Rules**: Restrict access to administrative ports
- [ ] **VPC/Network Segmentation**: Isolate ProximaDB in private network

==== Authentication & Authorization
- [ ] **API Keys**: Require API keys for all requests
- [ ] **JWT Tokens**: Use JWT for user session management
- [ ] **Role-Based Access**: Configure user roles and permissions
- [ ] **Audit Logging**: Enable comprehensive audit trails

==== Data Protection  
- [ ] **Encryption at Rest**: Enable storage encryption
- [ ] **Backup Encryption**: Encrypt all backup files
- [ ] **Key Management**: Use proper key rotation policies
- [ ] **Data Retention**: Configure automatic data cleanup

== 🚨 Troubleshooting Guide

=== Common Issues & Solutions

[cols="2,2,2,1", options="header"]
|===
| Symptom | Likely Cause | Solution | Priority

| **High search latency (>10ms)**
| Memory pressure, no indexing
| Increase memory, enable HNSW index
| High

| **High memory usage**
| Large vectors, no quantization
| Enable INT8/binary quantization  
| Medium

| **Slow ingestion**  
| Small batch sizes, sync writes
| Use larger batches, async mode
| Medium

| **Connection timeouts**
| Resource exhaustion
| Scale vertically or horizontally
| High

| **Background CPU high (>5%)**
| Aggressive compaction
| Tune compaction intervals  
| Low
|===

=== Upgrade Procedures

[source,bash]
----
#!/bin/bash
# upgrade.sh - Safe ProximaDB upgrade

NEW_VERSION="$1"
CURRENT_VERSION=$(curl -s http://localhost:5678/version | jq -r '.version')

echo "Upgrading ProximaDB from $CURRENT_VERSION to $NEW_VERSION"

# 1. Backup before upgrade
./backup.sh

# 2. Download new version  
docker pull proximadb/proximadb:$NEW_VERSION

# 3. Rolling upgrade (zero downtime)
docker-compose up -d --force-recreate --no-deps proximadb

# 4. Health check
sleep 30
curl -f http://localhost:5678/health || {
    echo "Upgrade failed, rolling back..."
    docker-compose up -d --force-recreate --no-deps proximadb:$CURRENT_VERSION
    exit 1
}

echo "Upgrade completed successfully"
----
