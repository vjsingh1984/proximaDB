= ProximaDB AutoML - Quick Reference
:icons: font

[.lead]
**AutoML Framework - Self-Optimizing Database at Your Service**

== 🚀 Quick Start

[source,toml]
----
# Add to config.toml
[automl]
enabled = true
optimization_interval_secs = 300  # Every 5 minutes
----

[source,rust]
----
// Start AutoML
let automl = AutoMLCoordinator::new(AutoMLConfig::default()).await?;
automl.start().await?;  // Runs in background
----

== 🎮 Manual Control

[source,rust]
----
// Manual optimization
let config = pipeline.optimize(
    "collection",
    OptimizationGoal::MinimizeLatency,
    OptimizationStrategy::BayesianOptimization { n_iterations: 50 },
    WorkloadPattern::ReadHeavy,
).await?;

// Workload analysis
let pattern = analyzer.analyze_workload("collection").await?;
let future = analyzer.predict_pattern("collection", 3600).await?;

// Hyperparameter tuning
let best = tuner.with_algorithm(TuningAlgorithm::TPE)
    .tune(objective)
    .await?;
----

== 🐛 Troubleshooting

[cols="2,3"]
|===
| Issue | Solution

| **Not triggering**
| Check `enabled = true`, verify `min_data_points`

| **Poor predictions**
| Need >1000 samples, check feature normalization

| **Timeouts**
| Increase `timeout_per_trial`, reduce search space

| **High memory**
| Reduce `max_data_points`, limit concurrent optimizations
|===
