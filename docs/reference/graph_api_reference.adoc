[cols="1,3"]
|===
|Endpoint |`POST /api/v1/graph/nodes`
|Purpose |Create a new node with labels and properties
|Content-Type |`application/json`

  "id": "user_123",

**Basic Pattern Examples:**

[source,cypher]
----
-- Find all users over 25
MATCH (u:User) 
WHERE u.age > 25 
RETURN u

-- Find friends of friends
MATCH (u:User)-[:FOLLOWS]->(f:User)-[:FOLLOWS]->(fof:User)
WHERE u.id = 'user_123'
RETURN fof

-- Shortest path with constraints
MATCH path = shortestPath((a:User)-[*..5]-(b:User))
WHERE a.id = 'user_123' AND b.id = 'user_789'
RETURN path
----

=== Data Modeling Guidelines

**Node Design:**
* Use meaningful, hierarchical labels (`User:Customer` vs generic `Entity`)
* Index frequently queried properties
* Keep property cardinality reasonable for index efficiency
* Use embeddings for semantic relationships

**Edge Design:**
* Use descriptive edge types (`PURCHASED` vs generic `RELATED`)
* Include relevant properties for filtering and weighting
* Consider bidirectional relationships where appropriate
* Optimize edge creation for write-heavy workloads

**Schema Evolution:**
* Plan for property additions (backward compatible)
* Design flexible label hierarchies
* Consider embedding model versioning
* Implement gradual migration strategies

=== Rust Native Integration

[source,rust]
----
use proximadb::graph::{GraphClient, Node, Edge, GraphQuery};
use proximadb::vector::VectorQuery;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Initialize native client
    let client = GraphClient::new("localhost:5679").await?;
    
    // Create node with type safety
    let node = Node::builder()
        .id("entity_123")
        .labels(vec!["Document", "Research"])
        .property("title", "AI Research Paper")
        .property("year", 2025)
        .embedding(vec![0.1, 0.2, 0.3]) // f32 vector
        .build()?;
    
    client.create_node(node).await?;
    
    // Complex traversal with filters
    let traversal_result = client
        .traverse()
        .from("entity_123")
        .follow_edges(&["CITES", "REFERENCES"])
        .filter_nodes(|n| n.get_property("year").unwrap_or(0) > 2020)
        .max_depth(4)
        .execute()
        .await?;
    
    println!("Found {} related documents", traversal_result.nodes.len());
    Ok(())
}
----

=== Common Error Codes

[cols="2,3,2"]
|===
|Error Code |Description |Resolution

|`NODE_NOT_FOUND`
|Requested node does not exist
|Verify node ID, check creation status

|`EDGE_ALREADY_EXISTS`
|Edge between nodes already exists
|Use update operation or check uniqueness

|`TRAVERSAL_DEPTH_EXCEEDED`
|Query depth exceeds configured maximum
|Reduce max_depth or increase limits

|`INVALID_PROPERTY_TYPE`
|Property value type not supported
|Use supported types: string, number, boolean

|`QUERY_TIMEOUT`
|Query execution exceeded time limit
|Optimize query or increase timeout
|===
