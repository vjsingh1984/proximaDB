== Development Workflow

[plantuml, dev-workflow, svg]
----
@startuml
start
:Fork Repository;
:Clone Locally;
:Create Feature Branch;
:Write Code;
:Add Tests;
:Run Tests Locally;
if (Tests Pass?) then (yes)
  :Commit Changes;
  :Push to Fork;
  :Create Pull Request;
  if (CI Passes?) then (yes)
    :Code Review;
    if (Approved?) then (yes)
      :Merge to Main;
      stop
    else (no)
      :Address Feedback;
    endif
  else (no)
    :Fix CI Issues;
  endif
else (no)
  :Fix Tests;
endif
@enduml
----

== Project Structure

[source]
----
proximadb/
├── src/
│   ├── api/               # API handlers
│   ├── compute/           # Distance computation
│   ├── core/              # Core types and utilities
│   ├── index/             # Indexing algorithms
│   ├── proto/             # Protocol buffers
│   ├── services/          # Business logic
│   └── storage/           # Storage engines
├── benches/               # Benchmarks
├── tests/                 # Integration tests
├── docs/                  # Documentation
├── examples/              # Example code
└── clients/               # Client libraries
----
