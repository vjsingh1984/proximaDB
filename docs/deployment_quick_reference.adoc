== 🛠️ One-Line Deploy Commands

=== Docker (Universal)
```bash
docker run -d \
  -p 5678:5678 -p 5679:5679 \
  -v /data:/data \
  proximadb/server:latest
```

=== AWS ECS
```bash
aws ecs create-service \
  --service-name proximadb \
  --task-definition proximadb:latest \
  --desired-count 3
```

=== Azure Container Instances
```bash
az container create \
  --name proximadb \
  --image proximadb/server:latest \
  --ports 5678 5679 \
  --cpu 4 --memory 16
```

=== GCP Cloud Run
```bash
gcloud run deploy proximadb \
  --image proximadb/server:latest \
  --port 5678 \
  --memory 16Gi \
  --cpu 4
```

=== Kubernetes (Any Cloud)
```bash
kubectl apply -f https://proximadb.com/deploy/k8s.yaml
```

== 📈 Scaling Guidelines

=== Small (< 10M vectors)
* **Memory**: 8-16 GB
* **CPU**: 4-8 cores
* **Storage**: 100-500 GB
* **Config**: Single engine

=== Medium (10M-100M vectors)
* **Memory**: 32-64 GB
* **CPU**: 16-32 cores
* **Storage**: 1-5 TB
* **Config**: Consider multi-engine

=== Large (100M+ vectors)
* **Memory**: 128+ GB
* **CPU**: 64+ cores
* **Storage**: 10+ TB
* **Config**: Multi-engine + AXIS tiering
