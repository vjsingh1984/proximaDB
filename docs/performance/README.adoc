== Configuration Defaults

=== Validated Optimal Settings

[source,toml]
----
[storage.sst_config]
# SST: Balanced engine (2.98ms with LZ4)
block_size_kb = 1024      # 1MB - 34% faster than 2MB
compression = "lz4"        # 7% faster than no compression!
compression_level = 3      # Balanced
vector_encoding_strategy = "FullVector"

[storage.swift]
# SWIFT: Low-latency engine (2.50ms)
records_per_block = 512    # Reduced from 2000 (11% faster)
blocks_per_superblock = 64 # Hierarchical structure
compression = "none"        # Latency-focused (LZ4 adds +34%)

[storage.viper_config]
# VIPER: Analytics engine (7.72ms)
row_group_size = 100_000   # Parquet optimal
compression = "lz4"         # Optional (+8% query, storage savings)
compression_level = 3

# HELIX: Fastest engine (1.43ms)
# Compression: Use Zstd (no penalty, max storage)
# Block size: Auto-tuned based on clustering
----

== Compression Recommendations

=== SST Engine

**Default**: *LZ4* (7% faster than no compression)

[cols="1,1,1,3"]
|===
|Algorithm |Latency |Savings |Use When

|*LZ4* ⭐
|2.98ms
|~50%
|*Default* - faster + storage

|Snappy
|3.08ms
|~45%
|Alternative to LZ4

|None
|3.32ms
|0%
|Uncompressed storage required

|Zstd
|5.31ms
|~65%
|❌ Avoid (+57% latency)
|===

**Why LZ4 is faster**:

```
Uncompressed: Read 1MB (0.33ms) + Process (3.19ms) = 3.52ms
LZ4:          Read 500KB (0.17ms) + Decompress (0.10ms) + Process (3.00ms) = 3.27ms
Savings:      0.16ms I/O + 0.09ms cache = 0.25ms ✅
```

---

[cols="1,1,1,3"]
|===

|1.42ms
|~70%
|*Recommended* - slight improvement!

|LZ4
|1.46ms
|~50%
|Also excellent (+2% negligible)

|1.46ms

|Also excellent

|1.43ms
|0%

**Why no penalty**: Hilbert pruning reads only 10% of blocks, compression overhead negligible on small I/O.

== Performance Tuning Guide

=== For <2ms Latency (99th percentile)

**Use**: HELIX only

**Config**:
[source,toml]
----
storage_engine = "HELIX"
compression = "zstd"          # Free compression
compression_level = 5
proxima_block_size = 256      # Vectors per block
----

**Requirements**: Data with natural clustering (semantic embeddings, products, images)

---

=== For <5ms Latency with Storage Optimization

**Use**: SST with LZ4

**Config**:
[source,toml]
----
storage_engine = "SST"
block_size_kb = 1024          # 1MB optimal
compression = "lz4"            # 7% faster!
compression_level = 3
----

**Benefits**: Best of both worlds (performance + compression)

---

=== For Maximum Write Throughput

**Use**: SWIFT

**Config**:
[source,toml]
----
storage_engine = "SWIFT"
records_per_block = 512        # Optimal granularity
compression = "none"            # 28ms flush
----

**Trade-off**: No compression for fastest writes
