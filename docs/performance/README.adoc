== Compression Recommendations

=== SST: Use LZ4 (Faster + Storage)

- None: 5.97ms
- LZ4: **5.34ms** (-11% faster!)
- Recommendation: **Enable LZ4 by default**

=== HELIX: No Compression Best

- None: **13.51ms** (best)
- Snappy: 13.27ms (-1.8%, slight benefit)
- LZ4: 13.59ms (+0.6%)
- Zstd: 14.33ms (+6% slower)
- Recommendation: **No compression** at 10K scale

=== Performance Recommendations

**For High-Throughput Applications**:

- Prefer label-based queries over property filters when possible
- Use BFS for shallow traversals (depth ≤ 3)
- Edge creation is 2× faster than node creation - batch edges separately

**For Low-Latency Applications**:

- All query types deliver sub-millisecond latency
- Single-path algorithms (Dijkstra, A*) deliver sub-10μs latency
- Traversal operations complete in <20μs for moderate graphs

**Scaling Considerations**:

- Node/edge creation throughput stable at 75-140K elem/s
- Connected components analysis scales linearly
- For graphs >10K nodes, consider partitioning for parallel analysis
