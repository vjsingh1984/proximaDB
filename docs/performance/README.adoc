== Compression Recommendations

=== SST: Use LZ4 (Faster + Storage)

- None: 5.97ms
- LZ4: **5.34ms** (-11% faster!)
- Recommendation: **Enable LZ4 by default**

=== HELIX: No Compression Best

- None: **13.51ms** (best)
- Snappy: 13.27ms (-1.8%, slight benefit)
- LZ4: 13.59ms (+0.6%)
- Zstd: 14.33ms (+6% slower)
- Recommendation: **No compression** at 10K scale

== Configuration

[source,toml]
----
[storage.sst_config]
block_size_kb = 1024
compression = "lz4"  # Validated 11% faster

[storage.swift]
records_per_block = 512
compression = "none"
----

== Dataset Size Guide

- <5K: SWIFT or HELIX
- 5K-50K: **SST-LZ4** (best choice)
- >50K: VIPER or SST-LZ4
