== Executive Summary

**Date**: 2025-10-03 +
**Status**: ✅ Implemented +
**Impact**: Critical compression optimization fix

**Problem**: GroupedFieldEncoded used sample-based scheme selection (10 vectors × 32 dims = 320 floats) representing only 0.04% of actual data, leading to suboptimal compression.

**Solution**: Implemented per-group analysis using ALL vectors in the row group (1000 vectors × 32 dims = 32,000 floats per group), matching GroupedBlockCompressed behavior.

**Expected Impact**:
- 5-10% better compression ratio for heterogeneous data
- Consistent compression across different dimension ranges
- Eliminates size discrepancy between GV and GB formats

== Solution: Per-Group Analysis

=== New Implementation

[source,rust]
----
use std::collections::HashMap;
let mut pattern_counts: HashMap<String, usize> = HashMap::new();

// Analyze EACH group individually using ALL vectors
for group_idx in 0..num_groups {
    // Collect ALL vectors for this group's dimensions
    let mut group_floats = Vec::with_capacity(vectors.len() * group_dims);
    for vector in vectors {
        for dim_idx in start_dim..end_dim {
            group_floats.push(vector[dim_idx]);
        }
    }
    // 1000 vectors × 32 dims = 32,000 floats analyzed per group

    // Analyze THIS group's pattern using full population
    let detected_scheme = analysis::analyze_and_choose_scheme_f32(&group_floats);
    let pattern = Self::analyze_pattern_f32(&group_floats);

    // Override lossy schemes for f32 safety
    let scheme = match &detected_scheme {
        CodecScheme::Simple8b | CodecScheme::RunLength |
        CodecScheme::VByte | CodecScheme::Zigzag { .. } |
        CodecScheme::PForDelta { .. } => {
            CodecScheme::Delta { base: 0 }  // Safe fallback
        },
        _ => detected_scheme.clone(),  // Delta, DoubleDelta, PForDoubleDelta, etc.
    };

    // Track patterns for debugging
    *pattern_counts.entry(pattern.clone()).or_insert(0) += 1;

    // Encode with group-specific optimal scheme
    let encoded_group = codec.encode(&group_floats, scheme.clone())?;
}
----

== ProximaCodec Scheme Support

=== Lossless Schemes (Safe for f32)

**✅ Allowed** (preserved in scheme selection):

[options="header"]
|===
| Scheme | Description | Use Case | Lossless?
| `Delta { base }` | First-order delta encoding | Smooth gradual changes | ✅ Yes
| `DoubleDelta` | Second-order delta encoding | Linear trends, polynomials | ✅ Yes
| `PForDoubleDelta` | DoubleDelta with exception handling | Linear with outliers | ✅ Yes
| `FrameOfReference` | Reference + small offsets | Clustered values | ✅ Yes
| `SparseBitmap` | Bitmap for sparse data | 70-95% zeros | ✅ Yes
| `SparseCOO` | Coordinate list for extreme sparsity | >95% zeros | ✅ Yes
| `BitPacked { bits: 32 }` | Store all 32 bits | Random data | ✅ Yes
|===

**❌ Blocked** (overridden to Delta):

[options="header"]
|===
| Scheme | Why Blocked | Problem
| `Simple8b` | Integer-optimized packing | Lossy for f32 bit patterns
| `RunLength` | Deduplicates similar values | May lose precision
| `VByte` | Variable-byte integer encoding | Not designed for f32
| `Zigzag` | Integer zigzag encoding | Loses f32 semantics
| `PForDelta` | Integer patched frame | May lose precision
|===

=== DoubleDelta Implementation

From `double_delta.rs:37-100`:

[source,rust]
----
pub fn encode_f32(values: &[f32]) -> Result<Vec<u8>> {
    // Convert f32 → u32 → i32 → i64 (LOSSLESS!)
    let base = values[0].to_bits() as i32;

    // First-order deltas in i64 (no overflow)
    for i in 1..values.len() {
        let curr = values[i].to_bits() as i32 as i64;  // Sign-extend
        let prev = values[i - 1].to_bits() as i32 as i64;
        let delta = curr - prev;  // i64 arithmetic
        deltas.push(delta);
    }

    // Second-order deltas (double deltas)
    for i in 1..deltas.len() {
        let dd = deltas[i] - deltas[i - 1];  // i64 arithmetic
        double_deltas.push(dd);
    }

    // Bitpack double deltas with minimal bits
    let bits = ((64 - max_abs.leading_zeros() as u8) + 1).min(64);
    bitpack::encode_i64_with_bits(&double_deltas, bits)
}
----

**Why This is Lossless**:

1. `f32::to_bits()` preserves all 32 bits (IEEE 754 representation)
2. i64 arithmetic prevents overflow (i32 deltas can overflow)
3. Bitpacking stores exact signed values
4. Decoding reverses: unpack → reconstruct deltas → reconstruct f32 bits → `f32::from_bits()`

**Mathematical Foundation**:

For polynomial data of degree n:
- Delta reduces to degree n-1
- DoubleDelta reduces to degree n-2

Examples:
- Quadratic (ax² + bx + c) → DoubleDelta → Constant
- Linear (ax + b) → DoubleDelta → Zero
- Constant (a) → Delta → Zero

This dramatically improves compression for smooth mathematical functions!

=== Pattern Detection

[source,rust]
----
pub fn analyze_and_choose_scheme_f32(data: &[f32]) -> ProximaScheme {
    // Priority 1: Constant values
    if is_constant_f32(data) {
        return ProximaScheme::RunLength;  // 318x compression
    }

    // Priority 2: Sparsity patterns
    if zero_ratio > 0.95 {
        return ProximaScheme::SparseCOO;  // 39x compression
    }

    // Priority 3: Jaggedness check (NEW!)
    if jaggedness > 0.7 {
        return ProximaScheme::BitPacked { bits: 32 };  // Avoid delta for random
    }

    // Priority 4: Linear patterns → DoubleDelta!
    if linearity > 0.85 && outlier_ratio < 0.05 {
        return ProximaScheme::DoubleDelta { ... };  // 50-60% compression
    }

    // Priority 5: Linear with outliers → PForDoubleDelta!
    if linearity > 0.70 && outlier_ratio > 0.05 {
        return ProximaScheme::PForDoubleDelta { ... };  // 45-55% compression
    }

    // Priority 6: Smooth gradual changes → Delta
    if smoothness > 0.75 && outlier_ratio < 0.05 {
        return ProximaScheme::Delta { base };  // 35-45% compression
    }

    // Default: Simple8b or BitPacked
}
----

            algorithm: CompressionAlgorithm::None,
            ..Default::default()
