== Unified Storage Interface

All engines implement the `UnifiedStorageEngine` trait:

[source,rust]
----
#[async_trait]
pub trait UnifiedStorageEngine: Send + Sync {
    async fn insert(&self, request: InsertRequest) -> Result<InsertResponse>;
    async fn search(&self, request: SearchRequest) -> Result<SearchResponse>;
    async fn flush(&self, params: FlushParameters) -> Result<FlushResult>;
    async fn compact(&self, strategy: CompactionStrategy) -> Result<CompactionResult>;
    async fn get_stats(&self) -> Result<EngineStats>;
}
----
