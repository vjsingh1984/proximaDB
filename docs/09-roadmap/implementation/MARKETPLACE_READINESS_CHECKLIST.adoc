== Cluster Module (Distributed Foundation)

The `src/cluster/` module provides the foundation for distributed operations:

[cols="1,3,2", options="header"]
|===
| Component | Description | Location

| Consensus (Raft)
| Leader election, log replication, RequestVote/AppendEntries RPCs
| `src/cluster/consensus.rs`

| Metadata Service
| Cluster-wide metadata, collection registration, shard placements
| `src/cluster/metadata_service.rs`

| Node Registry
| Node discovery, health tracking, role management (Leader/Follower/Candidate/Observer)
| `src/cluster/node_registry.rs`

| Shard-Aware Routing
| Request routing based on shard placement, load balancing (RoundRobin, LeastLoaded, LeastLatency, WeightedRoundRobin)
| `src/cluster/routing.rs`

| Shard Model
| Shard lifecycle, state management, rebalancing coordination
| `src/cluster/shard.rs`

|===

=== Load Balancing Strategies

* **RoundRobin**: Distribute requests evenly across nodes
* **LeastLoaded**: Route to node with lowest current load
* **LeastLatency**: Route to node with lowest measured latency
* **Random**: Random node selection
* **WeightedRoundRobin**: Distribution based on node capacity weights
