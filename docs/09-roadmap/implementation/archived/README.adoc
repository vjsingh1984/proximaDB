= Archived: `distributed` branch design docs

These documents were authored on the now-deleted `distributed` branch (Phase-1
exploration of a sharding/replication/membership/RPC distributed architecture
with lease-based leader election and REST admin scaffolding, ~2025-10).

That approach was *superseded* by the Raft-based `src/cluster` implementation on
`main`/`develop` (consensus, node_registry, distributed_ops, cache_affinity,
metadata_service). The `src/distributed/*` scaffolding and `admin_distributed`
REST surface were never merged.

These files are preserved for design reference only; they do not describe the
current implementation.
