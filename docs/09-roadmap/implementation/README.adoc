== 🏗️ **Architecture Principles**

All implementation guides follow these core principles established in the codebase analysis:

=== **Collection-Engine Binding**
- Collections are permanently bound to one storage engine type
- No cross-engine data movement or routing
- Optimization happens within the collection's designated engine

=== **Existing Infrastructure Usage**
- **UnifiedCache** for all caching needs
- **UnifiedMetrics** for monitoring and workload analysis
- **UnifiedCachingFilesystem** for all I/O operations
- **UnifiedQuantizationEngine** for compression

=== **CollectionConfig-Driven**
- All feature availability determined by CollectionConfig
- Security policies at collection level
- Quantization settings per collection
- Index configuration per collection
