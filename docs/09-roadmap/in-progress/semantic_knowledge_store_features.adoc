== Section 2: Storage Engine Selection Rationale

=== Available Storage Engines Analysis

ProximaDB has 5 production-ready storage engines with distinct characteristics:

[cols="2,2,3,3", options="header"]
|===
| Engine | Type | Best For | SKS Suitability

| **SST**
| Row-based (LSM-tree)
| - High write throughput (200K/sec)
- OLTP workloads
- Frequent updates
| **Primary for Entity Headers**: 
- Fast point lookups (< 5ms)
- Efficient updates
- Bloom filters for existence checks

| **VIPER**
| Columnar (Parquet)
| - Analytics queries
- Batch operations (500K/sec)
- Maximum compression (5-10x)
| **Primary for Embeddings**:
- Columnar storage for vectors
- Advanced quantization pipeline
- Cloud-optimized with footer cache

| **NOVA**
| Enhanced columnar
| - Extended statistics
- Zone maps
- Aggressive pruning
| Alternative for embeddings
(85% complete)

| **SWIFT**
| High-perf row-based
| - Adaptive block sizes
- Fast traversal
| Alternative for relations
(75% complete)

| **PRISM**
| Metadata-first
| - Progressive quantization
- Metadata-heavy workloads
| Future option for metadata
(70% complete)
|===

=== Recommended Storage Architecture for SKS

**Decision**: Use hybrid storage with multiple engines optimized for each data type:

1. **Entity Headers (Metadata + Provenance)**: **SST Engine**
   - Rationale: Frequent updates, fast point lookups, efficient bloom filters
   - Key format: `(collection_id, entity_id)` 
   - Performance: < 1ms reads with decompression cache

2. **Embeddings Storage**: **VIPER Engine**
   - Rationale: Best compression (5-10x), columnar benefits, quantization support
   - Key format: `(collection_id, entity_id, model_id, modality)`
   - Performance: 10-50ms for batch retrieval

3. **Relations Storage**: **SST Engine**
   - Rationale: Fast adjacency list lookups, bloom filters for edge existence
   - Key format: `(collection_id, entity_id, relation_type, target_id)`
   - Performance: < 5ms for degree-bounded traversal

4. **Provenance Registry**: **SST Engine**
   - Rationale: Small dataset, fast lookups, good compression
   - Key format: `(source_id)` for sources, `(source_id, chunk_id)` for chunks

=== Quantization Strategy for SKS

Based on ProximaDB's quantization infrastructure:

```rust
// Use SMART_DEFAULTS strategy for automatic configuration
QuantizationConfig {
    enabled: true,
    strategy: Strategy::SMART_DEFAULTS,
    enable_progressive_search: true,
    // Automatic selection based on dimension:
    // - d < 128: Binary + INT8
    // - d >= 128 && d < 512: Binary + INT8 + PQ8
    // - d >= 512: Binary + PQ4 + PQ8 + INT8
}
```

**Rationale**:
- Progressive search reduces search space by 95% with bloom filters
- Quantization provides 5-10x storage reduction
- SIMD acceleration available (13.5M - 20.8M ops/sec for 128D)

=== Index Selection Strategy

```rust
// Primary index per modality
IndexConfig {
    index_name: "text_embeddings_primary",
    algorithm: IndexingAlgorithm::HNSW,
    update_mode: IndexUpdateMode::Async,
    hnsw_config: Some(HnswConfig {
        m: 16,
        ef_construction: 200,
        ef_search: 100,
        adaptive_parameters: true,
    }),
    use_quantization: true,  // Inherit from collection

```

**Rationale**:
- HNSW for high recall (>95%) with sub-linear search
- Async updates to not block writes
- INT8 representation in queue for 4x memory savings

=== Metadata Storage Decision

**TypedMetadata vs FlexibleMetadata**:

1. **TypedMetadata** (Parquet columnar in VIPER):
   - For declared fields with known types
   - 2-5x faster access with columnar projection
   - Automatic indexing and statistics

2. **FlexibleMetadata** (JSON in SST):
   - For ad-hoc fields
   - Auto-promotion to typed when query frequency > 100/day
   - Compressed with ZSTD for 3x reduction

#[async_trait]
impl EntityStore for ProximaEntityStore {
    async fn upsert_entity(
        &self,
        collection_id: &str,
        mut entity: Entity,
    ) -> Result<String> {
        // Validate entity
        if entity.id.is_empty() {
            entity.id = uuid::Uuid::new_v4().to_string();
        }
        
        // Store embeddings in vector engine
        for embedding in &entity.embeddings {
            let key = Self::embedding_key(
                collection_id,
                &entity.id,
                &embedding.model_id,
                &format!("{:?}", embedding.modality),
            );
            
            // Store vector using existing engine
            self.vector_engine
                .store_vector(&key, &embedding.vector)
                .await?;
        }
        
        // Store entity header (metadata, provenance, temporal)
        let header_key = Self::entity_key(collection_id, &entity.id);
        let header = EntityHeader {
            typed_metadata: entity.typed_metadata.clone(),
            flexible_metadata: entity.flexible_metadata.clone(),
            provenance: entity.provenance.clone(),
            temporal: entity.temporal.clone(),
        };
        
        self.metadata_store
            .store_entity_header(&header_key, &header)
            .await?;
        
        // Store relations
        for relation in &entity.relations {
            self.relations_store
                .add_relation(collection_id, relation.clone())
                .await?;
        }
        
        // Track provenance
        if let Some(ref provenance) = entity.provenance {
            self.provenance_registry
                .register_provenance(&entity.id, provenance.clone())
                .await?;
        }
        
        Ok(entity.id)
    }
    
    async fn get_entity(
        &self,
        collection_id: &str,
        entity_id: &str,
        include_embeddings: bool,
        include_relations: bool,
    ) -> Result<Option<Entity>> {
        let header_key = Self::entity_key(collection_id, entity_id);
        
        // Fetch entity header
        let header = match self.metadata_store
            .get_entity_header(&header_key)
            .await? 
        {
            Some(h) => h,
            None => return Ok(None),
        };
        
        let mut entity = Entity {
            id: entity_id.to_string(),
            typed_metadata: header.typed_metadata,
            flexible_metadata: header.flexible_metadata,
            provenance: header.provenance,
            temporal: header.temporal,
            collection_id: collection_id.to_string(),
            embeddings: vec![],
            relations: vec![],
        };
        
        // Optionally fetch embeddings
        if include_embeddings {
            entity.embeddings = self
                .fetch_embeddings(collection_id, entity_id)
                .await?;
        }
        
        // Optionally fetch relations
        if include_relations {
            entity.relations = self.relations_store
                .get_relations(collection_id, entity_id)
                .await?;
        }
        
        Ok(Some(entity))
    }
    
    async fn delete_entity(
        &self,
        collection_id: &str,
        entity_id: &str,
        hard_delete: bool,
    ) -> Result<bool> {
        let header_key = Self::entity_key(collection_id, entity_id);
        
        if hard_delete {
            // Remove all data
            self.metadata_store.delete(&header_key).await?;
            self.vector_engine
                .delete_entity_vectors(collection_id, entity_id)
                .await?;
            self.relations_store
                .delete_all_relations(collection_id, entity_id)
                .await?;
            self.provenance_registry
                .remove_provenance(entity_id)
                .await?;
        } else {
            // Soft delete: mark as deleted
            self.metadata_store
                .mark_deleted(&header_key)
                .await?;
        }
        
        Ok(true)
    }
    
    async fn search_entities(
        &self,
        collection_id: &str,
        query_vector: Option<Vec<f32>>,
        metadata_filter: Option<MetadataFilter>,
        temporal_filter: Option<TemporalFilter>,
        top_k: usize,
    ) -> Result<Vec<(Entity, f32)>> {
        // Use existing progressive search infrastructure
        let mut results = Vec::new();
        
        if let Some(vector) = query_vector {
            // Vector similarity search
            let search_results = self.vector_engine
                .search(collection_id, &vector, top_k)
                .await?;
            
            for (entity_id, score) in search_results {
                if let Some(entity) = self
                    .get_entity(collection_id, &entity_id, true, false)
                    .await?
                {
                    // Apply metadata filters
                    if Self::matches_filters(&entity, &metadata_filter, &temporal_filter) {
                        results.push((entity, score));
                    }
                }
            }
        } else {
            // Metadata-only search
            let entities = self.metadata_store
                .scan_with_filters(collection_id, metadata_filter, temporal_filter)
                .await?;
            
            for entity in entities.into_iter().take(top_k) {
                results.push((entity, 1.0));
            }
        }
        
        Ok(results)
    }
}
