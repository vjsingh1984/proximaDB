**Unified SQL-like query language for vector, graph, and metadata operations**

== Overview

Design and implement a unified query language that seamlessly combines vector similarity search, graph traversals, metadata filtering, and aggregations in a single intuitive syntax.

== Planned Syntax

=== Basic Vector Search
```sql
SELECT id, score, metadata
FROM vectors
WHERE SIMILARITY(vector, [0.1, 0.2, 0.3, ...]) > 0.8
  AND metadata.category = 'research'
ORDER BY score DESC
LIMIT 10;
```

=== Hybrid Vector-Graph Query
```sql
SELECT DISTINCT v.id, v.score, g.path
FROM vectors v
JOIN graph g ON v.id = g.node_id
WHERE SIMILARITY(v.vector, :query_vector) > 0.7
  AND g.CONNECTED_TO('node_123', depth=3)
  AND v.metadata.timestamp > '2025-01-01'
ORDER BY v.score * g.centrality DESC
LIMIT 20;
```

=== Multi-Modal Search
```sql
SEARCH multimodal
WITH
  VECTOR [0.1, 0.2, ...] WEIGHT 0.5,
  TEXT 'machine learning' WEIGHT 0.3,
  GRAPH NEIGHBORS('node_456', 2) WEIGHT 0.2
WHERE metadata.status = 'active'
FUSION reciprocal_rank(k=60)
RERANK cross_modal
LIMIT 50;
```

=== Aggregation Query
```sql
SELECT
  metadata.category,
  COUNT(*) as count,
  AVG_SIMILARITY(vector, :centroid) as avg_similarity,
  PERCENTILE(score, 0.95) as p95_score
FROM vectors
WHERE timestamp BETWEEN '2025-01-01' AND '2025-01-31'
GROUP BY metadata.category
HAVING count > 100
ORDER BY avg_similarity DESC;
```

=== Query Planner
[source,rust]
----
pub struct QueryPlanner {
    statistics: TableStatistics,
    cost_model: CostModel,
    rules: Vec<OptimizationRule>,
}

impl QueryPlanner {
    pub fn plan(&self, query: QueryNode) -> Result<ExecutionPlan> {
        // Step 1: Logical plan
        let logical = self.build_logical_plan(query)?;

        // Step 2: Optimization
        let optimized = self.optimize(logical)?;

        // Step 3: Physical plan
        let physical = self.build_physical_plan(optimized)?;

        Ok(physical)
    }
}
----

== Grammar Specification (ANTLR/EBNF)

```ebnf
query         ::= select_stmt | search_stmt | mutation_stmt
select_stmt   ::= "SELECT" projections "FROM" table_ref
                  [join_clause]* [where_clause] [group_clause]
                  [having_clause] [order_clause] [limit_clause]

search_stmt   ::= "SEARCH" modality "WITH" search_specs
                  [where_clause] [fusion_clause] [rerank_clause]
                  [limit_clause]

similarity    ::= "SIMILARITY" "(" column "," vector_literal ")"
connected_to  ::= "CONNECTED_TO" "(" node_id "," "depth" "=" integer ")"
vector_literal::= "[" number ("," number)* "]"

fusion_clause ::= "FUSION" fusion_method "(" [parameters] ")"
rerank_clause ::= "RERANK" rerank_method
```
