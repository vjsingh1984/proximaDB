=== GlobalQuantizationCache
Location: `src/compute/quantization/cache.rs`

Basic caching infrastructure:
* Simple HashMap-based cache
* No LRU eviction
* No persistence
* Memory-only storage

=== Distance Functions
Location: `src/compute/distance/`

Basic scalar implementations:

* Cosine similarity (no SIMD)
* Dot product (no SIMD)
