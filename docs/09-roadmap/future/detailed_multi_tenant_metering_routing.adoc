=== Tenant and Access Management Service

**Purpose**: Centralized, authoritative source for tenant, organization, and collection access control.

[source,mermaid]
----
classDiagram
    class TenantService {
        +get_tenant_info(tenant_id) TenantInfo
        +check_collection_access(tenant_id, collection_id, permission) bool

        +get_shared_collections(tenant_id) Vec~String~
        +grant_collection_access(collection_id, tenant_id, permissions) Result
        +revoke_collection_access(collection_id, tenant_id) Result
    }
    
    class Tenant {
        +tenant_id: String

    participant Client
    participant Router as CustomerRouter (Future)

    participant Current as Current Production System
    
    Client->>+Router: API Request with Auth
    Router->>+Auth: Validate Tenant
    Auth-->>-Router: Tenant Context
    Router->>+Handlers: Request + Tenant Context
    Handlers->>+Current: Execute with Current System
    Current-->>-Handlers: Response
