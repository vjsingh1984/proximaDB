== Overview

This roadmap highlights near‑term engineering work and longer‑term themes. Items reflect current code reality and known gaps.

== In Progress

* SQL frontend + unified execution integration (vector/graph/hybrid)
* Proto v1 migration finalization (remove legacy build artifacts)
* SKS (entities) service build‑out (persistence, tests)
* REST/gRPC parity and endpoint consistency
* Test hygiene (feature‑gated perf/integration tests)

== Planned

* Distributed features (clustering, replication, HA)
* Security (TLS hardening, authN/authZ, RBAC)
* Backup/restore tooling
* Expanded monitoring/metrics (Prometheus, alerts)
* Cloud backend hardening (S3/Azure/GCS validation + CI tests)
* Client tooling (SDK packaging + examples)
