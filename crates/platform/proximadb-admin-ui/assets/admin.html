ProximaDB Admin · read-only never refreshed
This is a read-only dashboard for local standalone / embedded operation. It only issues GET requests against the server's diagnostic endpoints — it cannot create, modify, or delete data. For mutations use the SDKs, REST /api/v2, gRPC, or pgwire. Metric charts parse the /metrics/prometheus exposition client-side; no data leaves the browser.
