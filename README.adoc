== Quick Start

=== Docker Installation (Recommended)
[source,bash]
----
# Pull and run ProximaDB
docker pull proximadb/proximadb:latest
docker run -d -p 5678:5678 -p 5679:5679 -v proximadb_data:/data proximadb/proximadb:latest

# Verify installation
curl http://localhost:5678/health
----

=== Build from Source
[source,bash]
----
# Clone repository
git clone https://github.com/vjsingh1984/proximaDB.git
cd proximaDB

# Build release version
cargo build --release

# Run server
./target/release/proximadb-server
----

=== Python Client
[source,python]
----
from proximadb import ProximaClient

# Connect to ProximaDB
client = ProximaClient("localhost:5678")

# Create collection with optimal engine selection
collection = client.create_collection(
    name="products",
    dimension=1536,
    engine="auto"  # Automatically selects best engine
)

# Insert vectors
collection.insert(vectors=[...], metadata=[...])

# Search with natural language
results = collection.search(
    query="Show me trending products from last week",
    top_k=10
)
----

== Configuration

Basic configuration in `config/config.toml`:

[source,toml]
----
[server]
http_port = 5678
grpc_port = 5679
data_dir = "/data"

[storage]
default_engine = "auto"  # Automatic engine selection
metadata_backend = "rocksdb"

[compute]
enable_simd = true
quantization = "adaptive"

[ai]
providers = ["openai", "anthropic", "azure"]
default_model = "gpt-4"
----
