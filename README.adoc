== HOW: Getting Started

=== 1. Quick Deployment (5 minutes)

.Option A: Docker with Local Storage
[source,bash]
----
docker run -d \
  --name proximadb \
  -p 5678:5678 \
  -v proximadb_data:/data \
  proximadb/proximadb:latest
----

.Option B: Production with Cloud Storage
[source,bash]
----
docker run -d \
  --name proximadb \
  -p 5678:5678 \
  -e STORAGE_BACKEND=s3 \
  -e AWS_BUCKET=my-proximadb \
  -e AWS_REGION=us-east-1 \
  proximadb/proximadb:latest
----

=== 2. Store Your Vectors

[source,python]
----
from proximadb import ProximaDBClient

# Connect
client = ProximaDBClient("http://localhost:5678")

# Create collection
client.create_collection("products", dimension=384)

# Insert vectors with metadata
vectors = [
    {
        "id": "product_1",
        "vector": [...],  # Your embedding
        "metadata": {
            "name": "Laptop",
            "category": "Electronics",
            "price": 999.99
        }
    }
]
client.insert_vectors("products", vectors)
----

=== 3. Search and Filter

[source,python]
----
# Semantic search with metadata filtering
results = client.search(
    collection="products",
    query_vector=[...],  # Query embedding
    filter={"category": "Electronics", "price": {"$lt": 1500}},
    top_k=10
)

for result in results:
    print(f"{result.id}: {result.score}")
----

== Technical Details

[%collapsible]
====
=== Architecture

* Single-server design with cloud storage backend
* Dual storage engines (SST for OLTP, VIPER for OLAP)
* Proto-first pipeline for zero-copy operations
* Hardware acceleration with GPU/SIMD auto-detection
* 13 compression algorithms with context-aware selection

=== API & Integration

* REST API (port 5678)
* gRPC API (port 5679)
* Python SDK (official)
* Docker & Kubernetes ready
* Cloud-native storage backends
