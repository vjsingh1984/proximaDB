## Quick Start: Get Running in 5 Minutes

### One-Command Enterprise Deployment

```bash
# Step 1: Clone and deploy (2 minutes)
git clone https://github.com/proximadb/proximadb.git
cd proximadb
./scripts/enterprise_deploy.sh --env production

# Step 2: Access enterprise dashboard (1 minute)
open http://localhost:5678/dashboard

# Step 3: Start building intelligence (2 minutes)
curl -X POST http://localhost:5678/v1/collections \
  -H "Content-Type: application/json" \
  -d '{"name": "enterprise_knowledge", "dimension": 1536}'
```

### Python SDK - Production Ready

```python
import proximadb

# Enterprise client with full security
client = proximadb.Client(
    endpoint="http://localhost:5678",
    auth_method="api_key",
    api_key="your-enterprise-key"
)

# Create intelligent collection
collection = client.create_collection(
    name="business_intelligence",
    dimension=1536,
    distance_metric="cosine"
)

# Unified intelligence query
results = client.unified_search(
    collection="business_intelligence",
    query="strategic market opportunities",
    include_relationships=True,
    include_knowledge_context=True
)
```
