== ⚡ Quick Start (2 minutes)

[source,bash]
----
# Start ProximaDB
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb && docker compose up -d

# Install client
pip install proximadb-client
----

[source,python]
----
from proximadb import ProximaDBClient

# Connect and create collection
client = ProximaDBClient("http://localhost:5678")
collection = client.create_collection("ai_docs", dimension=384, engine="viper")

# Insert vectors with metadata
vectors = [
    {"id": "doc1", "vector": [0.1, 0.2, ...], "metadata": {"title": "AI Guide", "category": "tutorial"}},
    {"id": "doc2", "vector": [0.3, 0.4, ...], "metadata": {"title": "ML Basics", "category": "reference"}}
]
client.insert_vectors("ai_docs", vectors)

# Search with SQL
results = client.execute_sql("""
    SELECT id, metadata->>'title' as title, score
    FROM ai_docs
    WHERE VECTOR_SIMILARITY(vector, [0.1, 0.2, ...], 'cosine') > 0.8
    AND metadata->>'category' = 'tutorial'
    ORDER BY score DESC
    LIMIT 10
""")
----

== 🏗️ Architecture Highlights

* **🔄 Dual Storage Engines**: VIPER (columnar analytics) + SST (row-based writes)
* **⚡ Hardware Acceleration**: Automatic GPU/SIMD with intelligent fallbacks  
* **🎯 AXIS Indexing**: Adaptive HNSW/IVF/LSH/Annoy selection
* **💾 MVCC Transactions**: ACID compliance with centralized version control
* **☁️ Multi-Cloud**: S3, Azure Blob, Google Cloud Storage
* **🔍 SQL Engine**: Complete AND/OR/NOT operators with vector similarity
