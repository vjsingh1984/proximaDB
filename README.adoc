=== The Challenge with Vector Databases

**Most vector databases force you to choose**:

- Fast search *OR* fast writes (not both)
- Low latency *OR* high compression (not both)
- Simple deployment *OR* advanced features (not both)

**ProximaDB solves this** with adaptive storage engines that optimize for your specific workload.

== Quick Start (60 Seconds)

=== 1. Deploy

[source,bash]
----
# Docker (production-ready)
docker run -d -p 5678:5678 proximadb/proximadb:latest

# Or build from source (Rust 1.88+)
git clone https://github.com/vjsingh1984/proximaDB
cd proximaDB && cargo run --release
----

=== 2. Create Collection with Type-Safe Metadata

[source,bash]
----
curl -X POST http://localhost:5678/v1/collections \
  -H "Content-Type: application/json" \
  -d '{
    "name": "products",
    "dimension": 768,
    "storage_engine": "AUTO",
    "filterable_columns": [
      {"name": "price", "data_type": "FLOAT"},
      {"name": "in_stock", "data_type": "BOOLEAN"},
      {"name": "category", "data_type": "STRING"}
    ]
  }'
----

=== 3. Search with Filters (20% Faster!)

[source,bash]
----
curl -X POST http://localhost:5678/v1/collections/products/search \
  -d '{
    "query_vector": [0.1, 0.2, ..., 0.768],
    "top_k": 10,
    "filter_expression": {
      "operator": "AND",
      "expressions": [
        {"field": "price", "operator": "LESS_THAN", "value": 500},
        {"field": "in_stock", "operator": "EQUALS", "value": true}
      ]
    }
  }'
----

== Use Cases (Validated)

=== Semantic Search & RAG

**Requirements**: <5ms latency, metadata filtering (source, date, category)

**Recommendation**: SWIFT (2.50ms) or SST-LZ4 (2.98ms)

**Example**: Document retrieval with type-safe filters
```python
results = collection.search(
    query_vector=question_embedding,
    filter_expression={
        "field": "doc_type",
        "operator": "EQUALS",
        "value": "technical"
    }
)
```

---

=== E-Commerce Recommendations

**Requirements**: Price/inventory filters, product similarity

**Recommendation**: HELIX (1.43ms) if products cluster by category

**Benefit**: 5x faster than columnar alternatives

---

=== Image/Video Search

**Requirements**: High-dimensional embeddings (1536D+), spatial locality

**Recommendation**: HELIX (1.43ms)

**Why**: Hilbert curve indexing + PCA compression optimized for visual embeddings

== Getting Started

=== Installation

[source,bash]
----
# Docker (recommended)
docker pull proximadb/proximadb:latest
docker run -d -p 5678:5678 -p 5679:5679 proximadb/proximadb:latest

# From source
git clone https://github.com/vjsingh1984/proximaDB
cd proximaDB
cargo build --release
./target/release/proximadb-server
----

=== Configuration (Validated Defaults)

[source,toml]
----
[storage.sst_config]
block_size_kb = 1024    # 1MB - 34% faster than 2MB
compression = "lz4"      # 7% faster + 50% storage savings
compression_level = 3

[storage.swift]
records_per_block = 512  # Reduced from 2000 (11% faster)
compression = "none"      # Latency-focused

[compute]
simd_enabled = true      # Auto-detect AVX2/NEON
----
