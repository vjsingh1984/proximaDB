== Quick Start

image::proximadb-overview.svg[ProximaDB Architecture, width=267, align=center]

=== 60-Second Installation

**Docker with Cloud Storage** (Production Ready):
```bash
# Stateless deployment with S3/Azure/GCS backend
docker run -d \
  -p 5678:5678 -p 5679:5679 \
  -e STORAGE_BACKEND=s3 \
  -e S3_BUCKET=my-proximadb-data \
  proximadb/proximadb:latest
```

**Docker with Local Storage** (Development):
```bash
docker run -d \
  -p 5678:5678 -p 5679:5679 \
  -v proximadb_data:/data \
  proximadb/proximadb:latest
```

**From Source**:
```bash
cargo build --release
./target/release/proximadb-server --config demo/local-demo-config.toml
```

=== Python SDK Integration

```python
from proximadb import ProximaDBClient

# Connect with automatic protocol selection (REST/gRPC)
client = ProximaDBClient("http://localhost:5678")

# Create collection with engine optimization
collection = client.create_collection(
    name="product_catalog",
    dimension=384,
    storage_engine="sst",  # Real-time OLTP
    compression={"algorithm": "zstd"}
)

# Insert vectors with rich metadata
vectors = [
    {
        "id": "prod_1", 
        "vector": [...],  # Your embeddings
        "metadata": {"category": "electronics", "price": 299.99}
    }
]
client.insert_vectors("product_catalog", vectors)

# Advanced search with metadata filtering
results = client.search_vectors(
    collection_id="product_catalog",
    query_vector=[...],  # Query embedding
    filter_expression={"category": {"$eq": "electronics"}},
    top_k=10,
    include_metadata=True
)
```

== Technical Architecture

=== Core Design Principles

* **Proto-First**: VectorRecord flows natively without serialization overhead
* **Direct Memtable Access**: VectorOperationsService bypasses coordination layers
* **Dual Storage Optimization**: 
  - **SST Engine**: Row-based, write-optimized with three-stage filtering
  - **VIPER Engine**: Columnar Parquet with quantization support
* **Hardware Adaptive**: Automatic detection and usage of available acceleration

=== Supported Features

**Vector Operations**:
* ✅ 6 Index Types: HNSW, IVF, PQ, FLAT, ANNOY, LSH
* ✅ 13 Distance Metrics: Cosine, Euclidean, Dot Product, Manhattan, Hamming, etc.
* ✅ Hardware Acceleration: CUDA, ROCm, MPS, SIMD
* ✅ Metadata Filtering with SQL-style expressions

**Storage & Deployment**:
* ✅ Multi-cloud Support: S3, Azure Blob, Google Cloud Storage
* ✅ Local Filesystem with optional cloud backup
* ✅ Docker containerization with stateless design
* ✅ Spot instance compatibility with automatic failover

**Compression & Optimization**:
* ✅ 13 Compression Algorithms: ZSTD, LZ4, Snappy, Gzip, Brotli, etc.
* ✅ Context-Aware Compression: SST blocks, Vector data, Parquet columns
* ✅ Quantization: INT8, PQ8, PQ4 with dual-column storage
