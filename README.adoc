== 💡 What is ProximaDB?

ProximaDB is a **high-performance vector database** specifically engineered for AI workloads. Unlike general-purpose databases with vector extensions, every design decision optimizes for vector operations.

=== Core Innovations

image::technical-overview.svg[Technical Overview, align=center, width=900]

[cols="1,3", options="header"]
|===
| Innovation | Business Impact

| **Proto-First Architecture**
| Zero serialization overhead → 40-60% latency reduction

| **Dual Storage Engines**
| VIPER for analytics (columnar) + SST for transactions (row-based)

| **Hardware Acceleration**
| Automatic GPU/SIMD detection → 10x distance computation speedup

| **Two-Tier Compression**
| Protocol (disabled) + Collection-level (SDK) → 50-80% storage reduction

| **Two-Stage Search**
| Coarse quantized search + fine reranking → Sub-millisecond queries

| **Unified Cache Architecture**
| Centralized caching eliminates duplication → 95% cache hit rate

| **I/O Optimization**
| Smart bloom filters & compression-aware caching → 60% fewer disk reads
|===

== 🚀 How to Get Started

=== 1. Quick Deployment (60 seconds)

[source,bash]
----
# Clone and start ProximaDB
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb && docker compose up -d

# Verify deployment
curl http://localhost:5678/health
# {"status": "healthy", "version": "1.0.0"}
----

=== 2. Your First Vector Collection

[source,python]
----
from proximadb import ProximaDBClient

# Connect to ProximaDB
client = ProximaDBClient("http://localhost:5678")

# Create a collection optimized for your use case
collection = client.create_collection(
    name="products",
    dimension=1536,        # OpenAI ada-002 embeddings
    storage_engine="viper" # Columnar for analytics
)

# Insert vectors at scale
vectors = [
    {
        "id": "product_001",
        "vector": [...],  # Your embedding
        "metadata": {
            "name": "Premium Headphones",
            "category": "Electronics",
            "price": 299.99
        }
    }
]
client.insert_vectors("products", vectors)

# Semantic search with metadata filtering
results = client.search_vectors(
    collection_id="products",
    query_vector=[...],  # Search embedding
    metadata_filter={"category": "Electronics"},
    top_k=10
)
----

=== 3. Benchmark Your Setup

[source,bash]
----
# Rust performance benchmarks
cargo bench distance_benchmark    # Distance computation
cargo bench simd_distance_bench   # Hardware acceleration

# Python SDK benchmarks
cd demo/benchmarks
python performance_suite.py --suite quick --vectors 1000

# Expected Results:
# gRPC Insert: 17,000+ vectors/sec
# gRPC Search: <1ms p99 latency  
# Storage: 50-80% compression ratio (collection-level)
# Protocol: Compression disabled for pure performance
----

=== 3. Production Configuration

[source,bash]
----
# Build from source for production
cargo build --release --bin proximadb-server

# Configure logging for production
export RUST_LOG=info  # Options: error, warn, info, debug, trace

# Run with production config
./target/release/proximadb-server --config demo/docker-config.toml
----

=== Technical Highlights

* **13 Distance Metrics**: Cosine, Euclidean, Dot Product, Manhattan, Hamming, and more
