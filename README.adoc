=== 🔧 Local Development Build

[source,bash]

# Build release binary

[source,python]
----
from proximadb import ProximaDBClient

# Connect and create collection
client = ProximaDBClient("http://localhost:5678")
collection = client.create_collection("ai_docs", dimension=384, engine="viper")

# Insert vectors with metadata
vectors = [
    {"id": "doc1", "vector": [0.1, 0.2, ...], "metadata": {"title": "AI Guide", "category": "tutorial"}},
    {"id": "doc2", "vector": [0.3, 0.4, ...], "metadata": {"title": "ML Basics", "category": "reference"}}
]
client.insert_vectors("ai_docs", vectors)

# Search with SQL
# Semantic search with SQL + Vector similarity
results = client.execute_sql("""
    SELECT id, metadata->>'title', VECTOR_SIMILARITY(vector, [0.1, 0.2, ...], 'cosine') as score
    FROM ai_docs
    WHERE metadata->>'category' = 'tutorial'
    ORDER BY score DESC LIMIT 10
""")
print(f"Found {len(results['rows'])} matches")
----

* **SST** (Row-based): Write-optimized, LSM-Tree, 10x faster ingestion

=== SQL + Vector Queries

[source,sql]
----
SELECT id, metadata->>'title', VECTOR_SIMILARITY(vector, [0.1, 0.2], 'cosine') as score
FROM documents
WHERE metadata->>'category' = 'research' AND score > 0.8
ORDER BY score DESC LIMIT 10;
----

== 🐳 Docker Build Process

ProximaDB uses **multi-stage Docker builds** that compile optimized release binaries during container creation:

=== 📦 Build Stages

**Stage 1: Rust Build Environment**
- Uses `rust:1.82-slim` with all build dependencies
- Compiles `proximadb-server` binary with release optimizations (`-C opt-level=3`)
- Includes dependency caching for faster subsequent builds
- **Build time**: ~5-10 minutes (first build), ~1-2 minutes (cached)

**Stage 2: Runtime Environment**  
- Uses `debian:bookworm-slim` for minimal runtime footprint
- Copies **only the release binary** from build stage (no debug symbols)
- Final image size: ~50MB (compared to ~800MB if debug included)
- Includes health checks and non-root user security

=== ⚙️ Binary Configuration

**Release Binary Features:**
- Optimized for production with `-C opt-level=3`
- SIMD auto-detection and hardware acceleration
- All storage engines (VIPER + SST) included
- gRPC and REST APIs enabled
- Multi-cloud storage support

**No Pre-built Binaries**: Docker builds compile from source to ensure:
- Architecture-specific optimizations (x86_64, ARM64)
- SIMD instruction set matching (AVX-512, AVX2, NEON)
- Security: Fresh builds with latest dependencies
- Reproducible builds with locked dependency versions
