== 🎯 Why ProximaDB?

Modern AI applications need vector databases that don't compromise on performance, scalability, or operational simplicity. ProximaDB delivers:

**⚡ 6.10x Performance Breakthrough**:: Storage-aware search adapts to data location (317ms → 52ms latency)
**🧠 Unified Architecture**:: Single memtable system eliminates 40% code duplication  
**☁️ Multi-Cloud Freedom**:: URL-based abstraction enables zero-downtime cloud migration
**🤖 ML-Driven Storage**:: K-means++ clustering provides 3-5x storage efficiency

== 🚀 What is ProximaDB?

Production-ready, cloud-native vector database built in Rust with three core innovations:

image::core-classes.png[Core Classes Architecture,700,align=center]

**Unified Memtable System**:: Single interface with pluggable backends and behavior wrappers
**Storage-Aware Search**:: Automatic engine selection with three-tier aggregation  
**Dual Storage Strategy**:: VIPER (Parquet+ML) and LSM (SSTable+bloom filters)

== 🛠️ Getting Started

=== Quick Start (2 Minutes)

[source,bash]
----
# Run with Docker
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb/demo && docker compose up -d

# Or build from source
cargo run --bin proximadb-server
----

=== Python Example

[source,python]
----
from proximadb import connect_rest

client = connect_rest("http://localhost:5678")
collection = client.create_collection("docs", dimension=768)
client.insert_vectors("docs", embeddings, metadata=[{"type": "doc"}])
results = client.search("docs", query_vector, k=10)
----
