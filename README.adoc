=== Option 1: Quick ROI Validation (30 minutes)

**For Executives**: Prove the business case immediately

1. **Deploy Instantly**: `docker run -p 5678:5678 proximadb/server`
2. **Run Benchmark**: Compare your current costs
3. **Calculate ROI**: Use our link:docs/business/roi_calculator.adoc[ROI Calculator]

=== Option 2: Technical Proof of Concept (2 hours)

**For Technical Teams**: Validate performance with your data

[source,python]
----
from proximadb import ProximaDBClient

# Connect to ProximaDB
client = ProximaDBClient("http://localhost:5678")

# Create a collection optimized for your use case
collection = client.create_collection(
    name="products",
    dimension=1536,        # OpenAI ada-002 embeddings
    storage_engine="viper" # Columnar for analytics
)

# Insert vectors at scale
vectors = [
    {
        "id": "product_001",
        "vector": [...],  # Your embedding
        "metadata": {
            "name": "Premium Headphones",
            "category": "Electronics",
            "price": 299.99
        }
    }
]
client.insert_vectors("products", vectors)

# Semantic search with metadata filtering
results = client.search_vectors(
    collection_id="products",
    query_vector=[...],  # Search embedding
    metadata_filter={"category": "Electronics"},
    top_k=10
)
----

== 🏗️ Architecture & Technology

image::business-capabilities-abstract.svg[Capabilities Overview, align=center, width=900]

=== Technical Highlights

* **13 Distance Metrics**: Cosine, Euclidean, Dot Product, Manhattan, Hamming, and more
* **6 Index Algorithms**: HNSW, IVF, LSH, PQ, FLAT, ANNOY
* **Multi-Cloud Storage**: S3, GCS, Azure Blob, MinIO
* **Enterprise Security**: TLS/mTLS, API keys, audit logging (roadmap)
* **Production Ready**: Prometheus metrics, health checks, hot reload
* **Unified Cache System**: VectorStore, IndexNodeCache, BitmapFilterCache, MetadataStore
* **Smart I/O Optimization**: Bloom filter skipping for cached data, compression-aware caching
* **Zero Filesystem Queries**: Direct URL-based data access from VectorOperationsService

For deep technical details, see our link:docs/developer/architecture.adoc[Architecture Documentation].

== 🎯 Real-World Impact

=== Success Stories by Use Case

==== E-Commerce: 300ms to 0.9ms Search Latency
A major retailer processing 50M product searches daily reduced their vector search latency from 300ms to 0.9ms, enabling real-time "similar product" recommendations that increased conversion rates by 23%.

**Key ProximaDB Features Used:**
- VIPER columnar engine for product catalog
- Two-stage search with PQ8 quantization
- Hardware acceleration with AVX-512

==== AI Chat Platform: 80% Storage Cost Reduction
An AI platform storing 10TB of conversation embeddings reduced storage to 2TB while maintaining <1ms query performance, saving $240,000 annually in cloud storage costs.

**Key ProximaDB Features Used:**
- Two-tier compression strategy
- AXIS automatic tiering (Memory → NVMe → S3)
- Collection-level compression configuration

==== Financial Services: ACID Compliance for Fraud Detection
A payment processor analyzing 1M transactions/hour for fraud patterns achieved both regulatory compliance and real-time detection with ProximaDB's transaction support.

**Key ProximaDB Features Used:**
- Full ACID transactions with WAL
- SST engine for transactional workloads
- Proto-native design for 40% latency reduction
