== HOW: Getting Started

=== 1. Quick Deployment (5 minutes)

.Build from Source
[source,bash]
----
# Clone and build
git clone https://github.com/proximadb/proximadb.git
cd proximadb
cargo build --release --bin proximadb-server

# Run with configuration
./target/release/proximadb-server --config config.toml
----

.Docker Deployment
[source,bash]
----
docker run -d \
  --name proximadb \
  -p 5678:5678 -p 5679:5679 \
  -v proximadb_data:/data \
  -e STORAGE_ENGINE=helix \
  -e ENABLE_GPU=true \
  proximadb/proximadb:latest
----

.Production Configuration
[source,toml]
----
[server]
rest_port = 5678
grpc_port = 5679

[storage]
default_engine = "helix"  # Use HELIX for similarity clustering
data_dir = "/data"

[engines.helix]
parallel_search_enabled = true
parallel_search_threshold = 3
max_search_threads = 4

[compute]
enable_simd = true
enable_gpu = true
----

=== 2. Store Your Vectors

[source,python]
----
from proximadb import ProximaDBClient
import numpy as np

# Connect to ProximaDB
client = ProximaDBClient("http://localhost:5678")

# Create collection with specific engine
client.create_collection("products", dimension=384)

# Insert vectors with metadata
vectors = [
    {
        "id": "product_1",
        "vector": [...],  # Your embedding
        "metadata": {
            "name": "Laptop",
            "category": "Electronics",
            "price": 999.99
        }
    }
]
client.insert_vectors("products", vectors)
----

=== 3. Search and Filter

[source,python]
----
# Semantic search with metadata filtering
results = client.search(
    collection="products",
    query_vector=[...],  # Query embedding
    filter={
        "category": {"$eq": "Electronics"},
        "price": {"$between": [500, 1500]},
        "tags": {"$contains": "featured"}
    },
    top_k=10
)

for result in results:
    print(f"{result.id}: {result.score} - {result.metadata}")
----

== 🛠️ Development

=== Building from Source

[source,bash]
----
# Clone repository
git clone https://github.com/vjsingh1984/proximadb
cd proximadb

# Build with optimizations
cargo build --release --all-features

# Run tests (2700+ tests)
cargo test --all --release

# Run benchmarks
cargo bench optimization_benchmarks

# Format and lint
cargo fmt && cargo clippy
----

=== Running the Server

[source,bash]
----
# Run with default configuration
./target/release/proximadb-server

# Run with custom config
./target/release/proximadb-server --config config.toml

# Run with environment variables
STORAGE_ENGINE=helix \
ENABLE_GPU=true \
./target/release/proximadb-server
----

=== Python Client Development

[source,bash]
----
cd clients/python

# Install development dependencies
pip install -e .[dev]

# Run tests
PYTHONPATH=src python -m pytest tests/ -v

# Build package
python -m build
----
