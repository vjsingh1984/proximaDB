== Quick Start

=== Installation

[source,bash]
----
# Docker (Recommended)
docker run -d -p 5678:5678 -p 5679:5679 proximadb/proximadb:latest

# From Source
git clone https://github.com/vjsingh1984/proximaDB
cd proximaDB
cargo run --release --bin proximadb-server
----

=== Basic Usage

[source,bash]
----
# Create collection
curl -X POST http://localhost:5678/v1/collections \
  -H "Content-Type: application/json" \
  -d '{"name": "documents", "dimension": 1536}'

# Insert vectors
curl -X POST http://localhost:5678/v1/collections/documents/vectors \
  -H "Content-Type: application/json" \
  -d '{"vectors": [{"id": "doc1", "values": [0.1, 0.2, ...]}]}'

# Search vectors
curl -X POST http://localhost:5678/v1/collections/documents/search \
  -H "Content-Type: application/json" \
  -d '{"query_vector": [0.1, 0.2, ...], "top_k": 10}'
----

== Core Features

=== 6 Auto-Optimized Storage Engines

[cols="2,3,2", options="header"]
|===
|Engine |Best For |Key Features

|**SST**
|Real-time queries, OLTP
|High insert throughput

|**VIPER**
|Analytics, batch operations
|3x compression, columnar

|**NOVA**
|Mixed workloads
|Progressive search

|**SWIFT**
|Low-latency operations
|FastLanes encoding

|**RAPTOR**
|Dynamic workloads
|Adaptive optimization

|**HELIX**
|Spatial/graph data
|Hilbert curve clustering
|===

== Development

=== Building from Source

[source,bash]
----
# Prerequisites
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Build and run
git clone https://github.com/vjsingh1984/proximaDB
cd proximaDB
cargo run --release --bin proximadb-server

# Run tests and benchmarks
cargo test
cargo bench --bench bench_01_core_distance
----

=== Configuration

[source,toml]
----
# config/config.toml
[server]
http_port = 5678
grpc_port = 5679

[storage]
data_dir = "./data"
engine_selection = "auto"

[performance]
enable_simd = true
max_batch_size = 10000
----

== Production Deployment

=== Docker Compose

[source,yaml]
----
version: '3.8'
services:
  proximadb:
    image: proximadb/proximadb:latest
    ports:
      - "5678:5678"
      - "5679:5679"
    volumes:
      - proximadb_data:/data
      - ./config:/app/config
    environment:
      - RUST_LOG=info

volumes:
  proximadb_data:
----

=== Kubernetes

[source,yaml]
----
apiVersion: apps/v1
kind: Deployment
metadata:
  name: proximadb
spec:
  replicas: 3
  selector:
    matchLabels:
      app: proximadb
  template:
    spec:
      containers:
      - name: proximadb
        image: proximadb/proximadb:latest
        ports:
        - containerPort: 5678
        - containerPort: 5679
        resources:
          requests:
            memory: "2Gi"
            cpu: "1"
          limits:
            memory: "4Gi"
            cpu: "2"
----
