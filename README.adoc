== ⚡ Quick Start

=== 🐳 Docker (Recommended)
[source,bash]
----
# Clone and start complete stack
git clone https://github.com/vjsingh1984/proximadb.git
cd proximadb && docker compose up -d

# Access services:
# http://localhost:8080 - Web UI with demos
# http://localhost:5678 - REST API
# http://localhost:5679 - gRPC endpoint

# Install Python client
pip install proximadb-client
----

=== 🔧 Development Build
[source,bash]
----
# Build from source (requires Rust 1.70+)
cargo build --release --bin proximadb-server

# Run server
./target/release/proximadb-server --config demo/local-demo-config.toml

# Test installation
cargo test --all  # 1,460+ tests, 100% pass rate
----

== 🚀 Key Features

=== Performance
* **17K+ vectors/sec**: Bulk insertion via gRPC
* **Sub-millisecond search**: 0.9ms with metadata filtering  
* **1,770 QPS**: Concurrent search throughput
* **13 distance metrics**: All with SIMD/GPU acceleration
* **6 indexing algorithms**: HNSW, IVF, PQ, FLAT, ANNOY, LSH

=== Storage & Search
* **Dual storage engines**: VIPER (columnar) + SST (row-based)
* **SQL integration**: Native vector similarity in SQL queries
* **Multi-cloud support**: S3, GCS, Azure Blob Storage
* **Hardware acceleration**: Automatic GPU/SIMD detection
* **Compression**: 50-80% bandwidth reduction

=== Enterprise Ready
* **Proto-first architecture**: Zero double serialization
* **ACID transactions**: Multi-collection consistency
* **Real-time indexing**: Updates without downtime
* **Monitoring**: Prometheus, OpenTelemetry, custom metrics
* **Scalability**: Horizontal scaling with intelligent sharding

== 🎯 Quick Examples

=== Python SDK
[source,python]
----
from proximadb import ProximaDBClient

# Connect to ProximaDB
client = ProximaDBClient("http://localhost:5678")

# Create collection
collection = client.create_collection("my_vectors", dimension=384)

# Insert vectors
vectors = [
    {"id": "doc1", "vector": [0.1, 0.2, ...], "metadata": {"title": "Document 1"}},
    {"id": "doc2", "vector": [0.3, 0.4, ...], "metadata": {"title": "Document 2"}}
]
client.insert_vectors("my_vectors", vectors)

# Search
results = client.search_vectors("my_vectors", query_vector=[0.1, 0.2, ...], top_k=10)
----

=== SQL Queries
[source,sql]
----
-- Vector similarity search with metadata filtering
SELECT id, metadata->>'title', 
       VECTOR_SIMILARITY(vector, [0.1, 0.2, ...], 'cosine') as similarity
FROM my_vectors 
WHERE metadata->>'category' = 'technology'
ORDER BY similarity DESC 
LIMIT 10;
----
