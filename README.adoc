== Get Started in 60 Seconds

=== Try ProximaDB Now

[source,bash]
----
# Quick start with Docker
docker run -d -p 5678:5678 -p 5679:5679 proximadb/proximadb:latest

# Test the API
curl -X POST http://localhost:5678/v1/collections \
  -H "Content-Type: application/json" \
  -d '{"name": "my_vectors", "dimension": 1536}'

# You're ready to build! 🚀
----

1. ProximaDB automatically selects the best storage engine for your data

4. Start querying immediately - no configuration needed

**The Secret: Intelligent Engine Selection**

ProximaDB doesn't just store your vectors - it analyzes your access patterns and automatically chooses the best storage engine:

- **Heavy Writes?** → SST engine optimizes for fast ingestion
- **Analytics Queries?** → VIPER engine uses columnar compression
- **Mixed Workload?** → NOVA engine balances read/write performance
- **Need Ultra-Low Latency?** → SWIFT engine maximizes cache efficiency
- **Unpredictable Patterns?** → RAPTOR engine adapts in real-time
- **Spatial Data?** → HELIX engine optimizes for locality

## Production-Ready from Day One

=== Simple Python Integration

[source,python]
----
from proximadb import ProximaDB

# Connect to ProximaDB
client = ProximaDB(url="http://localhost:5678")

# Create collection - ProximaDB picks the best engine
collection = client.create_collection(
    name="product_embeddings",
    dimension=1536,
    engine="auto"  # Let ProximaDB decide
)

# Insert with metadata
collection.insert([
    {
        "id": "product_123",
        "vector": embedding_model.encode("wireless headphones"),
        "metadata": {
            "category": "electronics",
            "price": 99.99,
            "in_stock": True
        }
    }
])

# Search with business logic
results = collection.search(
    query_vector=embedding_model.encode("bluetooth headphones"),
    top_k=10,
    filter={"category": "electronics", "in_stock": True}
)

# Results are ready immediately!
for result in results:
    print(f"Product: {result.id}, Score: {result.score}")
----
