== Quick Start

image::proximadb-overview.svg[ProximaDB Architecture, width=267, align=center]

=== 60-Second Installation

**Docker** (Recommended):
```bash
docker run -d \
  -p 5678:5678 -p 5679:5679 \
  -v proximadb_data:/data \
  proximadb/proximadb:latest
```

**From Source**:
```bash
cargo build --release
./target/release/proximadb-server --config demo/config.toml
```

=== Python SDK

```python
from proximadb import ProximaDBClient

# Connect and create collection
client = ProximaDBClient("http://localhost:5678")
client.create_collection("products_catalog", dimension=384)

# Insert vectors with metadata
vectors = [
    {"id": "prod_1", "vector": [...], "metadata": {"category": "electronics"}},
    {"id": "prod_2", "vector": [...], "metadata": {"category": "books"}}
]
client.insert_vectors("products_catalog", vectors)

# Search with filters
results = client.search_vectors(
    "products_catalog", 
    query_vector=[...],
    metadata_filter={"category": "electronics"},
    top_k=10
)
```

== Architecture Highlights

* **Zero-Copy Operations**: Vectors flow without conversion overhead
* **Dual Storage Engines**: SST (OLTP) + VIPER (analytics) optimized for different workloads
* **Hardware Acceleration**: Automatic GPU/SIMD detection and usage
* **Unified Compression**: 13 algorithms with context-aware optimization
* **Hierarchical SST**: 85% reduction in cloud storage costs
