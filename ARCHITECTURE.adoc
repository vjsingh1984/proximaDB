== Data Flow

=== Vector Ingestion Data Flow

[source,mermaid]
----
sequenceDiagram
    participant Client
    participant API
    participant ServiceLayer
    participant WAL
    participant Memtable
    participant StorageEngine

    Client->>API: Insert Vector(s)
    API->>ServiceLayer: Call VectorOperationsService
    ServiceLayer->>WAL: Write to WAL (durability)
    WAL->>Memtable: Append to Memtable (in-memory)
    Memtable->>StorageEngine: Flush (periodically/on-threshold)
    StorageEngine->>StorageEngine: Write to SSTable/Parquet File
    StorageEngine-->>Memtable: Clear flushed data
    ServiceLayer-->>API: Acknowledge
    API-->>Client: Success Response
----

=== Vector Search Data Flow

[source,mermaid]
----
sequenceDiagram
    participant Client
    participant API
    participant ServiceLayer
    participant QueryOptimizer
    participant StorageEngine
    participant Indexes
    participant Cache

    Client->>API: Search Vector(s)
    API->>ServiceLayer: Call VectorOperationsService
    ServiceLayer->>QueryOptimizer: Optimize Query Plan
    QueryOptimizer->>Cache: Check Cache (e.g., Query Cache, Metadata Cache)
    Cache-->>QueryOptimizer: Cached Results / Miss

    alt Cache Miss / No Cache
        QueryOptimizer->>Indexes: Query Indexes (e.g., HNSW, IVF)
        Indexes-->>QueryOptimizer: Candidate Vectors
        QueryOptimizer->>StorageEngine: Fetch Data (e.g., SSTables, Parquet)
        StorageEngine-->>QueryOptimizer: Full Vectors / Metadata
    end

    QueryOptimizer->>ServiceLayer: Processed Results
    ServiceLayer-->>API: Return Search Results
    API-->>Client: Search Results
----
