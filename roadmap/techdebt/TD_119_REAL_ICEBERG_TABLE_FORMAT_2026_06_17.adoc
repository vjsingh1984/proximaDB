= TD-119 Promote v1 Key-List Manifest to Real Iceberg Snapshots
:toc:
:toclevels: 3
:sectnums:

Status: Open / proposed +
Date: 2026-06-17 +
Owner: Storage, catalog

== Context

The design doc `docs/12-design/PROXIMADB_AS_LAKEHOUSE_NATIVE_PG_ENGINE_2026_06_17.md` §3.4/6 and §9-P6
calls for real Iceberg snapshots so external engines can consume ProximaDB tables and so branching
(TD-117) has a snapshot-ref substrate (Iceberg `refs` map). The current v1 manifest is an opaque
key-list, which keeps the "Snowflake/Trino interop" claim FALSE.

== Current State (grounded)

* v1 manifest = newline-delimited list of object keys
  (`crates/storage/proximadb-iceberg-engine/src/lib.rs:99`) committed under CAS as `v{N}.manifest`.
  No `metadata.json`, snapshot layer, manifest list, `refs` map, or column statistics.
* Iceberg REST service (`src/catalog/iceberg_rest_service.rs`) returns **stub** snapshot structures.
* `DrPathBuilder::snapshots_subprefix()` is reserved but unused for a real snapshot layer.

== Target Design

Emit a real Iceberg `metadata.json` + manifest-list Avro alongside each `v{N}.manifest` commit, as a
**derived index** (the v1 key-list stays the low-level store, backward compatible). Populate column
stats from PAX `BlockStats`. Wire the REST service to serve the real metadata.

== Deliverables

1. `IcebergSnapshot` / `SnapshotSummary` types + a `metadata.json` writer (snapshots list,
   `current-snapshot-id`, `refs`, schema, parent-snapshot-id) under
   `DrPathBuilder::snapshots_subprefix()`.
2. A manifest-list Avro per snapshot pointing at the existing key-list.
3. Populate column stats from `BlockStats` (PAX) into manifest entries.
4. Wire `iceberg_rest_service.rs` `/v1/{ns}/{table}` + `/snapshots` to read the real `metadata.json`.
5. (Design sub-task) Evaluate the DuckLake model — move the manifest/branch registry into a
   transactional catalog DB if S3 metadata ops dominate at branch scale.

== Acceptance

* PyIceberg/Spark reads a ProximaDB table including snapshot history.
* The CAPABILITY_MATRIX interop claim can be evidenced (no longer FALSE).

== Dependencies & Sequencing

Independent to start; **enables TD-117** (manifest-version refs).
